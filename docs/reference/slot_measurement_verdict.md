# 插槽识别算法可用性判定（2026-11-26，逐项证据）

> 判据分两类：**重复性**（precision，同条件多次测的一致性）与
> **准确性**（accuracy，与独立真值的一致程度）。两者证据链不同，不能互相替代。

## 一、重复性 —— **可用（证据充分）**

| 指标 | 实测 | 判据 | 结论 |
|---|---|---|---|
| 组间平移极差（3 组） | **0.07 mm** | ≤1.0 mm | ✅ 优于判据 14 倍 |
| 组间姿态极差 | **0.018°** | ≤0.5° | ✅ 优于判据 28 倍 |
| 覆盖率 | **0.994** | ≥0.95 | ✅ |
| 精配准 fitness | **0.993 / 0.994 / 0.994** | ≥0.5 | ✅ |
| 翻转歧义组 | **0** | =0 | ✅ |
| 退化组剔除 | **0** | — | ✅ |
| 离群组 | **无** | — | ✅ |
| 跨会话（11-25 → 11-26） | 中心差 3.4 mm | ≤10 mm | ✅ |

**结论：重复性完全满足插入所需（间隙 2 mm，要求远低于 0.5 mm）。**

## 二、准确性 —— **大概率可用，但缺一项独立验证**

| 检查 | 内容 | 结果 |
|---|---|---|
| V1 顶面高度自洽 | 夹具模型原点在顶面（z_max=0），测量 z 应等于槽顶高度 | 0.4427 vs 11-04 手验 0.4444 → **差 1.7 mm** ✅ |
| V2 模板与 CAD 同坐标系 | 我方碰撞网格 z_max = 0.000000；与 RVS 模板同框 | ✅ 成立 |
| V3 与手摆位姿偏差分布 | 10.3 mm 几乎全在 x，y/z 仅 1.7/1.8 mm | ✅ **单轴系统偏差**，不是随机误差 |
| V4 物理机制解释 | 手摆是在"张紧式抓取撑偏工件"之后记录的 → 自带 10 mm 偏差 | ✅ 与 V3 方向一致（+x） |
| V5 所有者独立目视 | "插入位需往插槽方向(+x)移 10 mm 左右才不紧绷" | ✅ 方向一致、量级一致（估算 ±5 mm） |
| V6 +x = 插槽方向 | 三条独立证据（位置/工具轴/夹具范围） | ✅ 一致 |

**支持"测量更准"的证据链（5 条独立来源相互印证）**：
1. 测量内部一致性 0.07 mm；
2. 精配准 fitness 0.993（点云与模型高度贴合）；
3. 与 11-04 手验的槽顶高度只差 1.7 mm；
4. 与手摆的偏差是**单轴系统性的**，且方向与"撑偏"物理机制完全一致；
5. 所有者独立目视判定方向与量级一致。

**⚠ 仍缺的独立验证（明天 1 分钟可补）**：
把机械臂分别开到两个候选插入位，**目视夹爪中心是否正对工件**：
- A = 测量推导 **1.1805**（含 10 mm 工具 x 修正）或 **1.1728**（不含）
- B = 手摆真值 **1.1625**

哪一个正对工件，准确性即从"大概率"变成"已确认"。

## 三、结论

```text
重复性：✅ 可用（0.07 mm / 0.018°，远优于 1 mm / 0.5° 判据）
准确性：⚠ 大概率可用（5 条独立证据一致），待明天一项目视验证转为"已确认"
当前风险点不在算法，而在**抓取**：张紧式抓取会把工件撑偏 ~10 mm，
        使插入时两侧余量不对称（手册第 83 条）。位姿算法再准也救不了这个问题。
```
