## 1. 六条工艺经验的力控映射

| # | 工艺经验（第 23 条） | 力控观测量 | 实验判据 |
|---|---|---|---|
| ① | 初始阶段绕 TCP **Y 轴小幅转动**，获得较宽松区域 | `M_y`（绕工具 y 的力矩）+ `F_x` | 转动过程中 `|M_y|` 应保持单调可控；若 `M_y` 突增说明远端顶壁 |
| ② | **随深度增加可转空间减小**，末段保留约 **1.5°** | 允许转角 `θ_max(z)` 随深度递减 | 用"能转多少度"作深度函数基线：直插 vs 边转边插各测一组 |
| ③ | Y 轴两端间隙**左右各约 2 mm** | `F_y` 的符号与幅值 | `|F_y|` 超过"间隙耗尽"对应反力即判贴壁；左右不平衡 = `F_y` 偏置 |
| ④ | **必须边转边插**，直插空间越来越小直至插不动 | `F_z` 随深度增长速率 | 直插：`F_z` 指数上升→堵转；边转：`F_z` 平台化 |
| ⑤ | 左右间隙不平衡会让**转 10° 的阻力大很多** | `M_x` | 转平段 `|M_x|` 与左右余量差的相关性 |
| ⑥ | 到底后**沿 Y 横移 1 mm/步、±2 mm** 放大间隙 | 横移时的 `F_y` | 每步后 `F_y` 应下降；若上升说明横移方向压壁 |

## 2. 三个必须由力控回答的问题（也正是今天的失败点）

```text
Q1 直插为什么必然失败？
   → 第 23 条②④：可转空间随深度递减。需要实验给出 θ_max(z) 曲线，
     并证明"边转边插"能让 F_z 保持平台（而不是指数上升）。

Q2 纯视觉/纯位置的误差余量是多少？
   → 间隙 2 mm、插入深度 444 mm；0.5° 角度误差在 444 mm 处 ≈ 3.9 mm > 2 mm
     → 结论先验成立：纯视觉必然插入失败（今天两次手摆已证实"只能转正、插不到底"）。
     力控实验要给出"角度误差多大时导纳仍能救回来"的边界。

Q3 力控的介入阈值怎么定？
   → 用第 23 条③的"左右各 2 mm"换算：F_y 阈值 = 间隙耗尽的接触刚度 × 2 mm。
     接触刚度需要单独标定（薄壁 + 楔形，参考手册第 23 条⑥的横移试验）。
```

## 3. 实验设计（对应纲要 5.6 的三档对照）

```text
A 纯位置（基线）：预插入位 → 插入位，直插 + 一次 10° 转平
   预期：F_z 指数上升 → 堵转/保护停机（今天已复现两次）

B 视觉 + 定参数导纳：
   导纳律 M ẍ + B ẋ = F_ext − F_d，插入轴 K=0
   切片节拍由 ft_latency_probe.py 实测决定（10 Hz 或更慢）
   预期：能把角度误差纠正到 ≤0.3°，但需要给"转多少度"的固定策略

C 视觉 + 变阻尼 RL：
   冻结 M/K，策略只输出阻尼缩放 B_t（上下界钳位）
   状态 = [F, M, 深度, 上一步 B, 视觉置信度]
   预期：在 B 档失败的偏置工况（±1.5 mm / ±1°）上成功率提升

共同记录：F_z 峰值、|F_y|、|M_x|、到底深度、分段用时、失败模式（按第 23 条 ①–⑥ 归因）
```

## 4. 与"逐点录制（背答案）"方案的关系

```text
逐点录制 = A 档的极端版本：把 400+ mm 行程拆成 N 个手摆关键点，按顺序走。
· 优点：今天就能做，可作为"纯位置能做到什么程度"的上界证据；
· 缺点：泛化性差（工件/桌子一动就废），且每个点位都是人工示教，不构成方法；
· 用法：只作基线 A 的一部分，**不作为论文主线**。
```
