# CW6SUARC_阻抗控制奠基

## 1. 元数据
Zotero itemKey: CW6SUARC / Impedance Control: An Approach to Manipulation: Part I—Theory / 期刊（ASME J. Dynamic Systems, Measurement, and Control, Vol.107, March 1985）/ 1985 / MIT / PDF 7 页，印刷页码 Vol.107 pp.1–7

## 2. 一句话结论与相关性
- 一句话：用键合图因果性论证"环境含惯性/运动学约束时必为导纳，操作臂必须表现为阻抗"，并给出虚拟轨迹与广义诺顿等效网络，证明非线性阻抗分量可按叠加合成——这是阻抗控制的理论奠基文 [原文证据] pp.1–7
- 相关性分类：**方法迁移（理论依据）**——供纲要 5.5 节"变阻尼 RL vs 位移残差 RL"决策的理论支点：决定动作空间该在"力-运动关系"一侧还是"位置命令"一侧。
- 影响本课题的具体决定：**柔顺参数**——解释为什么"只有 position 接口 + 六维力反馈"（我们的平台）在理论上属于"导纳型/先看力再改位置"的那一侧，并给出它与阻抗型的边界条件。

## 3. 对象与任务
- 无具体对象/尺寸/精度（纯理论文，Part I）；应用场景指向喷漆/焊接（可视为孤立系统）与钻孔/磨削等动力学交互任务 [原文证据] p.1
- 传感配置：仅假设层级控制结构（上层规划者 + 下层实时控制器），不限定传感器 [原文证据] pp.1–2

## 4. 方法与机制链
`上层命令 {c} → 实时控制器（软件）→ 执行器/结构/传感器（硬件）→ 环境机械交互端口`
- 核心因果论证：一个自由度上不能同时强加力与运动；环境（质量、受约束惯性体）在因果上只能描述为**导纳**（输入力、输出运动），故操作臂相对环境必须呈现**阻抗**（输入运动、输出力）[原文证据] pp.3–4
- 对 Nevins/Whitney "命令位置、看反馈力"路线的定性：那等于让操作臂当导纳，隐含"环境是阻抗"的假设，与惯性环境不符——这是"位置型阻抗（admittance）"理论局限的原始出处 [原文证据] p.4
- 关键公式组（诺顿等效推广）[原文证据] p.5：
  F = S(X):{c}（静态力-位移关系，式 8）；X₀ = X₀:{c}（虚拟位置，式 9）；
  V₀ = V₀:{c}（虚拟源，式 10）；f = V₀ − V（结方程，式 11）；
  dz/dt = Zs(z,f):{c}（式 12）；F = Z₀(z,f):{c}（式 13）
  完整系统方程 (16)–(19) 将阻抗型操作臂与导纳型环境耦合。
- 叠加性质：多个（可非线性）阻抗分量作用于同一导纳时直接相加——任务分解（沿不同方向的刚度/阻尼要求）可独立设计后叠加 [原文证据] p.6
- 最低必要控制器结构：图 5 给出 nodic 阻抗 Z₀ + non-nodic 阻抗 Z_n 的键合图最小结构（non-nodic 分量对应"有限工作空间"这类依赖绝对位置的约束）；作者声明本文只处理 nodic 分量 [原文证据] pp.4–5
- 与纯力控/柔顺路线的界限：纯力控网络（图 4(a)）缺"弹簧式力-位静态关系"，无法稳定定位一个质量；"命令位置、看反馈力"等价于让操作臂做导纳（admittance control）——这是本文对那一侧路线的原始批评 [原文证据] p.4

## 5. 证据强度
- **无实验**：纯理论文（Part I；Part II/III 为实施与应用）。无真机/仿真、无试次、无成功率、无统计——引用时只能作理论依据，不能作实验证据。
- 论证链：由物理公设（"控制器不能使系统表现得不像物理系统"）+ 因果约束推导，属形式化论证而非实证 [原文证据] pp.2–4
- 数值缺失：全文无任何刚度/阻尼/惯性数值示例（唯一数值是键合图示意与方程编号）——与后续实施类论文（如本批 VM5LEYKR）的 M/B/K 参数互为理论-实施对照 [原文证据] pp.1–7

## 6. 最脆弱的 1–3 个假设
1. "环境总能描述为导纳（含惯性或运动学约束）"——方法必需；[分析推断] 对"固定在地基上的刚性夹具"这类环境，环境侧近似刚性阻抗，此时操作臂反而应为导纳——**范围内反例**（Hogan 本人承认纯力控制对应图 4(a) 的不完备性，p.4）。
2. "静态力-位移关系在零力处定义唯一平衡位置（nodicity 条件）"——作者明说（为保持叠加性质）[原文证据] p.5 → **范围外迁移限制**（多接触/摩擦楔紧时零力位置不唯一）。
3. 层级开环（上层运动期间不用传感闭环调制命令）——作者明说的结构假设 [原文证据] p.2；与我们"观测→规划→执行"的循环结构不同 → **尚未测试**。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **5.5 节理论引用**：用"力-运动因果关系"论证两种 RL 动作空间的理论归属——变阻尼（含刚度/阻尼输出）是阻抗侧动作；位移残差是导纳侧动作。给出判断句：凡上层动作直接是位置/位移命令、由力反馈修正者，皆属导纳型，其稳定性依赖环境刚度上界。
2. **叠加原则落地**：把插入任务按方向分解为"沿槽法向低刚度（柔顺）、沿插入方向高刚度（位置跟踪）"两组阻抗要求，分别设计后叠加——这正是我们 tight 相位 0.005 m/s 之外还应加"法向刚度限制"的理论依据。
3. **虚拟轨迹概念**：X₀ 不必在可达工作空间内、也不必被到达（p.5）——可用作"槽内期望位置在工件未就位时的软化目标"，与我们的"带先验精观测"目标设置衔接。

## 8. 与本课题现有路线的冲突点
- 与"ros2_control 只有 position 命令"冲突：本文主张的阻抗型是"输出力 = 阻抗×(运动输入)"，需要力矩接口；我们的链路天然只能走导纳型（力→位置修正），即被本文 p.4 批评的那一侧。**引用时必须同时引这段批评**，否则 5.5 节会被审稿人追问。
- 与"站位表选站"无关（观测层）；与"六维力柔顺"一致——KWR75 正是导纳侧实现所需要的传感。
- 与"执行安全契约"（0.10 rad/s 上限）不冲突；低刚度 + 限速在理论上同属减小冲击的手段。
