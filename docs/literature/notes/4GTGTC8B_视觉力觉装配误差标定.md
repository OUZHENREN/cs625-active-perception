## 2. 一句话结论与相关性
- 一句话：把"机器人绝对定位误差 + 装配平台安装误差"合并成一个**每工位 4 参数（θ, t_x, t_y, t_z）**的综合误差，用"装夹在工位上的通用标定块（∅10 沉孔、H8/g6、位置度 ≤0.01 mm）+ 视觉粗定位（SIFT+AAMED 孔心，残余 1.5 mm）+ 力控把轴插入标定孔拿实际坐标"自动标出该参数，再按"工件坐标落在哪两个标定块围成的矩形区域"选对应参数校正离线编程点位；标定精度以"能顺利插入的最小间隙"定义，达 **0.278 mm**，产品"舱"装配成功率 模块 90.48% / 顶盖 100% / 螺钉 83.33% [原文证据] p.17–p.19、p.76–p.82。
- 相关性分类：**方法迁移**（不是同对象：航天产品"舱"+7 模块；但"按工位分区标定综合误差参数、运行时查表校正"与本课题的"站位表选站 + 误差链/公差"同构，且它是本批唯一给出完整数值口径与 24 次重复的标定论文）。
- 影响本课题的具体决定：**误差预算**（把机器人绝对定位误差与平台安装误差合并为 4 参数）、**验证方式**（用"最小可通过间隙"定义精度，而不是用位姿偏差）、**站位/分区表**（按 xy 区域归属查误差参数，可与现有按 yaw 最近站互补）、**定位要求**（视觉只需把轴送进沉孔倒角范围）。

## 3. 对象与任务
- 标定块：**40×30×20 mm** 四棱柱，四个直角倒角 **C4**（避开工位内圆角干涉）；标定孔基本尺寸 **∅10**，与标定轴配合公差 **H8/g6**，孔为**沉孔、深 7 mm**（"轴端低于孔表面一定深度即判装成"）；孔轴线到标定块侧面位置度公差 **≤0.01 mm** [原文证据] p.17（印 p.10）。
- 标定轴：**∅10 (−0.014, −0.005) mm** [原文证据] p.76（印 p.69）。
- 精度验证板：加工 ∅10(+0.022)、∅10.20(+0.022)、∅10.30(+0.022)、∅10.50(+0.022) 四种孔，对应轴孔间隙 **0 / 0.2 / 0.3 / 0.5 mm** [原文证据] p.76（印 p.69）。
- 装配对象：产品"舱"——舱体框架 + **7 个模块** + 顶盖 + **4 个螺钉**；模块与框架装配时底部**定位销轴与销孔间隙 0.3 mm**；模块插到底、顶盖靠内侧边缘对齐后拧螺钉 [原文证据] p.78（印 p.71）。
- 环境/传感：多关节工业机器人（**型号未给**）+ 上位机（工控机）+ PLC + 普通工业相机 + 六维力传感器 + 末端"标定轴"工具（图 4.3 显示工具含相机支架、快换转接板、六维力传感器）[原文证据] p.46（印 p.39）。
- 无质量/尺寸/洁净度数据：**"舱"与模块的质量、外形尺寸全文未给**；仅在失败分析中提到"该模块比其余六个模块厚度更大""工件底部夹具为 3D 打印" [原文证据] p.82（印 p.75）。

## 4. 方法与机制链（本批重点：手眼标定 / 观测量 / 精度口径）
- 链条：`Visual Components 离线编程出仿真坐标 → 标定阶段：机器人携相机拍标定块 → SIFT 模板匹配定大致区域 → AAMED 弧段邻接矩阵椭圆检测定孔心像素 → 相机内参 + 手眼矩阵把像素变基坐标 → 力控把标定轴插入标定孔拿到"实际坐标" → 由仿真坐标与实际坐标解 4 参数(θ,tx,ty,tz) → 运行时按工件 xy 落在哪个标定块矩形区选参数 → 校正离线程序点位 → 执行装配` [原文证据] p.16、p.18、p.79。
- **手眼标定：AX=XB，eye-in-hand**。文中定义 `H_O^B = H_T^B · H_C^T · H_O^C`（式 3-35），对两个位姿消元后得 `A X = X B`，其中 `A = (H_T^B2)^-1·H_T^B1`（工具在运动前后的相对变换）、`B = H_O^C2·(H_O^C1)^-1`（相机在运动前后的相对变换）、`X = H_C^T`（相机相对末端工具）[原文证据] p.37–p.38（印 p.30–31，式 3.35–3.37）。
- **AX=XB 用哪种解法：未交代。** 文中只写"基于上述 10 组标定板图片对应的机器人姿态信息和相机外参，利用公式（3.37）联合求解" [原文证据] p.40（印 p.33），**没有指明 Tsai-Lenz / Selman / Horaud / Andreff / 对偶四元数 / 非线性优化中的哪一种**，也没有写旋转轴不平行等可观测性条件（对比 8G2H64GR 明确写了 Tsai-Lenz）。→ 本条按模板规则记 **未定位**。
- **标定残差如何评价（两级，口径不同，务必区分）**：
  1. **相机内参重投影误差**：把 10 张图的角点按内参反投影，"主要集中在 **0.2 像素**以内，X 方向最大约 **0.3 像素**，Y 方向最大 **<0.3 像素**"；内参 `M1 = [[5461.276, 0, 1261.078], [0, 5459.941, 1018.809], [0,0,1]]`，像元 4.8 µm ⇒ `f_x = 26.21412 mm`、`f_y = 26.20771 mm`、`c_x = 1261.078 px`、`c_y = 1018.809 px` [原文证据] p.39（印 p.32）。
  2. **手眼结果的"闭合一致性"**：手眼矩阵 `H_C^T = [[0.00057, 1, 0.00325, −184.5998], [−0.99946, 0.000467, 0.03262, 0.91267], [0.03262, −0.00327, 0.99946, −109.449], [0,0,0,1]]` [原文证据] p.40；随后用 10 组位姿反算"标定板在机器人基坐标系下的位姿"，统计极差/标准差：极差 X **0.2355 mm**、Y **0.3889 mm**、Z **0.1871 mm**、A **0.055°**、B **0.079°**、C **0.055°**；标准差 X **0.0755**、Y **0.1359**、Z **0.0649 mm**、A **0.0186°**、B **0.0253°**、C **0.0177°** [原文证据] p.40–p.41（印 p.33–34，表 3.2）。
  3. **注意这不是 AX=XB 的方程残差**（文中的 `A X − X B` 残差从未计算），而是"同一块标定板在基坐标系下的重复性"，属间接闭合校核；顺带一处**口径不一致**：p.41（印 p.34）本章小结写"手眼标定结果中最大极差分别为 **0.3889 mm** 和 **0.0253°**"，但 0.3889 mm 是 Y 的极差、0.0253° 是 B 的**标准差**（B 的极差是 0.079°）——极差与标准差混用。
- **标定误差对末端定位的影响（三个量化台阶，这是本文最有价值的数）**：① 按仿真坐标直接去，轴孔之间约 **10 mm** 误差；② 经视觉定位后减小到约 **1.5 mm**；③ 再经力控调整后插入 [原文证据] p.79（印 p.72，图 6.7 a/b/c）。作者把视觉残余误差归因于三条：相机自身性能（分辨率）、模板与测试图的**透视变换**、**相机标定与手眼标定的误差** [原文证据] p.79。
- **观测量与不确定度来源**：观测量是**椭圆孔心的像素坐标**（AAMED 给定局部区域内检测椭圆并算中心与旋转角）[原文证据] p.41（印 p.34）；圆孔对齐"只需关注 x、y，与旋转角无关" [原文证据] p.79——即**主动放弃绕 Z**，这是对称性带来的自由度削减。不确定度源：模板裁剪精度（作者以此作为创新点之一）、透视变换、内参/手眼误差、力控触底判定（沉孔深 7 mm 为容差）。
- **力觉段**：六维力传感器 + 工具重力补偿（G = **8.7281 N**，重心 (−4.5135, −1.1926, 71.0786) mm）+ 初始值补偿（Fx0…Mz0 六个数）[原文证据] p.45（印 p.38，表 4.2/4.3）；有效接触力用"接触时读数 − 未接触时读数"差分（式 4.8）[原文证据] p.46；接触判据阈值为 **(3, 3, 3, 0.3, 0.3, 0.3)**（N / N·m）[原文证据] p.46；XGBoost + 决策树集成模型预测**调整方向**（回归 [0°,360°)，因 0° 与 360° 同向而自定义评价指标），减函数曲线预测**调整步长** [原文证据] p.47、p.83。
- **精度口径（关键）**：不是重复性、也不是位姿绝对误差，而是**"校正后能顺利插进去的最小间隙"折算值**：`Err = (c + ES_hole − ei_shaft)/2 + δ`（式 6.1，c 为间隙、ES 为孔上偏差、ei 为轴下偏差、δ 为标定块位置度公差）[原文证据] p.77（印 p.70）。代入 ∅10.20 孔得 0.128 mm，代入 ∅10.50 孔得 **0.278 mm**，并以 ∅10.50 的 95.83% 成功率作为"稳定可装"依据 [原文证据] p.77。
- **样本量与统计**：**4 组 × 每组标定 6 次 = 24 次标定**（每组验证板随机放置，组间改变位置），每个孔做 **24 次**装配（A/B/C/D 各 24）⇒ 成功率 0 / 0 / 8.33% / **95.83%**（23/24，唯一失败因力控测得的孔坐标不准）[原文证据] p.77–p.78；产品"舱"做 **6 次**标定+装配，含 **42** 次模块、**6** 次顶盖、**24** 次螺钉装配 [原文证据] p.81–p.82。**无置信区间**。
- **标定参数自身的重复性（原文只给表，未算统计；以下为我按表 6.2 复算）**：组内极差 组1 θ 0.047° / tx 0.323 mm / ty 0.682 mm / tz 0.231 mm；组3 θ 0.039° / tx 0.191 mm / ty 0.866 mm / tz 0.236 mm **[分析推断，数据取自 p.77 表 6.2]**。即"同一工位重复标定"的散差约 **0.2–0.9 mm / ≤0.05°**，比宣称的 0.278 mm 精度大 2–3 倍——两个口径不能互换引用。

## 5. 证据强度
- 试验类型：**真机**（工业机器人 + 相机 + 六维力 + PLC + Visual Components 离线编程），无仿真代替实测的段落；力控模型有 2160 条样本（360 方向 × 6 个偏移距离 {0.5,1,1.5,2,3,4} mm）[原文证据] p.47（印 p.40）。
- 样本量与失败样本：24 次标定 + 96 次验证孔装配 + 72 次产品件装配（42+6+24），**失败样本逐一归因**（模块 4 次失败全在同一"较厚模块"、因 3D 打印夹具精度；螺钉 4 次失败因吸钉管过大）[原文证据] p.82。
- 基线公平性：**部分公平**。A/B 孔（间隙 0 / 0.2 mm）成功率为 0，D 孔（0.5 mm）95.83%，构成了天然的"间隙-成功率"对照；但**没有"不做标定/只做视觉"的同工况对照**，因此"标定带来多少提升"无法从本文直接读出（只能从 p.79 的 10 mm → 1.5 mm → 插入三台阶间接看）。
- 统计口径问题：① 0.278 mm 是**由式(6.1)推算的上界**（取"能稳定通过的最小间隙"），不是实测位姿残差；② 手眼残差把极差与标准差混称（p.41）；③ 视觉误差在同一篇里出现 **1~2 mm**（p.42）、**≤3 mm**（p.46）、**~1.5 mm**（p.79）三种说法，未说明是同一口径的不同工况还是笔误。
- 结论：作为**"按工位标定综合误差 + 查表校正"的方法证据与数值口径证据可用**；作为"精度可达 0.278 mm"的绝对精度证据需谨慎——该数依赖 ∅10.5 孔 + 式(6.1) 的推算方式。

## 6. 最脆弱的 1–3 个假设
1. "仿真环境到实际环境的变换可近似为**刚体平面运动 + 上下平移**（4 参数）" —— **作者明说**，理由是"实验台上的各个工位已通过水平仪调平" [原文证据] p.18（印 p.11）；并在展望中把"未考虑实验台倾斜"列为不足 [原文证据] p.84。分类：**范围外迁移限制**。我们的站位/插槽若存在绕 x/y 的倾斜（实测插槽姿态并非严格水平），4 参数模型会把倾斜误差整体塞进 t_z。
2. "两个标定块按'包含原则'围成的矩形区域内，误差参数处处相同" —— **方法必需**（作者用式 2.2 的矩形判据做区域归属）[原文证据] p.18（印 p.11）。分类：**方法必需的简化**，其反例在本文内部即存在：表 6.4 四组参数虽然有差异（θ −1.5498/−1.5446/−1.5495/−1.5243°，ty −20.94/−20.63/−20.84/−20.31 mm），但作者自己解释"四个工位全部固定于一块平板上，本质是平板在仿真系与实际系之间的误差，因此误差参数相近" [原文证据] p.81——这与"不同工位安装误差不同、需要分多组标定"的研究动机**自相矛盾**，也让"分区校正"的必要性在本实验中未被真正验证。
3. "力控能把轴准确导到标定孔中心，因此力控得到的实际坐标可作为标定基准" —— **方法必需**，但作者把"力控测得的标定孔坐标准确度不高"列为 D 孔唯一一次失败的原因 [原文证据] p.77。分类：**尚未测试**（力控收敛到孔心的残差从未测量，只以"能否插入"二值判定）。

## 7. 可迁移到本课题的具体做法（1–3 条，可落地）

> 说明：以下 1–3 条均为 **[待验证设想]**——迁移方案尚未在本平台跑通，给出的验收指标是建议门槛，不是已验证结论。

1. **给站位表加"每站 4 参数残差 + 区域归属判据"**：现有 `config/tasks/common.yaml:workpiece_views` 是按 **yaw 最近站**（tolerance 15°、near 12°）选站；本文是**按工件 xy 落在哪两个标定点围成的矩形**选误差参数。两者可互补：yaw 决定**用哪个站位去拍**，xy 决定**用哪组标定残差去校正插入点位**。落地：在每个站位条目下增 `residual_theta_deg / residual_t_mm`，并给出一条 `region` 矩形；运行前用工件实测 xy 查区域。需要：至少 2 个"标定块"（我们可用插槽本体 + 一件已验证的标准件替代，因为不便向插槽加装标定块）。验收：同一工件在同一区域重复标定 6 次，θ 极差 ≤0.05°、t 极差 ≤0.5 mm（本文组内 0.2–0.9 mm 可作参照），校正后插入成功率相对不校正提升 ≥20 个百分点。
2. **用"最小可通过间隙"重定义我们的精度口径（把 gate 从位姿偏差改成可通过性）**：照式(6.1) 写我们自己的版本：对单侧间隙 g = 1–2 mm、"轴"端为插槽内壁/倒角，允许的最大位姿偏差 ≈ 倒角可吸收量 + g，而不是现在的 `slot 1.0 mm / 0.5°`（该门在 2026-11-13 实测中因"平移重复性 1.3 mm"未过，见 common.yaml 注释）。验收：先做 3 档人为偏置（0.5 / 1.5 / 3.0 mm）插入，各 10 次，画出"偏置-成功率"曲线，再据此重设 gate。
3. **标定块的"埋孔 + 触底判据"思路用于我们的插槽基准复核**：在插槽口放一件带 ∅10 沉孔的标定块（或用插槽自身台阶面 + 力触底），用"轴到底的 z 深度"判成功，可把"视觉 + 手眼 + 机器人"三者的综合误差一次测出，避免现有误差链分项重复计数。需要：所有者同意在插槽上加/取标定件；`insert` 段 0.005 m/s 速度上限不变。验收：连续 10 次触底 z 的标准差 ≤0.2 mm。
- **[待验证设想]**：如果 CS625 的绝对定位误差也在本文的 1–2 mm 量级（本文 1.573 → 0.595 mm），它单项就会吃掉 `slot 1.0 mm` 的全部门限，而现有误差链（camera → hand-eye → TCP → slot）**没有这一项**。需先实测：同一 TCP 目标点重复回访 20 次，统计到位偏差的极差与标准差（区分重复定位/绝对定位），再决定是否补『机械臂标定』分项。

## 8. 与本课题现有路线的冲突点
- **与"三平面 RANSAC + CAD ICP"冲突（最大）**：本文完全不用点云配准，用的是**合作标定块 + 力控触底**取得实际坐标，因此它的精度不依赖点云质量。这恰好绕开了我们当前的病根——插槽"以大平面为主，ICP 在面内方向没有约束"，同一片点云两条路径差 **66 mm**、三条组角点重复性 x 4 / y 11 / z 19 mm（`docs/reference/task_pose_derivation.md` §6.2）。若采纳本文，插槽位姿就不再需要 ICP 面内约束，但代价是每个工位要装标定件并做插入标定。
- **与"站位表选站"冲突（分区口径不一致）**：我们按 **yaw** 分区（−45°…+25°，15° 容差），本文按 **xy 矩形**分区。两套分区对同一工件的归类可能不同（尤其工件远离插槽时），需要统一到同一 key（建议：yaw 选站 + xy 选残差，两套参数各自独立、明确写进 common.yaml 注释）。
- **与"误差链/公差分配"冲突**：本文明确把机器人绝对定位误差与平台安装误差**合并成一个 4 参数**，并论证"若只存在其中一种，标出的就是那一种" [原文证据] p.19（印 p.12）。我们的误差链要求分项（camera → hand-eye → TCP → slot）。直接引用本文会丢失分项信息；反之，若我们坚持分项，就必须回答"分项后如何合成"——本文给出的答案是"合成后按区域查表"，可作为我们误差链的**落地层**。
- **与"绝对坐标不参与"路线（`task_pose_derivation.md` §6.1）冲突**：本文全程使用**绝对坐标**（仿真坐标 → 实际坐标），而我们抓取链已确立"绝对坐标从不出现，只用固定相对变换"。插槽段若照本文走，会重新引入绝对坐标依赖。
- **与 7 kg / 371 mm 的冲突**：本文是 ∅10 轴 × 7 mm 沉孔的短插入，靠"触底"判成功；我们插入 **371 mm**，中途的姿态漂移、侧壁摩擦累积、插入力随深度增长都在本文讨论范围之外；且 7 kg 工件的重力矩对"力控触底"的读数有持续偏置（本文工具仅 8.7 N）。

## 9. 待确认
- 机器人**型号与重复定位精度/绝对定位精度**（全文只写"多关节工业机器人"），否则 4 参数标定无法与我们的 CS625 指标对照。
- **AX=XB 采用的具体解法**（Tsai-Lenz / Selman / 其它），以及是否做了旋转轴不平行的可观测性检查。
- 相机型号、分辨率、像元（仅从内参反推 f≈26 mm、像元 4.8 µm，约 2560×2048 量级）——**未给型号**。
- 手眼标定的"10 组位姿"是否覆盖足够大的旋转角差（表未给位姿，只有标定板位姿结果表 3.2）。
- 力控"调整方向/步长"模型的在线耗时、以及是否在插入过程中实时运行（p.47 只给训练与评价）。
- 表 6.4 显示四组误差参数相近，作者解释为"同一块平板"；若如此，"分区校正"在本实验中的必要性仍未被证明——需确认其真实工装是否真的共用一块平板。
- "舱"与模块的质量、外形尺寸、以及 0.3 mm 销孔间隙下允许的位姿误差（正文未折算）。
- 24 次标定的 θ 跨组差异极大（8.75° / −8.12° / 1.02° / −2.46°），说明每组验证板摆放不同——这使"跨组比较"无意义，需确认组间可比性。
