## 2. 一句话结论与相关性
- 一句话：在**关节空间**把 RRT* 改成 **AS-RRT\***——局部节点拒绝（`d_near < d_father` 即拒）+ 自适应目标偏置（`P_tr = 1 − 1/(n·S)`，成功 S+=1、失败 S−=2）+ Sobol 低差异序列滑动采样池（6000 维生成矩阵，窗口内按到目标距离排序，每次只新增 1 点）+ 树长上限重搜；**4 种步长 × 5 种算法 × 100 次**实验：成功率 **0.6775 → 0.9975（+32 个百分点）**、路径代价 **−2%**、规划时间 **−90.36%**；再用非均匀五次 B 样条 + 改进 NSGA-II（种群扩增）把 7 s 轨迹压到 **4.75 s**（关节 5 加速度由 2152.4°/s² 的超限降到约束的 87.3% 以内）；真机（双目视觉定位白色球障碍）两次场景验证避障 [原文证据] p.38（印 p.29，表 3.2）、p.50（印 p.41）、p.53（印 p.44）。
- 相关性分类：**方法迁移**。它是本批唯一把**成功率当一等指标**、且给出完整试次口径的论文，其对比表结构可直接做我们"接近段规划"的评价模板；"节点拒绝 + 低差异序列"两个技巧可落地到 OMPL 采样器。
- 影响本课题的具体决定：**验证方式**（成功率 + 试次 + 分布）、**观测动作/规划时间预算**（p95 规划时间）、**误差预算**（碰撞模型粗化引入的安全裕度与 1–2 mm 间隙的相容性）。

## 4. 方法与机制链（本批重点：约束 / 碰撞 / 规划指标）
- **碰撞模型与判定（可复现）**：关节与障碍用**包围球**，连杆用**包围圆柱**；关节判定 `‖C_i − (a,b,c)‖ < r + R_i` 即碰撞（式 3-11）；连杆判定用**海伦公式**算障碍球心到圆柱轴线的纵向最短距离 `Lx_min`（式 3-12/3-13）、横向 `Ly_min = max(√(l1²−Lx_min²), √(l2²−Lx_min²))`（式 3-14），`Lx_min ≥ r_i + R` **或** `Ly_min ≥ l3 + R` 判安全（式 3-15）[原文证据] p.30–p.31。
- **约束怎么建**：① 关节限位（Step1 参数 `J_l`，正文未列数值）；② 碰撞；③ 树的最大长度（超限则清空重搜，Step9）——用"重搜"换成功率，这是它相对标准 RRT* 的一个策略性取舍 [原文证据] p.36（印 p.27）；④ 速度/加速度约束**不在规划层**，而在第 4 章用 B 样条 + NSGA-II 事后满足（表 4.1：位置 **179/146/146/179/179/179°**、速度 **70°/s**、加速度 **148°/s²**）[原文证据] p.49（印 p.40）。
- **可达性怎么判**：**没有显式判据**。不做 IK 可达性预筛，靠"树清空重搜 + 成功率统计"间接反映；这是与 SUHKBEF7（工作空间闭式判据）、9CABC9I6（工作空间分析）相比最弱的一环 [分析推断]。
- **RRT\* 改进的三件套（每个都可独立复现）**：
  1. **节点拒绝**：新节点 `q_new` 到树中其他节点最小距离 `d_near`、到父节点距离 `d_father`，若 `d_near < d_father` 则拒绝（避免点过密、减少父节点重选/剪枝的碰撞检测次数）[原文证据] p.33（印 p.24）。
  2. **自适应目标偏置**：`P_tr = 1 − 1/(n·S)`，S 初值 5，采样成功 S+=α（α=1）、失败 S−=β（β=2）[原文证据] p.34（印 p.25，式 3-16~3-18）。
  3. **Sobol 滑动采样池**：Sobol 序列（基 2、生成矩阵 C 取自 Joe-Kuo 库、用 **6000 维**生成矩阵）一次性生成大采样池 `Sample_room`（大小 6×k），滑窗每次取 k 点按到目标距离排序，逐个做碰撞检测，通过后窗口下移一格——"除第一次外每次只算 1 个新点，不增加计算压力却增强目标导向" [原文证据] p.35–p.36（印 p.26–27）。
- **轨迹优化（第 4 章）**：非均匀五次 B 样条（`C²` 连续）；利用**凸包性**把速度/加速度约束转成**控制点约束**（简化计算）；对时间节点编码；双目标 NSGA-II：`f1`=总时间、`f2`=约束违反量；锦标赛选择**强化 f2=0 的倾向**（Step1–4），快速非支配排序**强制 Pareto 等级 1 的个体 f2=0**；种群扩增策略（初始 30 vs 180）[原文证据] p.43–p.51（印 p.34–42）。
- **跟踪（第 5 章）**：变增益 PD 迭代学习控制，增益随误差自适应，仅 Simulink 2 自由度仿真（正弦 + B 样条轨迹，5 次迭代）[原文证据] p.67–p.71（印 p.58–62）。

## 5. 证据强度（本笔记做了逐项复算）
- **表 3.2（核心表，4 步长 × 5 算法 × 100 次，取平均）** [原文证据] p.38（印 p.29）：
  - RRT*：21.8 s / 389 / 0.65；24.6 / 393 / 0.62；28.8 / 417 / 0.70；34.2 / 442 / 0.74
  - AS-RRT*：**1.77 s / 382 / 1.00**；1.25 / 379 / 1.00；2.44 / 407 / 0.99；5.09 / 440 / 1.00
  - RRT：0.43/492/0.54 …；Sobol-RRT：0.48/463/0.69 …；PVAS-RRT：1.6/495/0.45 …
- **本笔记复算（全部通过，这是本批数字自洽性最好的一篇）**：成功率均值 0.6775 → 0.9975 = **+32.0 pp**（原文"提高了 32%"应为百分点）；路径代价 410.25 → 402.0 = **−2.0%**；时间 27.35 → 2.6375 s = **−90.36%**。
- **统计口径缺陷**：只有**均值**，无标准差、无每步长的分布、无 95% 置信区间；100 次全成功（1.00）时，按二项分布 95% 单侧下限 ≈ **97%**（[分析推断]，rule-of-three 1−3/n）——即"100% 成功"严格说是"≥97%"。
- **真机验证（第四章 4.4）**：中科深谷臂 + 双目视觉 + 白色球障碍 r=18–22 mm，两组场景（改 4 个障碍物位置），"成功避开障碍并到达指定姿态"；**无重复次数、无成功率、无末端跟踪误差、无关节角误差**（只有过程图 4-14/4-15）[原文证据] p.53–p.56。
- **NSGA-II 对比的公平性问题**：加入种群扩增（初始 30）vs 不加入（初始 180），迭代均 500 次；结果规划时间 **12.83 s vs 142.37 s**，收敛代数 ~150 vs ~200，机械臂运行时间 4.75 s（vs 手动 7 s）[原文证据] p.51（印 p.42）。→ 两者**初始种群规模不同**（30 vs 180），"12.83 s vs 142.37 s"混入了种群规模效应；且 12.83/142.37 是**算法运行时间**，不是机械臂运行时间，容易误读。
- 轨迹优化结果：各关节最大加速度达约束的 **74.3/83.7/86.5/71/87.3/29%**，运行时间缩短 **32.1%**（7 → 4.75 s）[原文证据] p.51。
- 第 5 章 ILC：仅 Simulink、2 自由度（m1=10, m2=5, l1=1, l2=0.5, r1=r2=0.5）、5 次迭代，误差只以曲线给出（PD 型位置误差约 10 次收敛、速度误差约 35 次收敛；变增益第 2 次迭代即收敛），**无任何数值** [原文证据] p.67–p.69（印 p.58–60）。
- 结论：作为**规划算法的对比证据**强（试次 100、数字自洽、四步长交叉验证）；作为**工程可用性证据**弱（真机只定性、无成功率、碰撞模型极粗）。

## 6. 最脆弱的 1–3 个假设
1. "障碍物是静态且位置已知" —— **作者明说**（展望：未考虑移动障碍物，需增加速度/加速度信息）[原文证据] p.72（印 p.63）。分类：**范围内反例**（我们的场景里"障碍"包括自身机械臂 + 工装 + 会随换位改变的遮挡关系，布局随观测动作变化）。
2. "包围球/圆柱的保守包络不影响算法可行性与结论" —— **方法必需**（半径 82–86 mm vs 连杆 120 mm 级）。分类：**范围外迁移限制**。我们的插槽单侧间隙 **1–2 mm**，用这种包络会把所有插入位姿判成碰撞——**它的碰撞模型在我们这里完全不可用**。
3. "成功率只由规划算法决定" —— **我的推断**：它没有区分"规划失败（超时/无解）"与"执行失败（碰撞/超限）"，而 1.00 的成功率是在"规划器返回路径且终点误差 < step"的判据下统计的，与真机执行无关。分类：**尚未测试**（真机未统计成功率）。

## 7. 可迁移到本课题的具体做法（1–3 条）
以下三条是**尚未在本课题验证**的做法，其中"成功率不降、p95 时间 −30%"属 [待验证设想]。
1. **把它的表 3.2 结构搬成我们的"接近段规划对比表"**：固定场景（停车位 → 预插入位，含插槽/工件/相机支架障碍）、固定 N=**100 次/算法**、记录 `time / path length / nodes / success`，报**均值±σ + 成功率 Wilson 95% CI**，失败样本按"超时/碰撞/无解"分类。需要：`cs625_view_evaluation` 或实验脚本里加一个批量规划 benchmark（复用 MoveIt/OMPL 接口，`plan_only` 模式）。验收：4 种算法（RRT-Connect / RRT* / Informed-RRT* / AS-RRT*）对比表 + 一张成功率-时间散点图；插入段**不参与**此 benchmark（插入段必须直线 + 0.005 m/s）。
2. **采纳"低差异序列 + 节点拒绝"降低规划时间**：在 OMPL 的自定义采样器里注入 Sobol 序列（Joe-Kuo 生成矩阵，维度取 6 足够，不必 6000 维），并加 `d_near < d_father` 拒绝。需要：一个采样器插件 + 单元测试。验收：同一场景 100 次规划，**p95 规划时间下降 ≥30%**、成功率不降（Wilson CI 下界不低于基线）。
3. **把"规划层约束"和"执行层约束"分开写清**：照它的思路，用 B 样条控制点约束速度/加速度（凸包性），对应我们的硬约束 `MAX_JOINT_SPEED_RAD_S = 0.10`（≈5.7°/s）、单段 25°/0.44 rad 上限；把现在"重定时 + 拒绝超限"的做法升级为"规划时就把约束写进控制点"。验收：100 段轨迹零 `REFUSED_LARGE_MOVE`、零超速、零 `time_scale<1` 请求。

## 8. 与本课题现有路线的冲突点
- **比我们的"误差链 + 蒙特卡洛 + 公差分配"更严谨的地方**：① **成功率是主指标**（本批唯一），且 100 次试次、四步长交叉验证，可直接支撑我们"P_success"的口径；② 指标定义（时间/路径代价/成功率/迭代次数）清楚、表格可复现；③ 我逐项复算全部通过（−90.36%/−2%/+32 pp），**数字自洽性本批最好**；④ 有真机（虽然只定性）。
- **它不适用/不如我们的地方**：① 碰撞模型粗化到 82–86 mm 球，与 1–2 mm 间隙**不在一个尺度**，完全不能用于插入段，只能用于粗接近段；② 关节空间的"路径代价"是关节角欧氏距离之和，**不是末端 mm**，无法与我们的 0.42 mm/0.078° 精度口径对接；③ **无任何误差/精度内容**（全文没有视觉精度、标定、补偿），不能进误差预算；④ 没有研究"同一末端路径的不同关节解对末端精度的影响"——而我们的冗余自由度选择恰恰会改变误差放大（`Δx = d·Δθ`），这是它完全缺失的一层；⑤ 真机无成功率、无跟踪误差。
- **与"站位表选站"的关系**：它的规划是"起点→目标点"的任意外形，我们的换位是**离散站位查表**。AS-RRT* 对我们的用处仅限于"从当前位到预插入位"的接近段，且必须叠加"站位表 + 200 mm 交叉核对"的闸门（`scripts/nbv_from_reference.py --auto-station`）。
- **与 0.10 rad/s 速度上限的冲突**：它表 4.1 的 70°/s（≈1.22 rad/s）是我们的 **12 倍**；其"4.75 s 完成轨迹"的时间尺度在我们的安全约束下不可达（我们单段 ≤25°、≤5.7°/s，等于每 25° 段至少 4.4 s）。引用其时间数字时必须换算。
