## 2. 一句话结论与相关性
- 一句话：为 ICF 装置的 **LRU 模块下装**设计一套"**底盘调平（面追逐式）+ 平面三自由度并联校准机构 + 被动柔顺浮动平台 + 洁净箱垂直提升**"的设备，并把 **LRU 插入过程拆成"倒角接触 / 一点接触 / 两点接触"三阶段**，给出每阶段的装配力解析式、几何可行判据 `|U0 − Lp·θ0| < W + (R−r)`、以及"最大可校正角度偏差 `θmax = arccos(1/(1+C))`"；参数敏感性结论：轴向装配力在**两点接触阶段达到最大**，随初始偏差 U0/θ0、侧向刚度 Kx、扭转刚度 Kθ、摩擦系数 μ 增大而增大，随**间隙比 C** 增大而减小（[原文证据] p.59–p.65）。
- 相关性分类：**直接对象证据**（同为 ICF 装置下装、长行程插入、狭小间隙的洁净精密装校）兼**方法迁移**（装配三阶段力学模型 + 几何准入判据 + 误差链分量分解）。
- 影响本课题的具体决定：**接触切换**（哪一阶段该由柔顺接管）、**柔顺参数**（Kx/Kθ 量级与"哪一项最敏感"）、**定位要求**（插入前允许的 U0、θ0 预算）、**误差预算**（4 项误差分量线性求和的结构）。

## 3. 对象与任务
- 对象：ICF 激光核聚变装置的 **LRU（Line Replaceable Unit，在线可替换单元）模块**，从下方装入洁净厢；模块百级洁净度要求（[原文证据] p.4）。
- 总体指标（10 条，原文逐条列出）：洁净度优于 **5 级**；对接精度 **mm 级**；转运车粗定位 **±50 mm**、下装设备精定位 **亚 mm 级**；最大载荷 **800 kg**；整机外形 ≤**3200×3000×3800 mm**；提升行程 ≥**2200 mm**、提升速度 ≥**10 mm/s** 且断电保持；整机刚度要求"结构最大变形不超过整机高度的 **0.2%**"（按 3800 mm 折算即 **7.6 mm**）；设计寿命 **30 年**；故障维修 48 h / 15 天两档（[原文证据] p.17）。
- 校准机构（3-PRP 平面并联）：负载 **2600 kg**、行程 **100 mm**、最大速度 **2 mm/s**、定位精度要求 **±0.1 mm/100 mm**（[原文证据] p.22）；选 C7 级 BNF3610-5 轧制滚珠丝杠，运行距离误差 **±0.05 mm/300 mm**（[原文证据] p.23）。
- 柔顺环节（被动）：软弹簧组件 + 硬弹簧组件 + 剪式千斤顶 + 浮动上平台，松压紧机构后由软/硬弹簧共同承载形成"微幅浮动"，浮动范围由压紧机构限制（[原文证据] p.27）。
- 装配分析用的参数（**注意：是"初始设定"而非实测**）：侧向刚度 `Kx = 20 N/mm`、扭转刚度 `Kθ = 200000 N/rad`（=2×10⁵ N·rad）、轴径 `r = 265 mm`、间隙比 `C = 0.0002`、初始侧向偏差 `U0 = 8 mm`、初始角度偏差 `θ0 = 0.002 rad`、摩擦系数 `μ = 0.10`（[原文证据] p.63）。按 `C = 间隙/半径` 理解，单侧间隙约 **0.053 mm**，比我们 1–2 mm 小约 20–40 倍。
- 环境：洁净箱内部 **100 级**，箱体内框抛光至表面粗糙度 **3.2 μm**，润滑脂按无尘室要求选 AFE 油脂；提升机构选滚珠丝杠 + 蜗轮蜗杆（自锁，掉电不下落），双丝杠同步解决偏载（[原文证据] p.28）。

## 4. 方法与机制链
- 主链：`转运车粗定位（±50 mm）` → `支腿调平（面追逐式，θX/θY/Z）` → `三自由度并联校准机构精定位（X/Y/θZ）` → `被动柔顺平台上浮（多自由度微幅调整）` → `滚珠丝杠垂直提升，边提边由柔顺吸收偏差` → `装配完成、压紧机构锁定`（[原文证据] p.18、p.41 图 4-1、p.27）。
- 关键机制 1（几何可行判据）：把模块抽象成"轴（半径 r）+ 孔（半径 R）+ 孔口倒角（宽 W、角 α）"，柔顺中心到轴端距离 Lp；若初始接触点落在倒角之外，即 `|U0 − Lp·θ0| > W + (R−r)`，则**无论怎么柔顺都插不进去**；反之才可能（[原文证据] p.60）。这条把"视觉位姿精度要求"直接翻译成"能不能插入"的二元判断。
- 关键机制 2（最大可校正角）：两点接触的临界状态 ZB=0 推出 `cosθ = 1/(1+C)`，即 `θmax = arccos(1/(1+C))`，其中 C 为间隙比；C 越大可校正的角度偏差越大（[原文证据] p.59 式 4-34）。也就是说**柔顺能救多少角度误差，在几何上由间隙比封顶**。
- 关键机制 3（三阶段装配力解析式）：倒角接触、一点接触、两点接触分别写出"几何协调方程 + 受力平衡方程 + 物理性质方程（`Fx = Kx(U−U0)`、`M = Kθ(θ−θ0)`、`f = μFN`）"三组方程联立，得到轴向装配力 `Fz` 作为插入深度的分段函数（[原文证据] p.61–p.63 式 4-35～4-46）。
- 关键机制 4（误差分量分解 → 最坏组合）：校准机构定位误差被拆成 4 项——丝杠运行距离误差 `ΔL1=17 μm`、热变形（Δt=5 ℃）`ΔL2=6 μm`、运行姿态变化（垂直公差 10″）`ΔL3=4.8 μm`、减速器空回（12′）`ΔL4=5.6 μm`，**线性相加**得最大定位误差 `ΔL=33.4 μm`；再把 ε=0.05 mm 作为驱动误差上界，枚举 3 个驱动件的 ±ε **8 种组合**求最大角度/位置误差（[原文证据] p.23、p.27、p.51–p.52）。
- 关键机制 5（敏感度优化的落点）：位置误差对结构参数敏感度的结论是"增大驱动件 L2、L3 的水平距离 s，减小 L1 到 X 轴的垂直距离 h，减小输入误差 ε，**尤其是控制 L1 的输入误差**"（[原文证据] p.58）。
- 改变了哪个假设：把"柔顺能自动消除所有位姿偏差"改成"**柔顺只能消除间隙比允许的那部分角度偏差，超出就必须在插入前用视觉/机构定位解决**"（[分析推断]，依据 p.59–p.60）。这正好是我们"视觉尽量做准 + 柔顺兜底"的分界线依据。

## 5. 证据强度
- 试验性质：**设计 + 解析 + 仿真**，**无实物装校试验**。第 3 章 ANSYS（APDL 命令流）静力与模态，第 5 章 ADAMS 运动学/动力学；全文没有一次真实 LRU 插入。
- 静力/模态的具体数字：装载工况底盘最大应力 **48.77 MPa**、某部件最大变形 **1.22 mm**、洁净箱顶部变形 **1.42 mm**（满足"≤整机高度 0.2% = 7.6 mm"）；举升工况底盘 **47.98 MPa**、部件 **16.31 MPa / 1.20 mm**；前六阶固有频率：装载 **5.00/6.35/14.95/16.97/17.66/18.67 Hz**、举升 **4.27/5.45/15.11/15.44/16.05/18.18 Hz**；丝杠挫曲载荷 **306 kN**、安全系数 **6**（[原文证据] p.33–p.40 附表）。
- ADAMS 仿真：三驱动件按给定速度曲线运动，动平台位移/速度/加速度曲线"除启动制动外几乎匀速"，X 向最大加速度 ≤**30 mm/s²**、Y 向 ≤**50 mm/s²**、转动角加速度 ≤**1（单位 OCR 丢失，疑为 °/s²）**；结论"加速度不大、无冲击"（[原文证据] p.76）。
- 装配力部分：**只有解析式 + Matlab 曲线**，没有任何实验或 ADAMS 接触仿真对照（[原文证据] p.61–p.65）；参数的来源（Kx=20 N/mm、Kθ=2×10⁵ N/rad、C=0.0002、U0=8 mm、θ0=0.002 rad）**未给依据**，只说"初始设定"（[原文证据] p.63）。
- 内部口径冲突（重要的两处）：① 粗定位精度——指标表写"转运车粗定位 **±50 mm**"，紧接的正文描述却写"粗定位精度可达 **±10 mm**"（[原文证据] p.17 vs p.18）；② 洁净度——指标写"优于 **5 级**"（ISO 5），正文写"**100 级**"（美标 Class 100），二者数值等效但混用两套标准，且同一段既说"局部 100 级洁净箱"又说"洁净度优于 5 级"，读者无法判断以哪个为准（[原文证据] p.17、p.28）。
- 另一处未闭环：全文反复说"插装力 `Fz` 不超过阈值 `Fz0`"（[原文证据] p.58），但**从始至终没有给出 `Fz0` 的数值**，也没有给出"超过阈值怎么办"的判据。
- 结论：作为**几何判据与装配力结构性证据**可用（公式链条完整、量纲自洽）；作为**精度与可行性证据**不可用（无实测、参数无来源、力阈值缺失）。

## 6. 最脆弱的 1–3 个假设
1. "LRU 模块与对接孔视为刚性，只有柔性装置发生弹性变形；Kx 与 Kθ 相互独立、两平面无耦合、绕轴各向同性、装配为准静态过程" —— **作者明说**（[原文证据] p.60，四条假定）。分类：**范围外迁移限制**。我们的柔顺是**主动导纳式**（关节 effort 残差触发），根本不存在"Kx、Kθ"这两个被动刚度参数；把本文的 20 N/mm / 2×10⁵ N·rad 当作我们的柔顺参数等于把两种物理机制混为一谈。
2. "间隙比 C 在整个插入行程上恒定（孔与轴平行、间隙均匀）" —— **方法必需**（[原文证据] p.59，C 是常数才能推出 θmax 闭式解）。分类：**范围内反例**（对我们则是常态）：我们的插槽长 371 mm，手册记录过"工件同时触碰槽底与两侧壁"，即**间隙沿深度不均匀、且存在多面同时接触**；此时 C 不是常数，θmax 的闭式解失效，只能作为保守下界。
3. "插入前初始偏差 (U0, θ0) 是已知且不变的" —— **方法必需**（[原文证据] p.60，U0、θ0 作为解析式输入）。分类：**尚未测试**。本文没有说明 U0、θ0 怎么测（它没有视觉系统介入插入段），而我们恰恰要靠视觉给出 U0、θ0，其**不确定度**没有进入本文的力学模型——所以本文的"装配力—偏差"曲线在我们这里只能当趋势看，不能当预测。

## 7. 可迁移到本课题的具体做法
1. **把"能不能插进去"变成插入前的一条几何断言**：照 `|U0 − Lp·θ0| < W + (R−r)` 写我们自己的准入判据。代入我们的量：单侧间隙 `(R−r) = 1–2 mm`、Lp ≈ 工具从柔顺点到轴端距离（可用 `tool_flange_to_tcp_mm ≈ 353` 量级）、`W`（插槽口倒角宽度，**目前未测**，−10° 倾斜导入相当于等效倒角）、U0 与 θ0 取视觉位姿误差的 p95（工件重复性口径 0.42 mm / 0.078°，gate 口径 1.0 mm / 0.5°）。落点：`scripts/plan_pose_ik.py` 之前加一条断言，超限则拒绝进入 insert 段并打印是"U0 项"还是"Lp·θ0 项"超限。需要：实测插槽口倒角尺寸与 Lp。验收：对 20 次历史插入回放该判据，判断与实际卡阻/中止的一致性 ≥90%，且不出现"判据说能插、实际卡死"的假阴性。
2. **做一次"装配力—初始偏差"扫描实验，把本文的定性趋势变成我们的定量曲线**：本文结论是 `Fz` 随 U0、θ0 增大而增大、随 C 增大而减小，且在两点接触阶段达峰值。我们可在固定站位下人为注入横向偏移（例如 0 / 100 / 200 / 400 μm）、保持插入深度 371 mm，用 KWR75 记录 `F_z` 峰值与 `M_x/M_y`。验收：给出 `Fz_peak = f(U0)` 曲线与斜率（N/mm），并与"Kx 的等效值"对照；若斜率在某 U0 处突增，说明进入了两点接触——这正好可以标定我们的"接触切换点"。需要：可重复的偏移注入方式（修改目标位姿而不是手推）。
3. **误差链用"分量 + 最坏组合"两种口径各算一遍**：本文把定位误差拆成 4 个分量线性相加（33.4 μm），再枚举 3 个驱动件 ±ε 的 8 种组合。我们的做法建议：把 slot/workpiece 位姿误差拆成"关节编码器/减速器空回、热、姿态（相机倾角）、视觉测量"4 项，先按极值法求和得到**最坏情况**，再按 RSS 得到**统计值**，两者都写进 `docs/reference/` 的误差预算表，并注明差异来源。验收：表里每项都有来源与数值；最坏值与统计值的比值有物理解释（例如 1.5–2.5 倍）。

- [待验证设想] `θmax = arccos(1/(1+C))` 在 C 取我们 1–2 mm/工件半径量级时会给出很大的可校正角（远大于 1°），但该式前提是"间隙沿深度均匀"；我们手册记录过"工件同时触碰槽底与两侧壁"的三点接触工况，此时 C 不是常数，θmax 会显著偏低。可用 KWR75 实测 `M_z` 反推"实际被柔顺吸收掉的角度"，与解析值对比，差值即"多点接触惩罚"。[分析推断] 若差值稳定，可把它写成一个经验折减系数进插入前准入判据，而不是改进解析式。

## 8. 与本课题现有路线的冲突点
- **与"导纳式柔顺"冲突（机制层）**：本文是**被动柔顺**——弹簧浮动平台，刚度 Kx=20 N/mm、Kθ=2×10⁵ N·rad 是**机械属性**，误差被"机构自己变形"吸收；我们的柔顺是**主动的**——关节 effort 残差超阈值（contact 0.68 / safety 1.63）就降速或中止，`/ft_sensor/wrench` 只记录不闭环。两者的"柔顺刚度"没有可比性：本文可以用"Kx 越小越好"来设计，我们的"刚度"由控制器增益与阈值决定，改小阈值等价于变"软"，但代价是中止更频繁。
- **与"站位表选站 + 视觉测量"冲突（定位来源层）**：本文**插入段不用视觉**，位姿完全由"机构精度 ±0.1 mm/100 mm + 转运车 ±50 mm 粗定位 + 调平"保证，视觉只在绪论里作为"全方位视频监测"提及（[原文证据] p.17 指标第 5 条）。我们的路线是"视觉位姿 → MoveIt 规划 → 插入"，把精度押在测量上。若接受本文口径，等于承认"现场不需要视觉闭环，机构精度足够"——在我们 CS625（重复定位 ~0.1 mm 量级但受相机/手眼误差支配）上不成立。
- **与"误差链/公差分配"的口径冲突**：本文用**极值法线性求和**（17+6+4.8+5.6=33.4 μm）+ **最坏组合枚举**，得到"控制 L1 输入误差最重要"的结论；这是**保守口径**下的敏感度排序。我们的误差预算目前是"实测 p95 + 单次 gate"，属统计口径；两种口径下"哪一项最该收紧"的结论可能不同（极值法偏向压制最大项，RSS 偏向压制方差最大项）。直接引用本文的优化优先级会误导我们的公差分配。
- **与 371 mm 插入深度的尺度冲突**：本文 θmax 的推导用了"柔顺中心到轴端 Lp"与"轴径 r=265 mm"的大件几何，且间隙比 C=0.0002（单侧 ~0.05 mm）；我们工件小、插入深 371 mm、单侧间隙 1–2 mm。**同一角度偏差在我们这里的末端位移被放大 371/Lp 倍**，所以我们的 θ0 预算必须比本文严得多；反过来，我们的间隙比 C 比它大约 20–40 倍，柔顺"能救"的角度远大于它。这两个事实叠加后，"视觉该做多准"的结论与本文完全不能互推。
- **与"洁净"要求的冲突（范围外）**：本文整套设备围绕百级/ISO 5 洁净设计（不锈钢抛光 3.2 μm、AFE 油脂、洁净箱）；我们现场没有洁净等级要求，若照搬其洁净设计约束（抛光、油脂、双丝杠同步）会直接改我们的机械接口与维护流程，属于范围外迁移。

## 9. 待确认
- **插装力阈值 `Fz0` 的数值**：全文只在 p.58 提出这个概念，从未给出数值，也没给"超过怎么办"的逻辑——这是本文最关键的空缺。
- **倒角参数 W、α** 的数值，以及 U0、θ0 的**测量方式**（本文没有视觉进入插入段，那两个量从哪来？）。
- **间隙比 C 的定义与单位**：文中写 `C = ΔC/2r` 一类式子但 OCR 后符号不可辨；按 `C=0.0002`、`r=265 mm` 反推单侧间隙约 0.053 mm，此推断须验证。
- **Kx=20 N/mm、Kθ=2×10⁵ N/rad 的来源**：是设计值、实测值还是文献取值？弹簧组件的刚度曲线（是否线性、是否有预压）未给。
- **浮动范围**：图 2-12 标注了"运动行程 / 浮动范围"，但正文没有给出数值（毫米与角度）；这是被动柔顺能力的核心参数。
- **粗定位 ±50 mm vs ±10 mm**、**洁净度 5 级 vs 100 级**两处口径必须澄清（见第 5 节）。
- ADAMS 的动力学响应**没有与解析动力学方程对比**（只给了响应曲线并称"满足要求"），也**没有与装配力解析式对照**；因此第 5 章的"验证"实际是"演示"。
