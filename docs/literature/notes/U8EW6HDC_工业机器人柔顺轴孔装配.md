## 2. 一句话结论与相关性

- 相关性分类：**方法迁移（最高优先级）**——标定流程、导纳参数、阶段判据、成功率口径都能直接搬到我们的 KWR75 链路。
- 影响本课题的具体决定：**末端接口**（标定要标哪 12 个参数）、**柔顺参数**（M/B 量级与采样周期）、**验证方式**（25 次成功率 + 接触峰值）。

## 3. 对象与任务
- 对象：圆柱单轴孔，铝件，**轴孔间隙 1 mm**；另一组插孔实验用木制积木（间隙 1 mm）[原文证据] p.19、p.50。
- 机器人：UR5（重复定位 ±0.1 mm，末端模块 5 kg，最大速度 180°/s），TCP/IP 30003 端口 **125 Hz** 反馈状态；UDP 下发 URScript [原文证据] p.20-21。
- 末端：Robotiq G85 二指夹爪（5 kg 模块、最大握力 60 N）[原文证据] p.21。
- 传感：ATI **MINI45 SI-580-20**，量程 ±580 N（Fx/Fy）/±1160 N（Fz）/±20 N·m，分辨率 1/4 N、1/188 N·m、1/376 N·m；NetBox 经 UDP 以 **7000 Hz** 输出；工控机—机器人—传感器同网段 [原文证据] p.22-23 表2-2。
- 标定装夹：三个专用法兰盘（机器人末端→法兰1→法兰2→传感器→法兰3→夹爪），保证刚性连接 [原文证据] p.22。

## 4. 方法与机制链
`六维力原始读数 → 12 参数一次最小二乘标定（零漂/安装角/重力/质心） → 死区 → 位置型阻抗（速度环） → 阶段状态机（接近/搜孔/倒角/一点/两点） → 完成`

### 4.1 六维力如何接入（采样 / 滤波 / 零漂 / 重力补偿 / 工具偏心）
- 采样：传感器 **7000 Hz**（NetBox UDP，约 142 µs/帧）；机器人状态 **125 Hz**；阻抗控制周期 **T = 0.008 s（125 Hz）**[原文证据] p.21-23、p.30。
- 力的三部分组成（本文的分解口径）：`读数 = 传感器零漂 + 末端模块重力 + 外部接触力`（低速忽略惯性力）[原文证据] p.23-24。
- **零点必须装好末端模块后再测**，因为"末端模块与传感器的连接方式及螺丝的拧紧程度会影响零点值"[原文证据] p.24 —— 这是很实用的工程规则。
- **标定三步（本文最值得抄的部分，[分析推断] 优先级判断）**：
  1. **质心辨识**（式2.1~2.8）：设重力 `G`、质心 `(x,y,z)`，重力矩 `Mgx = Gz·y − Gy·z` 等；把 `Mx = Fz·y − Fy·z + Mx0 + Fy0·z − Fz0·y` 写成线性形式 `m = F·p`，用**最小二乘** `p = (F^T F)^{-1} F^T m` 一次解出 `(x, y, z, k1, k2, k3)` [原文证据] p.24-26。
  2. **安装倾角 + 零点**（式2.9~2.19）：认为传感器系只相对末端系**绕 Z 转 θ**，`R = Rz(θ)`；基座系与重力平行 `g_t = (0,0,−G)`，`g_s = R^{-1}·R_BE·g_t`；无接触时 `g_s + F_0 = F_s`，再写线性方程 `f = R·u`，解 `u = [Gcosθ, Gsinθ, G, Fx0, Fy0, Fz0]^T`，LS 得 `u = (R^T R)^{-1} R^T f`；θ 由 `arccos(Gcosθ/G)` 反算 [原文证据] p.26-27。
  3. **精确外力**：`F_ec = F − F_0 − G_s`，其中 `G_s = Rz(θ)·R_BE·[0,0,−G]^T`，即"随姿态实时预测重力分量再相减"[原文证据] p.27 式2.20-2.21。
- **补偿后加死区**：因为"未建模误差与传感器噪声"，补偿后仍在 0 附近有微小偏差，所以"只有在数值大于某个范围时才做柔顺控制"；死区大小本文**未给具体数值**，只推导了其必要性 [原文证据] p.29。
- 工具偏心：`(x,y,z)` 是"末端模块质心在传感器系下的偏移"，直接进了重力矩项 —— 等价于我们说的工具偏心补偿；但**旋转偏移只考虑绕 Z 的 θ**，没有完整 3 自由度姿态偏移 [原文证据] p.26。

### 4.2 接触阶段如何划分/识别
- 阶段划分：接近 → 搜孔 → 倒角 → 一点接触 → 两点接触 [原文证据] p.18 图2.2。
- 搜孔成功的**几何判据**：Z 向插入深度 **> 3 mm** 即认为找到孔（不靠力判据）[原文证据] p.45。
- 搜孔策略对比（硬数据）：
  - 阿基米德螺线盲搜：`r = a + bθ`，取 `a = 0.001`、`b = 0.0004`、每 **10°** 一点、步距约束 `2πb < 2(R_hole − R_shaft)`；实测 **207 步**找到孔 [原文证据] p.44-45。
  - MLP 搜孔：输入 `Fx/Fy/Mx/My`，输出 up/down/left/right 四分类，单隐层（4 输入、5 隐单元）softmax；测试集平均准确率 **79%**（类别 1 最好 88%）；实测 **35 步**找到孔，比盲搜少 5.8 倍；另有 3 组随机初始位姿全部成功 [原文证据] p.44-47。
- 插孔阶段的判据：接触瞬间靠力突变进入力控；之后"各方向力/力矩被减小到 0 附近"即认为轴孔法线对齐，再进入插入 [原文证据] p.51。
- 误判率：MLP 分类有准确率（79%）；**状态机本身的误判率未统计** [原文证据] p.46、p.51。

### 4.3 柔顺控制：导纳还是阻抗？参数与稳定条件
- 类型：**基于位置的阻抗（即导纳）**，明确写"力外环输出位置指令给机器人控制系统，易于在传统工业机器人上实现"；实现方式是把力误差转成**速度修正值**交由末端速度环 [原文证据] p.28-29。
- 控制律（后向差分，式2.22~2.23）：
  `Fd − F = Md(V̇d − V̇) + Bd(Vd − V)`，离散为
  `ΔV(k) = [ΔF(k)·T + Md·ΔV(k−1)] / (Md + T·Bd)`，`Kd` 被**显式省略**（"牵引示教与轴孔装配不需要存储能量"）[原文证据] p.29。
- **参数数值（可直接作为我们的起点）**：
  - 跟随示教：`Fd = 0`、`Kd = 0`、`Bd = [160,160,160,16,16,16]`、`Md = 0.008`（六维同值）、`T = 0.008 s` [原文证据] p.30。
  - 插孔：`Fd = [0,0,15,0,0,0]`（Z 向 15 N 压入）、`Bd = [150,150,150,25,25,25]`、`Md = 0.008`、`Kd = 0` [原文证据] p.50。
  - 对比组（普通阻抗）：`Bd = [500,500,500,50,50,50]` [原文证据] p.65。
- **稳定条件（本文给了判据形式）**：把环境刚度 `Ke`、滤波时间常数 `Tf`、延迟 `Td`、上升时间 `TR` 一起写进闭环传递函数 `Φ(s)`，用**劳斯判据**选 M、B；并推出稳态误差
  `e_ss = Fd·B/(B + Ke)`（式3.4，OCR 有残损）[原文证据] p.35-36。
  含义：`Ke ≫ B` 时 `e_ss → 0`，所以位置型阻抗**不需要积分项**也能零稳态力误差 [分析推断] —— 这解释了为什么本批六篇里五篇都不用 PI。
- 学习改进：模糊 Q-learning 学六维阻尼（离散动作 `[50, 75, 100]`、5 个模糊集、学习率 0.3、折扣 0.5、**160+ 回合**），目标插入深度 36 mm、最大 50 步 [原文证据] p.64-67。

### 4.4 实验口径（次数 / 扰动 / 失败样本）
- 搜孔：螺线 207 步、MLP 35 步、3 组随机初始位姿（全成功）[原文证据] p.45-47。
- 插孔：模糊 Q 优化后**测试 25 次，成功率 100%**；对比未优化阻抗（同初始 6° 偏差）[原文证据] p.65。
- 扰动（最关键的口径）：初始终端姿态**绕 X 旋转 6°**（两者都能完成）与 **15°**（普通阻抗"无法在有限步数内完成"，学习后可完成）[原文证据] p.65-66。
- **力峰值**：1 mm 间隙、姿态误差存在时，接触瞬间 **Fz 达 76 N**，阻抗介入后各向力/力矩降到 0 附近 [原文证据] p.51 —— 这是本批文献中最有价值的"硬碰"数字。
- 失败样本：15° 偏差下普通阻抗失败 1 类，未给失败次数；学习后的 25 次没有失败案例 [原文证据] p.65-66。

## 5. 证据强度
- 真机 vs 仿真：**真机**（UR5 + ATI MINI45），全部实验在实机 [原文证据] p.51、p.65。
- 基线公平性：学习法 vs 固定阻抗，同一初始位姿（6°/15°）对比，基线设置公平 [原文证据] p.65。
- 次数：25 次（插孔）、3 组（搜孔随机位姿）、207/35 步（单次但可复现）；标定实验只给了"补偿后稳定在 0 附近"的曲线，**未给残差数值** [原文证据] p.29。三者中 25 次 + 成功率是本批最规范的口径 [分析推断]。
- 统计口径：报成功率但**未报失败次数与重试**；"100% 成功"的分母是 25 次测试，训练回合不计入。
- 未做消融：标定精度、导纳参数、MLP 搜孔三者对最终成功率的贡献未分离。

## 6. 最脆弱的 1–3 个假设
1. **安装偏移只有绕 Z 的 θ**（作者明说，式2.9）。分类：**范围内反例**——实际法兰加工与装配会有绕 X/Y 的倾斜，作者假设 Z 轴共线；我们若用加工件，必须验证这一条或扩成 3 自由度。
2. **Kd = 0 足够**（作者明说"不需要存储能量"）。分类：**范围外迁移限制**——Kd=0 意味着没有位置刚度，接触后会"漂"；对 7 kg 工件 + 371 mm 深插入，Kd=0 会让位置在重力下有静态偏移。
3. **MLP 四分类够用**（作者明说 79% 准确率可满足）。分类：**尚未测试**——四分类假设姿态误差可忽略；我们 371 mm 深度下姿态误差是主导，四分类不够。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **12 参数一次最小二乘标定（最值得迁移的一条）**：用 15–20 个不同姿态（覆盖 J2/J3 俯仰与小幅 J4/J6 转动，避开 J4 抱闸受限的大幅腕部旋转），采"无接触"数据，线性 LS 一次解出：`G, θ, Fx0, Fy0, Fz0, 质心(x,y,z)`（可扩展成 3 自由度安装角）。验收：15 姿态下补偿后 |F| < 1 N、|M| < 0.2 N·m；重复上电 30 min 漂移 < 0.5 N；标定脚本可一键重跑（记录每次的 G 与质心，监控抓取变化）。
2. **导纳参数从 `Md = 0.008、Bd = 160/16、Kd = 0、T = 0.008 s` 起调**：我们的链路慢（RS485 + MoveIt），应把 T 放大到实测控制周期、把 Bd 同比放大（`Bd ∝ 1/T` 量级），先保证不振荡再加 Kd（Kd = 0 的静态偏移问题用"插入段速度前馈"补偿）。验收：撞墙实验（固定平面）超调 < 20%、稳态力误差 < 2 N、无持续振荡。
3. **几何判据与力判据组合**：搜孔成功用"Z 插入深度 > 3 mm"这种几何判据，避免纯力判据误判；插孔完成再用"到达目标深度 + Fz 上升"双条件。验收：10 次装配的判据与人工标注一致率 ≥ 9/10。

## 8. 与本课题现有路线的冲突点
- **与"视觉引导 + 站位表"的冲突**：本文用**力觉搜孔**补视觉的毫米级误差（并明说"视觉有盲区，所以主要用力觉"），我们的主线是"用站位表把视觉误差降到足够小，再位置插入"。两者是替代关系：若站位表能把横向误差压到 < 1 mm，搜孔阶段可以省掉；若压不到，就必须加本文的搜孔（35 步），这会显著增加节拍（每步 1 mm + 力稳定等待）。
- **与误差链的冲突**：本文的 15° 偏差实验说明"**姿态误差 > 某阈值后，位置型阻抗在有限步内无法收敛**"；我们的误差链里姿态误差经 371 mm 放大，必须把这个阈值算出来并写进误差链的判据（否则"视觉精度够用"的结论可能只在浅插入时成立）。
- **与执行接口的冲突（最硬）**：位置型阻抗要求**高频下发位置/速度增量**（本文 125 Hz 速度环）。我们的 CS625 走 MoveIt 轨迹执行，若没有 ServoJ/实时位置流接口，导纳只能"分段重新规划"，等效控制周期会从 8 ms 掉到几百 ms，本文参数**不可直接移植**，必须重算 Bd。
- **"视觉失效时力觉能否接管"的可检验设计**：
  - 实验 A（标定残差 → 阈值下限）：静止 + 15 姿态扫掠，量补偿后 σ_F；判据：σ_F < 0.5 N，且死区取 4σ 时误触发 0/10000 帧。
  - 实验 B（导纳带宽）：固定平面撞墙，用 8/20/50/100 ms 四种等效周期跑同一 Bd，测超调与稳态误差；判据：找到"不振荡的最大 Bd"，作为我们平台的导纳上限。
  - 实验 C（偏置分档接管）：视觉偏置 0.5/1/2/3 mm 四档 × 10 次，切断视觉后仅力觉插入 50 mm；判据：≤ 1 mm 档 ≥ 9/10 且峰值 < 30 N（本文 76 N 是反例，说明没控好的代价）。
  - 实验 D（姿态阈值）：0.2°/0.5°/1°/2° 四档倾角，看固定阻抗何时开始"有限步内无法完成"；判据：给出 θ_crit，并与误差链算出的 θ 比较。
