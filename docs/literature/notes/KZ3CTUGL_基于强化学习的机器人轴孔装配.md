## 2. 一句话结论与相关性
- 一句话：**把导纳控制器做成 DDPG 的"动作空间载体"——M 与 K 固定、只用 DDPG 在线输出虚拟阻尼 B**，奖励里叠一层模糊惩罚；在真机 UR10 上对 **5 种孔径（φ11.0~φ14.0 mm）** 各训到收敛（所需回合 8~58 次），测试 **每种孔 30 次、成功率 100%、7~10 步完成**；定参数导纳同样工况需 **28 步**（[原文证据] PDF p.9–10）。
- 相关性分类：**直接对象证据 + 方法迁移**（本批与本课题第 5 章"导纳参数整定"最贴合的一篇）。理由：它就是"位置型导纳 + 只整定阻尼 + 真机"的组合，输出量正是我们缺的"参数整定"环节，而且**不需要力矩命令接口**。
- 影响本课题的具体决定：**柔顺参数**（M/K 固定的取法与 B 的调节范围，可直接当我们的初值网格）+ **验证方式**（"步数"作为主指标，比力曲线更易复现）+ **安全约束**（力/力矩/步长/速度四重限幅，是本批写得最具体的一组数字）。

## 3. 对象与任务
- 机器人：**UR10 六自由度**；力传感器 **南宁宇立 M4313M2B 六维力**，**读取频率 1 000 Hz**；夹爪 **Robotiq 2F-85 二指**（[原文证据] PDF p.8）。→ **1 kHz 力采样与我们坤维 KWR75 的 1 kHz 完全同档**，这是本篇对我们最有参考价值的一点。
- 装配对象（两种轴）：
  - 钢轴：**直径 10.0 mm、长 35.0 mm**，由二指夹爪夹持；从力传感器受力面到轴末端**约 23.5 cm**（[原文证据] PDF p.9）；
  - 铝合金轴：**直径 10.0 mm、长 40.0 mm**，直接固定在力传感器受力面（[原文证据] PDF p.9）。
- 孔：3D 打印树脂实验台，孔直径分别为 **14.0 / 13.0 / 12.0 / 11.5 / 11.0 mm**（[原文证据] PDF p.8 图 10(b)、p.9）。
- 间隙：直径差 4.0~1.0 mm ⇒ **单侧间隙 2.0 / 1.5 / 1.0 / 0.75 / 0.5 mm**（[分析推断]，按 (D−d)/2 换算）。→ **φ11.0 mm 孔（单侧 0.5 mm）比我们 1–2 mm 单侧间隙还要紧 2~4 倍**。
- 初始姿态误差：φ11.0 mm 孔初始角度差**约 10°**，其它孔**约 15°**（[原文证据] PDF p.9）。
- 精度/完成判据：**轴插入深度 ≥ 30 mm 即完成装配**（[原文证据] PDF p.9）。**未报告**角度/位置精度阈值。
- 轴质量、孔深、摩擦系数、材料硬度：**未报告**（只有"钢"/"铝合金"与树脂台）。
- 环境：普通实验室；无洁净度/空间限制描述。

## 4. 方法与机制链
- 主链：`六维力 F/M + 末端姿态 θx,θy + 插入深度 h（8 维状态）→ DDPG Actor → 3 个虚拟阻尼参数 [b1,b2,b3] → 导纳控制器 H(s)=1/(Ms²+Bs+K)（Tustin 离散）→ 末端位姿修正量 ΔX → UR10 位置指令 → 接触力 → 模糊奖励 + 完成奖励 + 超力惩罚`（[原文证据] PDF p.5–7）。
- **RL 到底学什么（本批必答 1）**：**学的是导纳参数中的虚拟阻尼 B（3 维连续），M 与 K 固定不变**。原文："装配过程中，令**虚拟惯性参数和虚拟刚度参数为常数**，采集机械臂末端受力信息和末端位姿信息作为强化学习输入，进而**在线辨识虚拟阻尼参数**"（[原文证据] PDF p.6）。动作定义：`a_t = [b1, b2, b3]`，其中 b1 对应 x、y 轴平移，b2 对应 z 轴平移，b3 对应绕 x、y 轴旋转（[原文证据] PDF p.6 式 16）。
- **状态（必答 2）**：`s_t = [F_x, F_y, F_z, M_x, M_y, θ_x, θ_y, h]`，**8 维**；F、M 为六维力传感器读数（**单位 N 与 N·m**），θx、θy 为末端绕 x、y 的旋转角（参考系为基坐标系），**h 为插入深度，单位 mm**（[原文证据] PDF p.6 式 17）。→ **状态里没有图像、没有历史帧**；**没有速度项**。
- **奖励（必答 2）**：`r = r1 + r2 + r3`（[原文证据] PDF p.7 式 20）：
  - `r1 = k·(1 − n/n_max)`：仅装配成功时可获得（判据 = 轴插到目标位置 + 接触力不超上限 + 在最大步数内完成），n_max 为给定最大步数、k 为奖励系数（[原文证据] PDF p.7 式 21）；
  - `r2`：接触力过大时的**负奖励，为一个定值**，且其绝对值"要大于执行 n_max 步探索时每一步的负奖励值之和"；未超限则为 0（[原文证据] PDF p.7）；
  - `r3`：每步的负奖励，**由模糊奖励系统给出**——输入 h、Δh、F_max、M_max 四个变量，模糊语言均为 **[差, 较差, 正常, 较好, 好]**；系统为**两层**、共 **3 个模糊集、每个模糊集 25 条规则**；惩罚权重随插入深度变大而**减小**（[原文证据] PDF p.7 式 22 与图 8）。
  - **k、n_max、r2 的具体数值均未报告**。
- **安全约束/动作限幅（必答 2）——本批写得最具体**（[原文证据] PDF p.9）：
  - 力上限 **35 N**、力矩上限 **5 N·m**（超限即判失败并刹停）；
  - 步长限幅：z 负方向 **≤ 5 mm**、z 正方向 **≤ 2 mm**、横向 **≤ 1.0 mm**；
  - 末端位移**速度限 0.001 m/s**、**加速度限 0.005 m/s²**；
  - 位姿调整**最大步数 100 步**；
  - **对虚拟阻尼参数的变化范围做限制**（"为了保证导纳模型的稳定性"）：**B1 ∈ [0.01, 10]、B2 ∈ [0.02, 10]**（[原文证据] PDF p.9 表 1）。
- **是否残差结构（必答 3）**：**不是输出空间残差**——DDPG 直接给 B 的绝对值（经硬限幅），导纳控制器用这个 B 生成 ΔX。**也没有"ΔB 叠加在 B0 上"**的写法。[分析推断] 等效于"参数空间的绝对整定 + 区间限幅"，**输出侧残差幅度（mm）未报告**（因为不存在残差项）；可对照的幅度是**每步 ΔX 的上限 5 mm / 2 mm / 1.0 mm**。
- 导纳离散化：`H(s) = ΔX(s)/ΔF(s) = 1/(Ms² + Bs + K)`（式 10），用 **Tustin 变换 `s = (2/T)(z−1)/(z+1)`** 得差分式 `X(k) = (1/A)[T²F(k) + 2T²F(k−1) + T²F(k−2) − C·X(k−1) − D·X(k−2)]`，其中 `A = 4M + 2BT + KT²`、`C = −8M + 2KT²`、`D = 4M − 2BT + KT²`（[原文证据] PDF p.5 式 11–13）。**采样周期 T 的数值未报告**。
- M/B/K 的先验仿真（选参依据）：令 `B = 20 N·s/mm、K = 10 N/mm`，M 取 **0.02 / 0.2 / 2 / 20 / 50**，结论是"随着 M 的增大，超调增大、调节时间变长，而位置修正量基本不变…M 应该取较小的值"（[原文证据] PDF p.5 图 7）。→ 注意这里 B、K 的单位写成 **N·s/mm、N/mm**，与表 1 的 0.01~10 量级不一致（见 §5 冲突 3）。
- 改变的关键假设：把"导纳参数必须人工试凑"改成"**只让一个参数（B）在线变、其余冻结**"——[分析推断] 这把搜索维度从 3 降到 1（实际 3 个独立 B 通道），是它能在真机上只用 8~58 回合收敛的根本原因。

## 5. 证据强度
- 训练环境：**真机**（UR10 上直接训，无仿真环节）；DDPG 网络 Actor/Critic 结构为 `60-全连接-ReLU` × 若干层，输出层 tanh（[原文证据] PDF p.8 图 9）。
- 训练量：Table 1 给出 Actor 学习率 **0.005**、Critic 学习率 **0.005**、batch size **120**、经验池 **500**（[原文证据] PDF p.9 表 1）；**收敛所需回合数分别为 24、8、28、58、30 次**（对应孔径 14.0/13.0/12.0/11.5/11.0 mm）（[原文证据] PDF p.10）。→ 总 episode ≈ 148 次 + 测试 150 次。**训练墙钟时长未报告**。
- **真机成功率与试次（必答 4，本篇是数字最干净的一篇）**：训练完成后用**不加随机噪声**的模型重新测试，**每种孔径 30 次**（合计 **150 次**），成功率**均 100%**；完成装配所需步数：φ14.0 **7~9 步**、φ13.0 **7~9**、φ12.0 **7~9**、φ11.5 **8~10**、φ11.0 **8、9 步**（[原文证据] PDF p.10 表 2）。
- 失败样本：**训练阶段有**——"轴孔直径差越小，失败的次数越多"、随机探索下"一次错误的随机探索可能会造成整个装配过程的失败"、收敛时存在"装配成功"与"触发力值超限导致装配失败"两种情况（[原文证据] PDF p.10）。→ 但**收敛后测试阶段一次失败都没有报告**，失败率无法统计。
- 基线对比：**定参数导纳**在同一 φ11.0 mm 孔上，M、K 与变参数版相同，`B = [2.0, 2.0, 0.5, 0.5, 0.5, 0.5]`，**28 步**完成；变参数版 **8 步**（[原文证据] PDF p.10）。→ 步数 **8 vs 28（降 71%）**，这是本篇最硬的对照。
- 与文献对比：文[15] 用模糊 Q 学习在"轴孔直径差 1 mm"上 160 回合收敛、收敛后 26 步；本文在同样直径差 1 mm（φ11.0 mm 孔）上 **30 回合收敛、8 步**（[原文证据] PDF p.10）。
- **内部口径冲突（5 条，均可核对）**：
  1. **动作维数三处不一致**：先写"所用到的导纳控制模型的**阻尼矩阵由 5 个参数组成，对应机器人运动的 5 个动作**"（PDF p.6），接着写"因此 Actor 网络的输出是 **3 个**阻尼参数"（PDF p.6），最后式(16) 也是 3 维——5 与 3 同时出现且未解释。
  2. **b1/b2/b3 的物理对应写反了两次**：第一处"b1 对应…x 和 y 轴上的平移量，b2 为 z 轴上的平移量，b3 对应绕 x、y 轴的旋转量"；而上一段写的是"沿 x、y 轴运动的阻尼参数，绕 x、y 轴旋转的阻尼参数，和沿 z 轴运动的阻尼参数"（PDF p.6）——两处顺序不一致（第二处读作 b2=旋转、b3=z）。
  3. **表 1 只有 B1、B2 两个调节范围，但动作有 3 个 b**：`B1 ∈ [0.01,10]`、`B2 ∈ [0.02,10]`（PDF p.9 表 1）对应 3 维动作无法一一映射，**b3（旋转）用的哪个范围未报告**。
  4. **M/B/K 的单位在同一篇里两套**：先验仿真写 `B = 20 N·s/mm、K = 10 N/mm`（PDF p.5），而表 1 的 B 调节范围 0.01~10、K1 = 0.02、K2 = 2 **无单位**（PDF p.9）——量级差 3 个数量级以上，无法判断表 1 的单位是 SI 还是 mm 制。
  5. **"100% 成功率"的样本口径**：每孔 30 次、5 孔共 150 次，且是**去掉探索噪声后**的测试（PDF p.10）；而训练期的失败次数没有汇总，因此"100%"只代表"收敛后 150 次"，不代表整体可靠性。
- 结论：本批**真机成功率 + 步数对照最完整**的一篇（150 次 / 5 孔径 / 8 vs 28 步）。但**样本量偏小（每孔 30 次）**、**失败率不可统计**、**M/K/B 单位混乱**是硬伤。

## 6. 最脆弱的 1–3 个假设
1. **"只调 B、冻结 M 与 K 就够"**（作者明说，PDF p.6；**方法必需**）。分类：**范围外迁移限制**——它的轴只有 35~40 mm 长、φ10 mm、质量未报告；我们 7 kg 工件 + 371 mm 插入，等效惯量与重力矩完全不同，冻结 M/K 后 B 的可用区间会变窄，**是否仍存在一个"7~10 步"的 B 区间是未测的**。
2. **"插入深度 h 可以作为状态里的一个标量"**（作者明说，PDF p.6 式 17；**方法必需**）。分类：**范围外迁移限制**——h 在真机上如何获得，本文**未报告**（是编码器正解还是外部测量？）。我们 371 mm 深插时 h 的累积误差会直接影响模糊奖励的"深度惩罚权重"。
3. **"35 N / 5 N·m 就是安全上限"**（作者明说，PDF p.9；**方法必需**）。分类：**范围内反例**——树脂孔 + φ10 mm 钢轴、无质量说明；7 kg 工件下同样的 35 N 会产生完全不同的力矩分配，且我们的工件是金属模块（不可用"树脂台"的容差心态）。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **"只整定 B、M 与 K 冻结 + B 区间硬限幅"就是我们在 position 接口上最省事的做法**（PDF p.6、p.9）。**在我们这里怎么做**：保持现有位置型导纳的 M、K 不变，让策略只输出 **3 个 B 通道**（x/y 平移、z 平移、绕 x/y 旋转），把 B 限在 **[0.1×B_ref, 10×B_ref]**（比本文的 [0.01,10] 更保守，因为我们的负载大 10 倍以上）。**需要**：先用我们现有的 tight 段（0.005 m/s）实测 B_ref。**验收指标**：插入步数相比定参数基线下降 ≥ 50%，且力峰值 ≤ 我们的力阈值。
2. **四重安全限幅直接照抄并映射到我们的常量**（PDF p.9）：力上限、力矩上限、**z 向步长 −5 mm/+2 mm、横向 1.0 mm**、**末端速度 0.001 m/s / 加速度 0.005 m/s²**、**最大步数 100**。**在我们这里怎么做**：把"z 向步长 5 mm/2 mm、横向 1 mm"写成动作裁剪的常量，把"速度 0.001 m/s"与我们现有的 **0.005 m/s tight 段**做比较（本文比我们还慢 5 倍，说明这个量级是安全的）。**验收指标**：任何一次实验都不出现力/力矩超限。
3. **"模糊奖励"可以只抄其结构、不抄规则**：它的模糊系统输入是 h、Δh、F_max、M_max，输出惩罚，且**惩罚权重随深度变大而减小**（PDF p.7）。**在我们这里怎么做**：把 R_T 改成"随插入深度衰减的力惩罚"——`w(h) = w0·(1 − h/H)`（H = 371 mm），力项用 KWR75 的 F_x、F_y 与 M_x、M_y。**验收指标**：深插段（后 1/3）的横向力均值比均匀权重方案下降 ≥ 20%。

## 8. 与本课题现有路线的冲突点
- **与"位置型导纳"完全一致，不冲突**：本文导纳输出就是**末端位姿修正量 ΔX**，再交给 UR10 的位置指令——这正是我们的接口形态（[原文证据] PDF p.5、p.6）。→ **本篇是本批唯一"照抄就能落地"的一篇**。
- **与"ros2_control 只有 position 命令"不冲突**：它全程只用位置修正量，没有力矩命令。→ 但**注意**：它的底层仍是 UR10 自带的位置/速度伺服，末端速度 0.001 m/s 这种极慢速度能否被我们的 `MAX_JOINT_SPEED_RAD_S = 0.10 rad/s` 重定时保留下来需要实测（[分析推断]）。
- **与"1 kHz 力"一致**：本文力读取 1 000 Hz（PDF p.8），但正文**没有给导纳环的控制周期 T**，也没有给"1 kHz 力 → 多少 Hz 位置修正"的降采样关系——这是我们必须自己补的关键参数。
- **与"7 kg 工件 / 371 mm 深插"的量级冲突**：本文轴 35~40 mm 长、深度判据 30 mm，我们 371 mm 是它的 **12 倍**；本文的"7~10 步完成"在我们这里不可能，**必须换成"分段 + 每段步数"** 的指标。
- **与"必须给安全约束"的纪律一致**：本文是本批唯一把力、力矩、步长、速度、加速度、最大步数六项都写出来的论文，可直接作我们的约束模板。
