## 2. 一句话结论与相关性
- 一句话：把含能部件轴孔装配拆成"接近/一点/两点/三点/边"接触状态与"推动/螺旋对齐/摆动/拧"四种力原语，用力阈值状态机驱动，底层用**基于位置的阻抗（导纳）**、上层用强化学习在线调阻抗；Kinova 臂上无/有外界干扰各做 1 次装配，**接触力峰值控制在 20 N 以内**，但**未用真实含能部件、未统计成功率**。
- 相关性分类：**方法迁移**（接触状态机判据、力噪声统计与卡尔曼观测器、阻抗稳定条件与 K/B 量级、安全力上限口径）。
- 影响本课题的具体决定：**接触切换**（判据是"突变"而非绝对值）、**柔顺参数**（K/B 量级与稳定条件）、**验证方式**（力峰值作为安全指标）。

## 3. 对象与任务
- 对象：含能部件（圆柱体，简化为**无倒角轴孔装配**），孔与轴间隙"非常小"，装配公差要求低/精度要求高 [原文证据] p.15-17。
- 几何量：间隙比 `c = (D−d)/D`；一点接触插入深度与倾角关系 `l·θ ≈ 2(R−r) = cD`（式2-6）[原文证据] p.18-19。
- 安全约束：含能部件"对压力极其敏感，易碎易变形"，必须把接触力约束在安全范围内 [原文证据] p.15、p.73。
- 机器人/传感：Kinova 6 DOF（装配实验）+ Reinovo 6 DOF（力控实验）；六维力/力矩传感器 TCP/IP，**采样 1 kHz**；运动控制卡与工控机 TCP/IP **100 Hz**；工作站跑学习算法 [原文证据] p.92。
- 视觉：Kinect 深度相机 + 点云分割做粗定位（第 3 章）[原文证据] p.50-69。
- 装配精度要求/间隙具体数值：**未给出 mm 级数值**，只有"间隙非常小"与间隙比 c 的符号表达 [原文证据] 检索无具体 mm 值。

## 4. 方法与机制链
`六维力 → 卡尔曼接触力观测器（去噪+去重力） → 力阈值状态机判接触状态 → 四原语（推动/螺旋/摆动/拧）下的期望力/力矩 → 位置型阻抗把力误差转成位置增量 → 关节执行`

### 4.1 六维力如何接入（采样 / 滤波 / 零漂 / 重力补偿 / 工具偏心）
- 采样：传感器 **1 kHz**（TCP/IP），运动控制卡 **100 Hz**，**柔顺控制周期 20 ms** [原文证据] p.92-93。三者不匹配，本文用观测器补。
- **噪声统计（本批六篇里唯一做了完整噪声标定的，[分析推断]）**：对原始力信号做 FFT 幅频、周期图功率谱、核平滑概率密度，结论是"功率谱在整个频域均匀分布、幅值近似高斯" ⇒ 高斯白噪声；六通道分布参数（原文表述为 `N(0, σ)` 形式）：`Fx N(0,0.0050)`、`Fy N(0,0.0018)`、`Fz N(0,0.0012)`、`Mx N(0,0.0123)`、`My N(0,0.0331)`、`Mz N(0,0.0041)` [原文证据] p.76-78 表5-1 → [待验证设想] 单位与"σ 还是 σ²"原文未标清（见 §9）。
- **滤波**：用**卡尔曼滤波接触力观测器**，状态 12 维（力/力矩及其导数），量测 6 维，式5-8~5-13；滤波后"噪声干扰明显降低"[原文证据] p.77-78 图5-7。
- **零漂**：模型式5-1 只写了 `测量 = 接触力 + 惯性力 + 重力`，**没有单独的零漂项**，也没有零漂标定实验 [原文证据] p.74。
- **重力补偿**：牛顿—欧拉式，`F_ec = F_sc − m·g_c`、`M_ec = S(r_cs)F_sc + M_sc − S(r_ce)F_ec`（式5-4/5-5，S(·) 为斜对称算子，r_cs 为质心→传感器向量，r_ce 为质心→接触点向量）[原文证据] p.74。
- **工具偏心**：上式里的 `r_cs/r_ce` 就是偏心臂，但**没有给辨识方法**；实测只做了"抓取后沿 Z 上抬一小段，用力变化估工件重力"，得**7.9 N** [原文证据] p.124 —— 这是"标定单参数"的做法，不是完整偏心辨识。
- 死区：未给统一死区，只在学习过程中通过奖励函数避开过大接触力 [原文证据] p.84-93。

### 4.2 接触阶段如何划分/识别
- 接触状态用**拓扑主接触/基本接触**描述：面—面、面—边、面—点、边—边，退化接触（点—点等）排除 [原文证据] p.16。
- 装配过程 5 状态：接近、面—面接触、两点接触、三点接触、边—边接触（图2-22）[原文证据] p.29。
- 三层判据（都是**突变/趋势**，不是绝对方值）：
  - 接近→接触："Z 向接触力超过一定阈值"即判接触（**具体阈值数值未给**）[原文证据] p.34。
  - 落孔："Z 向接触力**突然减小**"且 X/Y 方向"不能移动" ⇒ 轴已落入孔 [原文证据] p.34、p.124。
  - 到底："Z 向接触力**突然增大**"且位置满足 `p_z = Λ + λ`（Λ 孔深）⇒ 插入完成 [原文证据] p.34、p.125。
- 三点接触被明确指认是"稳定的局部极值状态"，**必须靠外力矩打破**（摆动 + 拧）[原文证据] p.32-33。
- 误判率：**未统计**；只给了"无/有干扰两次都成功"的定性结果 [原文证据] p.121-127。
- 防卡死判据（解析，可复用）：楔紧条件 `|θ| < θ_w = c/μ`（式2-23）；卡阻条件式2-24/2-25（含 M/(rFz) 等项）[原文证据] p.28 → [待验证设想] 式2-23 经 OCR 显示为 `c/μ`，需回原文核对（见 §9）。

### 4.3 柔顺控制：导纳还是阻抗？参数与稳定条件
- 类型：**基于位置的阻抗 = 导纳**（明说"适用于工业机器人的方式是导纳控制，也叫基于位置的阻抗控制"），因为工业臂不开放关节力矩接口 [原文证据] p.80-81。
- 阻抗模型：`Md(Ẍc−Ẍd) + Bd(Ẋc−Ẋd) + Kd(Xc−Xd) = Fd − Fe`（式5-14）[原文证据] p.79。
- 离散实现：双线性变换 `H(z) = H(s)|_{s=2(z−1)/(T(z+1))}`，给出 ω1..ω4 与 `T` 的关系及位置增量递推式（式5-22~5-24）[原文证据] p.81。
- **稳定条件（本文唯一给出解析稳定判据的一篇）**：把环境等效为弹簧—阻尼 `Fe = Be(Ẋm−Ẋe) + Ke(Xm−Xe)`，代入后得二阶系统
  `ωn = √((Kd+Ke)/Md)`，`ζ = (Bd+Be) / (2√((Kd+Ke)·Md))`（式5-29）；
  且稳态力跟踪误差为零的条件是参考位置收敛到 `Xd → Xc = Xe + Fd/Ke`（式5-27）[原文证据] p.81-82。
  含义：**环境刚度 Ke 变化会直接改变 ωn/ζ**，所以固定阻抗参数在换环境后必然失稳或迟钝 —— 这正是它做变阻抗的动机。
- **实际 K/B 数值（学习得到的轮廓）**：表5-6 给出第 20 次学习的四个阶段关键状态，`Kd` 在 **2.379–8.468**、`Bd` 在 **588.97–673.83** 之间变化（原文表头单位标注为 `Kd/N·m⁻¹`、`Bd/N·s·m⁻¹`，OCR 不清）[原文证据] p.104 → [待验证设想] 量级上对应约 2.4–8.5 N/mm 与 589–674 N·s/m，需回原文确认单位。
- 学习变阻抗（ELVIC）：强化学习 + 高斯过程模型，20 次学习、2 次迭代（约 6 s 交互）即可完成力跟踪 [原文证据] p.104-105；"仅需不到十次学习"、"学习速度提高十倍"为其自述创新 [原文证据] p.129-130（**无第三方复现，属作者自评** [分析推断]）。

### 4.4 实验口径（次数 / 扰动 / 失败样本）
- 无外界干扰装配 **1 次** + 有人为干扰装配 **1 次**（干扰方式：人手在趋近过程中阻碍机械臂）[原文证据] p.121-127。
- 硬指标：两次装配的**接触力峰值均 < 20 N**；抓取后上抬测得的部件重力 7.9 N [原文证据] p.124-127。
- **成功率、重复次数、失败样本：全部没有**；作者在结论里自述"由于实际条件限制，并未对实际的含能部件进行装配实验"[原文证据] p.130。
- 力控实验（非装配）：弹簧/绳子组合体作环境，20 次学习对比自适应阻抗等方法 [原文证据] p.103-105。

## 5. 证据强度
- 真机 vs 仿真：**真机**（Kinova + Reinovo 两套），但装配只各 1 次，属"演示级"[原文证据] p.121。
- 基线公平性：力控实验里与"自适应阻抗控制"等方法做了对比曲线，但未给统计算法/次数 [原文证据] p.105-106。
- 次数：装配 2 次；力控学习 20 次迭代；噪声统计用多段数据但未报样本长度 [原文证据] p.76-78。
- 统计口径：把"演示成功"当结论，**没有分母**；20 N 的上限是有价值的量化口径，但只有两个样本支撑。
- 仿真/硬件：视觉定位与示教部分有实验，装配部分未用真实危险部件（作者自认的最大局限）。

## 6. 最脆弱的 1–3 个假设
1. **力传感器噪声是平稳高斯白噪声**（作者用 FFT/功率谱/概率密度"证明"）。分类：**范围内反例**——该结论是在静止/准静态下测的；装配接触瞬间的冲击、RS485 链路的丢帧都不是平稳白噪声，卡尔曼增益会失配。
2. **接触状态可由"力突变"唯一确定**（方法必需）。分类：**尚未测试**——摩擦、爬行、速度变化都会造成 Fz 突变，本文没给误判率。
3. **学到的最优阻抗可迁移到真实含能部件**（作者隐含）。分类：**范围外迁移限制**——作者自己声明未做真实部件实验。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **先做噪声标定，再设计阈值与观测器**（照它的三件套：FFT 幅频 → 功率谱 → 幅值概率密度）。在我们这里：静止 60 s、空载/带 7 kg 工件各一段，4800 组，算出六通道 σ；再决定用不用卡尔曼。验收：给出六通道 σ 表 + 阈值 = 4–5σ 的推导过程；静止误触发 0/10000 帧。
2. **四原语动作库（推动/螺旋对齐/摆动/拧）**：把它当"插入阶段的行为字典"，而不是整套策略。我们最可能需要的是"推动 + 微摆动"；"拧"（绕插入轴往复转）可显著降摩擦，但**受 J4 抱闸与手腕 ±45° 电缆限制**，必须先做可达性筛查。验收：在 MoveIt 里对 371 mm 深度末端位姿做 ±1° 摆动与 ±5° 拧的 IK 检查，能解的位姿占比 ≥ 90% 才纳入策略。
3. **安全力上限的量化口径**：不要写"小于某值"，而写"每次装配记录峰值，并在 N 次内峰值 P99 < X N"。本文的可比数是 20 N（轴孔、含能件、无倒角）。验收：我们给出 7 kg 工件 + 1–2 mm 间隙下的峰值分布（至少 10 次），并说明上限怎么定（材料/工装允许力 + 4σ）。

## 8. 与本课题现有路线的冲突点
- **与"视觉引导 + 站位表"的冲突**：本文的接触状态机在**视觉粗定位已把轴送到孔上方**之后才启动（趋近阶段靠视觉），这和我们的"视觉 + 站位表"是同一分工；冲突在于它把**姿态完全交给力**（摆动/拧），而我们的姿态由视觉+CAD 给到 0.078°，若再叠一层力觉摆动，可能把已经对齐的姿态打乱。所以力觉只应做**平移微调 + 极小幅姿态修正**（≤0.2°），不能照搬 ±5° 摆动。
- **与误差链的冲突**：本文证明"三点接触是稳定局部极值"，意味着**误差链里那部分残余横向误差无法靠推力自愈**，必须靠旋转动作打破；这会在误差链中增加一个"需要主动动作才能消除"的误差项，不能简单按线性传播处理。
- **与硬件限制的冲突（最硬的一条）**：371 mm 插入深度下，末端 0.1° 摆动 = 0.65 mm 横向偏移；本文的"摆动"原语在短插入深度（其轴孔装配插入深度未给，但含能件尺寸小）成立，在 371 mm 深槽里**摆动会在槽底放大成干涉**。这是本文方法在我们平台上最大的不可迁移点 [分析推断]。
- **"视觉失效时力觉能否接管"的可检验设计**：
  - 实验 A（突变判据误判率）：录制 100 段插入（含失败），人工标注"落孔/到底/卡住"三类，用其"力突变"规则离线判定；判据：误判率 < 10%，且"卡住"与"到底"不混淆。
  - 实验 B（深度放大效应）：在 100/200/371 mm 三个深度注入同样的 ±1° 摆动，测末端横向位移与 Fx/Fy 峰值；判据：若 371 mm 处 Fx 峰值 > 30 N，则摆动原语在该深度禁用。
  - 实验 C（力觉接管成功率）：视觉偏置 ±2 mm 后关闭，仅"推动 + 微调"完成最后 50 mm；判据：≥ 8/10 且峰值 < 20 N。
