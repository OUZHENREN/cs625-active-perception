## 2. 一句话结论与相关性

- 影响本课题的具体决定：**观测动作/规划时间预算**（候选视角与接近路径的采样效率）、**验证方式**（对比表必须写清迭代预算）、**可达性**（椭圆采样的适用前提是"已有初始可行解"）。

## 4. 方法与机制链（本批重点：采样/约束/评价）
- **GR-ConvNet（抓取位姿预测）**：生成式残差卷积网络，输入 RGB-D，输出 4 张图（抓握质量、角度、宽度、抓握表示）；结构为 3 个卷积层 + 5 个残差层 + 卷积转置层；**共 19,900 个参数**；作者称"比其他网络计算和预测速度更短更快" [原文证据] p.2–p.3（印 p.114–115，图 2）。
- **规划四段机制（可复现）**：
  1. **自适应采样函数**（式 1）：`X_rand = x_rand`（rand < 0.25，在起点周边 1/4 采样空间内采）或 `X_Goal`（rand ≥ 0.25）；"当随机树长度超过 1/4 个采样空间时，直接将随机采样点设置成目标点，直至采样点与目标点距离进入阈值范围，停止采样，生成初始路径" [原文证据] p.3（印 p.115）。
  2. **椭圆子集直接采样**：`X_ellipse = L·X_ball + X_centre`（式 2），`X_centre = (X_Start+X_Goal)/2`（式 3），`L·Lᵀ = S`（式 4，Cholesky），`S = diag(c_best²/4, (c_best²−c_min²)/4, …, (c_best²−c_min²)/4)`（式 6），故 `L = diag(c_best/2, √(c_best²−c_min²)/2, …)`（式 7）；旋转 `C = U·diag(1,…,1,det(U)det(V))·Vᵀ`（式 8），由 `M = UΣVᵀ`、`M = a₁⊗l₁`、`a₁ = (X_Goal−X_Start)/‖X_Goal−X_Start‖₂` 给出（式 9–11）；最终 `x_f = C·L·X_ball + X_centre`（式 12）[原文证据] p.3–p.4（印 p.115–116）。→ **这是 Informed-RRT\* 椭圆采样的完整闭式实现**，比"拒绝采样"省算力，是我们最值得抄的一段。
  3. **贪心去冗余**：从首节点起逐个做碰撞检测，若 `P₁` 与 `P_k` 无碰撞则中间的 `P₂…P_{k−1}` 全判冗余删除 [原文证据] p.4。
  4. **三次 B 样条平滑**：以去冗余后的路径点为控制点，`P(t) = Σ P_i B_{i,3}(t)`，给出显式基函数（式 16）与矩阵形式（式 18）[原文证据] p.4（印 p.116，式 13–18）。
- **约束怎么建**：**基本没有**。全文只提"无碰撞"与"三次 B 样条保证曲率连续"，**没有关节限位、没有速度/加速度约束、没有动力学约束**、没有可达性判据（不判 IK）。→ 这是我们与它最大的距离：我们的插入链有 0.005 m/s、25°/段、0.10 rad/s 三条硬约束，它一条都没有。
- **碰撞怎么判**：**未描述**（只写"检测新的路径是否与环境中的障碍物发生碰撞"），没有包络体、没有安全距离、没有检测库 [原文证据] p.3。
- **评价指标**：Time（s）、Path length、Iterations，**N = 50 次/算法/环境**（表 1）；ROS 里只比了 1 条轨迹长度；真机只看"能否抓到"。
- 机制链：`RGB-D → GR-ConvNet → 抓取位姿（质量/角度/宽度）→ 逆解到关节空间 → GI-RRT* 规划（自适应采样→椭圆采样→去冗余→B 样条）→ FR3 执行 → 柔性夹爪抓取`。

## 5. 证据强度（含本笔记复算）
- **表 1（2D 仿真，50 次/算法）** [原文证据] p.5（印 p.117）：
  - 简单环境：RRT 10.354 / 718.618 / 0；RRT* 33.928 / 593.082 / 1500；Informed-RRT* 31.884 / 592.636 / 1500；GI-RRT* **13.114 / 555.946 / 800**
  - 复杂环境：RRT 20.96 / 1010.388 / 0；RRT* 13.228 / 890.88 / 1500；Informed-RRT* 15.718 / 894.25 / 1500；GI-RRT* **5.866 / 804.74 / 800**
- **本笔记复算（全部吻合）**：简单 555.946/592.636 = −6.19%、13.114/31.884 = −58.87%；复杂 804.74/894.25 = −10.11%、5.866/15.718 = −62.68%。→ 表内数字自洽。
- **对比公平性问题（最关键）**：GI-RRT\* 的迭代次数是 **800**，而 RRT\*/Informed-RRT\* 是 **1500**（表 1 Iterations 列）；**迭代预算不同**，"时间更短、路径更短"有一部分来自预算少一半，不能全部算作算法改进 [原文证据] p.5 + [分析推断]。此外 RRT 的 Iterations 记为 **0**（未记录或未达上限），说明各算法的终止条件并不统一。
- **统计口径**：只有**均值**，无标准差、无每环境分布、**无成功率**（正文只写"在两个不同的环境中算法都能成功规划出路径"，未给次数）；**无置信区间**；50 次试次对成功率类结论偏少（若 50/50 成功，95% 单侧下限 ≈94%）。
- **ROS 对比**：只给一条轨迹（1.314 vs 1.235 m），关节角/角加速度曲线（图 8）说明"更流畅"，**无数值指标、无重复** [原文证据] p.6。
- **真机**：仅定性——"机械臂可以成功预测物体的待抓取位姿"、图 9 展示抓取与避障过程、图 10 展示 3 类物体的抓取质量/角度/宽度图；**没有抓取次数、没有成功率、没有位姿误差** [原文证据] p.6–p.7。
- 结论：作为**采样算法的实现参考**可用（椭圆采样闭式、贪心去冗余、B 样条都有公式）；作为**性能证据**弱（迭代预算不对等、无成功率、无离散度）；作为**精度证据**为零（无任何误差内容）。

## 6. 最脆弱的 1–3 个假设
1. "2D/3D 地图上的收益可以外推到 6 轴关节空间" —— **方法必需**（2D 验证 + ROS 单次演示）。分类：**范围外迁移限制**。关节空间维度升高后椭球体积占比急剧下降，椭圆采样的收益会显著缩水；我们的 6 维关节空间 + 相机在 TCP 后 0.3 m 的干涉，比它的 2D 地图复杂得多。
2. "各算法在相同迭代上限下比较" —— **我的推断**：表 1 中 GI 800 次 vs 其他 1500 次，若把 GI 也跑到 1500 次，其路径可能更短但时间会长，"−58.87%"会缩水。分类：**范围内反例**（表内自证）。
3. "障碍物静态、已知且不随动作变化" —— **方法必需**。分类：**范围内反例**（我们的换位动作会改变遮挡与相机-工装关系，障碍布局随观测动作变化）。

## 7. 可迁移到本课题的具体做法（1–3 条）
以下三条是**尚未在本课题验证**的做法，其中"p95 时间 −30% 而成功率不降"属 [待验证设想]（椭圆采样在 6 维关节空间的收益需实测）。
1. **椭圆子集直接采样（式 6–12）直接实现进我们的候选/接近路径采样**：拿到初始可行解后，用 `c_best / c_min` 构造椭圆，闭式生成均匀样本，替代 OMPL 里的拒绝采样。需要：一个采样器（6 维，`c_min` 用起点-终点直线距离）。验收：同一场景 100 次规划，**p95 时间 −30%**、成功率不降（Wilson CI 下界不低于基线）；并记录 `c_best` 随迭代的收敛曲线。
2. **规划对比表必须写清"迭代预算 / 超时 / 试次"三列**：照它踩的坑（800 vs 1500），我们的对比表固定 `N=100`、相同 `max_iterations` 与超时，报均值±σ + 成功率 CI，任何"改进"必须在同预算下赢。验收：一张可复核的 6 列表（算法 / 预算 / 时间 / 路径 / 成功率 / 失败分类）。
3. **贪心去冗余 + 三次 B 样条只用于"预插入接近段"**：插入段必须直线 + 0.005 m/s 不能平滑。接近段用 B 样条后要检查末端速度 ≤0.03 m/s、jerk 无尖峰（否则进插入段前会激发振动）。验收：接近段末端速度 ≤0.03 m/s、插入段入口横向偏差 ≤0.2 mm。

## 8. 与本课题现有路线的冲突点
- **比我们的"误差链 + 蒙特卡洛 + 公差分配"更严谨的地方**：① **椭圆采样是闭式、可复现**的（式 6–12 给全，能直接写成代码），比我们"生成候选再筛"的流程更省算力；② 指标定义清楚、数字自洽（我复算全过）；③ 有 ROS + 真机的完整链路（虽然只定性），工程完整度高于纯仿真论文。
- **它不适用/不如我们的地方**：① **迭代预算不对等（800 vs 1500）**，提升幅度不可信；② **无成功率、无标准差、无置信区间**；③ **零误差/精度内容**——没有视觉精度、没有标定、没有补偿，对我们的误差链与公差分配没有任何输入；④ 无关节限位/速度/加速度约束，其"路径"不能直接执行；⑤ 2D 地图结论不能外推到 6 维关节空间；⑥ 真机抓取成功率未报，"能抓"与"抓得准"是两件事。
- **与"站位表选站"的关系**：它是"眼在手上 + 任意位姿"的抓取范式，我们的真实主线是"离散站位查表 + 交叉核对"。它的采样思路可用于"站位之间的过渡路径"，但不能替代站位决策。
- **与"三平面 + CAD ICP"的关系**：它用 GR-ConvNet 直接回归抓取位姿（端到端），我们用几何配准（可解释）。两者不是替代关系：端到端省事但给不出残差与置信度，而我们的公差分配需要残差。
- **与 7 kg / 371 mm / 1–2 mm 间隙的冲突**：它的柔性三指夹爪抓水瓶/剪刀/轮子，负载与精度要求与我们差两个量级；B 样条平滑后的路径末端速度不受限，进入 1–2 mm 间隙前必须减速到 0.005 m/s，这一条它完全没有。
