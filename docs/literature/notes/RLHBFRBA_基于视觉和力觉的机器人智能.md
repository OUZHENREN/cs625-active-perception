## 2. 一句话结论与相关性
- 一句话：在 **UR5（无关节力矩接口）+ OptoForce HEX-70-XE 六维力 + D435i** 上，用"**串联双卡尔曼滤波 + 极点补偿/重力补偿四参数标定**"把力测准（连续变姿态下极值差从 5.70/5.50/8.00 N 压到 **0.47/0.89/1.77 N**），再用**导纳控制（= 基于位置的阻抗控制，明确这么命名）+ 阿基米德螺旋搜孔 + 三档期望力（3 N → 2.5 N → 6.5 N → 2 N）**完成 **径向总间隙 0.4 mm、配合长 30 mm** 的轴孔装配，全程 **最大接触力 11.0205 N、最大力矩 0.3425 N·m，约 25 s** [原文证据] p.42–45、p.54–55、p.65–72。
- 相关性分类：**方法迁移**（最近的一篇同构：同为"无关节力矩接口的协作臂 + 外置六维力 + 导纳"，且它把"滤波/零漂/重力"三件事拆开做了实验）。
- 影响本课题的具体决定：**柔顺参数**（导纳结构的写法）、**定位要求**（视觉只做粗对齐、靠搜孔消化残差）、**验证方式**（用"最大接触力/最大力矩/总时长"三指标）。

- 相机/末端：Intel RealSense **D435i** + 因时电动夹爪；手眼为 eye-in-hand（左臂相机与夹爪同侧）[原文证据] p.23。

- 对象 B（作业任务）：同为树脂轴孔件，间隙 0.4 mm [p.68]。

## 4. 方法与机制链（Q1 六维力接入 / Q2 接触阶段 / Q3 柔顺类型）
- 链条：`视觉（YOLOv5 粗定位 / RANSAC 圆柱分割）→ 预装配点 → 导纳控制沿 −Z 下压至接触（F_d=3 N）→ 孔外阿基米德螺旋搜孔（F_d≈2.5 N）→ F_z 骤降判入孔 → 孔内调整（F_d=6.5 N）→ 末端力/力矩达标（F_d=2 N）→ 停` [原文证据] p.57–59、p.65–67、p.69。

### Q1 六维力怎么接入
- **采样率与通信周期：全文未给**（80 页内"Hz"0 次命中、无控制周期数值、无"控制频率"描述）→ [未定位]。可推的只有：传感器走以太网（RJ45）[p.22]，数据进上位机后参与 100% 由 Python/C++ 侧决定的循环（见 Q3）。
- **滤波（本文主贡献之一：串联双卡尔曼）**：
  - 观测事实：静止时 Z 轴力信号"极不稳定，最大差值可达 **4.6 N**"，幅频分析判为"含高斯白噪声、分布在全频段" [原文证据] p.42。
  - 结构：第 1 个经典 KF（状态方程 `x_k = x_{k−1} + w_{k−1}`、观测 `u_k = x_k + v_k`，式 4.1–4.4）；第 2 个 KF 专门处理有色噪声，对预测误差方差做指数加权 `P2_k = α1·P2_{k−1} + α2·q`（式 4.5）[p.42–44]。
  - **效果（表 4.1，原始数据极值差 4.6000 N）**：单卡尔曼 0.8685 N、**双卡尔曼 0.6051 N**、滑动窗口 0.8300 N、中值 1.3500 N；标准差 0.1471 / **0.1196** / 0.1468 / 0.1603 N；方差 0.0216 / **0.0143** / 0.0215 / 0.0257 [原文证据] p.45。
  - **未给**：过程噪声 Q/R 的取值、α1/α2/q 的取值 → 无法直接复现 [未定位]。
- **重力补偿与工具偏心（完整公式链，与 R3JVJZ7U 同构但多了一个"世界系倾斜角"）**：
  1. 世界系相对机器人基座有绕 x、y 的倾斜 θ、δ：`R_base^w = [[1,0,0],[0,cosδ,−sinδ],[0,sinδ,cosδ]]·[[cosθ,0,sinθ],[0,1,0],[−sinθ,0,cosθ]]`（式 4.6）[p.46]（原文两矩阵次序以式 4.6 为准）。
  2. 基座→传感器姿态 `R_s^base`（式 4.7，Z-Y-X 欧拉角 α/β/γ）；重力在传感器系 `g_s = R_s^base · R_base^w · [0,0,−G]^T`（式 4.8）[p.46]。
  3. 无接触时测量值 = 零点 + 重力：`F = f_0 + g_s`（式 4.9）；令 `a = [a_x, a_y, a_z]^T` 为重力在基座系的三分量（式 4.10），线性化成 `F = [R_s^base, I]·[a; f_0]`（式 4.11）→ 堆 n 组解 `(F^T F)^{-1} F^T …`（式 4.13）[p.47–48]。
  4. **工具偏心（力矩）**：`m_g = r_p × g`，即 `m_gx = g_y·p_z − g_z·p_y` 等（式 4.14）；把 `m_0` 并入后线性化成 `M = [F 阵, I]·[p; b]`（式 4.16–4.18）→ 最小二乘解**重心 p** 与常数 b → 再回代求**力矩零点 m_0**（式 4.19）[p.48–50]。
  5. 补偿与真实值：`F_c = f_0 + g`、`M_c = m_0 + m_g`（式 4.20）；`F' = F − F_c`、`M' = M − M_c`（式 4.21）[p.50]。
- **标定步骤（可照做，6 个位姿）**：① 只改 **Wrist1/Wrist2**，固定 Base/Shoulder/Elbow（表 4.2：Base −90°、Shoulder −85°、Elbow −115° 固定；Wrist1 ∈ {−70°, 20°, −160°}、Wrist2 ∈ {90°, 0°, 180°}）；② 每位姿"采集 **500 组**取平均值"作为标定数据（表 4.3）；③ 两段最小二乘 [原文证据] p.50–51。
- **标定结果**：**G = 2.424 N**、重心 **P = (−0.000085, 0.000296, 0.002776) m**（即质心几乎在传感器原点、下方仅 **2.8 mm**）、力零点 **f_0 = (4.4426, 0.2378, 5.1233) N**、力矩零点 **m_0 = (−0.0807, 0.2810, 0.0513) N·m** [原文证据] p.51–52。
- **补偿效果（这是本文最值钱的一组数）**：机器人以恒定低速连续变姿态、**不与环境接触**时，
  原始极值差 `[5.70, 5.50, 8.00, 0.070, 0.039, 0.026]` → 补偿后 `[0.47, 0.89, 1.77, 0.012, 0.011, 0.003]`（前三个 N、后三个 N·m）[原文证据] p.52。
- **零漂**：并入 f_0 一次标定；**无上电重零、无温漂漂移监测** [未定位]。

- **切换判据（唯一给了可执行判据的地方，但阈值是定性的）**：

  - 预装配接触：导纳控制以 **3 N** 期望力下压直至接触 [p.66]。
- **状态机**：4–5 态流程（图 4.18 / 图 5.2），**没有形式化状态机图、没有阈值表、没有漏报/误判统计** → **误判率：未给** [未定位]。

### Q3 柔顺类型：阻抗还是导纳？为什么？
- **结论：明确选导纳（admittance）= 基于位置的阻抗控制**，理由与我们一致（末端无关节力矩控制）：
  > "基于力的阻抗控制由于其对机器人动力学模型的精确性要求以及对**关节力矩控制功能**的依赖，应用范围受到显著制约。鉴于本文选用的 **UR5 协作机器人不具备关节力矩控制功能**，因此本文采用基于位置的阻抗控制策略…基于位置的阻抗控制**又称为导纳控制**。" [原文证据] p.54
- **导纳律**：`ẍ_e = M_d^{-1}(F_ext − B_d ẋ_e − K_d x_e)`（式 4.25，其中 `F_ext = F_d − F_e`），对 `ẍ_e` **两次积分**得修正位姿 `x_e`（式 4.26），再叠加到期望输入 `x_d` 得 `x_u` → IK → `q_u` [原文证据] p.55。
- **外环 5 个动作**：由当前关节角算位姿偏差与速度偏差 → 由力偏差算加速度偏差 → 积分得下一修正位姿 → 叠加 → 逆解 [p.55 图 4.9]。
- **M_d / B_d / K_d 数值：全文未给**（"Md/Bd/Kd"在 80 页内 0 次命中）→ [未定位]。**控制周期/频率：全文未给** → [未定位]。这是本篇最大的空白：**它给出了完整的导纳结构与真机效果，却没给任何一个能让别人复现的参数**。
- 可替代的"参数线索"只有期望力分档：3 N（接近）/ 2.5 N（搜孔）/ 6.5 N（插入）/ 2 N（末端调整）[p.66、p.69]。

## 5. 证据强度（Q4 实验口径）
- 试验类型：**真机**（双 UR5 + 六维力 + D435i + 电动夹爪），无仿真替代；视觉部分另有 YOLOv5 置信度 0.83 的检测结果 [p.70]。
- **试次**：力觉精确感知实验 1 组（连续变姿态）；柔顺示教 2 类（单轴推拉 + 螺旋线示教）；玻璃件装配 1 次；综合任务装配 1 次 [p.55–56、p.65–72]。**均无重复试次**。
- **间隙分档：只有 0.4 mm 一档**（径向总间隙），没有更小/更大档位对照。
- **成功率：未给数值**（只写"能够实现配合间隙为 0.4 mm 的轴孔柔顺装配""对于接触力与力矩的控制效果良好"）[p.72]。
- **力峰值/力矩峰值（给了具体数）**：装配过程**最大接触力 11.0205 N、最大力矩 0.3425 N·m**；全程控制在 **<12 N / <0.35 N·m**；"由于轴孔零件皆为树脂材质，能够承受更大的装配接触力，因此提高了调整阶段的期望装配力" [原文证据] p.72。玻璃件实验的阶段稳定值：预装配 3 N → 搜孔 2.5 N（波动 2–3 N）→ 孔内 6.5 N → 两点接触段 **F_z 在 6 N 与 −2 N 之间大幅快速波动** → 末端调整 2 N [p.66–67]。
- **总时长**：约 **25 s** [p.72]。
- **失败样本**：未给。唯一"失败/异常"描述是搜孔阶段"由于轴件与工件表面初次接触，机器人运动速度较快，Z 轴受力呈现震荡"以及"3–4 s 段 F_z 因工件表面凹凸不平持续快速波动" [p.66]。
- 统计口径问题：① 力觉标定的"6 个位姿"只动 Wrist1/Wrist2，**姿态空间覆盖很窄**（Base/Shoulder/Elbow 全固定），外推到我们"整个插入过程姿态连续变化"风险大；② 补偿后仍有 1.77 N（Z）残差，而装配期望力 2.5 N ⇒ **残差与有用信号同量级**，这一点作者没有讨论。
- 结论：作为"**无关节力矩接口的协作臂 + 外置六维力 + 导纳能做 0.4 mm 间隙装配**"的工程存在性证据可用；作为"参数可复现/统计可信"的证据**不可用**（M/B/K、周期、试次、成功率全部缺失）。

## 6. 最脆弱的 1–3 个假设
1. "**导纳参数（M_d/B_d/K_d）可以不给，效果靠期望力与选择矩阵就能说明**"——**方法必需**（全文确实没给）[p.54–55]。分类：**尚未测试**：没有参数敏感性分析，别人换 UR5 载荷/工件重量后是否还能 11 N 峰值未知。
2. "**重力补偿后残差可忽略**"——**方法必需**（装配期望力 2.5 N 级）。分类：**范围内反例**：它自己测出补偿后 Z 向残差 **1.77 N**（约为搜孔期望力 2.5 N 的 71%）[p.52、p.66]，说明残差与信号同量级，只是被后续"力学行为"掩盖了。
3. "**0.4 mm 间隙 + 树脂件可承受 11 N**"——**作者明说**（"由于轴孔零件皆为树脂材质，能够承受更大的装配接触力，因此提高了期望装配力"）[p.72]。分类：**范围外迁移限制**：我们 7 kg 工件、单侧 1–2 mm 间隙、371 mm 插入，允许的接触力受工件/插槽表面（光学模块）限制，不能按 11 N 设计。

## 7. 可迁移到本课题的具体做法（CS625 + KWR75 + 7 kg + 371 mm + 0.10 rad/s）
1. **把"双卡尔曼"降级为"卡尔曼/低通 + 死区"，先在 KWR75 上复现它的对比表**。我们现状：`scripts/ft_sensor_node.py` 直接把 1 kHz 原始帧换算成 N 发布，**无滤波**（`config/ft_sensor/kwr75.yaml` 只有协议与单位）。做法：加 `--filter {none,mean,kalman,double-kalman}` 与 `--lowpass-hz`，用静止 60 s 数据算四个指标（最大值/最小值/极值差/标准差），照它表 4.1 的格式记录。验收：静止时 Z 向极值差从当前量级压到 **≤1 N**（本文 4.6 N→0.6051 N）；带 7 kg 工件时补偿后残差 **≤2 N**（本文 1.77 N 可作上限参照）。
2. **照它的"分档期望力"设计我们的插入力阶梯**：预接触 2–3 N、搜孔/找正 2.5 N、直插 5–6.5 N、末端/到底 2 N。落地到 `compliant_insert.py` 的替代品：新增 `--force-stage` 参数表，按 `phases.json` 的阶段切期望力；同时保留现有 effort 安全闸（0.68/1.63）做**独立急停**通道。验收：371 mm 插入全程 f_z 不超过 30 N（我们的工件/插槽承受能力需 owner 给上限）、超限即停响应 ≤100 ms。
3. **把它的"重力补偿四参数标定"当成我们的标准流程模板，但把 6 个位姿扩到 15–20 个**：因为我们的力臂 353 mm、工件 7 kg，Wrist1/Wrist2 两个关节的姿态覆盖不足以辨识质心（本文质心只有 2.8 mm，接近理想；我们是量级差 100 倍的力矩）。做法：在 `scripts/ft_calibrate.py` 里规定"必须改变 J2/J3 至少 3 档 × J5/J6 至少 3 档"的采样矩阵，并输出"补偿后 15 姿态残差表"。验收：|F|<1 N、|M|<0.5 N·m（本文 |F|<1.77 N，我们要更严）。

## 8. 与本课题现有路线的冲突点
- **与"100 Hz 级流式位置下发"冲突（核心）**：本文导纳是"**两次积分**得修正位姿→逆解→位置控制"（式 4.25–4.26）[p.55]，这个结构要成立必须**每个控制周期都能改目标位置**。而我们的 `scripts/execute_assembly_chunks.py` 是把**整条 `FollowJointTrajectory` 交给 ros2_control position 接口**，中途不能改。=> 这条路线在我们的架构上需要"**切片重发**"（每 100 ms 一个新 goal）或"**在 MoveIt Servo / 速度接口上重做**"，两者都不是现在的能力。
- **与"371 mm 插入"冲突**：本文配合段 **30 mm**、总时长 25 s、期望力 6.5 N；我们要 371 mm，按 0.005 m/s 是 **74 s 纯插入**，是它的 12 倍长度/3 倍时间。深孔内的摩擦累积、力信号随深度的偏置漂移，本文完全没有覆盖。
- **与"7 kg / 353 mm 力臂"冲突**：本文负载 2.424 N、质心 2.8 mm；我们 68.6 N、353 mm。它的标定只在 Wrist1/Wrist2 上做，**外推到"末端大姿态变化"时误差会被 24 N·m 量级的重力矩放大**（[分析推断]）。
- **与"树脂件可承受 11 N"的冲突**：我们工件为光学模块相关件，接触力上限必须由 owner 给定；不能把"11 N 峰值"当设计目标。
- **与"视觉只做粗定位"这一点不冲突**：本文视觉定位到"预装配点"后完全靠力/搜孔消化残差 [p.64–65]，与我们现在"站位表 + 三平面/CAD ICP 定插槽、力觉兜底"的分工一致，可以作为我们"力觉兜底层"的参考实现。
