## 2. 一句话结论与相关性
- 一句话：用 **N 个姿态下的"力方程 + 力矩方程"两段最小二乘**，从**同一批一般姿态数据一次性解出**六维力传感器六个零点、负载重力 G、负载质心 (x,y,z)、机器人安装倾角 (θ₁,θ₂)，实验用 **6 个姿态 × 每组 1000 组数据取均值**，在 4.75–58.44 N 五档负载下把外力感知误差压到 **≤ 0.61 %**、外力矩误差 **≤ 0.92 %**；随后用"力→速度积分"做拖动示教 [原文证据] p.26–36、p.40–41。
- 相关性分类：**直接对象证据**——这是本批唯一把"**重力补偿与偏心**"的公式、姿态数量、每组样本数、误差百分比全部给全的论文，是我们 KWR75 标定流程的直接参照。
- 影响本课题的具体决定：**六维力接入**（标定步骤与样本数）、**误差预算**（0.18–0.61 % 是可达水平）、**末端接口**（它选的"力→速度"是 position 接口下最省的实现）。

## 3. 对象与任务
- 机器人：JLRB20 六自由度工业机器人，最大负载 **20 kg**、重复定位精度 **±0.05 mm**、最大水平半径 **1595 mm**、本体 **260 kg**；各轴最大速度 2.75/1.96/2.61/3.92/3.14/3.92 rad/s [原文证据] p.18。
- 传感器：安徽埃力 **Smart300** 六维力传感器：量程 **Fx,Fy 0–100 N；Fz 0–200 N；M 0–5 N·m**；灵敏度 5–10 mV/F.S.；**综合精度 ≤1 %F.S.**；Ethernet/IP；**最高采样频率 5000 Hz**；**16 位 AD**；最大过载 120 %F.S.；工作温度 −10~+50 ℃ [原文证据] p.19（表 2-2）。
- 负载：**4 个与传感器机械定位精准的配重块**，5 种方案（0–4 块），实测重力 5.0 / 18 / 38.4 / 48.1 / 58.6 N [原文证据] p.33、p.35（表 3-5）。
- 任务：**人机拖动示教 + 轨迹复现**（不是装配）；间隙/公差/精度要求：**不适用**（无装配实验，全文无 mm 级间隙）。
- 环境：温度 0–45 ℃、湿度 20–80 %（机器人本体要求）[原文证据] p.18；洁净度：未讨论。

## 4. 方法与机制链（含四问）
`6 路电压 → 16 位 AD → 解耦矩阵 D（F = V·D）→ 两段最小二乘求零点/重力/质心/倾角 → 重力与力矩补偿 → 外力 f_e → 安全阈值闸门 → 速度积分导纳 → J⁻¹ → 关节速度 → 示教轨迹记录/复现` [原文证据] p.21–25、p.38–41、p.47。

### Q1 六维力接入（本文的强项，全部有数）
- **采样率**：软件界面"选择传感器采样频率"，实验时"**将传感器的采样频率调整为最高值**"（传感器上限 **5000 Hz**）[原文证据] p.19、p.33。
- **滤波**：**未定位**——全文没有滤波器类型、截止频率、阶数；数据处理只做"连续采集 1000 组后求平均值" [原文证据] p.33。
- **零漂**：不做模型补偿，做**两点式零位冻结**：① 装传感器后先"**零点重置**"（无工具手）；② 装工具手后再做重力补偿；程序界面有"重力补偿"按钮实时更新示数 [原文证据] p.50–51。作者明确"传感器零点标定必须在**工作状态下**进行" [原文证据] p.20。
- **重力补偿与偏心：公式 + 标定步骤（可直接照做）**
  - 坐标链：世界系 O₀ → 基座系 O₁（绕 X 转 θ₁、绕 Y 转 θ₂，式 3-1）→ 工具系 O₂（Z-Y-Z 欧拉，式 3-6）。重力方向 `g₀ = [0,0,−1]ᵀ`（式 3-7），转到传感器系 `g₂ = R₂₁ᵀ·R₁₀ᵀ·g₀`（式 3-8）。
  - **第一段（力）**：无外力时 `[Fx,Fy,Fz]ᵀ = R₂₁ᵀ·[Lx,Ly,Lz]ᵀ + [Fx0,Fy0,Fz0]ᵀ`（式 3-9/3-11），令 `L = [Lx,Ly,Lz,Fx0,Fy0,Fz0]ᵀ`，N 个姿态堆成 `f = R·L`，最小二乘 `L = (RᵀR)⁻¹Rᵀf`（式 3-15）→ 得三个零点 + Lx,Ly,Lz；再 `G = √(Lx²+Ly²+Lz²)`（式 3-16）、`θ₁ = sin⁻¹(−Ly/G)`、`θ₂ = tan⁻¹(−Lx/Lz)`（式 3-17）。
  - **第二段（力矩/偏心）**：`M = [0 Fz −Fy; −Fz 0 Fx; Fy −Fx 0 | E]·[x,y,z,p1,p2,p3]ᵀ`（式 3-22/3-23），要求 **N（N ≥ 3）组不共面的末端姿态**，最小二乘 `P = (FᵀF)⁻¹FᵀM`（式 3-26）→ 质心 (x,y,z) + p1,p2,p3；再由式 3-27 反解三个力矩零点 `Mx0,My0,Mz0`。
  - **补偿**：`F_e = F − F₀ − G·g₂`（式 3-29）、`M_e = M − M₀ − M_g`（式 3-30）。
  - **姿态数量**：公式要求 **N ≥ 3 且不共面**；实验取 **6 个姿态**（表 3-1：A/B/C 各姿态明显分散，如 (0,120,180)、(−55,167.7,55.5)、(101.4,156.1,−57.9)…）[原文证据] p.34。
  - **每组样本数**：**连续采集 1000 组求平均**作为该姿态的计算输入 [原文证据] p.33。
  - **精度**：外力误差 **0.61 / 0.50 / 0.34 / 0.25 / 0.18 %**（对应 4.75→58.44 N），力矩误差 **0.92 / 0.90 / 0.84 / 0.83 / 0.65 %**；负载重力与电子天平（最大误差 1 N）比对，最大偏差 **−0.85 N** [原文证据] p.35（表 3-4/3-5）。
  - 作者归因：残余误差"可通过机器人的姿态误差来解释"（末端位置精度 5 % 以下、0.5 % 定位偏差）[原文证据] p.35–36。
- **作者主张的三个优点**（可引用）：① 只需一次"不少于三个姿态"的调整就能算全部参数，且**提高姿态数量可提高精度**；② 一次性解全部参数，避免"各参数独立"假设；③ 相对已有方法 1–2 % 的误差，本文 0.18–0.61 % [原文证据] p.36。

### Q2 接触阶段识别（很弱）
- **状态数**：**2 态**。安全阈值判据 `S = 0`（力/力矩在 (−μ_f, μ_f)、(−μ_m, μ_m) 内 → 看作不受力、保持静止）或 `S = 1`（超出 → 上电、做好运动准备）[原文证据] p.38（式 4-2）。
- **阈值怎么定**：只说"可根据实际使用情况来确定合适的力/力矩区间"，**无整定方法、无任何数值（μ_f、μ_m 均未给）** [原文证据] p.38。
- **误判率**：**未给**（无试验次数、无假阳性/假阴性统计）。
- 定性：这只是"使能闸门"，不是接触阶段识别；**没有"接近/接触/入孔"的多状态机**。

### Q3 柔顺类型：速度型（积分导纳），不是标准 M/B/K
- 控制律：`Δv = (σ_f / M)·∫₀ᵗ f_T dt`（式 4-7）、`Δω = (σ_m / I)·∫₀ᵗ m_T dt`（式 4-8），其中 **M = 机器人末端负载质量、I = 负载转动惯量、σ_f/σ_m = 运动灵敏度** [原文证据] p.40。
- 类型判断：这是"**力积分 → 速度增量**"的一阶导纳（本质是把力当加速度源的积分形式），**没有刚度项 K、没有显式阻尼项 B**；因此严格说是"**力→速度的积分导纳**"，不是 Hogan 的 M/B/K 阻抗。
- **M/B/K 数值与单位**：只有"M = 负载质量"这一物理定义，**没有给数值，也没有 σ_f/σ_m 的数值** [未定位]。
- **为什么选它**：原文理由只有"建立基于机器人末端速度的力控制策略…提高对接触力的灵敏度"；另加安全阈值是为了"避免机器人运动速度过大或受到非规范力"[原文证据] p.37。
- **控制周期**：**未给**。软件是 VS2015/C++/MFC + TCP/IP Socket 与机器人和传感器通信 [原文证据] p.44–45；实验只描述"直线跟随较平稳，圆弧略慢并偶尔卡顿" [原文证据] p.51。→ 无 Hz、无 ms。
- 轨迹层面的"实时性"证据：只有"某些点位力施加不均衡时速度变化略有延后"这一句定性描述 [原文证据] p.51。

### Q4 实验口径
- 试次：重力补偿 **5 种负载 × 6 个姿态 × 1000 组**；示教实验为**单次**直线/圆弧/翻转三种动作 [原文证据] p.33、p.51。
- 间隙分档/成功率/力峰值/失败样本：**全部不适用或未给**（没有装配任务、没有成功率、没有力峰值读数）。
- 真机 vs 仿真：仿真用 VirtualBox + ControlStudio 虚拟机器人（只验证"阈值外不动、阈值内跟随"）[原文证据] p.41–43；真机示教 [p.50–51]。
- **唯一的硬指标**是重力补偿精度（0.18–0.61 % / 0.65–0.92 %），这是可以拿来做误差预算的。

## 5. 证据强度
- 优点：**参数与步骤全部公开**（6 个姿态的 A/B/C 角度、1000 组、两段 LS 公式、5 档负载、误差表），**可复现性本批最高**。
- 弱点：① **零漂/温漂完全没处理**（只做一次性零点重置），长时间运行会漂；② **无滤波**，1 kHz 以上的噪声直接进最小二乘（好在有 1000 次平均，等效降噪 31.6 倍 [分析推断]）；③ **没有装配实验**，所以"补偿后能不能装配"没有证据；④ 姿态只有 6 个且都集中在"工具轴偏转"范围，未做姿态数敏感性分析（虽然声称"提高姿态数量可提高精度"）。
- **≤10 Hz 停走节拍核实（本批专项）**：**不适用/没有**。本文无装配任务、无位置目标节拍，且有**控制周期未给**（只有"最高采样率 5000 Hz"与"1000 组取均值"）；它的"实时性"只有定性描述（"圆弧运动略慢并偶尔卡顿"，p.51）。→ 对"10 Hz 节拍"这个问题**零证据**。
- 结论：**Q1 的证据强度本批最高**，可直接作为我们 KWR75 标定流程的模板；Q2/Q3/Q4 只能作背景。

## 6. 最脆弱的 1–3 个假设
1. **"6 个姿态 + 1000 次平均就能把零点/质心定准"**——作者明说（并称提高姿态数可提高精度）；分类：**尚未测试**：没有做 N=3/4/6/10 的对比，也没有重复标定的重复性数据。
2. **"残余误差全部由机器人姿态误差解释"**——我的推断（作者只用 0.5 % 定位偏差做定性归因，没有误差分离实验）；分类：**范围内反例风险**：若传感器本身温漂存在，长时间标定会把漂移误算进姿态误差。
3. **"力→速度积分就足以柔顺交互"**——作者明说但只在示教场景验证；分类：**范围外迁移限制**：无接触力保持需求时够用，**做插入/装配时必须有力跟踪（稳态力）能力，而积分型没有刚度项，无法维持恒定接触力**。

## 7. 可迁移到本课题的具体做法
1. **把"两段最小二乘 + 6 姿态 + 1000 样本"直接落成 KWR75 标定脚本**。做法：在 `scripts/ft_sensor_record.py` 之上加一个标定模式：机械臂走 6 个不共面姿态（复用站位表附近的可行位形），每姿态静止 1 s 采 1000 帧（KWR75 1 kHz ⇒ 1 s/姿态，总 6 s），用式 3-15/3-26 解 F₀/M₀/G/质心/倾角，写进 `config/handeye/` 或新建 `config/ft/`。验收：**同一负载重复标定 3 次，零点漂移 ≤ 0.5 N / 0.2 N·m；补偿后空载外力 ≤ 1 N**。
2. **把"负载重力 7 kg"当标定工况而不是例外**：本文最大 58.44 N，我们是 ≈70 N（7 kg × 9.81），按其 0.18 % 的误差斜率外推，**力误差量级 ≈ 0.13 N**（若线性）；但要注意它的误差在**小负载时最大（0.61 %）**，说明固定误差项（≈0.03 N）主导 → 我们 70 N 下反而更好 [分析推断]。验收：7 kg 负载下补偿后残余 ≤ 1 N、≤ 0.3 N·m。
3. **不要照搬它的"力积分→速度"**：改用带刚度项的导纳（见第 8 节），只借用它的"安全阈值 S 门 + 灵敏度 σ"这两个概念。

## 8. 与本课题现有路线的冲突点
- **与"自建位置型导纳"的冲突**：本文是**积分型**（力→速度），无 K 项 ⇒ **无法维持恒定接触力**，而我们的插入段需要"接触后保持小力推进"。→ 只能借它的标定，不能借它的控制律。
- **与 0.10 rad/s 上限的冲突**：`Δv = (σ_f/M)∫f dt` 是**无界积分**，力持续存在时速度会一直涨；本文靠"安全阈值 S"粗暴截断。我们必须把治理器的 0.10 rad/s 与 0.44 rad/plan 作为**外层硬钳位**，并在导纳律里加**速度饱和**，否则一旦 KWR75 读数偏置就会持续加速。
- **与 7 kg 负载的冲突**：它的 M 取"末端负载质量"，我们 7 kg 时 `σ_f/M` 变小 ⇒ 同样的力产生更小速度 ⇒ 拖动变"重"；若要手感一致，必须按负载重算 σ_f（它没讨论换负载后 σ 是否重调）。
- **与"整条轨迹下发"的冲突**：它是**在线 Socket 下发增量速度**（每个周期改速度），与我们的"一条 `FollowJointTrajectory` + 治理器重计时"架构相反；搬到我们这里必须退化成"每片一条短轨迹"。
- **与 KWR75 的精度口径一致**：KWR75 准度 0.5 %FS（≈2.5 N / 3.5 N·m），本文补偿后 0.18–0.61 % 的**相对误差**说明"标定不是瓶颈，传感器本身精度才是瓶颈"——这条直接支持我们"不追求亚牛级力控、把力气花在节拍与安全上"的判断。
