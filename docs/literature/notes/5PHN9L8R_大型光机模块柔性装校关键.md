## 2. 一句话结论与相关性
- 一句话：为"光机模块从下方进入洁净厢"设计一台 **3-PSS/PS + 4-PP 混联的六自由度装校单元**，把装校切成**对接密封（双目视觉初定位）**与**精密装校（力觉）**两段；精密装校段用动平台上 4 个三维力传感器解六维力、扣掉重力项后，按"孔外接触 / 倒角接触 / 孔内接触"三类工况的**力特征表**反推位姿偏差（甚至给出闭式解 `ux = −2M_sy/F_sz − m − a`、`γ = arctan(−F_jy/F_jx)`），再配合"基于位置的阻抗控制 + 模糊自适应整定 M_d/B_d"实现柔顺；**全部结论来自 Adams + MATLAB/Simulink 仿真，无实物实验**（[原文证据] p.100–p.101）。
- 相关性分类：**方法迁移**（力→位姿映射 + 接触工况判别 + 阻抗参数整定）兼**直接对象证据**（同一族"大型激光装置光机模块下装/进厢"对象，指标量级可直接对照）。
- 影响本课题的具体决定：**接触切换**（何时从视觉主导切到力觉主导）、**柔顺参数**（导纳式柔顺的死区与刚/阻尼设置）、**误差预算**（重力补偿残差与质心标定误差必须单列）、**验证方式**（仿真口径不能当真机证据）。

## 3. 对象与任务
- 对象：大型光学装置的光机模块 + 洁净厢；光机模块"种类繁多、造价昂贵、重量较重、尺寸较大"，洁净度与装校精度要求高（[原文证据] p.20）。实际模块宽度尺寸 **700 mm × 100 mm**，动平台边长按"略大于模块尺寸"取 **d = 900 mm**（[原文证据] p.39）。
- 技术指标（表 2.1）：洁净保持箱 X/Y **±50 mm、0.1 mm**，Z **0~50 mm、0.1 mm**，绕 X/Y **±2°、0.1°**，绕 Z **±5°、0.1°**，负载 **≥2000 kg**；六自由度调整单元 X **±40 mm、0.1 mm**，Y **±100 mm、0.1 mm**，Z **0~2995 mm、0.1 mm**，绕 X/Y **±2°、0.1°**，绕 Z **±5°、0.1°**，负载 **≥650 kg**（[原文证据] p.22 表 2.1）。
- 间隙/公差：正文没有给出真实间隙数值；**仿真**把模块简化为长方体 **700 mm × 200 mm × 3400 mm**、洁净厢内壁 **730 mm × 230 mm**、倒角 **20 mm × 45°**（[原文证据] p.87），即仿真单侧间隙 **15 mm**（X 与 Y 同）。
- 环境：洁净厢**内部光线较差，无法用机器视觉判断模块位置与接触情况**（[原文证据] p.20）；这是"必须上力觉"的直接理由。
- 传感配置：对接密封段两台 **Basler ACA200-60GM**（1626×1236、**20 fps**、GigE）组成双目，布置在洁净保持箱尾部（[原文证据] p.44）；精密装校段 **4 只 ME K3D100 三维力传感器**，量程 **0~2 kN**、精度 **0.2%FS**、线性误差 ≤0.2%FS、灵敏度温移 ±0.02%RD、输出 **2 mV/V**（[原文证据] p.51）。

## 4. 方法与机制链
- 阶段 A 对接密封（视觉）：`双目拍标定板目标点` → `目标点在相机系的坐标 S_c` → `H_c^t（相机→末端动平台，固定）` → `H_t^b（动平台→基座定平台）` → `S_b` → `洁净保持箱逆运动学` → `X/Y 调平对位，再沿 Z 提升到密封圈压紧`（[原文证据] p.48–p.50、p.71 图 4.1）。全流程定位精度只说"**毫米级误差的初定位**"（[原文证据] p.21）。
- 阶段 B 精密装校（力觉）：`4 个三维力传感器测力` → `ΣF=0、ΣM=0 解六维力（式 3.13，四点正方形布局 a×a、高度差 h）` → `扣系统误差 F_0 与模块重力 F_G（式 3.14–3.18，需要质心坐标 (x,y,z)）` → `由传感器系平移到模块接触点系（式 3.27/3.28，需要距离 d 与接触点 (a,b,c)）` → `按接触工况查表判别位姿偏差类型` → `按闭式解算偏差量并反向调整` → `提升行程作为二级判别量`（[原文证据] p.51–p.56、p.67–p.69）。
- 工况分解（本文最实用的部分）：把"带倒角的矩形轴孔装校"分成 4 类——**接近 / 孔外接触 / 倒角接触 / 孔内接触**，并强调这些状态"并非前后接续发生，而是随位姿偏差可能发生"（[原文证据] p.56–p.57）。每类给出力特征判据：孔外接触 8 种（单侧 X±、Y±，双侧四象限），判据是 `F_sx=F_sy=0` 且由 `M_sx、M_sy` 的符号定方向（[原文证据] p.67–p.68 表 3.1）；倒角接触用 `M_sz` 的符号判 γ 方向、单点/多点/线接触用 `M_sz=0` 与几何区分（[原文证据] p.68 表 3.2）；孔内接触用 `F_sy/F_sx` 与 `M_sx/M_sy` 符号判 α/β 方向（[原文证据] p.69 表 3.3）。
- 闭式偏差解：单侧孔外接触时 `ux = −2M_sy/F_sz − m − a`、`uy = 2M_sx/F_sz − n − b`（式 4.1，[原文证据] p.72）；倒角单点接触时 `γ = arctan(−F_jy/F_jx)`（式 4.4，[原文证据] p.74）。这两式把"力矩/力"的比值直接翻译成**毫米与度**，是本文最可迁移的一步。
- 调整策略是"降级链"而不是一次求解：孔外**双侧接触**先按固定步长单向试调，直到变成单侧接触再套闭式解；倒角**多点接触**先反向转到单点接触，单点解出 γ 后再处理线接触（[原文证据] p.71–p.73 图 4.2/4.3）。
- 控制：采用**基于位置的阻抗控制（表现导纳特性）**，理由明确——并联机构强耦合、动力学建模困难，所以不用基于力的阻抗（[原文证据] p.78）；力外环给位置修正量、位置内环用 PID，力控制律带死区 `|F_i|≤20 N 与 |M_i|≤20 N·mm 时置 0`（式 4.11，[原文证据] p.79）；在 `K_d` 取 0 的前提下用模糊控制器（7 级语言变量，输出只保留 PS/PM/PB）实时整定 `M_d、B_d`（[原文证据] p.80–p.81）。
- 改变了哪个假设：把"力信息只能用来报警/停机"改成"**力信息可以反解位姿偏差量并驱动调整**"；把"位置控制精度决定装校成功"改成"接触后由力的允许范围决定成败，位置精度只需把模块送进倒角区"（[分析推断]，依据 p.57、p.72）。

## 5. 证据强度
- 试验性质：**纯仿真**。Adams 验证逆解与碰撞受力；MATLAB/Simulink 对比传统阻抗与模糊自适应阻抗；作者在展望中明确下一步才是"搭建实验平台、对理论分析进行实验验证"（[原文证据] p.101）。**没有任何实物装配数据**。
- 仿真参数（决定了结论的适用范围）：模块质心质量 **500 kg**、摩擦系数 **μ = 0.1**、接触刚度 **50 N/mm**、碰撞力指数 **1.5**、阻尼 **2000**、穿透深度 **0.01 mm**（[原文证据] p.87 表 5.1）。
- 力学模型验证的量化程度：孔外单侧接触 `ux=100 mm` 时闭式解给形心 `X_D=417.5 mm`，Adams 给 **417.9 mm**，差 **0.4 mm**；双侧接触 `ux=uy=100 mm` 时闭式解 148.5/152.4 mm 对仿真 **151.3/151.3 mm**，差 **2.8/1.1 mm**（[原文证据] p.91–p.92）。接触力量级 **285–319 N**（[原文证据] p.89、p.90）。
- 阻抗参数敏感性：扫 `M_d` 1/5/10/20 kg、`B_d` 650/1300/1950/2600 N·s/m、`K_d` 1500/11500/21500/31500 N/m，结论是"增大 B_d 消超调但变慢、减小 K_d 减稳态误差"（[原文证据] p.94–p.95）。
- 统计口径缺陷：**每个工况只有一条曲线、没有重复次数、没有失败样本、没有扰动扫描**；"位姿识别策略正确"的证据是"仿真结果与理论值相差 0.4–2.8 mm"，而识别策略真正需要的是"在噪声/多点接触下会不会误判"，这一点没有测。仿真里还预设了 `|F|<5 N、|M|<3 N·m` 的探测阈值（[原文证据] p.88）——它等价于把"小力"从问题里删除。
- 内部口径冲突：正文写"碰撞参数设置如**表 5.2** 所示"，紧接着的表却编号为**表 5.1**（[原文证据] p.87）；摩擦系数只在仿真参数表里出现（μ=0.1），而第 3 章的力学模型（式 3.42 等）通篇用符号 μ，**正文没有给真实工况的 μ**。
- 结论：作为**方法与判据结构证据**可用（接触工况表 + 闭式解 + 降级链是完整可抄的骨架）；作为**精度证据**不可用（仿真、无统计、间隙 15 mm 与我们 1–2 mm 不同量级）。

## 6. 最脆弱的 1–3 个假设
1. "运动速度很小、可看作准静态，惯性力 F_I 忽略不计" —— **作者明说**（[原文证据] p.53，理由"装校平稳性要求、运动速度很小"）。分类：**范围外迁移限制**。我们的插入段虽被 0.10 rad/s 与 0.005 m/s 限住，但末端到 KWR75 的力臂上还挂着约 0.3 m 的相机与工具，起停瞬间的惯性力矩会直接进入力矩通道；"准静态"在小质量场景成立，在带长悬臂的场景需要另算。
2. "洁净厢下表面始终与大地保持水平、模块进厢前已被倾角传感器调平" —— **作者明说**（[原文证据] p.57）。分类：**范围内反例**（针对本文自己的误差链）：同一篇论文在 p.20 把"洁净厢内部结构复杂、装校空间狭小"列为难点，却把"厢体水平"当无条件前提；一旦厢体面与大地不平行，倒角/孔内接触的力特征表会整体偏置。
3. "`K_d` 取 0 不影响稳态精度与稳定性" —— **方法必需 + 引用他人结论**（[原文证据] p.80"根据文献[73]的结论…在刚度系数 K_d 趋于 0 时，可以保证稳态误差也接近于 0"）。分类：**尚未测试**。刚度项归零意味着系统对"位置偏差"没有回复力，只靠阻尼；在本文的仿真里没有验证"有持续侧向力（例如工件自重压在槽壁上）时会不会缓慢漂移"。

## 7. 可迁移到本课题的具体做法
1. **做一张"我们插槽的力特征表"，并把闭式偏差解接进柔顺层**：我们的插槽是"单侧间隙 1–2 mm + 底部接触 + 插入深度 371 mm"，可照本文的式 4.1 与式 4.4 的思路，用 KWR75（`/ft_sensor/wrench`）的 `F_z、M_x、M_y` 算横向偏差、用 `F_x/F_y` 的比值算绕插入轴的偏转。落点：`scripts/compliant_insert.py` 在现有 effort 残差阈值（contact 0.68 / safety 1.63）之外，增加一路**N/N·m 口径的偏差估计**，两者并行输出、相互校核。需要：KWR75 的重力补偿（工件约 7 kg ⇒ 约 **68.6 N** 常值项必须扣掉，否则 F_z 淹没横向力）、质心 (x,y,z) 标定、以及把 kgf/kg·m 换成 N/N·m（×9.80665）。验收：同一批 10 次插入中，"力算出的横向偏差"与"插入前视觉偏差"之差的绝对值 ≤0.5 mm；插入段接触力峰值**不高于**现有关断阈值对应的力量级，且卡阻中止次数为 0。
2. **用"插入深度"做二级判别，而不是新增传感器**：本文区分"倒角接触"与"孔内接触"靠的是提升行程是否超过倒角高度（[原文证据] p.69）。我们有天然的等价量——插入深度（0→**371 mm**）与 `depth_below_fixture_mm`。做法：把插入过程按深度切成"入口段 / 倒角段 / 槽内段"，每段用不同的力特征判据与不同的速度上限（紧间隙段仍 **0.005 m/s**），并在段切换时打印"当前段 + 判据 + 实测力"。验收：371 mm 全长插入中，段切换点重复性 ≤10 mm；段判据与人工标注一致率 ≥95%。
3. **给柔顺参数一个"死区 + 自适应"的显式结构**：本文的力控制律（|F|≤20 N、|M|≤20 N·mm 置零）与"模糊整定 M_d/B_d、K_d=0"可以简化成我们的一步——在导纳式柔顺里把**死区按重力补偿后的残余力标定**（不是照搬 20 N），并把刚度/阻尼从"拍脑袋常量"改成"按接触状态取两组值"（接近段软、座合段硬）。需要：`config/` 里把柔顺参数从代码提取为配置；标定流程写进 `docs/manuals/`。验收：同一工况下连续 20 次插入的接触力峰值标准差 ≤10%；出现"力死区内位置不修正"导致的卡阻 0 次。

## 8. 与本课题现有路线的冲突点
- **与"导纳式柔顺"直接冲突（控制结构层）**：我们现在的柔顺是"关节 effort 残差超阈值 → 降速 / 取消控制器目标 / 停"（`scripts/compliant_insert.py`，contact 0.68、safety 1.63，**只降不纠**），KWR75 的力值目前只用于记录。本文是"**力外环算位置修正量、位置内环执行**"，即真正的力闭环纠偏。照搬意味着把"停"改成"改目标位姿"，这与我们"超限即停、由人接管"的安全红线冲突，必须先解决"谁有权改目标"的问题（建议：只在死区内小幅纠偏 + 超阈值仍走中止）。
- **与"站位表选站 + 一次精拍"冲突（分工层）**：本文视觉只负责"毫米级初定位"，接触后完全交给力觉，视觉在洁净厢内是**不可用**的（[原文证据] p.20）。我们的主线是"视觉把位姿做到 0.42 mm / 0.078°，gate slot 1.0 mm / 0.5°"，把视觉当成接触前的唯一依靠。这两种分工对"视觉精度指标"的要求差一个数量级：接受本文口径，我们的 gate 可以放宽；坚持我们的 gate，本文的力觉判据只是兜底。
- **与"误差链/公差分配"冲突（误差源层）**：本文的核心误差项是**重力补偿残差 + 质心标定误差 + 传感器系统误差 F_0**（式 3.14–3.18），并用 4 只传感器解算（力臂 h、间距 a 引入放大）。我们的误差链里目前没有"重力/质心"这一类，若引入力觉闭环，必须在 `docs/reference/` 的误差预算里新增三项，否则会低估接触段的偏差。
- **与"RANSAC 三平面 + CAD ICP"不冲突但会互相掩盖**：本文不用 CAD/点云，只测标定板与箱体；它的"位姿识别"完全在接触后完成。若我们同时启用"视觉 ICP 位姿"和"力觉偏差估计"，两者在接触瞬间会给出**两个不同的偏差量**（视觉是绝对位姿，力觉是相对接触点的偏移），必须定义谁为准、差值多大时报警——否则调试期会出现"视觉说对、力觉说偏"的互锁。
- **尺度冲突**：本文仿真间隙 **15 mm**、模块质量 **500 kg**、接触力 285–319 N；我们单侧间隙 **1–2 mm**、工件 **~7 kg**、允许接触力小两个数量级。"力→位姿"的闭式解里 `ux ∝ M_sy/F_sz`，力小、力矩更小，**信噪比会更差**，不能把本文的 0.4–2.8 mm 吻合度当作我们能达到的精度。

## 9. 待确认
- **真实间隙与倒角**：正文只给仿真值（730−700=15 mm 单侧、倒角 20 mm×45°），真实洁净厢孔口倒角宽度 `c`、单侧间隙 `a−m、b−n` 的具体数值未给——直接决定"力特征表"能否唯一区分工况。
- **摩擦系数 μ**：只在 Adams 参数表里出现（0.1），第 3 章推导全用符号；真实"模块-洁净厢内壁"是金属对金属还是带涂层，完全没写。
- **质心 (x, y, z) 的标定方法**：式 3.16–3.18 需要质心坐标，但正文没有给标定流程，也没给质心误差对补偿残差的敏感度。
- **4 只 K3D100 的标定与解耦**：四点支撑解六维力时，`d_i、b_i` 的安装误差如何进入结果，未分析；0.2%FS 在 2 kN 量程上是 **±4 N**，能否分辨本文自己给的 5 N 探测阈值，存疑。
- **模糊规则表**（表 4.2/4.3）只有语言等级名，没有具体的量化因子、比例因子与解模糊方法数值，无法复现。
- **阻抗参数整定的最终取值**：全文只做敏感性扫描（M_d、B_d、K_d 各四档），没有给出"选定值"，也没有给"选定值下的稳态力误差"。
- 双目视觉定位的**实际精度**：只说"毫米级"，没有重投影误差、没有标定次数、没有基线长度。
