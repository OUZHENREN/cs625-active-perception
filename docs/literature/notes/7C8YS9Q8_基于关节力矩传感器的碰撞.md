## 2. 一句话结论与相关性
- 一句话：用**自制关节力矩传感器**（力矩波动硬件补偿 + 温漂补偿 + 动态标定，非线性 0.878 %、迟滞 0.903 %）+ **广义动量扰动观测器**估计外力，提出**时变阈值**包络观测器残差（每关节 5 个可调参数），并给出**只滤速度信号**的降噪做法；在同一台单关节平台上把**零力控制、阻抗控制、阻抗力跟踪**做成**纯位置伺服**实现，实验在**14 次随机碰撞**上时变阈值 14/14 检出、固定阈值在参数不准时漏检 9/14 [原文证据] p.4–5、p.34–41、p.65–71。
- 相关性分类：**方法迁移**——"关节力矩/扰动观测 + 时变阈值"是**接触检测**最完整的一篇；"纯位置伺服实现柔顺 + 力跟踪取 k=0"与我们"只有 position 接口"的现实高度契合。
- 影响本课题的具体决定：**接触切换**（阈值必须随轨迹变化，固定阈值会在动力学误差大时闭锁）、**柔顺参数**（力跟踪段刚度置 0 是抗环境刚度变化的必要条件）、**验证方式**（漏检/误检要按次报，不要只报曲线）。

## 3. 对象与任务
- 对象：**单关节机械臂实验平台**（不是装配任务）：伺服驱动器 Golo-Solo-Whistle（PID 三闭环）、控制器 Platinum Maestro（EtherCAT）、增量编码器电机侧 512 脉冲/圈、谐波减速器、自制力矩传感器内环接减速器、外环接连杆 [原文证据] p.58。
- 动力学：`τ = J q̈ + mgl·sin(q)`，且"关节负载与传感器直接连接，所以动力学模型中**不存在摩擦力**" [原文证据] p.58——这是它比整臂简单得多的关键前提。
- 辨识结果：`(ml²+J) = 0.0096 kg·m²`、`mgl = 0.5022 N·m`；力矩残差 RMS **0.0129 N·m** < 力矩噪声 RMS **0.0216 N·m** [原文证据] p.64。
- 间隙/公差/装配精度要求：**不适用**（无装配任务，全文无 mm 级间隙数字）。
- 洁净度/空间：**未定位**（未讨论）。

## 4. 方法与机制链（含四问）
`编码器位置/速度 + 力矩传感器 τ_m → 广义动量观测器（一阶低通，增益 K_O）→ 残差 r̂(t) → 时变阈值上下界包络 → 超界判碰撞 → 位置伺服层执行零力/阻抗/力跟踪` [原文证据] p.35–41、p.48–53。

### Q1 力/力矩怎么接入（本文是"关节力矩"路线，不是六维力）
- **采样率**：实验"控制系统的采样频率 **100 Hz**"、离散化周期 **T = 0.01 s** [原文证据] p.65；辨识时"控制器采样频率 **100 Hz**"、每周期 **K = 2000** 点、共重复 **40 次**激励轨迹后平均 [原文证据] p.63。
- **滤波（本文最硬的一条）**：只用 **IIR 巴特沃斯低通**滤**速度**信号，**截止 10 Hz、2 阶**（式 3-42 给了离散传递函数 `0.06746(1+2z⁻¹+z⁻²)/(1−1.143z⁻¹+0.4128z⁻²)`）[原文证据] p.42。
  - 理由（可直接引用）：加速度噪声最大→**观测器刻意不含加速度**；位置噪声可忽略；**力矩信号绝不能滤**，因为会带来估计延时。
  - 实验验证：只滤速度 → 观测器最大噪声从 **0.0617 N·m 降到 0.0255 N·m**；滤力矩 → 碰撞响应**晚 0.03 s** 才触发 [原文证据] p.71。
- **零漂/温漂**：不是软件补偿，而是**硬件层**解决——力矩波动用"垂直布置应变片 + 惠斯通全桥"消除谐波减速器柔轮变形引起的波动；温漂用**温度补偿模块**；动态标定平台 + LabVIEW 上位机完成动态标定，指标非线性 **0.878 %**、迟滞 **0.903 %** [原文证据] p.34。
- **重力补偿与偏心**：**没有六维力的重力/偏心补偿**；重力项 `g(q)` 直接进动力学模型，靠辨识 `mgl` 吸收。→ 对我们 7 kg 负载 + 腕部 KWR75 的场景，这篇只能借用"辨识重力项"的思路，不能借用"六维力零漂"的做法。
- **标定步骤（姿态数量/样本数）**：Swevers 有限项傅里叶级数激励（**5 项、基频 0.05 Hz、带宽 0.25 Hz、11 个轨迹参数**），瞬态消失后采集，**40 次重复**取均值，K=2000 点/周期 [原文证据] p.59–63。这是本批"样本数"最明确的一篇。

### Q2 接触阶段识别（本文核心）
- **状态数**：**2 态**（有碰撞 / 无碰撞），全部判别压在一个标量残差 `r̂(t)` 与阈值的比较上 [原文证据] p.36–41。
- **阈值怎么定（固定 vs 时变）**：
  - 固定阈值：`b₁L ≤ r̂(t) ≤ b₁H`，由实验多次试凑；仿真取的两个界限是 **0.32 N·m 与 −0.07 N·m**（原文写"两个关节的固定阈值界限"，与其单关节平台表述**不一致**，疑为上下界之误）[原文证据] p.47。
  - 时变阈值：把建模误差写成"参数估计值 × 误差调整系数 + 解耦余项"（式 3-24/3-26），推导出 `b₂L(t) ≤ r̂(t) ≤ b₂H(t)`（式 3-30/3-31），**每关节 5 个可调参数**：常数平移 `b₂C,j` + 惯性项 `γ_Mj`、离心哥氏项 `γ_Cj`、重力项 `γ_gj`、摩擦项 `ε_fj`（式 3-41）。整定方法：让机械臂跟踪几条不同轨迹，用数据反解这 5 个参数 [原文证据] p.38–41。
- **有没有给误判率**：**给了漏检，没给"率"**。仿真 5 次碰撞：固定阈值 **2 次假阴性**（含 ID=5 的较大外力），时变阈值漏 **1 次**（ID=4 较小力）[原文证据] p.47；真机 14 次随机碰撞：参数较准时两种阈值都 **14/14** 检出；参数误差大时固定阈值**漏检 9 次**（ID 1,2,4,5,7,8,9,10,13），时变阈值 **14/14** [原文证据] p.67–69（表 5-6）。
  - 注意口径：**全文没有"误检/假阳性次数"的统计**，只有定性叙述"固定阈值想避免假阳性就必然漏检"[原文证据] p.38 → 我们引用时只能说"漏检次数"，不能说"误判率"。
  - 时变阈值的代价：参数较准时，它在 7 次碰撞（ID 2,4,5,7,8,9,13）中比固定阈值**晚 0.01 s** 检出 [原文证据] p.69。

### Q3 柔顺类型：阻抗（关节空间），但**只用法位置伺服实现**
- 类型与理由：三种都做——**零力控制**、**基于位置的阻抗控制**、**基于位置的阻抗力跟踪**。选择理由是"避免柔顺控制算法对伺服系统**力矩命令**的依赖…仅在位置伺服中实现"，因为"商业化机器人不开放底层接口" [原文证据] p.48。
- **M/B/K 数值与单位（关节空间，单位按原文）**：
  - 零力控制：`q̇_c = K_r · r`，**K_r = 2**（相当于虚拟阻尼器阻尼系数 1/2）[原文证据] p.48、p.54。
  - 阻抗控制：`m q̈ + b q̇ + k q = f`，整定为 **m = 1 kg、b = 8 N/(rad/s)、k = 20 N/m**（作者扫参：m 0.5→5 kg、b 1→20、k 0→50 N/m）[原文证据] p.54–55。
  - 力跟踪：**k = 0**（关键结论），`b = 42`、`m = 1`，环境刚度在 1000/3000/6000 N/m 三段跳变下仍能跟踪 [原文证据] p.56–57。
  - **为什么 k=0**：式 4-11 的稳态力误差 `Δf_ss = [k_e k(x_r−x_e) − f_d]/(k_e+k)`，只有 k=0 时才与未知环境刚度 k_e 解耦 → **力跟踪段刚度必须置 0**，这是全文最可迁移的一条 [原文证据] p.43。
- **控制周期**：**T = 0.01 s（100 Hz）**，且原文明确"T 是机器人控制器与伺服驱动器的通信周期" [原文证据] p.53、p.65。
- 稳定性代价：k=0 时"干扰力消失后机械臂不再回到期望位置"→ 只适合拖动示教/力跟踪，不能当位置保持 [原文证据] p.55。

### Q4 实验口径（不是装配实验，所以"成功率/间隙"不适用）
- 试次：碰撞检测 **14 次**随机大小/方向碰撞；观测器增益对比 **K_O = 10 / 50 / 100**；滤波四组对照 [原文证据] p.65–71。
- 力峰值：`K_O=100` 时持续力估计**最大误差 0.1129 N·m**、碰撞力估计**最大误差 0.0897 N·m**（K_O=10 时分别 2.4317 / 0.9629 N·m）[原文证据] p.65–66。
- 失败样本：**给了**（固定阈值漏检的 9 个碰撞 ID 全部列出）→ 这是本批唯一给出"漏检清单"的论文。
- 真机 vs 仿真：**两者都有**（第 3 章 SIMULINK 单关节、第 5 章真机单关节）。
- **间隙分档、成功率：不适用/未做**；**没有六维力传感器**，因此对我们"六维力接入"只能间接参考。

## 5. 证据强度
- 优点：**有明确分母**（14 次）、**有失败清单**（9 个漏检 ID）、**有参数对比**（K_O 三档、滤波四组）、真机 + 仿真互证。
- 弱点：① **单关节平台**，"不存在摩擦力""连杆质量 m 与转惯量 J 合并辨识"，到 6 轴整臂后模型误差量级完全不同；② 时变阈值有 5 个待整定参数/关节，**6 轴 = 30 个参数**，整定成本没讨论；③ 只有 1 个自由度、没有装配任务，**成功率的定义缺失**。
- **≤10 Hz 停走节拍核实（本批专项）**：**本文没有**"每 100 ms 发一次位置目标"的装配节拍。它的 10 Hz 是**速度低通滤波的截止频率**（p.42），100 Hz 是**观测器/通信采样率**（T=0.01 s，p.65），两者都不是命令节拍；且它没有装配实验，**无法提供间隙-成功率**。→ 引用时切勿把"10 Hz 滤波"误读成"10 Hz 节拍"。
- 结论：**接触检测的证据强度是本批最高**；但"能否迁移到 6 轴"是它的边界。

## 6. 最脆弱的 1–3 个假设
1. **"时变阈值只需跟踪几条轨迹就能整定出 5 个参数"**——作者明说（式 3-41 后）；分类：**范围外迁移限制**：6 轴整臂的参数耦合与摩擦模型远比单关节复杂，文中"不存在摩擦力"的前提在整臂上不成立。
2. **"只滤速度、不滤力矩"**——作者明说并有对照实验；分类：**范围内反例**：这条依赖"位置噪声可忽略"（其编码器 512 脉冲/圈细分后），若我们的关节位置来自驱动器估计且噪声较大，结论需重测。
3. **"k=0 的力跟踪在未知环境下鲁棒"**——方法必需（式 4-11 推导）+ 仿真验证（环境刚度三段跳变）；分类：**尚未测试**：没有在真实刚性/柔性工件上做恒力跟踪实验，只有仿真。

## 7. 可迁移到本课题的具体做法
1. **把"力跟踪段刚度置 0"写成我们导纳律的硬约束**（最值得搬）。做法：自建位置型导纳里，插入/力控阶段的刚度项 `K_imp = 0`，只保留 M、B；位置保持阶段再把 K 加回来。需要：两套参数集（接触前/接触后）与切换条件。验收：在 1–2 mm 间隙、371 mm 插入段，接触力稳态误差 ≤ 2 N（KWR75 准度 0.5 %FS ≈ 2.5 N 是下限），且不因工件刚度变化而漂移。
2. **时变阈值的"降维"版本**：我们不做 30 参数整定，只做**按速度分段**的包络（`|fz|` 阈值随关节速度线性放大），先解决"运动中最容易误触发"的问题。需要：KWR75 1 kHz 序列 + 关节速度。验收：在 0.005 m/s 插入段的 20 次空跑中，误触发 ≤ 1 次、漏检 0 次（用人工敲击制造 20 次已知碰撞）。
3. **只滤速度不滤力的原则**：我们 KWR75 是 1 kHz、命令 125 Hz，力信号若要滤，截止频率必须 ≥ 20 Hz 且用一阶，否则会引入 ≥ 30 ms 延时（本文实测 0.03 s 的代价）。验收：从"力超阈值"到"轨迹停止"的实测延迟 ≤ 50 ms。

## 8. 与本课题现有路线的冲突点
- **与"只有 position 接口"完全一致，不冲突**：这正是本文的出发点（"仅在位置伺服下实现"），可作为我们"自建位置型导纳"的**方法论背书**。
- **与安全治理器的冲突**：本文的零力/阻抗是"**每个周期改命令位置**"，而我们 `execute_assembly_chunks.py` 是"**一条轨迹 + 治理器重新计时**"，且**拒绝 `time_scale < 1`**。要把本文的离散递推（式 4-7）搬过来，必须每秒发 100 条短 goal——与我们"每条轨迹过 `plan_pose_ik` 安全闸"的架构直接冲突。
- **与 0.10 rad/s 上限的冲突**：本文 k=0 时机械臂"可被随意拖动"，速度完全由外力决定；我们的治理器会把任何速度钳到 0.10 rad/s。→ 导纳律输出必须**先做速度钳位再下发**，否则会出现"力很大但不动"的死区（这是我们必须自己补的一层，本文没有）。
- **与 7 kg 负载的冲突**：本文单关节"无摩擦力"、质量参数合并辨识；我们 7 kg 末端负载的惯量在 0.10 rad/s 低速下仍会产生可观的重力/惯性力矩，**必须做重力补偿**（本文不需要）。
- **与六维力路线的关系**：本文用关节力矩观测器替代六维力，精度 0.1 N·m 量级；我们 KWR75 是 0.5 %FS（≈2.5 N / 3.5 N·m）。两者不能互替，但**观测器可作为 KWR75 的交叉校验通道**（驱动已有 `tcp_fts_sensor` 只读接口）。

## 9. 待确认
