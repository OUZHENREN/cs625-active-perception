## 2. 一句话结论与相关性
- 一句话：以 ABB IRB1410 + 自研整体预紧双层七分支六维力传感器 + MV-UC2000C 单目工业相机搭建系统，视觉用**四个共面标志点**做单帧 PnP 式定位（Newton-Raphson 解距离约束）只求"平面位置 + 绕 Z 转角"三个量作为装配初始位姿，之后完全靠六维力按"受力方向 → 绕正交轴微转"逐次纠偏，完成矩形花键轴孔装配；**全文无一个精度数字**，结论靠过程曲线与定性描述 [原文证据] p.22、p.45–p.49、p.79–p.85。
- 相关性分类：**方法迁移**。理由：不是同一对象（中型花键 vs 我们的矩形工件/插槽），但它是本批唯一"单目视觉只做粗定位 + 力觉做终定位 + 显式三阶段（搜索定位/接触调整/插入）"的完整工程闭环，且给出力→位姿的解析映射式，可作为我们插入段柔顺层方向判据的公式来源。
- 影响本课题的具体决定：**观测动作**（视觉是否只做粗定位）、**接触切换**（何时把位姿权威从视觉交给力觉）、**定位要求**（视觉只要进倒角范围）、**误差预算**（它把视觉误差当"已知不足"整体让给力觉吸收，不给分项）。

## 3. 对象与任务
- 装配对象：中型**矩形花键轴 + 花键套**，源自专用工程车辆扭矩传递系统，键齿为矩形、作者自评"配合精度较低" [原文证据] p.70（印 p.60）。
- 花键具体参数原文为乱码数字串 `842488`（PDF 提取丢分隔符）[原文证据] p.70；按 GB/T 1144 矩形花键记法推测为 **8×42×48×8**（8 齿 / 小径 42 mm / 大径 48 mm / 键宽 8 mm）——**[分析推断]，需回纸本核对**。
- 为适配 IRB1410 载荷，花键轴被设计成**中空减重**结构，两端加工螺纹孔与辅助连接件；装配端有倒角，花键套为成品件、装配端内花键倒角**大于**轴端倒角 [原文证据] p.70–p.71（印 p.60–61）。
- 质量/间隙/公差：**论文未给花键轴质量、配合间隙、公差等级的具体数值**（只说"中型花键""配合精度较低"）[原文证据] p.70；这是本笔记最关键的缺项，我们无法据此推算允许位姿误差。
- 传感配置：六维力传感器量程 X/Y/Z 各 **100 N**、绕三轴各 **10 N·m**，重复性 **0.13%–0.88%**、线性度 **0.25%–1.03%**、回差 **0.39%–0.88%**（六通道分列）[原文证据] p.43–p.44（印 p.33–34，表 3-2）；采集卡 14 位转换、系统测量精度 0.1% [原文证据] p.42（印 p.32）。
- 相机：维视 MV-UC2000C，最大分辨率 **1600×1200**，CMOS，像元 **4.2 µm × 4.2 µm**，H0514-MP2 定焦镜头焦距 **5 mm** [原文证据] p.45（印 p.35）。
- 执行机构：ABB IRB1410 六轴串联机器人，力传感器经过渡法兰装于末端轴，**传感器连接法兰（测力平台）朝上、下平台接机器人**，工件经辅助连接件（含弹簧缓冲销）挂在测力平台上 [原文证据] p.72（印 p.62）。

## 4. 方法与机制链（本批重点：手眼标定 / 观测量 / 精度口径）
- 链条：`单目相机拍一帧 → 背景减除+动态阈值+形态学 → Canny 边缘按曲率分直线/圆弧 → 拟合四特征点中心像素 → Newton-Raphson 解距离约束得四点在相机系坐标 → 三点法向定 z 轴、重心偏移定目标点 → 输出平面 x,y 与绕 Z 角 → 100% 速度直线靠近至 10% 距离 → 10% 速度、路径改为"水平段 + 竖直段" → 力传感器检到接触即停 → 按 Fx/Fy 与 Mx/My 判据绕 JY/JX 微转 → 循环至进入"接触状态一" → 绕 Z 快转对齐键齿 → 沿 Z 插入到底` [原文证据] p.63–p.64、p.79–p.82（印 p.53–54、69–72）。
- **手眼标定：全文没有。** 以 `手眼` 检索 96 页 **0 命中**；相机内参 f、u0、v0、dx、dy 只写"可以通过标定得到"却**未给标定方法与结果** [原文证据] p.47（印 p.37）；机器人侧只有示教器里"建立新工具坐标后只设 Z 偏移 **354.5**（mm，图 5-15 步骤文字）"这一处外参性操作 [原文证据] p.78（印 p.68）。因此 **相机坐标系如何落到机器人基坐标系、XY 与 yaw 如何变成运动指令，全文未交代**——这部分是断链，不是"方法不同"。
- **标定残差如何评价：无。** 无重投影误差、无 AX=XB 一致性残差、无靶标残差；视觉精度只有一句定性："由于视觉图像本身的局限性和图像处理精度…位置精确程度有限，仅以此作为初始的装配位置" [原文证据] p.22（印 p.12）；另一处把"零件加工误差 + 关节运动误差 + 传感误差 + 定位误差"合称"最终装配综合误差…远远超出了机器人系统的精度范围"，同样无数值 [原文证据] p.35（印 p.25）。
- **观测量与不确定度来源**：观测量是**四个共面标志点的像素中心**（1,2,3 等距，4 为 1-2-3 三角形重心），把像点写成 `(k_i·x_i, k_i·y_i, k_i·f)` 后由六条已知点距约束列无约束目标函数最小化求解 k_i [原文证据] p.46–p.48（印 p.36–38，式 3-9~3-14）；姿态只解到"标志点平面法向与相机三轴夹角"（式 3-17、3-18），即**法向确定、平面内绕法向转角未给解法**。不确定度源可辨识为四类：① 四特征点像点拟合精度（圆弧边缘、未封闭圆弧被剔除）、② 单帧单目无绝对尺度（尺度完全由已知标志间距确定，标志间距加工/测量误差直接进尺度）、③ 相机内参未标定、④ 无外参。前三项作者均未量化。
- **力→位姿映射（本文唯一可解析复用的部分）**：作者证明"绕 x 轴的角度偏差只与 F_y 或 M_x 有关、绕 y 轴的角度偏差只与 F_x 或 M_y 有关" [原文证据] p.30（印 p.20）；控制律即 `F_x 正向受力 → 工件绕接触系 JY 正向转 δβ`、`F_y 正向 → 绕 JX 正向转 δα`；由于"每次调整幅度很小"，把调整视为微分运动，用螺旋理论把接触系 {J} 的广义速度映射到末端系 {B}（式 2-12、2-15），从而给出关节侧该转多少 [原文证据] p.30–p.32（印 p.20–22）。
- 装配完成判据显式给出：`f_z ≥ f_0`（阻尼阈值）**且** `z ≥ z_0 + l`（z_0 为初始端面距孔台面的距离，l 为轴长）[原文证据] p.33（印 p.23，式 2-16）——这是"位置 + 力"双条件，可直接借作我们的插入到底判据。
- 改变了哪个假设：把"视觉必须给出足够准的 6D 位姿"改成"视觉只负责把轴送到倒角接触区，位姿由力觉闭环纠"；代价是**视觉段与力觉段之间没有共同的坐标基准**（因为无外参），只能靠"人先摆好初始位姿"衔接 [分析推断]。

## 5. 证据强度
- 试验类型：**真机**（ABB IRB1410 + 实物花键轴套 + 自研六维力传感器），有 RobotStudio 离线仿真作前置验证 [原文证据] p.69、p.76（印 p.59、66）。
- 试验次数/样本量：**未给装配次数、未给重复次数、未给成功/失败统计**。唯一可数的是力数据："采集频率 **2 Hz**，共取 **180** 个点"（≈90 s）[原文证据] p.83（印 p.73）；姿态伺服类实验没有独立计数。
- 统计口径：只有一条 `F_x` 与 `β` 曲线的"节点 1–15"分段描述（节点处 Fx 突增→β 开始调整→Fx 归零→β 停调；节点 4 处 Fx 方向突变判定为"单点接触变两点接触"）[原文证据] p.84–p.85（印 p.74–75）。**无均值、无方差、无极差、无置信区间**。
- 基线公平性：**无基线**。没有"不做视觉""不做柔顺"的对照，也没有与其它柔顺策略比较；"取得了较好的实验效果"是自评 [原文证据] p.85。
- 数字口径问题：文中唯一带条件的定量指标是传感器性能（0.1%、0.13%–0.88%）与相机的分辨率/像元，**都不是装配精度**。因此该文只能作为"工艺流程 + 力→位姿映射式"的结构证据，**不能作为任何精度证据引用**。

## 6. 最脆弱的 1–3 个假设
1. "视觉给出的平面坐标与转角逐字可作为机器人的初始目标位姿" —— **作者隐含**（全文未写外参/手眼，也无标定章节）。分类：**范围内反例**。同一篇论文一边承认"视觉图像本身局限、图像处理精度有限"，一边把视觉三自由度直接当运动目标，中间缺的恰好是标定环节；按其自述误差"远超机器人精度范围" [原文证据] p.22、p.35，这条链路在本课题是不能直接照抄的。
2. "接触状态可由 Fx/Fy/Mx/My 四个量唯一判定" —— **方法必需**，且作者明确限定在"键齿未进入键槽、按光滑轴孔处理"的第一类接触 [原文证据] p.24（印 p.14）。分类：**范围外迁移限制**。一旦出现"键齿已入槽"或"侧壁+底面同时接触"，文中的单点/两点接触分类不再唯一。
3. "沿 Z 插入阶段只需直线运动，卡阻可用主动避让解决" —— **作者明说**（"通过实践经验，定性的分析其因素…让花键轴主动的避让阻力"）[原文证据] p.32（印 p.22）。分类：**尚未测试**。没有给出避让的判据与阈值，也没有失败样本。

## 7. 可迁移到本课题的具体做法（1–3 条，可落地）

> 说明：以下 1–3 条均为 **[待验证设想]**——迁移方案尚未在本平台跑通，给出的验收指标是建议门槛，不是已验证结论。

1. **把"视觉只做粗定位、力觉做终定位"写成显式切换判据**：照它的三阶段划分，在我们插入链里定义 `粗定位段（视觉）→ 接触段（力觉主导）`，切换点取可观测量而非几何猜：`插入深度 > 20 mm` 或 `KWR75 有效接触力 > 0.5 N` 二者先到即切（当前 `scripts/compliant_insert.py` 是 effort 残差触发**停**，不是切模式）。需要：`/ft_sensor/wrench` 已完成工具重力补偿（工件约 7 kg ⇒ 约 68.6 N 常值分量）、`tool0→TCP` 力臂换算、`0.005 m/s` 紧间隙速度上限。验收：20 次插入中，切换点前后的 TCP 位姿跳变 ≤0.5 mm，且因"切换过晚"导致的接触力峰值超限 **0 次**。
2. **借它的"力→微转角"符号表 + 微分运动映射式（式 2-12/2-15）做柔顺方向判据**：在插入段用 `Fx>0 ⇒ 绕接触系 JY 正向微转、Fy>0 ⇒ 绕 JX 正向微转` 输出方向符号，角度步长按 `θ_step ≤ arctan(g/L)` 取上界（我们 g = 1–2 mm 单侧间隙、L = 371 mm ⇒ `θ_step ≤ 0.15°–0.31°` **[分析推断，公式来自 p.30–p.31 的微分运动思路]**）。需要：接触坐标系 {J} 与工件坐标系的固定相对变换（正好可用我们 6.1 已验的"固定相对变换"方式标一次）。验收：每次纠偏的实测转角误差 ≤0.05°，且纠偏 3 次内 Fx/Fy 降到 0.5 N 以下。
3. **"先快后慢 + 路径改水平段→竖直段"的靠近策略**：它在距目标 10% 距离处把速度从 100% 降到 10%，并把直线路径改成"水平段 + 竖直段"以保证接触方向垂直向下 [原文证据] p.79–p.80。我们可对照 `d2b_entrance_tilted`（空爪 0.03 m/s）与 `insert`（0.005 m/s）之间的过渡：把"最后 10% 行程"显式建模为两段（先水平到位、再竖直下插），而不是一条倾斜直线。验收：`--plan-only` 打印的分段里能看出两段，且竖直段起点横向偏差 ≤0.3 mm。

## 8. 与本课题现有路线的冲突点
- **与"三平面 RANSAC + CAD ICP"直接冲突（路线级，不是参数级）**：本文视觉只有 3 自由度（平面 x,y + 绕 Z）、单帧单目、无外参；我们的定位链要求 6D 位姿且必须落在 `T_base_cam = T_base_tcp @ T_tcp_cam` 这条已验的手眼链上（`docs/reference/pose_conventions.md` §4.1：2026-11-10 用 Q12-340-25 棋盘、25 mm 格距实测，纯平移 50 mm 残差 0.19 mm/0.013°，原地旋转 15° 残差 0.71 mm/0.038°，据此换算手眼平移误差上界 **≈2.7 mm**；文档明写"若要亚毫米需多姿态最小二乘重标（**未做**）"）。照抄本文等同放弃 6D 与手眼链。
- **与"站位表选站"冲突**：本文相机固定、不做任何换位观察，视觉只拍一帧；我们的站位表（`config/tasks/common.yaml:workpiece_views`，共 15 个站位条目、其中 11 个显式 `validated: true`、1 个 `validated: false`（缺省视为 true），覆盖 0.954–0.985、重复性 0.14–0.41 mm / 0.022–0.155°）是为"遮挡下的多次观测"服务的。本文的"单帧足够"结论建立在花键套固定、无遮挡、倒角大三个前提上，我们不满足。
- **与"误差链/公差分配"冲突**：本文把视觉误差整体让给力觉吸收，**不做分项误差链**（无相机/hand-eye/TCP/夹具分项），并明确说综合误差"远超机器人精度范围" [原文证据] p.35。我们若引用它的结论，会得到"分项标定无必要"的错误推论——事实相反：正因为没有分项，它才只能靠力觉兜底。
- **与"六维力柔顺"的冲突**：我们的柔顺是 effort 残差触发降速/中止（安全网语义），本文是**主动按力方向移动位姿**（控制语义）。二者不是阈值差别：照搬需要新增"力→微位移"执行环节，并解决两套阈值（effort 口径 vs N/N·m 口径）的互锁。
- **与"7 kg / 371 mm 插入"的尺度冲突**：本文花键轴中空减重以适配 IRB1410，插入方向竖直向下、插入深度只有花键套长度量级（未给值）；我们插入 **371 mm**，深孔内的姿态漂移与侧壁摩擦累积不在本文讨论范围 [分析推断]。
- **[待验证设想]**：现有 `slot 1.0 mm / 0.5°` 的角度门在 371 mm 插入深度下对应端部横向偏移 `371·tan0.5° ≈ 3.2 mm`，已超过单侧间隙 1–2 mm —— 因此真正约束我们的可能是**角度**而非位置。此推断尚未实测，需用 §7 第 2 条的偏置实验（角度档 0.1/0.3/0.5°）验证；若成立，gate 应改为『角度 ≤ arctan(g/L) 且位置 ≤ g』的形式，而不是两者各自取固定值。
