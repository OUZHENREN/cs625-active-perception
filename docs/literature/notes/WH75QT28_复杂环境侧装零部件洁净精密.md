## 2. 一句话结论与相关性
- 一句话：面向"从系统**侧面**把零部件装入洁净、狭小、大重量、高精度要求的复杂环境"（侧装），用 SolidWorks 虚拟装校把**装校尺寸链（公差链）**、装校信息/序列规划、干涉检验、装校能力（可装校性）模糊评价串成一套**工艺与设计方法**，再据此设计"侧装现场装校小车 + 洁净转运箱 + 移动平台 + 监控系统"的辅助装校系统；本质是**工艺规划与机构设计论文，不含视觉/力觉算法与闭环控制**（[原文证据] p.3、p.5）。
- 相关性分类：**工程工具**。理由：与我们的对象与目标并不重合（它是侧装、重载、洁净为主，我们是 7 kg 工件、下装/插槽、视觉+力觉为主），但它给了我们目前**最缺的两件工程口径**——怎样把装校误差写成封闭的尺寸链并按极值法/统计法分配公差，以及怎样把"能不能装"变成可打分、可判阈值的评价。
- 影响本课题的具体决定：**误差预算**（尺寸链的增环/减环与封闭环定义）、**验证方式**（干涉检验与可装校性评价的输出形式）、**公差分配**（极值法 ΣT 与统计法 √ΣT² 两个口径都要给）。

## 3. 对象与任务
- 对象：某工程中"从系统侧面装入/拆出"的零部件（SLP），特点被明确概括为四点——**洁净要求、操作空间狭小、零部件重量较大、定位精度要求较高**（[原文证据] p.3）。
- 规模：正文的零部件参数表（表 2.1）**全是符号**（L_i×W_i×H_i、G_i、侧送行程 s_i、提升高度 h_i），只有分类信息（地面/踏板上、侧装系统或人工辅助、侧挂或"一搁准"），**没有任何一个真实尺寸或重量数字**（[原文证据] p.16 表 2.1）。实测数字只在第 4 章有限元算例里出现：最大零部件重量按 **240 kg** 分析（[原文证据] p.56）。
- 环境与洁净度：跨五个洁净环境——主实验室**十万级**、前处理间**百级**、中转间**可变百级**、洁净转运箱内部**百级**、装校现场**局部百级**（[原文证据] p.34–p.35 附近，见 3.3 节末段）。
- 定位方式：采用"**一搁准**"指导思想——精度主要靠机械定位结构与贴合面保证，而非在线测量；现场"无法通过人工直接观察到侧装零部件是否已经到达'一搁准'装校位置"，因此再配一套**基于视频图像的高精度定位系统**作辅助（CCD + 图像采集卡 + 计算机 + AT89C52 单片机 + **17 位绝对式编码器**伺服）（[原文证据] p.32–p.33）。
- 精度指标：**没有给出任何数值型装校精度指标**；3.4.2 节"精度评价"只有一句结论——"由于采用'一搁准'设计，通过预装校、基准复制与校核、离线光机精密装校，完全可以将零部件安装控制在系统在线调整范围之内"（[原文证据] p.43）。

## 4. 方法与机制链
- 主链（工艺层）：`SolidWorks 三维实体模型（轻量化）` → `装校信息分层描述（部件层/特征层/装校过程层）` → `提取装校尺寸链并判定增环/减环` → `装校顺序与路径规划（拆卸法/约束矩阵法）` → `按步长推进 + 全局干涉函数检测，输出干涉报告（干涉零部件名 + 干涉体积）` → `动画仿真与工艺卡片输出`（[原文证据] p.16–p.26）。
- 关键机制 1（尺寸链/公差链）：把装校精度问题写成**封闭尺寸链**（特性：封闭性 + 相关性；每个尺寸称"环"），封闭环为最终要保证的装校量；给出两种算法——**极值法（代数和）**：封闭环公差 `T0 = Σ Tt`（式 2.6）、上/下偏差分别为增环之和减减环之和（式 2.4/2.5）；**统计公差法**：假设各环正态分布且线性传递，`T0 = √(Σ Tt²)`（式 2.7），非正态时引入相对分布系数 K（[原文证据] p.17–p.18）。这是本文对我们最有价值的部分。
- 关键机制 2（可装校性模糊评价）：把"能不能装"拆成"零部件质量、质心位置、外形尺寸、夹持方式"等 N 个影响因素，用**降半梯形隶属函数**把每个因素映射到 [0,1]，加权求和 `A_i = Σ a_j s_ij`（权重满足 Σa_j = l ≤ 1），再对全部部件取平均 `A = (1/n)ΣA_i`，与阈值 `t_A` 比较决定是否需要重新设计（[原文证据] p.42–p.43）。
- 关键机制 3（干涉检验）：几何可行性 + 机械可行性两类；程序流程为"输入待装配单元初始位姿 → 按步长矩阵变换前进 → 调全局干涉函数 → 发生干涉则输出干涉报告并调整姿态或路径 → 否则继续到最终位姿"（[原文证据] p.23–p.24）。
- 关键机制 4（结构化实现）：侧装小车由提升机构 + 悬臂侧送机构 + 前端执行器组成，转动轴 J1–J4，"空间六自由度调节"；关键件用 Ansys Workbench 11.0 做静力/模态（[原文证据] p.49–p.50、p.56）。
- 改变了哪个假设：把"装校精度靠现场测量与调整"改成"**装校精度靠设计阶段的公差分配 + 机械'一搁准'定位 + 预装校基准复制**，现场只做检测与校核"（[分析推断]，依据 p.32、p.43）。对我们而言这是一个**反向命题**：我们恰恰把精度押在现场测量与柔顺上。

## 5. 证据强度
- 试验性质：**无实物装校实验、无闭环控制实验**。第 4 章是方案设计与有限元验算；全文的"验证"是 SolidWorks 虚拟装校与 ANSYS 强度校核（[原文证据] p.56–p.57、p.61）。
- 有限元算例的具体数字（唯一可核的量化部分）：托板最大变形 **0.08 mm**（最前端）；两导轨最大变形差 **0.020 mm**，对比 THK SNR55L 导轨平行度容许值 **0.50 mm** 判定合格；最大应力 **45.849 MPa**，材料 0Cr18Ni9 屈服强度 **205 MPa**；托板最大速度 **0.016 m/s**，按低速静力学处理；零部件重量 **240 kg**，作用点偏离导轨面 L_z=**783 mm**、L_x=**843 mm**，算得力矩 **939.6 N·m / 1011.6 N·m**（[原文证据] p.56–p.57）。
- 统计口径问题：① 力矩算式的数值用的是**g≈10 m/s²**（783×240×10/2 = 939.6 与文中一致；若用 9.80665 应为 920.8 N·m），全文未声明重力加速度取值；② "最大应力 45.849 MPa、屈服 205 MPa"之后的安全系数一段被 OCR 打乱（原文出现 "2.4849.48/205"，无法确认是 4.47 还是别的口径），**不作为证据引用**；③ 有限元只算了**一个零件（托板）**、一个工况（两悬臂夹角 45°、最大重量最大行程），作者自己写"限于篇幅，仅以托板为例"（[原文证据] p.56）。
- 评价体系的可验证性：可装校性评价给了公式与阈值判定逻辑，但**权重 a_j、隶属函数上下限 a1/a2、阈值 t_A 全部无数值**；效率评价只给了三档时间（第一类 **30～40 min**、第二类 **120 min**、第三类一个工作日），无样本无统计（[原文证据] p.43–p.44）。
- 内部口径冲突：摘要与 3.1 节都强调"装校定位精度要求高"（[原文证据] p.3、p.15），但 3.4.2 节把精度评价**定性化**为"控制在在线调整范围之内"，两处口径不一致（一处是可量化的指标承诺，一处是不可验证的定性结论）；表 2.1 的"侧送行程 s_i / 提升高度 h_i"也没有任何量纲或数值。
- 结论：作为**公差链方法与工程流程的证据**可用（公式是教科书经典，可靠）；作为**精度/可行性证据**不可用（无实测、无闭环、无指标数字）。

## 6. 最脆弱的 1–3 个假设
1. "精度可以由'一搁准'的机械定位 + 预装校基准复制保证，现场不需要在线闭环" —— **作者明说**（[原文证据] p.32、p.43）。分类：**范围外迁移限制**。这个前提成立的条件是"零部件的定位面本身足够刚、重复定位足够好、且装配路径唯一"；我们的插槽是 1–2 mm 单侧间隙 + 371 mm 插入深度，误差随深度线性放大（0.1° 在 371 mm 处 ≈0.65 mm），"一搁准"式的死定位会把误差直接顶到卡死。
2. "各组成环的偏差服从正态分布且装校函数可线性化，所以统计公差法 T0=√ΣTt² 成立" —— **方法必需**（[原文证据] p.18，作者自己承认非线性时须 Taylor 线性化）。分类：**尚未测试**。我们的误差链里"位姿误差 × 371 mm 杠杆臂"是乘法关系，线性化在 0.1° 以上会引入明显偏差，必须先做敏感度检查再决定用极值法还是统计法。
3. "装校过程按固定步长离散推进即可检出全部干涉（步长足够小）" —— **方法必需**（[原文证据] p.24 流程图）。分类：**范围内反例**（针对其自身流程）：步长法只能检测离散位姿上的干涉，对"薄壁擦碰"必然漏检；作者没有给步长选取依据，也没有给"步长→漏检率"的量化关系。

## 7. 可迁移到本课题的具体做法
1. **把我们插入问题写成一条封闭尺寸链，并用两种口径各算一遍**：封闭环取"插槽单侧间隙余量 A0"（名义 **1–2 mm**），组成环至少包括——工件外廓尺寸公差、夹具定位/夹持重复性、视觉位姿误差在插入端的投影（0.078° × 371 mm ≈ **0.50 mm**；若按 gate 的 0.5° 则 371 mm 处 ≈ **3.24 mm**）、插槽内腔尺寸公差、插槽位姿测量误差（slot gate **1.0 mm / 0.5°**）、热变形。极值法算"最坏情况是否 A0<0（必然卡死）"，统计法算"P(A0<0)"。落点：`docs/reference/` 新建误差预算表。需要：插槽内腔与工件外廓的**实测尺寸**（目前只有"1–2 mm"的估计）。验收：预算表每个环都有来源与数值；给出"gate 从 0.5° 收到 0.078° 时装配成功率的变化"曲线。
2. **把干涉检验的输出从"布尔"改成"结构化报告"**：本文的干涉报告要求给"干涉零部件名 + 干涉部分体积"（[原文证据] p.24）。我们 `scripts/plan_pose_ik.py` 现在只拒绝/通过；可改为输出"与哪个碰撞对象、在哪一段（pre_insert/insert/straighten）、估计穿透体积或最小距离"，并把"最小距离"写进每段执行日志。验收：一次完整 371 mm 插入产生 ≥3 个检查点（入口/倒角/槽内）的"最小距离"记录；出现拒绝时能直接读出是哪个对象。
3. **给"站位/观测位"加一个可装校性评分**：照式(3.14) 的加权隶属度结构，把我们的站位评价从"validated 布尔"扩展成 0–1 评分（因素：yaw 偏差角、与工件的距离、点云覆盖率、可达性裕度、IK 是否翻腕），并设阈值。好处是：现在站位表只有"已验证/未验证"，无法排序；打分后可以解释"为什么这个站比那个站好"。验收：对现有站位表打分后，排序与该站位实测覆盖率（0.954–0.985）排序一致（Spearman ≥0.8）；对未验证站位拒绝进入插入。

## 8. 与本课题现有路线的冲突点
- **与"视觉测量 + MoveIt 运动"路线冲突（责任划分）**：本文把精度放在机械定位（"一搁准"）与预装校基准复制上，视觉只是"把定位点传递出来"的辅助检测（边缘拟合中心提取 + 单片机执行，[原文证据] p.33）。我们的路线是"深度相机 + RANSAC 三平面 + CAD ICP 测位姿 → MoveIt 规划 → 导纳式柔顺兜底"，精度押在测量与规划上。照搬本文等于把 gate（slot 1.0 mm/0.5°、workpiece 3.0 mm/1.0°）废掉，改成"机械定位即足够"——这在我们 1–2 mm 间隙下不成立。
- **与"误差链/公差分配"的口径冲突**：极值法 `T0=ΣTt` 的前提是"所有环同时处于极限"，这给出的是**最坏情况保证**；我们现在的 gate 是**单次测量的偏差门限**（超过就重测/拒绝），两者语义不同。若把 gate 数值当作"组成环公差"代入尺寸链，会把"测量门限"和"制造公差"混为一谈，导致公差重复计入（其中视觉误差项会被算两遍）。
- **与"导纳式柔顺"的关系是空缺而不是冲突**：本文（2010 年）没有接触力闭环，插入过程"靠死定位 + 判断是否到位"，与我们的"effort 残差阈值 + 0.005 m/s 紧间隙"相比缺少接触段；因此它既不能支持、也不能否定我们的柔顺参数，**只能作为"无柔顺时会发生什么"的对照**。
- **与"站位表选站"不冲突但层次不同**：本文的"装校顺序与路径规划"（拆卸法、约束矩阵法）是**零件级装配序列**的组合规划，我们对的是**观测站位**选择；把它的序列规划引入会与我们固定的阶段序列（13 个 load 阶段 / D1–D9 unload）冲突，属于不同层次，不应混用。
- **洁净度分级对本课题暂不适用但提示一个未测项**：本文要求前处理间/转运箱/现场局部**百级**（ISO 5），我们现场没有洁净等级要求（[原文证据] p.34–p.35）。但"局部百级"背后的物理事实是**颗粒污染会改变光学测量与接触摩擦**；我们从未测过"镜头/工件表面污染对点云覆盖率的影响"，这一点可作为附录级待确认项。

## 9. 待确认
- **装校精度的量化指标**：全文没有一处给出毫米/角度数字（表 2.1 全符号、"控制在在线调整范围之内"无定义）；无法判断"高精度要求"到底是 0.1 mm 还是 1 mm 量级。
- **间隙与配合公差**：侧装零部件与环境的实际单侧间隙、配合面公差、定位面数量，均未给出。
- 表 2.1 的**符号参数**（L/W/H、G、s、h）取值来源与分布——决定了尺寸链能不能真正算。
- 可装校性评价的**权重 a_j、隶属函数上下限 a1/a2、阈值 t_A** 的具体取值，正文没有；只给了函数形式。
- 效率评价三档（30–40 min / 120 min / 一个工作日）的**依据与样本量**（是否有现场统计数据）未说明。
- **图像定位系统的精度**：只说"高精度"、硬件为 CCD + AT89C52 + 17 位编码器，没有标定方式、没有像素当量、没有重复性数据。
- 有限元只算托板一个零件，**整机刚度/传动链背隙**如何进入"一搁准"精度，未讨论（这恰是本文精度论证的薄弱环节）。
