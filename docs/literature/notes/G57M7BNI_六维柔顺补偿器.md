# G57M7BNI_六维柔顺补偿器

## 1. 元数据
Zotero itemKey: G57M7BNI / A Novel Compliance Compensator Capable of Measuring Six-Axis Force/Torque and Displacement for a Robotic Assembly / 期刊（IEEE/ASME Trans. on Mechatronics, Vol.29 No.1）/ 2024 / DGIST（韩国）/ PDF 12 页，印刷页码 pp.29–40

## 2. 一句话结论与相关性
- 一句话：基于 6-RUS 并联柔顺机构做一个"被动柔顺 + 六维力/位移双测量"的末端补偿器，用位移（而非力）做轴孔装配的偏差补偿运动学，三次试装把装配反作用力降低 92.6% [原文证据] p.29, p.38
- 相关性分类：**直接对象证据（传感器链路）+ 方法迁移**——与 KWR75 传感器链路直接相关：它是"传感器 + 柔顺机械"合一的路线，我们只有传感没有被动柔顺，对比可明确"有 1 kHz 力反馈但无柔顺机构"的得失；其"位移型补偿运动学"可直接写成软件。
- 影响本课题的具体决定：**柔顺参数**（被动柔顺的刚度/行程预算）与**验证方式**（力/位移双通道标定口径）。

## 3. 对象与任务
- 轴孔装配：UR3 机器人（重复定位精度 0.1 mm）；钉/孔 3D 打印（分辨率 0.01 mm），装配公差 0.1 mm、无倒角；初始偏差 0.8 mm（135° 方向），插入速度 50 mm/s [原文证据] p.37–38
- 器件：尼龙 6（MC901 PA6，抗弯刚度 3.45 GPa、屈服 110 MPa，屈服/刚度比 0.032），直径 80 mm、高 54 mm；量程：力 50 N（三轴）、力矩 3/3/2.2 N·m（Mx/My/Mz）；位移感知量程侧向 1.0 mm、俯仰 0.3°、扭转 2°（限位 1.5 mm/1°/3°）[原文证据] p.30–31

## 4. 方法与机制链
`接触力 → 6 条 RUS 柔顺链弹性变形 → 应变片半桥 → 标定矩阵 C（F=C·ΔS，式 9）→ 六维力 → 乘柔顺矩阵 K_t⁻¹（Hooke 律）→ 六维位移 → 偏差补偿运动学 → 机器人位姿修正`
- 刚度分析：Castigliano 第二定理（局部）+ 柔顺矩阵法（全局），K_t 结构式 (7)–(8)；实测侧向 58923 N/m、俯仰 1565 N·m/rad、扭转 57 N·m/rad；理论 vs FEA 平均误差 3.31%、最大 4.95%；改变链厚度可定制刚度（平均误差 4.6%）[原文证据] p.32–33
- 位移补偿运动学（式 17–20）[原文证据] p.37：补偿向量 ẽ = e₁ + e₂；e₁ = [Δx, Δy, 0] 由器件测出；e₂ = [βΔx/√(Δx²+Δy²), βΔy/√(Δx²+Δy²), 0]；β = Dp·cosα/2 + Lp·sinα − Dh/2；三点接触角满足 Dh = Dp·cosα + Lh·tanα
- 关键假设变化：把"装配本质是对齐"落到位移量上做补偿，而不是回到力闭环——更直观、不需要熟练的力控知识 [原文证据] p.38

## 5. 证据强度
- 传感标定：静态加载 ±49.05 N（步长 9.81 N）、±2.943 N·m / ±2.20725 N·m，5 次重复取均值；标定后满量程误差平均 1.53%（≤1.26 N、0.14 N·m）[原文证据] p.34–35
- 标定矩阵：FEA 显示载荷-应变线性度 99.5%、应变梯度矩阵条件数 15.79；实测标定矩阵条件数 13.19；Fz 分量串扰最大，用二次函数拟合 + 解二次方程标定（式 16 例）[原文证据] p.33–35
- 其他性能：迟滞（加载/卸载至额定载荷）、漂移（空载 30 min）、带宽（FEA + 加速度计冲击实验，取最低固有频率的 2/3，Table III 数值为图片未读出）均有评估 [原文证据] p.36
- 时间响应：与商用 OnRobot HEX-E 对照，100 Hz 采 80 s，各轴平均误差 0.63/0.40/1.77/0.70/1.61/0.44%，最大 4.11/1.83/10.12/4.98/7.98/4.65%（Fz 最差）[原文证据] p.35
- 位移感知：精密台架（分辨率 0.06 mm/重复 0.005 mm），满量程误差平均 4.78%（≤0.09 mm、0.05°）[原文证据] p.36
- 装配应用：**3 次试装**（第 1 次纯被动柔顺：位移 −0.37/0.34 mm、力 −8.7/8.3 N → 第 2 次补偿后：−0.03/0.11 mm、−0.8/2.8 N → 第 3 次：位移与反力较第 1 次平均降 86.3%/92.6%）；结论"下次起反力可控制在 2 N 内" [原文证据] p.38
- 统计口径：3 次试装、无成功率统计、无失败样本；传感指标有 5 次重复，装配环节没有——引用"92.6%"时须注明 n=1 次对比口径。
- 作者声明的应用方向：输送线来料位置小幅变化时的"自动再示教"（据测得位移改下一位姿），以及插入后需附加动作（如槽锁）的复杂装配——与我们的"槽内 371 mm 深插"需求同型 [原文证据] p.38

## 6. 最脆弱的 1–3 个假设
1. "补偿只需要侧向（x,y）位移，绕 z 扭转与俯仰由被动柔顺自行消化"——[分析推断] 来自其 e₁/e₂ 只含 x,y；我们 371 mm 深插时长钉杠杆会放大小角度误差 → **范围内反例**（需加角度项）。
2. "初始偏差 ≤ 器件允许偏差（1.0–1.5 mm）"——作者明说（允许偏差范围 1.5 mm 带圆角、1.0 mm 无圆角）[原文证据] p.37；我们单侧间隙 1–2 mm 与视觉残差联合后是否总能落进该窗口 → **尚未测试**。
3. "50 N 量程足够"——器件设计值；[分析推断] 我们 7 kg 工件自重即 ~68.7 N，超其 Fz 量程，且插入摩擦/楔紧可能更高 → **范围外迁移限制**（若仿制该器件需 ≥100 N 量程）。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **位移型补偿运动学软件化**：用 KWR75 测 F，除我们估计的末端刚度得"虚拟位移" e₁，再套式 (17)–(20) 算 e₂ 做机器人位姿修正（无需新硬件）；β 公式需代入我们的 Dp/Dh/Lp/Lh（371 mm 深插要特别算长杠杆项）；验收：连续 3 次试装反力逐次下降 ≥50%。
2. **对标 KWR75 的标定口径**：把本文 5 次重复、满量程误差、串扰、迟滞、漂移、带宽的传感验证清单作为 KWR75 接入后自检项（其 100 Hz 采样的对照协议可直接用于我们 1 kHz 传感器的降采样验证）；验收：各轴满量程误差 ≤ 2%、串扰 ≤ 5%。
3. **被动柔顺的量程设计参考**：若未来给末端加柔顺机构，按"工件自重 68.7 N + 插入反力"设计量程（≥100 N）与侧向行程（≥1.5 mm），刚度定制方法（改链厚）可直接引用 [原文证据] p.33。

## 8. 与本课题现有路线的冲突点
- 冲突点：其路线是"加硬件换掉力控算法"，而我们"六维力柔顺"路线是"用 KWR75 做主动柔顺"——两者在论文里是竞争路线；引用时明确：我们没有该器件，但其位移型补偿运动学可以软件化，形成"无柔顺硬件 + 力换位移补偿"的中间路线。
- 与其"被动柔顺可承受 50 mm/s 快速插入"相比，我们 0.005 m/s 慢插是靠主动限速换安全，机制不同、可互引为对照。
- 与"站位表选站/视觉链"不冲突（其前提是偏差已被视觉压到 0.8 mm 级，恰好佐证视觉-柔顺的交接窗口）。
