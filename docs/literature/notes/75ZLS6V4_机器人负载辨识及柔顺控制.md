## 2. 一句话结论与相关性
- 一句话：先用**静态示教位姿法**（同一姿态下空载/带载各采一组关节角 + 关节电流，**电流每 0.015 s 采一次、共 100 次、冒泡排序后取均值**）分两步最小二乘辨识"电流-力矩常数 K、B"和"负载质量 M、质心 CZ"，**1–6 kg 六档负载**下质量平均误差 **4.6130 %**、质心平均误差 **23.7931 %**；再用**六维力传感器 + 导纳控制**（`M_d ẍ + B_d ẋ = F_e`，无刚度项）做拖动示教，并把 B_d 用**模糊模型参考学习**在线调整到 **150–250 mm/(s·N)**，**20 名受试者 × 20 次**对照实验把速度误差均差从 **6.0559** 降到 **2.4538 mm/s** [原文证据] p.47–49、p.52–53、p.58、p.63–66。
- 相关性分类：**方法迁移**（"负载质量/质心辨识"的位姿数与样本数、"导纳 vs 阻抗"的取舍论证、B 的量纲与区间，都可直接用）。
- 影响本课题的具体决定：**六维力接入**（质心辨识误差量级 → 重力矩误差预算）、**柔顺参数**（B 的量纲 `mm/(s·N)` 与数值区间）、**末端接口**（证明"位置控制器 + 导纳"是工业机器人主流做法）。

## 3. 对象与任务
- 机器人：艾利特 **EC66** 协作机器人（额定负载 **6 kg**，用于第 3 章负载辨识）；ROKAE **XB7** 工业机器人（臂展 1206/707/906 mm，重复定位精度 ±0.02 mm，用于第 4–5 章导纳实验）[原文证据] p.47、p.61。
- 力传感器：**OnRobot HEX-E v2** 六维力传感器：F 上限 **200 N**，x/y 分辨率 **0.2 N**、z 分辨率 **0.8 N**；M 上限 x/y **10 N·m**（分辨率 0.001）、z **6.5 N·m**（分辨率 0.002）[原文证据] p.61。
- 负载：**标准圆柱质量块 1–6 kg**，质心规律 `CX = CY = 0, CZ = n × 7 mm`（1 kg → [0,0,7] mm，2 kg → [0,0,14] mm…）[原文证据] p.47。
- 任务：**拖动示教**（不是装配）；间隙/公差/装配精度：**不适用**；洁净度：未讨论。
- 实验工位：固定距离实验台，期望轨迹初始位 `x₀ = 375 mm`、终止位 `x_f = 500 mm`（即 **125 mm 行程**）[原文证据] p.63。

## 4. 方法与机制链（含四问）
`相同姿态空载/带载关节角 + 关节电流 → 两步最小二乘（先 K,B 后 M,CZ）→ 负载参数 → 六维力传感器拖拽力 F_e → 导纳律 ẍ = M_d⁻¹(F_e − B_d ẋ) → 速度/位置累加 → 逆解 → 关节位置指令` [原文证据] p.44–46、p.52–53。

### Q1 六维力接入 / 负载辨识（本文的强项是"位姿数与样本数"）
- **采样（三个数字全给）**："电流数据**每 0.015 秒采集一次，共采集 100 次**并对采集的数据进行**冒泡排序以及均值滤波**"，作为该姿态下的关节电流 [原文证据] p.47。→ 单姿态采样时长 **1.5 s**，等效 **66.7 Hz**（1/0.015）[分析推断]。
- **姿态数量**：表 3.1 给出 **10 个示教位姿**（关节 1–6 角度全列出，如位姿 1 = (12.955, −75.126, 21.021, −64.510, 115.153, 28.332)°）；**空载与带载各采一遍**；两组独立数据（第 1 组、第 2 组）分别辨识并统计误差 [原文证据] p.47–49。
- **标定步骤（可照做）**：① 用 **3 kg** 标准负载 + 已知质心标定"电流-力矩常数 K、B"（QR 分解取最大线性无关组，构成最小参数集）→ K/B 结果：关节 2 `K=6.24526, B=−1.53815`、J3 `−9.44454 / 1.43509`、J4 `43.9384 / −2.07451`、J5 `52.193 / −0.638533`；**关节 1、6 因"静态示教位姿过程中没有转矩输出"被剔除** [原文证据] p.48。
 ② 在 K、B 已知下，用同一批空载/带载电流差辨识 `M = [CX·mg, CY·mg, CZ·mg, mg]ᵀ`（4×4 系数阵 W）[原文证据] p.45–46。
- **零漂/温漂**：**未定位**（全文无零漂处理；只用"冒泡排序 + 均值"抗野值）。
- **滤波**：**未定位**（除均值外无滤波器；作者反而在误差分析里把"静摩擦力"列为主要误差源）[原文证据] p.49。
- **重力补偿与偏心：这是本文的核心，但结论是"质量准、质心不准"**：
  - 1–6 kg 六档：质量辨识值 0.940 / 1.880 / 2.876 / 3.929 / 4.816 / 5.849 kg（第 1 组），误差 −5.99 ~ −1.78 %；**平均质量误差 4.6130 %**。
  - 质心 CZ（表头写 `CZ/cm`，但按 `CZ = n×7 mm` 的规律与误差百分比反算，**数值实际是 mm，表头单位标错**）：第 1 组 4.84/10.16/18.34/21.75/26.40/32.42，误差 −30.9 ~ −12.7 %；**平均质心误差 23.7931 %** [原文证据] p.49（表 3.5/3.6）。
  - 作者归因（三条，可直接引用）：**静摩擦力**在静态下无法由电流反映（质量越小影响越大）、**负载外力与关节转矩的模型误差**、**质心与质量耦合导致质量误差放大质心误差** [原文证据] p.49。
- **对我们的直接含义**：若把 24 % 的质心误差搬到 7 kg 负载上，重力矩误差 ≈ `m·g·Δc`，取 c≈50 mm、Δc≈12 mm → **≈ 0.82 N·m** 的常值力矩偏置 [分析推断]；这比 KWR75 的 0.5 %FS（≈3.5 N·m）小，但已接近可用阈值，说明**质心必须用六维力法标（4QFLA6S4 式 3-26）而不是电流法**。

### Q2 接触阶段识别
- 本文**没有接触阶段识别**（任务是拖动示教，全程"接触但无力跟踪"）。
- 唯一的"状态"是 `F_ext = 0`（自由）与 `F_ext ≠ 0`（交互），由导纳律**同一个式子**自动覆盖："当机器人与环境发生交互之前 F_ext = 0 时，导纳控制器输入为 0 → 位置修正量 0；交互时 F_ext ≠ 0 → 产生修正量" [原文证据] p.52。
- **阈值、状态数、误判率：全部不适用/未给**。

### Q3 柔顺类型：导纳（位置型），理由给得最清楚
- **明确选导纳，且给出一张"阻抗 vs 导纳"对照**（可直接引用）：
  - 阻抗：输入位置偏差、输出期望力，**需要力控制器 + 精确动力学模型与参数**；优点是精度高，缺点是**存在稳定性问题、需要高性能驱动器** [原文证据] p.51。
  - 导纳：输入交互力、输出位置补偿量，**在位置控制器上实现**；"**系统鲁棒性较好，但受位置控制影响，控制精度较低**"；"**导纳控制可以使机器人系统展示出高刚度，从而与刚度较低的环境进行交互**" [原文证据] p.52。
  - 选导纳的理由：**"导纳控制因需要计算机器人末端所受的外力，更适合在末端安装六维力传感器的机器人上实现"** [原文证据] p.51。
- **M/B/K 数值与单位（本批唯一给出 B 的物理量纲区间的一篇）**：
  - 模型：`M_d ẍ_e + B_d ẋ_e = F_e`（**无 K 项**，因为"拖动示教时不需要恢复力"，式 4-4）[原文证据] p.52–53。
  - 参数确定顺序（可引用）：先定 **M_d**（"越大惯性越大，过小会造成导纳控制器输出过大"），再定 **K_d**（"越大刚度越大…刚度过小跟踪误差大"），最后由期望阻尼比 ξ 反算 **B_d = 2ξ√(M_d K_d)** [原文证据] p.51。
  - **数值**：仿真中"阻尼系数 `b_x = 100` 不变"、"惯性系数 `m_x = 100` 不变"（用于控制变量法扫参）[原文证据] p.55–56；实验中 **B_d ∈ [150, 250] mm/(s·N)**（划分为 {150,175,200,225,250} 五个模糊子集）[原文证据] p.58。
  - **量纲提醒**：B 用 `mm/(s·N)`，即"1 N 力 → 1 mm/s 速度"的倒数关系；换成 SI 是 **0.15–0.25 m/(s·N)**。这与 7C8YS9Q8 的 `b = 8 N/(rad/s)`（关节空间）不同量纲，**不能直接对比**。
  - M_d 的数值 100 与 B_d 的 100/150–250 在原文中单位不统一（仿真里是"惯性系数/阻尼系数"无量纲化表述）→ **需自行换算才能用**。
- **控制周期**：**未给**（全文没有控制周期/采样率的数字，唯一时间量是辨识用的 0.015 s）→ [未定位]。这是它相对 NKYCD8A3 的最大缺口。
- 导纳离散实现（可照抄）：`t+1 ẋ_e = ᵗẋ_e + ẍ_e·Δt`、`t+1 x_e = ᵗx_e + ṫx_e·Δt`（式 4-8/4-9），"**为了防止积分误差累积**" [原文证据] p.53。
- 变导纳（模糊模型参考学习）：输入 = 拖拽力 + 末端速度（各 9 个模糊子集），输出 = B_d（5 个子集）；模糊逆模型输入 = 速度误差及其导数（各 11 子集）、输出 P 调节隶属函数中心；代价函数 = 与"最小加加速度（minimum jerk）"参考模型的偏差 [原文证据] p.57–60。

### Q4 实验口径
- 试次：**20 名受试者**，每人手持 **1 kg** 重物模拟惯性；**对照组每人 20 次**拖动示教；实验组"不断进行直到受试者感觉柔顺性与自身手臂运动差异不大时停止训练" [原文证据] p.63。
- 动作时间标定：20 人测得自然运动时间平均 **8.7 s**，实验中取 **10 s**；拖拽力范围 **±10 N**、末端速度范围 **±40 mm/s**[原文证据] p.63。
- 结果（三组：对照 / 中间 10 次训练 / 实验 20 次训练）：
  - 速度误差**均差**：**6.0559 / 3.3404 / 2.4538 mm/s**；**标准差**：**6.4486 / 4.2706 / 2.7393 mm/s**[原文证据] p.66（表 5-3）。
  - 位置跟踪最大误差：对照组 **14.4173 mm**（τ=0.6837 处）vs 实验组 **5.8671 mm**（τ=0.1275 处）[原文证据] p.64。
  - 速度误差最大/最小：对照组 10.6816 / 2.2381 mm/s；实验组 5.2509 / 0.6316 mm/s [原文证据] p.64。
- 间隙分档/成功率/力峰值：**不适用**（无装配、无成功率、无力峰值；只有"力/位移"曲线）。
- **失败样本**：**无**；作者主动说明一个"异常"：运动结束时速度不为 0，因为"受试者无法准确停在期望位置…会前后摆动调整"，并声明"予以忽略" [原文证据] p.66。→ 这是**被剔除的失败样本**，值得记一笔。
- 真机 vs 仿真：**两者都有**（第 4.2.3 是 MATLAB/Simulink 仿真，第 5 章是 XB7 + HEX-E v2 真机）。

## 5. 证据强度
- 优点：**样本量本批最大**（20 人 × 20 次 = 400 次对照），有**中间组（10 次训练）**做剂量-反应关系，有位置/速度两类指标，**并给了均差与标准差**（不是只给均值）。
- 弱点：① **负载辨识误差极大**（质心 23.79 %），作者自己承认三条原因；② 没有控制周期，导纳实现的可复现性差；③ 受试者是人（主观"感觉差异不大"作为停止条件），**不是客观收敛判据**；④ 表头单位标错（CZ/cm vs 实际 mm）、B 的量纲混用 → 口径不干净。
- **≤10 Hz 停走节拍核实（本批专项）**：**不适用，但反向相关**——本文**通篇没有控制周期**（唯一时间量是辨识电流的 0.015 s），却完成了 125 mm 行程的拖动示教，说明"导纳不需要高频命令"；但它**没有装配任务、没有间隙、没有成功率**，因此不能用它证明"10 Hz 停走能装配"。若要找 100 ms 节拍的装配证据，只能引本仓库另一批的 `5UFZI35T`（100 ms 运动节拍、单边 0.3 mm、250 mm 深孔，其笔记见 `docs/literature/notes/5UFZI35T_融合视觉和力觉的工业机器.md`）。
- 结论：**作为"负载质心辨识不可靠"的反面证据 + "导纳 B 的合理区间"的工程参考**可用；作为装配性能证据不适用。

## 6. 最脆弱的 1–3 个假设
1. **"相同姿态下空载/带载电流差只由负载力矩引起"**——方法必需；分类：**范围内反例**：作者自己指出静摩擦力无法由电流反映，且这是质心误差 23.79 % 的主因。
2. **"质心与质量可以解耦辨识"**——作者明说用 `[CX·mg, CY·mg, CZ·mg, mg]` 线性化；分类：**范围内反例**：正因为耦合，质量的 4.6 % 误差被放大成质心的 23.8 % 误差（作者自己承认）。
3. **"B_d ∈ [150,250] mm/(s·N) 与模糊规则可泛化到新任务"**——作者明说这是"专家知识 + 操作人员经验"定的；分类：**范围外迁移限制**：换机器人/换负载必须重训（作者在展望里自己承认"针对不同情况需要重新训练，离线训练实验较为繁琐"）。

## 7. 可迁移到本课题的具体做法
1. **把 B 的"物理量纲区间"当导纳初值的设计锚点**。做法：我们的导纳律若用 `Δv = (1/B)·F`（速度型），B 取 **0.15–0.25 m/(s·N)** 量级作为起点（即 1 N 力产生 4–6.7 mm/s），再按 `D = 2ξ√(MK)` 与我们 7 kg/0.10 rad/s 约束重标。验收：手推末端 10 N 时速度 ≈ 40–67 mm/s（与本文受试者自然速度 ±40 mm/s 同量级），且不触发 0.10 rad/s 关节上限。
2. **负载质心必须用六维力标、不要用电流法**（反面证据落地）。做法：用 4QFLA6S4 的两段最小二乘（6 姿态 × 1000 样本）标 KWR75 的 F₀/M₀/G/质心；**不要**照本文的电流差法（质心误差 23.79 %，在 7 kg 上会变成近 1 N·m 的常值重力矩偏置）。验收：质心重复性 ≤ 5 mm（3 次标定），比本文的 24 % 好一个量级。
3. **"剂量-反应"式的验证设计**：本文用"0 次训练 / 10 次 / 20 次"三档证明变导纳确实在收敛。我们可以照搬这个设计验证"切片周期"——用 100 ms / 200 ms / 500 ms 三档切片（若最终不做 10 Hz 节拍则用 50/100/200 ms），看成功率是否随节拍变慢而单调变化。验收：三档各 20 次，成功率单调且最优档 ≥ 90 %。

## 8. 与本课题现有路线的冲突点
- **与"自建位置型导纳"最契合的一篇，冲突最少**：它就是"位置控制器 + 六维力 + 导纳"，与我们路线同构；差别只在它**没有 K 项**（拖拽示教不需要恢复力），而我们**插入段需要 K=0、接近段需要 K>0**。
- **与"仅 position 接口"**：完全一致——"导纳控制器的关键**是位置控制器的设计**"，它的输出是**位置补偿量**，正好只有 position 接口也能实现 [原文证据] p.52。
- **与安全治理器的冲突**：它的导纳输出是**连续的末端位置补偿量**，没有关节速度上限；我们的治理器会把 0.10 rad/s 以上的需求钳掉。→ 移植时必须把 `Δx` 先经雅可比换成关节增量，再按 0.44 rad/plan 与 0.10 rad/s 截断。本文没做这一层。
- **与 7 kg 负载的冲突**：它的实验是"1 kg 重物"模拟惯性；我们有 7 kg 末端负载 + 腕部传感器，`M_d` 若照它的 100（无量纲）取值会严重失配；必须按实际惯量重算，且要注意"12 % 的 M_d 误差 → 导纳响应速度变化"（本文仿真里 m 扫 0.5–5 kg 已显示响应时间显著变化）[原文证据] p.55。
- **与 KWR75 的冲突**：HEX-E v2 的分辨率 0.2 N (xy) / 0.8 N (z)，KWR75 是 0.5 %FS（≈2.5 N）；我们**分辨率更差**，因此本文"±10 N 拖拽力"的区间在我们这里信噪比更低 → 导纳死区必须设得更大（否则噪声会推动机械臂）[分析推断]。
- **与"高频流式"的冲突是反向的**：本文**通篇没有控制周期**却完成了拖动示教 → 又一次说明"导纳不需要高频"；但**没有周期也意味着无法复现**，这正是我们不能照抄的地方。
