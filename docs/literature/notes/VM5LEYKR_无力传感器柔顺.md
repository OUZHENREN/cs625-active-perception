# VM5LEYKR_无力传感器柔顺

## 1. 元数据
Zotero itemKey: VM5LEYKR / Force/Torque Sensorless Compliant Control Strategy for Assembly Tasks Using a 6-DOF Collaborative Robot / 期刊（IEEE Access, Vol.7）/ 2019 / 天津大学 / PDF 11 页，印刷页码 pp.108795–108805

## 2. 一句话结论与相关性
- 一句话：用"动力学模型辨识 + 驱动扭矩残差 + 雅可比伪逆"替代六维力传感器估计末端外力，外环阻抗 + 内环 PD 位置控制做柔顺装配，并提出虚拟接触面（VCS）在真实接触前减速消冲击；轴孔装配全程接触力波动 ≤ 4 N [原文证据] p.108795, p.108803
- 相关性分类：**直接对象证据 + 方法迁移**——与"我们无力矩接口"直接相关：它证明了没有末端力矩控制时，"位置内环 + 阻抗外环"仍是可行结构；但我们有 KWR75 六维力（1 kHz），其"无力传感器"前提在我们这里不成立，可取的是**外环结构与 VCS**。
- 影响本课题的具体决定：**柔顺参数**（位置内环+阻抗外环的参数分层）与**接触切换**（接近→虚拟接触→物理接触→插入的四段切换）。

## 3. 对象与任务
- 轴孔装配：钉直径 21.5 mm、长 60 mm；孔直径 22 mm（直径间隙 0.5 mm、单侧约 0.25 mm），孔口倒角 5 mm×45°；孔固定在工作台 [原文证据] p.108802–108803
- 机器人：实验室自研 6-DOF 协作机器人；控制 TwinCAT 软 PLC + EtherCAT 驱动 + LabVIEW HMI（实时平台）[原文证据] p.108802
- 传感：不用力传感器；用驱动扭矩读数 + 辨识动力学估计外力；六维传感器（AEF-6A250）仅作验证对照 [原文证据] p.108800, p.108802

## 4. 方法与机制链
`驱动扭矩 τc（卡尔曼滤波）− 辨识模型扭矩 τiden → 关节外力矩 → Fcar=(Jᵀ)†(τc−τiden)（式 27）→ 阻抗外环算出 Δx（式 37–39）→ xc=xd−Δx → PD 位置内环（式 44–45）→ 关节扭矩 → 环境`
- 动力学辨识：五阶傅里叶激励轨迹 + 遗传算法优化 + 加权最小二乘；摩擦 = 库仑+粘滞（式 18）+ 二次补偿（位移二阶傅里叶 + 速度三阶多项式，式 24）；辨识 RMSE：关节 1–3 为 1.8365 N·m、关节 4–6 为 0.3654 N·m，相对误差 <5%；二次补偿使误差降约 50% [原文证据] p.108798–108799
- VCS 模型：Fvir = Bvir·ẋ + Kvir·1（式 8）；参数 ρ=3 mm、Kvir=6000 N/m、Bvir=40 N·s/m（z 向）[原文证据] p.108797, p.108803
- 阻抗参数（式 53）[原文证据] p.108803：M=diag[2,2,2,1,1,1] kg；B=diag[40×6] N·s/m；K=diag[1000,1000,5000,2000,2000,2000] N/m
- 四段装配：接近→虚拟接触（减速+部分姿态调整）→物理接触（力/矩快速上升，阻抗调整最频繁，力波动 ≤4 N）→插入（沿孔壁下滑，位置调整≈0）[原文证据] p.108803
- 外力计算链细节：关节 1/2/3 与 4/5/6 分两组各设计两条五阶傅里叶激励轨迹（式 21），遗传算法最小化回归矩阵条件数，加权最小二乘解参数（式 23）；驱动扭矩经卡尔曼滤波（式 28–30）后再进 Fcar=(Jᵀ)†(τc−τiden) [原文证据] pp.108798–108800
- z 向插入保留力裕度（克服插入摩擦）；步 IV 结束后机器人停止 [原文证据] p.108802–108803

## 5. 证据强度
- 口径：**真机验证**（自研协作机器人，轴孔装配）；无仿真对比。
- 试次/统计：**未报告试次数与成功率**，无失败样本——证据形式是单次过程的力/矩/位置曲线（Fig.11–13）与辨识误差（RMSE、相对误差）；VCS 效果为"有/无 VCS"两条 z 向力曲线对比（Fig.12）[原文证据] p.108799, p.108802–108803
- 统计口径：只对辨识误差给了 RMSE 与相对误差；装配环节无重复试验统计（如"多次装配成功率"未报告）→ 引用其"≤4 N"时必须注明是单次过程口径。

## 6. 最脆弱的 1–3 个假设
1. "动态参数时不变（M、B、K 视为常量）"——作者明说（变化微小）[原文证据] p.108796；[分析推断] 我们工件 7 kg 使载荷相关摩擦/惯性变化显著 → **范围外迁移限制**。
2. "外部力只作用在末端接触点、只有末端与环境接触"——作者明说（雅可比只能算末端点）[原文证据] p.108799；我们 371 mm 深插时工件侧壁多点接触 → **范围内反例**。
3. "接触前位置已知（钉与孔位姿预先已知）"——作者明说（仅姿态误差需调整）[原文证据] p.108803 → **范围外迁移限制**（我们工件位姿带估计误差，这正是视觉链存在的理由）。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **VCS 软件化落地**：在预测接触平面前 ρ 处（本文 3 mm）把速度从接近段降到插入段——我们已有"tight 0.005 m/s"硬规则，可加"VCS 带"参数化（Kvir/Bvir 用我们的 1 kHz KWR75 直接测 F 替代其虚拟力模型）；验收：接触瞬间力峰值 ≤ 无 VCS 时的 50%（对照 Fig.12 口径）。
2. **外环阻抗 + 内环位置的结构**：把本文外环的"辨识外力"换成 KWR75 实测 Fe，仍按式 (37)–(39) 算 Δx、以 position 命令下发——这是我们无末端力矩接口时的柔顺实现蓝本；验收：插入期力波动 ≤ 阈值（先按 ≤4 N 参考，再按 7 kg 工件重定）。
3. **四段装配切换状态机**：接近/虚拟接触/物理接触/插入四段的切换判据（点 A/B 与 VCS 的相对几何，式 48–49）可移植到 phase runner 的接触切换；验收：每段入口条件可打印、可回放。

## 8. 与本课题现有路线的冲突点
- 冲突点 1：本文靠"读驱动扭矩"实现无力传感器——我们的 Elite 驱动不开放扭矩读数（ros2_control 只有 position 接口），这条线做不了；但我们有 KWR75，等于把本文的"估计环节"换成了直接测量，链路更短。
- 冲突点 2：其 0.25 mm 单侧间隙远小于我们 1–2 mm，且插入深度仅 60 mm（我们 371 mm）——其"位置已知"假设的余量在我们这里不成立，接触切换判据必须与视觉残差结合。
- 与"六维力柔顺"路线一致（外环结构同源）；与"站位表选站"无关（属装配执行层）。
