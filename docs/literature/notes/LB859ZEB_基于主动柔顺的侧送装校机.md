## 2. 一句话结论与相关性
- 一句话：为"从侧面把光学元器件送进半封闭洁净厢"设计了**六自由度串联（P-P-R-S）装校机构 + 末端六维力传感器**的主动柔顺系统，用最小二乘标掉传感器零位与负载重力，得到纯外部接触力，再按**一点接触（8 种）/ 两点接触（10 种）/ 边接触（单边、双边）**力特征与"卡阻/楔紧"约束反推位姿，最后用 Z-Y-Z 欧拉角把元器件"摆正再侧送"；结论仅由 ADAMS 仿真"代入公式算得一致"支撑，无实物实验（[原文证据] p.88 展望④"搭建光学元器件装校实验平台"）。
- 相关性分类：**直接对象证据**（同一族"光学模块侧送进洁净厢"任务、同一传感配置"末端六维力"、同样的"无光源无法目测"约束）+ **方法迁移**（接触工况分类 + 力→位姿判据 + 卡阻/楔紧的力比与几何判据）。
- 影响本课题的具体决定：**接触切换**（何时判定"已接触/已卡阻/可继续送进"）、**柔顺参数**（50 N 级力阈值与力比约束）、**误差预算**（六维力零位、负载重力/质心、倒角几何三项必须单列）、**验证方式**（ADAMS 代入式验证不算实验证据）。

## 3. 对象与任务
- 对象：两类光学元器件（**500×200×500 mm / 100 kg / 侧送行程 1000 mm / 提升高度 92–1900 mm** 与 **500×200×390 mm / 86 kg / 924 mm / 286–1900 mm**），从洁净厢侧面开口装入，每件有唯一装校位置（[原文证据] p.19 表 2.1）。
- 环境约束（本文最贴近我们的部分）：洁净厢**半封闭**、只有侧面开口、**内部无光源、装校过程无法目测**、装配间隙狭小（[原文证据] p.20）；因此把"力觉监测"作为解决办法，并把"视觉盲区"明确列为需用外力觉解决的难点（[原文证据] p.22 表 2.2）。
- 机构指标（表 2.3）：X 向移动 **50–1000 mm**、Y 向 **0–2000 mm**、Z 向 **≥1100 mm**；转动 **±30° / ±150° / ±30°**；**精度 ±1 mm / ±0.1°**；**负载 ≥110 kg**（[原文证据] p.22）。注意同一页下方的技术要求又写"侧送行程不低于 1100 mm、最大提升高度 2000 mm"（[原文证据] p.23），两者口径不同（见第 5 节冲突 3）。
- 力的规模与阈值：接触力需减小到**阈值 50 N 以下或零**，再继续侧送，往复循环实现柔顺装校（[原文证据] p.23）；50 N 被定义为"一个对光学元器件损坏可以接受的力数值"（[原文证据] p.23）。
- 传感配置：**六维力传感器**装在六自由度机构末端抓手与光学元器件之间，测量三维正交力与三维正交力矩（[原文证据] p.23）；驱动为伺服电机 + 减速器（滚珠丝杠提升、齿轮齿条侧送）、手腕用蜗轮蜗杆 + 电动推杆（[原文证据] p.27）。
- 间隙/几何：把元器件视为**矩形轴 2m×2n、长度 l**，洁净厢开口视为**矩形孔 2a×2b**，定义间隙比 `c₁=(a−m)/a`、`c₂=(b−n)/b`；插入倾角的临界值与间隙比成正比（[原文证据] p.48）。**正文没有给真实间隙数值**，只有符号；ADAMS 仿真中间隙由 500×200 轴与孔的关系隐式给出（未明写）。

## 4. 方法与机制链
- 主链：`六维力传感器读数 → 扣零位与负载重力 → 纯外部接触力 F=[Fx,Fy,Fz,Tx,Ty,Tz] → 顶点分解（A/B/C/D 四点各沿三边分解为 i/j/k）→ 由力/力矩的符号与比值判定接触工况（一点/两点/边）→ 由判据式反推位姿偏差 → 解 Z-Y-Z 欧拉角 → 绕等效轴转 ω 摆正 → 再次侧送`（[原文证据] p.49–p.57、p.69–p.73）。任务收益：把"看不见"变成"用力反推位姿"。
- **零位与重力补偿（最可复用的一步）**：先假设无外力时 `F'=F₀+重力投影`（式 4.2），把质心 (x,y,z) 与零位 F₀/T₀ 一起当未知量，用 **n≥3 个不共面姿态**列矩阵方程，最小二乘解出质心（式 4.10）与零位（式 4.23），最后按式(4.25) 从测量值里逐项扣掉（[原文证据] p.49–p.54）。
- 触点力分解：把矩形轴四个顶点 A/B/C/D 处的作用力沿三条邻边分解成 (i,j,k)，由力平衡与力矩平衡写出 6×12 的映射（式 4.30 附近），从而把"六维力"与"某个顶点受的力"对应起来（[原文证据] p.56–p.57）。
- 工况判据（本文的核心资产）：
  - 一点接触判据（式 5.5–5.8）：`T_z = F_x·n + F_y·m`（A 点）、`−F_x·n+F_y·m`（B 点）等，用符号区分顶点；再用 `F_x` 与 `F_y` 的大小关系区分"与倒角面哪一侧接触"（[原文证据] p.61–p.62）。
  - 两点接触判据（式 5.15–5.20）：形如 `(l·F_x − T_z)/(F_z·n − F_y·l) = −1…` 的比值等式，配合 `T_z` 符号区分区域（[原文证据] p.63–p.64）。
  - 边接触判据（式 5.23）：**`T_z = 0` 是边接触的充要特征**；再用 `F_x`、`F_y` 是否为零区分单边/双边（[原文证据] p.65）。
- 卡阻与楔紧（两种"装不进去"）：
  - **卡阻**是力的问题：装配力比例不当导致侧向力过大，判据化为 `F_y/F_z`（或 `F_x/F_z`）与摩擦系数 μ 的不等式（式 5.27、5.29），即**侧向力必须小于插入力乘以摩擦系数**（[原文证据] p.67–p.68）。
  - **楔紧**是几何问题：由摩擦锥 `tanφ=μ` 与几何协调得最大插入深度 `l'`，进而得允许柔顺偏转角 `α < μ(b−n)/n`（式 5.36、5.37）；楔紧**不可通过改力消除**，只能靠控制初始位姿避免（[原文证据] p.68–p.69）。
- 调整策略：把"元器件坐标系与洁净厢坐标系重合"表示为两向量夹角 ω 与绕 `c=a×b` 转 ω 的过程，用 Z-Y-Z 欧拉角写解析式（式 5.38），调整顺序为"先绕新 Z 转 −γ、再绕新 Y 转 −β、最后绕 Z 转 −α"，与构造顺序相反（[原文证据] p.69–p.73）。
- 改变了哪个假设：把"柔顺=降低刚度"改成"**柔顺=先判接触工况，再按工况给位姿修正量**"（[分析推断]，依据 p.59 引言与 p.65 的判据表结构）；也把"卡阻靠试错"改成"卡阻有显式力比条件"（[原文证据] p.68）。

## 5. 证据强度
- 证据性质：**纯仿真**。ADAMS 里把元器件设为 500×200×500 mm、`l₀=50 mm`、倒角 **45°**，四个顶点各固连一个实体球来产生接触（[原文证据] p.78）；作者在展望里明确"搭建光学元器件装校实验平台，验证…在实际装校中的实用价值"（[原文证据] p.88）。
- 位姿判断"验证"的实际做法：把 ADAMS 量到的六维力**代进判据公式**，看等式两边是否相等，得到 0.9668–1.0784 的一组比值（理论值记作 1）（[原文证据] p.82 表 5.1）。这只能证明"公式自洽"，**不能证明判据在噪声/多点接触下唯一**（[分析推断]）。
- 姿态调整"验证"：先绕 Z 转 5°、新 Y 转 0°、新 Z 转 5° 造出 A、C 与倒角面Ⅰ、Ⅲ接触，再把测得力代进式(5.38) 看能否解回同样的欧拉角（[原文证据] p.82–p.83）。
- **内部口径冲突（均可复算，四条）**：
  1. **仿真接触力与 50 N 阈值差 2–3 个数量级**：p.23 定的可接受接触力阈值是 **50 N**，而 p.79 一点接触仿真的外力是 `F'=[−3.2591, −3787.6784, −35.3033] N`、力矩到 `951400 N·mm`；p.81 两点接触是 `F'=[6.4461, −3748.4442, −89.0173] N`；p.83 姿态调整是 `[−2.519, −30.8718, −113.9575] N`。**3787 N 是阈值的 76 倍**，若按 p.23 的规则"超过 50 N 就停止侧送"，这套仿真里的工况根本不允许发生。
  2. **同一张表里各通道的换算系数不一致**：p.79→p.80 从 `F'` 到"接触力 F"的变换中，`F_x`、`F_z`、`T_y`、`T_z` 原样保留，`F_y` 由 **−3787.6784 → 37.8453**（÷100.06），`T_x` 由 **951400 → 15118.5435**（÷62.93）。式(4.25) 的重力/零位补偿不可能对不同通道用不同系数，说明这一步存在**未说明的缩放或抄写错误**（[分析推断]）。
  3. **任务指标三处对不上**：表 2.3 的三列只写"X 向移动 50–1000 mm / Y 向 0–2000 mm / Z 向 ≥1100 mm"，**没有说明哪一列是侧送、哪一列是提升**；p.23 的技术要求却是"侧送行程**不低于 1100 mm**、最大提升高度 **2000 mm**"；而表 2.5 的移动副是 `d₁`（提升）**200–2000 mm**、`d₂`（侧送）**−260 ~ +260 mm**（总行程 520 mm）。无论把表 2.3 的哪一列当"侧送"，都与"≥1100 mm"或"d₂ 只有 520 mm"对不上（[原文证据] p.22–p.23、p.27）。工作空间结论句（p.45"侧送范围 Y=110 10 1 00mm mm−～"）OCR 残缺，无法用来仲裁。
  4. **工况种数前后不一**：p.59 写"发生两点接触光学元器件位姿则存在**十种**情况"，p.62 又写"可能产生 **12 种**接触情况"；公式编号也串章（正文引用"式（4.30）""式（4.36）到（4.41）"，实际对应第 5 章的 5.1–5.14）。
- 结论：作为**判据结构与误差项清单的证据**可用（工况分类、边接触 `T_z=0`、卡阻力比、楔紧几何角）；作为**力/精度证据**不可用（无实验、力数值与阈值矛盾、换算不自洽）。

## 6. 最脆弱的 1–3 个假设
1. "装校系统视为刚体、过程准静态、各处动摩擦系数相同、倒角面高度与斜度都相同" —— **作者明说**，四条假设列在 p.55。分类：**范围外迁移限制**。我们的工件 7 kg 不算重，但**悬臂上挂着约 0.3 m 的相机与工具**，起停惯性力矩会进入力矩通道；另外我们的插槽 1–2 mm 单侧间隙下，倒角尺寸公差会直接改变力特征表。
2. "接触力可以按'顶点受力沿三条邻边分解'来建模" —— **方法必需**（整套判据都建立在 A/B/C/D 四顶点接触上），但 ADAMS 里用"顶点固连实体球"制造接触（[原文证据] p.78），球面接触与真实 45° 倒角面接触的力分布不同。分类：**尚未测试**（作者没有做"球 vs 平面"的对照）。
3. "50 N 是可接受的接触力阈值，同时仿真里的 3787 N 工况也算合格" —— **作者明说 50 N**（p.23），但仿真结果与它矛盾且作者未讨论。分类：**范围内反例**（同一篇论文里阈值与仿真力值不能同时成立）。

## 7. 可迁移到本课题的具体做法
1. **把"六维力零位 + 负载重力/质心"的最小二乘标定照搬过来，用 6 个姿态而不是 3 个**：本文需要 n≥3 个不共面姿态解质心与零位（[原文证据] p.51、p.53）。我们已有坤维 KWR75（`/ft_sensor/wrench`）与工件 **7 kg ⇒ 68.6 N** 常值项，做法：在自由空间让 CS625 摆 6 个不共面姿态（关节速度上限 **0.10 rad/s** 下每个姿态停稳后取 2 s 平均），最小二乘解出零位 6 维与质心 3 维，写进 `config/`（不要写死在代码里）。验收：标定后同一姿态重复 20 次，残余力漂移 ≤0.3 N、残余力矩 ≤0.03 N·m；换装夹后重新标定，两次质心差 ≤5 mm。
2. **先做一张"我们自己的接触工况判据表"，只保留三类**：本文的 8+10+2 种太细，我们的插槽是**单侧间隙 1–2 mm、插入深度 371 mm** 的窄长配合，实际可分辨的是①入口倒角单点接触 ②槽内单侧边接触 ③卡阻。判据取最稳的三个量：`T_z` 是否 ≈0（边接触）、`F_x/F_z` 与 `F_y/F_z` 的符号与比值、以及插入深度。落点：`scripts/compliant_insert.py` 的日志通道（现在只有 effort 残差 0.68/1.63 的降速/中止），新增"工况标签"字段供事后分析。验收：与人工标注（看录像）一致率 ≥90%；并统计"判据不唯一"的比例，超过 10% 就退回只用 `|F_xy|` 幅值。
3. **用"力比 < 摩擦系数"当降速/中止的物理判据，替代纯经验阈值**：本文卡阻条件化为 `F_侧向/F_插入 < μ`（式 5.27、5.29，[原文证据] p.67–p.68）。我们的等价量：`|F_xy| / |F_z|`。做法：插入段当 `|F_xy|/|F_z| > 0.15` 时降速、`> 0.30` 时中止（首次取 0.15/0.30 作为钢-钢干摩擦 μ=0.1–0.15 的保守倍数）。验收：这条判据与现有 effort 残差判据的触发时刻对比 10 次插入，二者**不能互相替代**（若完全同步触发则说明其中一路是冗余的，需要重新选阈值）。

- **平台锚点（本节所有条目都用这几个数落地）**：ELITE CS625 + 深度相机 + 坤维 KWR75（`/ft_sensor/wrench`）；工件 **7 kg（68.6 N）**；单侧间隙 **1–2 mm**；插入深度 **371 mm**；关节速度上限 **0.10 rad/s**。
- [待验证设想] 把本文的楔紧判据 `α < μ(b−n)/n` 代进我们的数：单侧间隙 `b−n = 1–2 mm`，若槽半宽 `n ≈ 50 mm`、`μ = 0.1`，得 **α_max ≈ 0.115°–0.23°**；而我们的视觉姿态重复性是 **0.045–0.078°**，在 1 mm 间隙那一端只剩约 1.5 倍余量。若实测 μ 更低（抛光/润滑）或槽更窄，允许角会掉到视觉噪声以下——**那时就不能靠"视觉把姿态做准"来防楔紧，必须靠柔顺**。验证方法：在 1 mm 间隙的槽上做 20 次插入，记录失败类型（卡阻/楔紧/成功）；若楔紧占失败数的一半以上，则判据成立且视觉不足。

## 8. 与本课题现有路线的冲突点
- **与"位置型导纳柔顺"冲突（离散 vs 连续）**：本文的柔顺是**事件驱动的分步摆正**——"接触 → 判工况 → 解欧拉角 → 转到新姿态 → 再侧送"，每一步之间是离散的、要求"停下来再判"；我们现在的导纳是连续的位置修正（只降速/中止，不改目标）。若照搬，就必须接受"插入过程中反复停-判-转"，这与我们"单段连续插入 371 mm、关节速度 0.10 rad/s"的节奏以及"不回头"的执行器设计冲突。
- **与"站位表选站 + 视觉定位 gate"正面冲突**：本文的前提是**内部无光源、完全无法目测**（[原文证据] p.20），所以整套精度责任交给力觉；我们的主线恰恰相反——视觉做到 0.41–0.42 mm / 0.045–0.078° 重复性，gate 是 slot **1.0 mm / 0.5°**。两者对"视觉能不能进接触段"的假设相反：接受本文，我们的 gate 只是粗筛；坚持我们的 gate，本文的力判据只是兜底。
- **与"误差链/公差分配"冲突（误差项完全不同）**：本文误差链是"六维力零位 + 负载重力/质心 + 倒角几何 + 摩擦系数"，我们用"手眼标定 + RANSAC 三平面 + CAD ICP + 机构重复性"。若引入力闭环，误差预算必须新增**零位 6 项、质心 3 项、μ 1 项**，否则会低估接触段偏差；反过来，本文完全没有视觉误差项，不能用来校核我们的视觉 gate。
- **与"RANSAC 三平面 + CAD ICP"没有直接冲突但会争"谁说了算"**：本文的"位姿"是**相对接触点的位姿偏差**（靠力反推），我们的是**绝对位姿**（靠点云配准）。接触瞬间两者会同时给出偏差量，必须定义优先级与报警阈值，否则调试期会出现"ICP 说对、力觉说偏"的互锁。
- **尺度冲突（阈值不可照抄）**：本文对象 **100 kg / 86 kg**、允许接触力 **50 N**、仿真力值 3748–3787 N、接触力阈值与仿真力差 76 倍；我们工件 **7 kg（68.6 N）**、单侧间隙 **1–2 mm**、插入深度 **371 mm**。50 N 相当于我们整个工件重力的 73%，若照抄，等于允许"把工件压在自己体重的大半上"，绝不可行；我们的力阈值必须在 68.6 N 的一个小分数上重新标定。

## 9. 待确认
- 六维力传感器的**型号/量程/精度/采样率**正文均未给（只写"六维力传感器"），而它的量程决定了 50 N 阈值是否可分辨。
- 最小二乘标定需要多少个姿态、标定残差多大，正文只给方法与公式（p.51–p.54），没有给实测标定精度。
- 真实**间隙数值**与**倒角尺寸**未给（ADAMS 用 45° 倒角，p.78）；`μ` 全文只有符号，没有取值。
- 50 N 阈值的**依据**只有一句"一个对光学元器件损坏可以接受的力数值"（p.23），没有材料/结构支撑。
- 式(5.38) 的欧拉角解析式在"两点接触"下是否仍唯一（作者只做了 A、C 一组算例），以及退化位形（ω≈0 或 c≈0）如何处理。
