## 2. 一句话结论与相关性
- 一句话：用 **VC90D 六维力传感器 + 一次最小二乘联合标定（零点 6 个 + 工具重力 G + 质心 (x,y,z) + 安装偏角 θ）**把"测量值 = 零点 + 工具重力/重力矩 + 接触力"拆开，再在该补偿模型上做**基于位置的阻抗控制（导纳）+ 模型参考自适应（MRAC）补偿项**，在 V6-Plus 上完成笛卡尔牵引（10 N 阈值、0.05 m/s）与恒力打磨（20 N，超调 5.3%，曲面平均法向力误差 **0.76 N**）[原文证据] p.31–48、p.61–66。
- 相关性分类：**方法迁移**（对象是打磨/牵引，不是精密轴孔；但它是本批唯一把"重力补偿公式 + 标定步骤 + M/B/K 数值 + 控制周期"四件事全部给全的论文，且选导纳的理由与我们 CS625 完全同构）。
- 影响本课题的具体决定：**柔顺参数**（M/B/K 的选法）、**末端接口**（无力矩口 ⇒ 只能位置型）、**定位要求**（力觉层只需把残余偏差压到"接触力可控"的量级）、**验证方式**（用"恒力跟踪误差/超调/调节时间"而不是位姿残差）。

## 3. 对象与任务

- **关键接口事实**：运动控制器支持"位置跟踪运动"，"其优点是可以在一段运动过程中可以更改目标位置，这样在柔顺控制中能达到较高的实时性" [原文证据] p.18。
- 传感器：**VC90D 电阻应变片式六维力传感器**，双法兰、高 52 mm、上下法兰盘直径 90 mm，通过定制法兰装在机械臂末端，工具（打磨头）直接装在传感器下端法兰上，刚性连接，保证工具 Z 轴与传感器 Z 轴共线 [原文证据] p.29–30。
- 量程/指标：F_x/F_y **330 N**、F_z **990 N**、T_x/T_y/T_z **30 N·m**；综合精度 **1% FS**；**采样频率 5000 Hz**；额定输出 1.0±0.2 mv/V；安全过载 120% FS；**分辨率 12 位 AD** [原文证据] p.30 表 3.1。
- 采集卡：**USB5935**，单端 16 路/差分 8 路，12 位，**500 kS/s**，USB 接上位机；"数据采集器将模数转换**与滤波**之后的数据通过 USB 通讯传给上位机" [原文证据] p.30（滤波环节在采集器内部，型号/截止频率**未定位**）。
- 被操作对象：打磨——铝合金笔记本外壳 **310 mm×220 mm**（平面）；不锈钢曲面 **R=293 mm、弧长 452 mm、宽 200 mm**（曲面）[原文证据] p.64、p.65。**无工件质量、无间隙、无洁净度数据**。
- 负载：力传感器敏感部分 + 打磨头；标定得工具重力 **G = 11.7120 N** [原文证据] p.36。

## 4. 方法与机制链（本批重点：Q1 六维力接入 / Q2 接触阶段 / Q3 柔顺类型）
- 链条：`六维力原始电压 → 采集器（AD+滤波）→ USB → 上位机 C++ → 零点/重力/安装角补偿得一阶接触力 → 阻抗外环（含 MRAC 补偿）算位置修正量 → 关节逆解 → 位置跟踪运动下发 → 下一控制周期` [原文证据] p.36、p.44–48、p.59–60。

### Q1 六维力怎么接入（本文给得最全）
- **采样/节拍（三个不同频率，必须区分）**：传感器标称采样 **5000 Hz** [p.30]；软件"力传感器采样频率 **500 Hz**"；**控制周期 10 ms（=100 Hz）**；上位机与运动控制器波特率 115200；伺服驱动器通讯周期 **500 µs–20 ms** [原文证据] p.59。另有一处写"采样时间为 **5 ms**"（打磨数据记录）[p.64]，与 10 ms 控制周期口径不一致。
- **滤波**：文中只说采集器内部做 AD 与滤波 [p.30]，**未给滤波类型、截止频率、是否软件二次滤波** → [未定位]。100 Hz 控制周期对 500 Hz 采样是 5:1 抽取（若取均值相当于 5 点滑动均值）。
- **零漂**：明确"传感器在空载时读取其数值并不为零，这是由于传感器存在零点漂移现象所导致的"；并且"安装传感器时，由于法兰盘精度会存在安装偏角" [原文证据] p.31。处理方式不是"上电按一次清零"，而是**把零漂并入一次性最小二乘标定**（见下）；**无温漂跟踪、无定期重零**（未定位）。
- **重力补偿与工具偏心（两段最小二乘，公式齐全）**：
  1. 测量分解：`F_m = F_0 + F_g + F_e`（式 3.1）[p.31]。
  2. 负载重力在传感器系：`F_g^S = R_S^B · [0, 0, −G]^T`（式 3.3）[p.32]。
  3. **重力矩（=工具偏心项）**：`T_g = r × F_g`，即 `T_gx = G_z·y − G_y·z`、`T_gy = G_x·z − G_z·x`、`T_gz = G_y·x − G_x·y`（式 3.4/3.6）[p.32]；其中 `(x,y,z)` 是**负载质心在传感器坐标系中的坐标**（单位 m，本文实标为 **(0.0018, 0.0037, 0.0493) m**，即质心在传感器下方约 **49.3 mm**）[p.32、p.36]。
  4. 线性化第一段：把 6 个读数写成 `T = F·L`，未知量 `L = [x, y, z, l1, l2, l3]`，`L = (F^T F)^{-1} F^T T`（式 3.10–3.12），要求"调整机械臂到 **N ≥ 6** 种姿态且法线不共面" [p.33]。
  5. 线性化第二段（求零点 + 重力 + 安装角）：**安装误差只按"绕 Z 轴一个转角 θ"建模**（式 3.13、3.19–3.22），最小二乘同时解出 `F_0x, F_0y, F_0z`、`G`、`θ`；由 `G cosθ / G sinθ` 反解角度（式 3.24）[p.34–35]。
  6. 最终接触力：`F_s = F_m − F_0 − G`（逐分量，式 3.25）[p.35]。
- **标定步骤（可照做）**：① 装好传感器+工具；② 在可达空间内选 **8 个彼此差别较大**的位姿（表 3.2 只给姿态角 α/β/γ，如 (−84.13°, 54.64°, 130.01°) 到 (161.39°) 量级）；③ **每个位姿连续采 100 组取平均**作为该位姿样本（共 800 组）；④ 代入两段最小二乘；⑤ 得工具质心、G、传感器零点 `S_0 = (±0.4342, ∓0.3986, ±0.8105, ±0.0986, ∓0.0949, ±0.0085)`（N / N·m；**PDF 文本层正负号被排版打乱，符号以原文表为准**）[原文证据] p.36。
- **备选路线（本文创新点）**：RBF 神经网络"位姿角 → 六维力"映射，只以 **J4、J5** 为输入变量（其余关节影响可由 J4/J5 还原），以 **2.5°** 间隔网格化，共 **1353 组**训练样本；力预测 MSE ≈ **0.1**、力矩 MSE ≈ **0.0001**，7000 epochs 后稳定 [原文证据] p.39–41。→ 这是"标定公式失效（工装改变/工具更换）时的数据驱动兜底"。

### Q2 接触阶段怎么划分/识别
- **本文不做接触状态机**：任务不是轴孔插入，而是"牵引"与"恒力打磨"两类单一柔顺模式。接触的"进入"靠一个力阈值：牵引实验**阈值 10 N**，"当力传感器检测到该方向的牵引力大于 10 N 时，控制器便会下达使机械臂沿该方向运动的指令，并保持其他笛卡尔方向位置不变" [原文证据] p.61。
- 打磨：接触由"力传感器检测到接触力变化后控制器随即开启自适应阻抗控制功能"触发 [p.65]，**阈值数值未给** → [未定位]。
- 状态数：无形式化状态机（隐含 2 态：自由/接触）。**误判率：全文未给**（只在牵引实验里定性说"接触力测量值出现了一定程度波动，这是由于人手牵引施力无法保持恒定"）[原文证据] p.63。

### Q3 柔顺类型：阻抗还是导纳？为什么？
- **结论：基于位置的阻抗控制 = 导纳（admittance）**，且给出的理由是**末端接口限制**，与我们一字不差：
  > "基于位置的阻抗控制是建立在关节运动控制的基础上…加之所使用的 **V6-Plus 机械臂不提供读取各关节输出力矩的功能**，所以本文使用基于位置的阻抗控制方法。" [原文证据] p.45
- 模型：`M(Ẍ−Ẍ_d) + B(Ẋ−Ẋ_d) + K(X−X_d) = F − F_d`（式 4.3）[p.44]；外环以力误差 `E_f = F_d − F` 经 `1/(M s²+Bs+K)` 生成位置修正量，内环是关节位置控制（图 4.3）[p.44–45]。
- 稳态误差（式 4.8）：`e_ss = (k_e/(k_e+k))·f_r + (k·k_e/(k_e+k))·(x_e − x_r)`，等效刚度 `k_eq = k·k_e/(k+k_e)`；零稳态力误差条件 `x_r = x_e + f_r/k_e`（式 4.9）[p.45]。
- 自适应：MRAC + Lyapunov 设计的补偿项 `Δx_r = w(t) + p(t)e(t) − d(t)ẋ(t)`（式 4.11/4.22），σ 修正防漂（式 4.23），结论是"能应对环境刚度与接触位置不确定性" [p.46–48]。
- **数值（这是本批最全的一组 M/B/K 扫描）**，仿真期望力 **20 N**、仿真步长 **1 ms** [p.48、p.50]：
  - 固定 `B=500`、`K=30`，`M ∈ {1,10,20,50,100}`：超调 **0 / 0 / 4.45 / 18.00 / 29.70 %**，调节时间 **1.10 / 1.21 / 1.34 / 1.89 / 2.53 s**，稳态误差恒 **0.2 N** [p.50–51 表 4.1]。
  - 固定 `M=1`、`K=30`，`B ∈ {150,200,250,300,400}`：超调 **31.00 / 19.70 / 11.80 / 6.05 / 0 %**，调节时间 **1.13 / 0.96 / 0.83 / 0.78 / 0.68 s**，稳态误差 **0.2 N** [p.51–52 表 4.2]。
  - 固定 `M=5`、`B=500`，`K ∈ {150,200,250,300,400}`：超调恒 **0 %**、调节时间恒 **0.82 s**、稳态误差 **0 / −0.67 / −1.25 / −2.35 / −3.33 N** [p.52 表 4.3]。
  - **单位未在正文写明**；按数值量级与仿真设定（20 N 力、秒级调节）应读作 M: kg、B: N·s/m、K: N/m → [分析推断]；**且三组扫描的基线不一致**（第一组 B=500、第三组 M=5，而第二组用 M=1）→ **口径不一致，不能直接拼成一套参数**。
  - 力跟踪仿真取 `M=10, B=300, K=150`，环境刚度 `K_e = 3500 N/m`，F_d=30 N：阶跃调节 2.15 s / 超调 6.2%（阻抗）vs 2.08 s / 0%（自适应）[p.53]；斜坡 `F_d = 2t+10 N` 跟踪误差 ≈0.2 N，自适 1.6 s 后≈0 [p.54]；正弦 `3sin(0.5t)+30`：超调 5.46%、时滞 0.43 s vs 0.16 s、超调 2.91% [p.54]；环境刚度 3500→6000 N/m 突变：最大跟踪误差 **12.6 N**/调节 2.7 s vs **5.8 N**/1.8 s [p.55]。
  - **真机参数**：`M=10, B=200, K=150`，`μ1=0.001, μ2=2, μ3=0.005, λ_p=0.01, λ_v=10, σ=0` [原文证据] p.64。
- **控制周期：10 ms（100 Hz）**，力采样 500 Hz [p.59]。

## 5. 证据强度（含 Q4 实验口径）
- 试验类型：**真机**（V6-Plus + VC90D + 自研 C++ 上位机），无仿真替代实测；但阻抗参数整定与参数扫描全部在 Matlab/Simulink（PUMA560 模型）里做 [p.48–57]。
- **试次**：牵引 X/Y/Z 各 1 次；平面打磨 1 次；曲面打磨 1 次 [p.60–66]。**无重复试次、无间隙分档**（非插入任务）、**无成功率**、**无失败样本统计**。
- 力峰值/误差：牵引阈值 10 N（超过即动），速度 0.05 m/s；滑块到位判据"光栅尺实测 − 目标 > 0.01 则报错退出"（**单位未写**，疑 mm）[p.57]。平面打磨：进给 15 mm/s、期望 20 N、**超调 5.3%**、调节 **1.6 s**、稳态波动 **±0.4 N** [p.64]。曲面打磨：进给 10 mm/s、期望 20 N、**平均法向接触力误差 0.76 N** [p.66]。
- 基线公平性：**只有"阻抗 vs 自适应阻抗"的同工况对比**（阶跃/斜坡/正弦/环境刚度突变/环境位置突变，共 5 类各 1 组仿真）[p.53–57]，无"无力觉"或"仅位置控制"对照。
- 统计口径问题：① 表 4.1–4.3 的稳态误差在 M、B 扫描中恒为 0.2 N（疑似同一初值/同一截断口径），而 K 扫描才出现单调增大，说明"稳态误差"对不同参数不敏感，不能当作统一验收指标；② 控制周期 10 ms 与"采样时间 5 ms"并存 [p.59 vs p.64]；③ M/B/K 三组扫描基线不一致（见 Q3）。
- 结论：**作为"重力补偿+偏心力矩公式 / 标定步骤 / 导纳选型理由 / 参数整定趋势"的方法证据可用且质量高**；作为"20 N 恒力可做到 ±0.4 N"的性能证据需注意它是**平面、慢速（15 mm/s）、单次**的结果。

## 6. 最脆弱的 1–3 个假设
1. "**安装误差可以只用一个绕传感器 Z 轴的转角 θ 描述**"（式 3.13）——**作者明说**（"传感器坐标系与机械臂末端之间会存在一定的安装误差，体现在 X 和 Y 轴不能完全重合，但是 Z 轴可以认为是共线的"）[p.33]。分类：**范围外迁移限制**。我们的 KWR75 装在法兰与夹爪之间、工具链长 `tool_flange_to_tcp_mm=353`，X/Y 倾斜会直接变成几 N·m 级的伪力矩，单参数 θ 模型不够。
2. "**标定参数（零点、G、质心）在任务期间不变**"——**方法必需**（一次标定、长期使用）。分类：**尚未测试**：文中没有任何"30 min 后/换工具后/温度变化后"的重复性数据；而它自己承认"每次使用预紧力不同就要清零"这是另一篇（HATPVGDA）的做法，本文是把它并进标定。
3. "**忽略力矩对偏转角的影响**"——**作者明说**："由于轴孔装配过程中产生的力矩都很小，因此在实际装配中可将力矩的影响忽略，只考虑力和偏转角的关系" [p.25]。分类：**范围内反例存在**：它自己的打磨任务里力矩量级 0.1–0.3 N·m 且直接参与阻抗环；在我们的 7 kg / 353 mm 力臂下，力矩不是小量（见 §7）。

## 7. 可迁移到本课题的具体做法（落到 CS625 + KWR75 + 7 kg + 371 mm + 0.10 rad/s）
1. **把本文的两段最小二乘直接改成"带工件的 KWR75 重力+偏心标定"**。我们现状：`config/ft_sensor/kwr75.yaml` 只声明单位换算（kgf→N，×9.80665），`scripts/ft_sensor_node.py` 只发布 `/ft_sensor/wrench` 原始值，**没有零点、没有重力补偿**；而工件 **7 kg ⇒ ≈68.6 N 常值分量**、工具链长 **353 mm**（`config/tasks/common.yaml: tool_flange_to_tcp_mm: 353.0`）⇒ 若质心接近 TCP，重力矩可达 **68.6 N × 0.353 m ≈ 24.2 N·m**（[分析推断]，需先确认 KWR75 力矩量程是否覆盖）。做法：① 在 `config/ft_sensor/` 增 `gravity_comp` 段（G、质心 r、零点 6 个、安装偏角）；② 写 `scripts/ft_calibrate.py`：空载+带件两种负载、各 ≥6 个不共面姿态、每位姿 1 s 静置后取均值（照本文"100 组取均值"+"姿态不共线"两步）；③ 验收：**带 7 kg 工件在 15 个姿态下补偿后 |F| < 1 N、|M| < 0.5 N·m，重复上电 30 min 漂移 < 0.5 N**。
2. **把"导纳 + MRAC 补偿项"降级成"导纳 + 常值前馈"，先不做自适应**。理由：本文真机最终用的就是 `M=10, B=200, K=150` 的固定参数，MRAC 只在仿真里验证过 [p.64 vs p.53-57]。落地：以 **100 Hz** 为外环周期写 `admittance_node`（订阅 `/ft_sensor/wrench`，发布 `geometry_msgs/Twist` 或直接修正目标位姿），初值取本文真机档的一半再逐步加（我们从 0.005 m/s、371 mm 得到的时间尺度是 **74 s 纯插入**，比打磨慢得多，可以用更小的 B）。验收：在"人工给定 0.5/1.0/1.5 mm 侧向偏置"三档下各 10 次，力峰值 ≤ 本文的等效量（我们既有 effort 口径 `safety 1.63`）且无中止。
3. **用本文的"参数扫描表"当我们整定阻抗参数的方法论模板**：单变量扫描 + 记录(超调、调节时间、稳态误差)三列，而不是"调到一个能跑的值"。需要：在 Gazebo（`--world sim`）里搭一个刚度已知的接触面（本文取 `K_e=3500 N/m` 作参照 [p.53]），用 KWR75 的仿真替身发 wrench，按 M∈{1,5,10}、B∈{150,300,500}、K∈{0,150} 扫，验收：选出的一组参数在 20 次插入里力峰值波动 <20%。

## 8. 与本课题现有路线的冲突点
- **与"整条轨迹下发"冲突（最硬的一条）**：本文能跑 100 Hz 外环，前提是它的控制器支持"位置跟踪运动，运动过程中可更改目标位置" [p.18]；我们的执行器 `scripts/execute_assembly_chunks.py` 是**把整条 `FollowJointTrajectory` 交给 `ros2_control` 的 position 接口**，中途改不了目标。=> 要么在 `execute_assembly_chunks.py` 之上加"按 100 ms 切片重发 goal"（每片内部仍是整条轨迹，片间可改），要么把外环周期降到与我们 371 mm/0.005 m/s 的节拍匹配的 **~5–10 Hz 切片**。**不能假设 100 Hz 流式可用**：按 0.005 m/s、100 Hz 算，每次插入需要 **≈7420 个位置指令**，而当前架构每个 chunk 只有一次 goal。
- **与"effort 残差当接触判据"冲突**：我们现在靠关节 effort 残差（`contact 0.68 / safety 1.63`，`scripts/compliant_insert.py`）判断接触；本文的接触判据是**力阈值（10 N）+ 力方向**。两套口径不能同时做主判据，否则会出现"力觉要求继续、effort 判据要求停"的互锁（这一点在本批其他笔记里也出现过）。必须做一次同工况标定：把 effort 0.68/1.63 对应的接触力测出来（用 KWR75 记录），再定 N 口径阈值。
- **与"7 kg 工件 + 353 mm 力臂"的冲突**：本文负载 11.7 N、质心 49 mm、力矩量级 0.1 N·m；我们是 68.6 N、353 mm、力矩量级 10 N·m 级。本文的"忽略力矩"假设与"安装误差只绕 Z 转一个角"假设**均不成立**，标定必须解 6 个零点 + 3 个质心 + 至少 2 个安装角。
- **与站位表/绝对坐标无关部分不冲突**：本文全程用绝对笛卡尔坐标 + 力纠正，不涉及站位表；我们可以把它当成"抓取/选站之后的末端柔顺层"，不改变现有 `common.yaml:workpiece_views` 的选站逻辑。
