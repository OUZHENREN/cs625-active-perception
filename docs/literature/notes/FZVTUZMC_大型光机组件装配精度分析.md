## 2. 一句话结论与相关性
- 一句话：以神光-III 大口径传输反射镜组件（610 mm×440 mm×85 mm、70 颗侧面螺钉预紧）为对象，把装配精度拆成"**面形精度**（预紧力不确定 → 有限元 + 蒙特卡罗 + 对数正态 3σ 上限）"和"**几何精度**（3DCS 三维公差仿真 → 法线 432 μrad ≫ 50 μrad 要求 → 三球铰离线装校修正）"两条线，最后用 NIF 的误差分配表给出稳定性指标 [原文证据] p.4、p.36、p.52–p.60。
- 相关性分类：**方法迁移**。理由：它研究的不是机器人，而是"零件制造/装配误差 → 装配功能指标"的**不确定度传播与指标分配**；但其蒙特卡罗流程、3σ 上限判据、杠杆臂灵敏度公式、稳定性分配表可以直接搬进我们的误差链。
- 影响的具体决定：**误差预算**（怎么把总量拆到子项）、**验证方式**（MC + 干涉仪实测对照）、**定位要求**（杠杆臂/支承间距决定"1 μm → 多少 μrad"）、**观测动作**（插入前对准误差与"必须离线校正"的边界）。

## 3. 对象与任务
- 对象：大口径平面反射镜组件，镜体 **610 mm×440 mm×85 mm**，材料 K9 玻璃，弹性模量 **88 GPa**、泊松比 **0.215**、密度 **2520 kg/m³**；周向支撑，**三个侧面共 70 颗螺钉**预紧 [原文证据] p.36 表 3.5。
- 性能要求：面形——移除离焦与像散后的残余面形 **PV < 211 nm** [原文证据] p.38；几何——镜面法线安装角度偏差 **≤50 μrad** [原文证据] p.52；稳定性——NIF 口径的总漂移 **Δθ 0.68 μrad / Δd 6.8 μm**（分解为结构 0.41/4.1、热瞬态 0.24/2.4、偶然 0.03/0.3）[原文证据] p.60 表 4.3。
- 检测/分析配置：ANSYS 有限元；ZYGO 大口径菲索干涉仪 + MetroPro（面形）；自准直仪/测角仪（法线）；3DCS（嵌入 CATIA V5）做三维公差蒙特卡罗仿真 [原文证据] p.46、p.50–p.53。
- 环境：光学装配大厅；45° 倾斜姿态下无面形检测装置（作者自认）[原文证据] p.46。

## 4. 方法与机制链
**链条 A（面形）**：`FEM（重力 + 70 螺钉预紧力）→ 镜面节点变形 → 矩形口径 Zernike（Schmidt 正交化）波面拟合 → 移除前 6 项（离焦+像散）→ 残余 PV/RMS → 预紧力不确定性蒙特卡罗 → 对数正态拟合 + K-S 检验 → PV 上限 PV_UE = e^(μ+3σ)` [原文证据] p.36–p.43。
**链条 B（几何）**：`小位移旋量（SDT）+ 雅可比公差模型 {FR}=[J]{FE} → 3DCS 多工序装配仿真（公差、装配顺序、Measure 功能要求）→ 法线准直误差 → 离线装校（三球铰 z 向调节）→ 复位误差 → 稳定性（振动/热/偶然）` [原文证据] p.49–p.51、p.55–p.60。

**误差源如何枚举与分类**（重点 ①）
- 面形侧：**装配应力**（螺钉预紧力，控制误差实测 **±25%**，文献称可到 ±30%~±40%）+ **自重**；制造原始面形被显式**排除**（"性能要求中忽略了面形的加工制造误差"）[原文证据] p.35、p.39、p.44。
- 几何侧：① 零部件加工误差（平面度等）；② 镜架地脚螺钉安装误差；③ 运动学支撑结构调整误差；④ **复位误差**（重复放置位置偏差 + 振动/姿态变化后镜片相对镜框的姿态变化）；⑤ 稳定性（结构振动 / 瞬态热冲击 / 偶然因素）[原文证据] p.52、p.58、p.60。这是一套**按物理成因分类**的枚举，比按"制造/装配"分类更适合做误差预算。
- 敏感误差识别（重点）：**没有灵敏度分析**，只有单因素扫描——把预紧力控制误差 p 取 15%/20%/25%/30%/35% 五档、把理论预紧力 Fn 取 180/220/260/300/340 N 五档，各跑 500 次 MC，看 PV 上限怎么变 [原文证据] p.40、p.43、p.46 表 3.8。属于"扫描式敏感性"，不是 Sobol/信息熵那类全局灵敏度。

**误差传播用什么模型**（重点 ②）
- 面形：**有限元（物理模型）+ 蒙特卡罗（统计传播）**，没有解析误差链。MC 流程：确定 F 分布区间 [Fn(1−p), Fn(1+p)] → 区间内随机抽样 → 赋给 70 颗螺钉 → 求解 FEM → 得 PV → 重复 N 次 → 统计 [原文证据] p.39–p.40 图 3.9–3.10。
- 几何：**小位移旋量 + 雅可比矩阵**的标准三维公差模型，**{FR} = [J]{FE}**，J 体现误差传递；具体仿真由 3DCS 完成（定义公差 → 按装配顺序定义 Move → 定义 Measure → 设定仿真次数）[原文证据] p.49–p.51 式(4.1)。
- **可复现性**：面形链可复现（FEM 载荷/约束、Zernike 流程、MC 抽样、对数正态 3σ 公式 e^(μ+3σ) 都写清）；几何链**不可复现**（3DCS 是商业软件，公差输入值与 Move 定义未列全）。
- **杠杆臂灵敏度公式（可直接用）**：三球铰定位下 Δθx = Δz₃/(y₃−y₁) = Δz/350 rad（I 型），Δθy = Δz/(x₂−x₁) = Δz/760 rad（II 型）；即 **1 μm 的 z 向调节量 ≈ 2.86 μrad（I 型）** [原文证据] p.56 式(4.9)–(4.10)。这正是"支承间距越小、角度越敏感"的定量表达。

**精度分配/公差分配的判据与目标函数**（重点 ③）
- 面形：判据是 **PV 上限 ≤ 211 nm（取 3σ 上限，等价 99.73% 分位）**；由此反解工艺参数——PV_UE=211 nm 对应理论预紧力 **221.422 N**，按 T = F[P/(2π) + μ_s·d₂/(2cosβ)]（μ_s=0.3、d₂=5.513 mm、P=0.75 mm、β=30°）算得扭矩 **237.862 N·mm**；实际工程取 **200 N·mm** 留余量 [原文证据] p.45–p.46 式(3.14)。[分析推断] 我用该式复算 221.422×[0.75/6.283 + 0.3×5.513/(2×0.866)] ≈ **237.8 N·mm**，与原文一致，公式可复现。
- 几何：判据是**分配表**——NIF 把总漂移 0.68 μrad/6.8 μm 拆成结构、热、偶然三项，再把结构振动拆成 6 个激励源 [原文证据] p.60 表 4.3–4.4；这是"自顶向下给每项一个上限"，而不是用成本函数优化分配。
- **没有**做"精度—成本"优化（论文的取舍是定性的：提高力矩扳手精度到 2%、改垫片材料、改支撑结构）[原文证据] p.43、p.68–p.71。
- 运动规划/可达性：**无机器人、无运动规划、无视角选择**；只有"离线装校工装上的三球铰 z 向调节"这类人工调整，可达性概念不适用 [分析推断]。

**可靠性怎么算**（重点 ④）
- 蒙特卡罗次数：**500 次**，作者称"达到 500 次时已经足够满足精度要求"（**无收敛性判据/无样本量试验**）[原文证据] p.40。
- 分布假设：先按**正态**拟合，K-S 检验（α=0.05，H=0 表示不能拒绝）给出 H=1（PV 样本**不服从**正态），改用**对数正态**，全部 H=0；理由是 PV 样本右偏 [原文证据] p.41、p.43 表 3.7。
- 置信/上限口径：用**3σ 准则**推到对数正态：PV_UE = e^(μ+3σ)，五档 p 下为 **241.06 / 291.45 / 346.91 / 377.56 / 417.93 nm** [原文证据] p.43 表 3.7。
- 实验验证：用 200 N·mm 扭矩装多件，ZYGO 实测残余 PV **全部 <211 nm**，与理论一致；但作者自认实测**扣除了近 100 nm PV 的制造面形误差**，且 45° 姿态无检测手段 [原文证据] p.46–p.48。
- 可靠性口径评价：**有"超标率"概念但未给数值置信区间**；没有把 500 次的抽样误差写成置信带，属于"点估计 + 3σ 经验上限"。

## 5. 证据强度
- 基线公平：面形部分有 FEM 理论 vs 干涉仪实测的对照（定性一致）；几何部分只有 3DCS 仿真 vs 现场实测两组数据（实测 405.5–508.5 μrad 远大于要求 50 μrad，与仿真 432 μrad 相符）[原文证据] p.52–p.53 表 4.1——**这是全文最强的证据对**。
- 试验次数：面形实测件数未报告（只说"多个反射镜组件"）；复位精度表 4.2 只列 **7 组**（正常 1.6–28.7 μrad，操作不当 58.0 μrad）[原文证据] p.59。
- 失败样本/扰动：报告了"操作不当"这一失败工况（58.0 μrad 超差），并归因于安装瞬时冲击（实测单方向加速度 **>10 g**）[原文证据] p.59——这一点值得学：**把失效工况单独列出来**。
- 统计口径：均值/标准差/上限都给了（表 3.7/3.8），但**没有置信区间**；MC 500 次的抽样误差未评估。
- 口径不一致：中文摘要写神光-III"**48 条光束**"，英文摘要写"**192 beams**" [原文证据] p.4、p.5——同一事实两个数字，引用时只能引中文摘要并注明存疑。

## 6. 最脆弱的 1–3 个假设
1. "同一扭矩下预紧力的离散可用区间 [Fn(1±p), Fn(1+p)] 内**均匀分布**描述" —— 方法必需（p.39 原文"以区间表示…随机赋值"）。分类：**尚未测试**。论文实测只给了"±25% 左右"这个区间宽度，没有给分布形状；若真实分布是右偏（对数正态），用均匀抽样会**低估**高预紧力尾部，PV 上限偏乐观 [分析推断]。
2. "面形误差只由重力 + 预紧力决定，制造面形可忽略" —— 作者明说 [原文证据] p.35。分类：**范围内反例**。作者自己在 p.48 承认制造面形"有近 100 nm PV，**不可忽略**"，与 p.35 的前提直接冲突；这说明它的 211 nm 判据是"装配引起的部分"，不是"总面形"。
3. "三球铰离线装校后，法线精度可长期保持（复位误差 ≤50 μrad）" —— 方法必需 [原文证据] p.57–p.59。分类：**范围外迁移限制**。复位实验里 1 次"操作不当"就跳到 58 μrad，说明保持性依赖操作规范而非结构；迁移到我们的 7 kg 工件 + 371 mm 长插入时，"复位/重复装夹"误差可能比标定误差更大 [分析推断]。

## 7. 可迁移到本课题的具体做法（1–3 条）
- 说明：以下 1–3 条均为 **[待验证设想]**——迁移方案尚未在本平台跑通，给出的验收指标是建议门槛，不是已验证结论。
1. **把"单点误差链"升级为"蒙特卡罗 + 3σ 上限"的插入成功率模型**：输入取我们的实测口径（工件位姿 **0.42 mm / 0.078°**、插槽 0.64 mm、手眼标定残差），对 371 mm 插入链做 N=500（先）与 1e5（校验）两次抽样，分布先正态、再用 K-S 检验决定是否换对数正态，输出"插入端横向偏差的 3σ 上限"和 **P_success = P(|Δx| ≤ 1 mm)**（单侧间隙 1–2 mm 取保守 1 mm）。需要：一个纯离线脚本（不占真机）+ `config/tasks/common.yaml` 里的公差/重复性字段。验收指标：N=500 与 N=1e5 的 95% 分位差 **<5%**；P_success 的 95% 置信区间宽度 **<0.02**（用 bootstrap 给）。
2. **杠杆臂灵敏度直接落地成"深度—误差"表**：用它的 Δθ = Δz/L 形式，取我们 L=**371 mm**，得 **1 μm → 2.70 μrad**；反过来，实测姿态重复性 0.078° = 1.36 mrad → 371 mm 处横向偏差 **0.51 mm**。把这张表写进插入前 gate：插入深度 d 处允许横向偏差 = 单侧间隙 × 0.8（留 20% 余量），当 d×tan(σθ) 超过该值时先补一次精观测。需要：`plan_pose_ik` 之前增加"深度—角度"断言、实验记录增加深度列。验收：20 次插入中因角度超限触发的重观测次数 ≤3 次，且无卡阻。
3. **照 NIF 的分配表做我们的"公差分配表"**：把 1 mm 单侧间隙按**测量/标定/运动学/热/重复性**五项分配（每项给 3σ 上限，平方和 ≤1 mm），并标注哪一项由谁负责（视觉组/标定组/机械组）。需要：一张表进 `docs/`，字段与 `config/tasks/*.yaml` 的 gate 对应。验收：分配表五项 RSS 校验通过（≤1 mm），并且实测各项与分配值偏差 <50%，否则重分配。

## 8. 与本课题现有路线的冲突点
- **与"误差链 + 蒙特卡洛 + 公差分配"设想相比，它更严谨的地方**：① 用 **K-S 检验决定分布族**，而不是默认正态——我们的 MC 目前假设正态，应当照做；② 用 **3σ 上限（分位数）而不是均值**作为判据，正好对应我们要的"成功率"；③ 把**失效工况**（操作不当 58 μrad）单列，这是可靠性叙事里最有说服力的一页。
- **它不适用/不如我们的地方**：① MC 只对**单个参数**（预紧力）抽样，不是多源联合抽样；我们的误差链有 5–6 个源，必须做**联合抽样 + 灵敏度排序**（它没有排序）；② 3DCS 是商业软件 + 全尺寸 CAD 模型，我们没有 CATIA 环境、也不该为 7 kg 工件建全尺寸公差模型，用**解析/脚本化误差链**更合适；③ 它的对象是"零件—零件"静力学装配，我们是"机器人—被测件—插槽"运动链，**运动学误差（关节、手眼）不在它的模型里**。
- **与"站位表选站"的冲突**：本文的几何误差修正靠"离线装校 + 三球铰"，是**一次性机械调整**；我们的站位切换是**离散重定位**，两者都会引入"复位误差"这一项，但它把复位误差限定在 50 μrad、且靠操作规范保证——我们的站位切换位移达 90–120 mm（站位 12–15° 偏差时的合法偏移），**复位误差不能按 50 μrad 量级假设**，必须实测 [分析推断]。
- **精度尺度冲突**：它要求 50 μrad / 211 nm，我们只需 1 mm / 1.36 mrad；照搬其 μm/nm 级指标会过度设计，反之其"3σ 上限"口径可以直接用 [分析推断]。
