## 2. 一句话结论与相关性
- 一句话：为 EAST 托卡马克第一壁石墨瓦螺栓拆装，搭了 **UR5 + SUNRISE M3705C 六维力 + 单目视觉 + 磁跟踪示教** 的平台，用**基于动态运动基元（DMPs）的力反馈"相停（phase stopping）"** 在力/力矩误差超阈值时暂停或放缓路径演化、回落后续行，配合**位置不确定性扩展圆搜索**，用**连续 7 次 DMP 迭代学习**把插入时间压到接近人工示教水平，最终完成螺栓拆卸 [原文证据] p.5–6、p.110–115、p.128–131。
- 相关性分类：**方法迁移**——硬件（EAST 专用臂、磁跟踪、UR5）不可搬，但"**力误差触发暂停/放缓 → 位姿修正 → 恢复**"这一事件驱动柔顺骨架，与我们"位置接口 + 需要接触阶段闸门"的现实最接近。
- 影响本课题的具体决定：**接触切换**（事件触发的暂停/恢复，而不是固定节拍）、**验证方式**（用"第 N 次迭代的插入时间曲线"当可复现证据，而不是单次成功）。

## 4. 方法与机制链（含四问）
`单目视觉位姿估计（椭圆孔 → P4P）→ 末端移动到估计点 → 扩展圆搜索找孔（Z 向力突变即判该点不可插）→ 回到示教起始位 → DMPs 泛化插入轨迹 → 力/力矩误差超阈值触发相停 → 位姿修正 → 恢复演化 → 完成拆卸` [原文证据] p.116–117、p.128–131。

### Q1 六维力怎么接入（本批最弱的一篇）
- **采样率**：传感器指标页只给量程/串扰/非线性，**没有采样率**；正文也未给 [未定位]。
- **滤波**：**未定位**（全文无滤波器/截止频率描述）。
- **零漂**：**未定位**（全文无"零漂/温漂/预热"命中）。
- **重力补偿与偏心**：**全文没有**——没有重力补偿公式、没有质心标定、没有姿态标定步骤。原因可从任务推断：工具轻（传感器本体 0.175 kg）+ 姿态基本竖直 + 只做拆卸，重力主要体现为 F_z 常值 [分析推断]。
- **唯一做了的标定**：相机内参（张氏，25 幅）+ 手眼（25 组，LM 求 AX=XB）+ trakSTAR 与机器人基座（**10 种关节位型**，各结果取平均）[原文证据] p.124、p.126–127。→ 这三组数字（10、25、25）反而是本批"姿态数量"里唯一可对照的量。
- **对 Q1 的结论**：这篇**不能**作为我们 KWR75 接入的参数来源，只能作为"不做重力补偿也能跑"的反例（因为它的负载与姿态条件太特殊）。

### Q2 接触阶段识别
- **两层判据，不是多状态分类**：
  1. **搜索层**：机器人垂直姿态尝试插入，末端与石墨瓦表面接触时"**沿 Z 方向的轴向力会产生突变**"，超过**保护阈值**即判"该尝试点不可插入"，抬起到下一点（阈值数值未给）[原文证据] p.109、p.128。
  2. **插入层（相停）**：定义力/力矩集成误差 `||e||`，超过预先定义阈值 `max_p`、`max_q` 时相变量 ẋ 被压低（式 5.33/5.34），机器人**暂停或放缓**前向运动并修正位姿，"一旦误差降低至阈值以下，恢复示教速度" [原文证据] p.110、p.113。
- **状态数**：搜索层 2 态（可插/不可插）+ 插入层 2 态（正常演化/相停）→ **共 2 个二值闸门，没有"接近/接触/入孔/到位"的多状态机**。
- **误判率：未给**（无假阳性/假阴性统计，无试验次数分母）。
- **阈值怎么定**：只说"预先定义""根据力反馈值实时调整"，**没有任何整定过程或数值** [未定位]。

### Q3 柔顺类型：导纳，且是"增益型位置修正"
- 原文明确写"通过公式（5.28）和（5.29）所示的**导纳控制机制**计算出对应的机器人末端位置和姿态偏移量" [原文证据] p.115。
- 结构：`p(x) = p_DMP(x) + Δp`、`q(x) = q_DMP(x) ⊗ Δq`，其中 Δp/Δq 由**力/力矩误差 × 增益矩阵 K_p、K_q2（3×3 对角）** 得到（式 5.28–5.32）[原文证据] p.112–113。
- **为什么选导纳**：原文只给理由"力和力矩误差被用来触发相变量的改变"，并说明"由于力反馈控制系统稳定性和鲁棒性要求，采用了**较低的增益系数**"→ 增益低 ⇒ 修正过程缓慢 ⇒ 需靠相变量降速来等它 [原文证据] p.113。
- **M/B/K 数值与单位：没有**。既没有质量阵、阻尼阵，也没有刚度矩阵的数值；只有"低的增益系数 K_p、K_q2"这一句 [未定位]。
- **控制周期**：柔顺环路没有周期；底层伺服是**电流环 25 kHz、速度环/位置环 5 ms**（表列 25 kHz / 5 ms / 5 ms）[原文证据] p.95。即这套"相停"跑在 **≈200 Hz 位置环**上，不是低频节拍。

## 5. 证据强度
- **无基线对比**：没有"不加 DMP / 不做相停"的对照组，7 次迭代只是同一方法的时间曲线。
- **无分母**：没有成功率、没有失败样本、没有多次独立试验。
- 曲线证据（偏移量、力、时间）是**单工位单次链**，不能外推为统计结论 [分析推断]。
- 唯一的定量硬指标是传感器指标表与 240 Hz/0.5 mm/0.1° 的跟踪仪参数，与装配性能无关。
- **≤10 Hz 停走节拍核实（本批专项）**：**不是**。它的"停"是**力误差超阈值触发的事件**（相停），不是每 100 ms 定时的位置目标；底层位置环 **5 ms（≈200 Hz）**，示教跟踪仪 **240 Hz**，全文无 100 ms/10 Hz 的命令节拍。→ 可作为"停走"的**思想原型**，但**不能**作为"10 Hz 节拍能装进去"的定量证据；且它没有间隙数值与成功率。
- 结论：**作为"存在性证明"可用**（力反馈 + 学习能在该场景把工具插进去），**作为定量证据不可用**。

## 6. 最脆弱的 1–3 个假设
1. **"相停 + 低增益位置修正就足以吸收视觉位姿误差"**——作者明说（且靠"位置不确定性搜索"兜底）；分类：**范围外迁移限制**：他们没量化间隙，我们 371 mm 深插入会把角度窗口压到 0.15–0.31°（见 §7），低增益慢修正会显著拉长插入时间。
2. **"一次示教路径可泛化到新螺栓"**——方法必需（DMP 的核心卖点）；分类：**尚未测试**：全文只有一个螺栓/一个工位的 7 次重复。
3. **"力阈值可预先定义且无需整定"**——我的推断（原文只说"预先定义"）；分类：**范围内反例**：同一篇里"保护阈值"和"相停阈值"是两套，说明单阈值不够，但作者没讨论两者关系。

## 7. 可迁移到本课题的具体做法
1. **把"相停"降级成我们架构里的事件闸门**（最值得搬）。做法：在 `scripts/execute_assembly_chunks.py` 的切片循环里，每片执行前读一次 KWR75 的 fz/fx/fy，若 `|f - f_ref|` 超过阈值就把**下一片的步长置 0（原地停 1 片）**并下发一个"保持位姿"的短 goal，回落后恢复。需要：KWR75 1 kHz 读数（已有）、阈值常量进 `config/tasks/`、每片耗时实测。验收：371 mm 插入段在有人工扰动下不中止，且停走次数 ≤ 5 次（对应 74 s 插入窗口）。
2. **位置不确定性扩展圆搜索**：入口段用"下扎 0.5 mm → 读 fz 突变 → 抬起 → 圆上下一角"替代盲目对中。我们间隙 1–2 mm 比它宽松，可把搜索半径压到 ≤ 1.5 mm、角度步 30°。验收：20 次入口搜索全部找到孔且 fz 峰值 < 10 N。
3. **不要搬 7 次迭代学习**：它需要 7 次真机插拔来"学会"一条路径，我们 371 mm/74 s 一次插入，迭代成本不可接受；且我们的安全治理器不允许在线连续演化轨迹。

## 8. 与本课题现有路线的冲突点
- **与"自建位置型导纳 + 安全治理器"的总冲突**：本文的导纳是"**力误差 × 增益 → 位置偏移**"，没有 M/B/K，因此**无法给出我们能直接填进导纳律的 K/B 数值**；它证明的是"增益型位置修正"路线可行，而不是"标准二阶导纳"可行。
- **与治理器 `time_scale ≥ 1` 的冲突**：相停要求"随时暂停轨迹演化"，而我们的治理器只会**拖慢**（`max(1.0, time_scale)`）、不会暂停；要实现"停一片"必须**取消并重发 goal**，这会撞上 goal 更新延迟（`docs/reference/force_control_interface.md` 已列为必须实测项）。
- **与"整条轨迹下发"的冲突可调和**：它的每次"暂停/恢复"等价于我们把 1 条长轨迹切成 N 条短轨迹——方向一致，代价是规划开销（我们每片还要过 `plan_pose_ik` 安全闸）。
- **与站位表/视觉路线的冲突**：它用单目椭圆孔 P4P + 扩展圆搜索**在线**找孔，与我们的"站位表 + 三平面 CAD ICP"是两套；不建议替换，但可作为"站位表失效时的兜底搜索"。
- **与 0.10 rad/s 上限**：本文没有关节速度限制这一层（UR5 原厂限速），它的"暂停"没有治理器约束；我们若照搬，必须先算清"停一片 = 一次 goal 取消 + 重发"是否吃满 0.44 rad 单次行程上限（0.005 m/s × 0.1 s = 0.5 mm，关节量极小，安全）。
