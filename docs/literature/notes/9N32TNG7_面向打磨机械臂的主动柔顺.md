## 2. 一句话结论与相关性
- 一句话：在 **PUMA560 的 MATLAB 仿真**上做打磨任务的关节空间阻抗控制，围绕"**外力反馈不精确**"和"**环境/模型不确定**"两个问题，提出变参数阻尼矩阵（关节 2 最大跟踪误差降到 **0.009312 rad**）、**自由/接触两模式切换 + 模糊自适应 K_d**（恒力 10 N 跟踪：超调 **0.5 %**、稳态误差 **0.001 N**；加模糊后 **0.2 % / 0 N**）、力误差微分 + RBF 网络补偿（期望力/环境刚度/环境位置变化下稳态误差 **≤0.02 N**）[原文证据] p.4、p.30、p.37、p.45、p.46、p.49。
- 相关性分类：**方法迁移（有限）**——**纯仿真、无真机、无力传感器**，不能作为任何工程参数来源；唯一价值是给出"**K_d ≠ 0 必有稳态力误差、K_d = 0 才零误差**"的定量对照（与 7C8YS9Q8 的真机结论互证），以及"**力误差微分项抑制超调**"这一条可搬到我们导纳里。
- 影响本课题的具体决定：**柔顺参数**（K_d 与稳态力误差的定量取舍）、**接触切换**（两模式 + 模糊切换的边界条件）。

## 3. 对象与任务
- 对象：**打磨/抛光任务**（不是装配）：末端在工件表面做圆周运动并跟踪 Z 向恒定接触力；仿真中"环境位置 z_e = **0.68 m**、环境刚度 k_e = **1000 N/m**" [原文证据] p.36。
- 机器人：**PUMA560**（仅用前 3 关节位置，θ₄=θ₅=θ₆≡0）[原文证据] p.18。
- 期望接触力：**f_d = 10 N**（恒力）；另做斜坡力、正弦力跟踪仿真 [原文证据] p.36。
- 传感器：**没有真实力传感器**——接触力由环境模型 `F_e = k_e(x_e − x)` 解析算出 [原文证据] p.32–33。这是本文与其它五篇最本质的差别。
- 工件尺寸/质量/间隙/公差/洁净度：**全部不适用或未给**（无零件级对象）。

## 4. 方法与机制链（含四问）
`期望关节轨迹 + 阻抗参数 → 关节空间阻抗控制律（含或不含 τ_e 项）→ 关节力矩 → PUMA560 动力学 → 与环境接触（弹簧模型）产生 F_e → JᵀF_e = τ_e 反馈` [原文证据] p.18–19、p.33–35。

### Q1 力怎么接入（本文最弱）
- **没有六维力传感器、没有关节力矩传感器**：τ_e 要么由 `Jᵀ F_e` 从环境模型算出，要么**直接删掉**（阻尼矩阵设计法，式 2-6/2-7）[原文证据] p.21–22。
- **采样率/滤波/零漂/重力补偿与偏心：全部未定位**（仿真里没有这些环节；全文唯一的采样相关表述是"六维力传感器过于昂贵、**力矩传感器精度较差**、实际采样速率较低"，作为"为什么要删掉 τ_e 项"的动机）[原文证据] p.12、p.21。
- **对 Q1 的结论**：这篇**不能**回答我们任何接入问题；它的价值恰恰是**反面**——它示范了"没有力反馈时如何靠阻尼矩阵注入保持稳定"，可作为我们 KWR75 掉线/失效时的降级方案参考 [分析推断]。

### Q2 接触阶段识别
- **状态数：2 个模式**——"自由空间"与"接触空间"，切换判据是"**根据反馈回的接触力是否为零**"，分别采用两套控制律（式 3-4 与式 3-6）[原文证据] p.33–35。
- **阈值怎么定**：**没有给任何数值阈值**，只说"反馈的接触力是否为零"；仿真中接触力由模型精确给出，所以"零/非零"是可判的 [原文证据] p.35。
- **有没有给误判率**：**不可能给**——仿真无噪声、无扰动，接触时刻由几何精确决定（文中给出"3.32 s 接触"、"3.36 s / 3.26 s"等时刻）[原文证据] p.37、p.45。
- 结论：这是**最理想化的接触识别**（零噪声、二值），不能作为阈值整定依据。

### Q3 柔顺类型：阻抗（关节空间、力矩层）
- **明确是阻抗，不是导纳**，理由（可引用）："关节空间内的阻抗控制可以**避免计算机器人雅可比矩阵及其逆解**，减小计算复杂度"；并批评笛卡尔阻抗"奇异位形使雅可比不可逆、末端位置测不准"[原文证据] p.17、p.19。
- 基本式：`M_d Ë + D_d Ė + K_d E = τ_e`（式 2-2，E = θ_d − θ），三个参数阵取对角 [原文证据] p.18。
- **M/B/K 数值与单位（原文按"关节空间"，M 实际是 6×6 惯量阵）**：
  - 第 2 章初始仿真：**M_d = I（6×6 单位阵）、D_d = diag(12)、K_d = diag(200)** [原文证据] p.19–20。
  - 第 3 章力跟踪：**M_d = I、D_d = 对角线元素 20、K_d = 对角线元素 5.5**（注：原文对 K_d 写"对角线元素为 5.5 的 6×6 对角阵"，单位按阻抗式应为 N·m/rad，但原文未标单位）[原文证据] p.36。
  - 阻尼矩阵设计法：`D_d(θ₀) = 2Q(θ₀)ᵀ diag(ξ_i λ_i) Q(θ₀)`，ξ_i 为广义特征值的阻尼系数（未给具体 ξ 值）[原文证据] p.22。
  - **单位口径提醒**：数值 12/20/200/5.5 混用"6×6 对角阵"表述，**单位在原文中不严格**（这是它的硬伤之一）。
- **控制周期**：**未给**（MATLAB 仿真未报步长/求解器）→ [未定位]。
- 仿真验证：关节 2 阻力 0.3 N·m 与式 2-2 反算一致（稳态角 1.5693 rad vs 期望 π/2）[原文证据] p.21。

### Q3 补充：K_d 与稳态力误差的定量关系（本文最有用的一条）
- 式 3-15 的稳定性分析结论："最简单的方法即令 **K_d = 0** 可以保证系统稳定、**稳态误差为 0**。但是通过仿真发现，前期位置跟踪的即时性无法保证，机械臂无法快速与环境接触。为保证系统的快速性，本文把 K_d 设为**非零值**…因此上述方法能保证系统稳定性，但**可能存在一定的稳态误差**" [原文证据] p.35。
- 这与 7C8YS9Q8 的 `k=0` 结论**完全一致**（两篇独立得出），是我们设计"接触前 K>0、接触后 K=0"两段参数的**交叉证据**。

### Q4 实验口径
- **没有真机实验**：全部是 MATLAB/Simulink 仿真（"通过对 PUMA560 的仿真"）[原文证据] p.4。
- 试次/间隙分档/成功率/力峰值/失败样本：**全部不适用**。
- 有意义的仿真指标：
  - 恒力跟踪（无模糊）：超调 **0.5 %**、接触时刻 **3.36 s**、峰值时间 **4.23 s**、稳态误差 **0.001 N**[p.45（表 3-3）]。
  - 加模糊：超调 **0.2 %**、接触 **3.26 s**、峰值 **3.94 s**、稳态误差 **0 N**；接触提前 **0.1 s**[p.45]。
  - 改变期望力/环境刚度/环境位置三种条件下，稳态误差 **≤0.02 N**；其中"环境位置变化时 0.02 N"[p.46、p.49]。
  - 关节 2 最大跟踪误差从"超过 0.25 rad"降到 **0.009312 rad**[p.30]。
- 扰动设置：t=2 s 时末端施加 **10 N** 沿 Z 轴阻力、持续 **0.5 s**（用于"外力不精确"仿真）[原文证据] p.23。

## 5. 证据强度
- **本批最弱**：**纯仿真**、无力传感器、无噪声、无摩擦、无真实环境刚度不确定性（k_e 是设定值）。所有"稳态误差 0 N""0.02 N"都是**模型内自证**，不能外推到真机。
- 优点：**对照做得细**（有/无模糊、三种环境变化、K_d=0 与 K_d≠0 的稳定性讨论），且**给出了 K_d 与稳态力误差的因果解释**。
- 弱点：① 单位口径不严；② 无采样周期；③ 只控制前 3 关节（打磨任务只需位置，回避了姿态）；④ RBF 网络补偿部分（第 4 章）只报"单关节跟踪误差"，没有力跟踪的定量改善表。
- **≤10 Hz 停走节拍核实（本批专项）**：**不适用**——纯仿真、无命令节拍、**连仿真步长都没给**；不能用它论证任何节拍可行性。
- 结论：**只能当"设计原则"来源，不能当"参数"来源**。

## 6. 最脆弱的 1–3 个假设
1. **"接触力可由 k_e(x_e−x) 精确得到"**——方法必需（仿真的全部基础）；分类：**范围外迁移限制**：真实工件有倒角、表面粗糙度 6.3 以上、多点接触，k_e 不是常数，这条在真机上必然失效。
2. **"K_d≠0 带来的稳态力误差可以接受"**——作者明说（为了快速接触）；分类：**范围内反例**：在装配任务里"稳态力误差"就是"插不进去/过盈"，不能接受 → 我们必须接触后置 K=0。
3. **"前 3 关节足够描述打磨"**——作者明说（θ₄=θ₅=θ₆=0）；分类：**范围外迁移限制**：我们的插入需要 6 维姿态，不能忽略腕部。

## 7. 可迁移到本课题的具体做法
1. **两段参数的切换逻辑（接触前 K>0 / 接触后 K=0）**。做法：在自建导纳里，接触判定前用"K_xy 小、K_z 小"的软参数便于接近；检测到 |fz| > 阈值后，**把 K 全部置 0**，只留 M/B 做力跟踪。需要：一个明确的"接触事件"信号（KWR75 fz 过阈值）与迟滞（防抖）。验收：接触后 2 s 内 fz 稳态误差 ≤ 2 N，且回弹（K≠0 导致的"顶回去"）消失。
2. **力误差微分项抑制超调**：式 4-x 引入 `ḟ` 项，作者称可"消除机械臂接触环境时的力超调"，并对微分系数做模糊调节 [原文证据] p.50–51、p.57。我们 371 mm 插入最怕的就是接触瞬间的力超调（KWR75 量程与工件都怕），这一项值得加。验收：接触瞬间 fz 峰值 ≤ 15 N（20 次），无超调振荡。
3. **不要搬"模糊自适应 K_d"**：它的模糊规则表（7×7，表 3-2）是在仿真里整定的，规则库不可解释且没有真机验证；我们若要做自适应，宁可用"按插入深度分段"的简单调度。

## 8. 与本课题现有路线的冲突点
- **与"仅 position 接口"的根本冲突**：本文是**力矩层阻抗**（直接算关节力矩），我们没有力矩接口 → **控制律完全不可实现**，只能借它的"K_d=0 的结论"与"参数切换逻辑"。
- **与安全治理器的冲突**：它的变参数阻尼矩阵要在线算 `Q(θ)`（Cholesky + 施密特正交化 + 特征分解），每次都要；我们的治理器是"轨迹重计时 + 速度钳位"，**没有力矩层**，也无法在 0.10 rad/s 下体现阻尼矩阵的效果。
- **与 7 kg 负载的冲突**：它删掉 τ_e 项的理由是"力矩传感器精度差"；我们恰恰有 KWR75（0.5 %FS），**不该删力反馈**，而应保留并做补偿。→ 本文的"删 τ_e"对我们只适用于**降级模式**（KWR75 失效时）。
- **与"自建位置型导纳"的定位**：本文可作为**导纳律的对照解释**——它证明了"K≠0 ⇒ 稳态力误差"，因此我们的导纳**在插入段必须 K=0**，这与 `docs/reference/force_control_interface.md` 里"自建位置型导纳"的设计判断一致。
- **与 371 mm 深插入的冲突**：打磨是"表面恒力"，接触面积大、法向单一；插入是"深孔多点接触"，力方向随姿态变化，本文的"单方向 Z 向 10 N"模型不适用。
