## 2. 一句话结论与相关性
- 一句话：为不规则形状工件的自动化精密装配开发一套 HALCON 视觉定位引导系统（Eye-in-Hand）——**改进 9 点标定**求图像↔机器人变换、**形状模板匹配 + 仿射对齐**、**卡尺工具亚像素边缘（1/100 像素）+ Tukey 加权最小二乘拟合三条边**求三顶点与中心、**角度线性回归**（y = 1.014638x − 40.0227）换算 C 轴转角；§4 系统实现与结论均称"X 方向最大定位误差 **0.0281 mm**、Y 方向 **0.026 mm**" [原文证据] p.111、p.113、p.114。
- 相关性分类：**工程工具**。理由：提供了一套"2D 视觉引导 + 标定 + 亚像素边缘"的标准工程流程与 HALCON 算子级细节，但没有 3D/6DoF、没有点云、没有 CAD 配准；同时它的精度主张证据最弱（见 §5），只能当"工程怎么做"的参考，不能当"精度能做到多少"的证据。
- 影响本课题的具体决定：**观测动作**（卡尺 + 直线拟合求长边交点，可作为插槽口长边的交叉验证通道）、**验证方式**（警惕"最大值口径 + 无 n"怎么写坏一个精度结论）、**误差预算**（标定残差必须显式给出，否则 9 点仿射的黑箱误差会直接进插入）。

## 4. 方法与机制链
- 链条：`grab_image 采图 → 预处理 → create_shape_model 建形状模板 → find_shape_model 得位置/角度/匹配分值 → vector_to_rigid / affine_trans_pixel 图像对齐（HomMat2D = H(T)·H(R)）→ gen_rectangle2_contour_xld 建卡尺 ROI → measure_pos 亚像素边缘（行投影 → 高斯导数卷积 → 边缘幅度/极性阈值 → 最近邻内插，以 1/100 像素为单位）→ pts_to_best_line（Tukey 加权最小二乘 + ClippingFactor 抑制异常点）→ intersection_lines 三线两两相交得 3 顶点 → Find_CenterPoint 求中心 → 标定矩阵把图像坐标换成机械手坐标 → 吸盘抓取 → 角度回归得 C 轴转角` [原文证据] p.112–p.113。
- **手眼标定方法与残差口径**：**Eye-in-Hand（EIH）** 手眼模型 + **改进的 9 点标定**，五步：①grab_image 采标定板；②Blob 分析（rgb1_to_gray、threshold、select_shape 二值化/形状选择/形态学）；③gen_contour_region_xld 取亚像素轮廓 + **Spoke 拟合**求各 Mark 点中心；④**控制机械手末端依次对准每个 Mark 点中心，记录机械坐标**；⑤用 9 组坐标建立图像↔机器人变换矩阵 [原文证据] p.112。**残差完全没有给**：只说"经过多次实验验证，此种优化算法能更精确地获取 Mark 点中心坐标"，未给 9 点仿射的最小二乘残差、未给对准误差、未给组数以外的信息。
- 角度校正：用"视觉测得的角度 Deg1/Deg2"与"机器人 C 轴转角 △Jc"做**线性回归**，5 组数据得 `y = 1.014638x − 40.02267721`（式 (6)）[原文证据] p.113。注意：斜率 ≈1.0146（视觉角与关节角比例并非 1:1）、截距 **−40.02°**，说明两者之间存在系统性偏置与增益差——**这本身就是标定残差未消化的证据**。
- **位姿估计的不确定度来源（逐项）**：①亚像素边缘量化（文中称 1/100 像素）[原文证据] p.113；②三线拟合的异常点（Tukey 抑制，但 ClippingFactor 取值未给）；③9 点标定的仿射残差（未给）；④**单平面、单高度假设**——整个流程只有 2D 坐标，没有 z、没有相机倾角；⑤角度回归残差（未给 R²、未给残差）；⑥模板匹配的相似度阈值与遮挡/反光敏感性（未给阈值）。
- 改变了哪个假设：它把"视觉引导"简化成"图像平面内的仿射 + 一条角度回归"，靠**两个拍照位（放料位、取料位）分别定位**来避免"一个视角看两处"的问题；但代价是所有精度都绑在"物面等高"上 [分析推断]。

## 5. 证据强度
- 真机 vs 仿真：**真机**（六轴机器人 + 实物工件 + 吸盘抓取装配），无仿真。精度类型上，它既不是重复性（无 2σ、无 n），也不是对标准件的绝对精度（无真值仲裁），而是"多次测试中的最大值"这一极值口径。
- **精度口径是"最大值"，不是重复性统计**：原文"经过多次重复性测试，得到如图 6 所示的由视觉定位获得的机械坐标数据折线图，在 X 方向最大定位误差为 **0.0281 mm**、Y 方向最大定位误差为 **0.026 mm**" [原文证据] p.114。→ ①**没有 n**（只说"多次"）；②**没有标准差、没有置信区间**；③"最大误差"是极值口径，随样本量增大必然变差，不能与其他论文的 2σ 直接比；④未说明误差相对**什么基准**（机械手示教坐标？CAD 标称？）。
- 文中表 1/表 2 的 5 组数据**不能当重复性证据**：表 1 是放料位被装配件的中心与"最长边与 x 轴夹角"（Qx1 跨 −28.751～−27.505，即 **1.246 mm**；Deg1 跨 12.454°～12.677°，即 **0.223°**），表 2 是装配基础件（Deg2 跨 −29.343°～−78.631°，接近 50°），这是**工件随机摆放的真实位姿**（文中明说"取料区的工件随机摆放"），不是同一目标的重复测量 [原文证据] p.113。→ 不能由这些数据推出重复性。
- 失败样本：未报告；装配成功率未报告。
- 基线：无（不与其他视觉方案对比；引言里的贴片机精度数字是文献转述）。
- 统计结论：**这篇是本批 6 篇里证据最弱的一篇**——所有关键精度主张都缺 n、缺分布、缺真值口径。

## 6. 最脆弱的 1–3 个假设
1. **"9 点标定得到的仿射矩阵足以把图像坐标变成机器人坐标"** —— 方法必需，作者未讨论残差 [原文证据] p.112。分类：**范围外迁移限制**：仿射隐含"相机相对机器人固定 + 物面等高 + 无镜头畸变残差"；我们随臂相机换站、有 z 与倾斜，仿射模型直接失效。
2. **"0.0281 mm / 0.026 mm 是定位精度"** —— 作者明说 [原文证据] p.114。分类：**范围内反例**：极值口径 + 无 n + 不含机器人重复定位误差，与我们"2σ + 绝对偏差"的口径不可比。
3. **"单平面、单高度"** —— 方法必需（全流程 2D）。分类：**范围内反例**：我们插槽插入 371 mm 且工件有 0.8° 级的姿态偏差（`teaching_grasp_geometry.snap_note`），任何单平面假设都会丢掉插入所需的那几维。

## 7. 可迁移到本课题的具体做法（1–3 条）
> 平台前提（本课题）：Elite **CS625** + 随臂 **Percipio 深度相机**（`T_base_cam = T_base_tcp @ T_tcp_cam`，链误差 ≤3 mm）+ **KWR75** 六维力（插 371 mm 的末段只有力觉可用）；工件 **7 kg**，插槽单侧间隙 **1–2 mm**，插入深 **371 mm**。
> 以下均为 **[待验证设想]**（本平台未跑通，验收门槛为建议值）。

1. **把标定做成"标定—残差—复核"闭环，而不是只给矩阵**。本文给出 9 点仿射却没给残差，导致 0.0281 mm 无法追溯；我们已有 `scripts/verify_handeye.py --draw`（两姿态一致性 0.19 mm / 0.013°）。落地：每次手眼/仿射标定都输出三样——①拟合残差 RMS；②留出点交叉验证误差；③**目标准件复核**（用已知尺寸的标准件比较视觉测值与游标卡尺/示教值）。验收：残差 RMS ≤0.3 mm，标准件复核偏差 ≤0.3 mm，两者都进日志。
2. **卡尺工具 + Tukey 加权直线拟合求长边交点，作为三平面角点的 2D 交叉验证**。插槽口两条长边是强直线特征，可用 HALCON 同款的"ROI 卡尺 + 加权最小二乘 + 两线交点"独立算一次角点，与"三平面 RANSAC 交点"对比。需要：插槽口在深度图/RGB 上的清晰长边。验收：两种方法角点差 ≤2 mm；若超差则说明三平面退化（正是当前 z 19 mm 的病），拒绝该帧而不是照用。
3. **角度必须逐站标定并报残差，不能只报单点误差**。我们 10 个 tier-1 站位覆盖 +27°～−44°（`docs/agent_memory.md` §163），可对每个站做"视觉 yaw → TCP yaw"回归并报斜率/截距/残差；本文的斜率 1.0146 + 截距 −40.02° 说明这种系统性偏差真实存在，不能靠单点误差掩盖。验收：每站回归残差 ≤0.2°（2σ），斜率落在 0.98–1.02。

## 8. 与本课题现有路线的冲突点
- **与"三平面 RANSAC + CAD ICP"的冲突**：本文只有 **2D 边缘拟合 + 三线交点**，没有 3D、没有点云、没有 CAD 模型比对；它的"三线交点"正是我们"三平面求交"的 2D 退化版。若在我们的插槽上只用 2D 边（单视角投影），**z 与倾斜永久丢失**，无法支撑 371 mm 插入——这与"必须用 3D 点云 + CAD"的路线直接冲突。
- **与"站位表选站"的冲突**：它的 9 点标定把"相机—机器人"压成一个**平面仿射**，隐含相机与机器人相对固定、物面等高；我们 11 个站位、随臂相机、不同朝向与高度，同一个仿射不可能全站成立。它的做法等价于我们"每个站一套标定"，而不是"一套标定全站通用"。
- **与"精度口径"的冲突（最该警惕）**：只用"最大误差"、不给 n 与分布，是我们最容易被审稿人攻击的写法；0.0281 mm 这种数字若被引用为"视觉可达精度"，会把整个误差预算带偏。
- **与 7 kg / 371 mm / 1–2 mm 间隙的冲突**：本文无负载（吸盘小件）、无插入行程、无间隙数据；其 2D 定位精度主张与"371 mm 行程末端 ±1 mm"完全不在一个问题上。
