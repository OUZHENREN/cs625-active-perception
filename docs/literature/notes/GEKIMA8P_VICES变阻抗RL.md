# GEKIMA8P_VICES变阻抗RL

## 1. 元数据
Zotero itemKey: GEKIMA8P / Variable Impedance Control in End-Effector Space: An Action Space for Reinforcement Learning in Contact-Rich Tasks / 会议（IROS 2019, Macau）/ 2019 / Stanford SAIL / PDF 8 页，印刷页码 pp.1010–1017

## 2. 一句话结论与相关性
- 一句话：把 RL 的动作空间从关节位置/速度/力矩换成"末端位姿增量 + 六维变阻抗增益（VICES）"，用 PPO 在三个接触程度不同的任务上训练，VICES 在接触富集任务里样本效率、能耗、峰值力都最优，且策略可零样本跨机器人迁移、仿真→真机迁移（真机擦板 8/10 成功）[原文证据] p.1010, p.1016
- 相关性分类：**方法迁移**——直接服务纲要 5.5 节"变阻尼 RL vs 位移残差 RL"的决策：本文给出了唯一一份同一套任务上 7 种动作空间的对照数据。
- 影响本课题的具体决定：**柔顺参数与动作空间选择**——VICES 要求 500 Hz 关节力矩接口；我们的 ros2_control 只有 position 命令接口，VICES 原样不可行，但"末端位移残差 + 外环阻抗"的变体（配合 KWR75 1 kHz 力反馈）是本文支持的可行替代。

## 3. 对象与任务
- 三个任务：路径跟随（无接触）、开门（运动学约束，θ_goal=60°）、擦板（连续接触，摩擦系数 μ 在 [0.1, 1.0] 均匀采样）[原文证据] p.1013, p.1015
- 机器人：仿真 Panda（7-DOF，Franka），迁移目标 Sawyer；真机为 Panda 平台，载荷上限 40 N 作为安全/惩罚阈值 [原文证据] p.1015
- 无装配间隙/精度参数（非装配任务）。

## 4. 方法与机制链
`观测（20 Hz 策略）→ 动作 = 末端位姿增量 + 变阻抗增益 → 操作空间阻抗 PD 控制器（500 Hz 关节力矩）→ 环境`
- 关键控制器公式 (4) [原文证据] p.1013：
  u = J_pos^T[Λ_pos(k_p^pos(p_des−p) − k_v^pos·v)] + J_ori^T[Λ_ori(k_p^ori(R_des⊖R) − k_v^ori·ω)]
  其中 Λ 为末端惯性矩阵（动力学解耦），k_p/k_v 为位置/姿态六维刚度与阻尼向量——**由策略直接输出**，即"变阻抗"。
- 对比动作空间：关节力矩、关节速度、关节位置、固定低/中/高阻抗末端位姿、关节空间变阻抗 [原文证据] p.1012–1013
- 关键机制：末端空间动作通过操作空间动力学公式因子化掉机器人本体差异，这是跨机器人迁移与 sim2real 成功的根源 [原文证据] p.1014–1016
- 改变的关键假设：动作空间不必是低层力矩或关节量；把"轨迹 + 柔顺参数"一起作为 RL 输出，可以在无直接力传感的情况下学出安全的接触行为（真机实验明确"未用力传感"）[原文证据] p.1016

## 5. 证据强度
- 全部真机/仿真口径：**三个任务均在仿真训练**（每动作空间 5 个随机种子，PPO）；仅擦板做了真机验证：10 次试验、成功判据为擦掉 >3/4 笔迹线、8/10 成功，1 次急动触发安全停机、1 次未擦净（失败样本有交代）[原文证据] p.1016
- 统计口径：训练曲线报 5 种子均值±标准差；迁移实验报 5 种子范围（error bar）；真机 10 次报 8/10，无更多统计检验 [原文证据] p.1013, p.1015, p.1016
- 关键数字：擦板任务 VICES 策略平均接触力 29 N（< 40 N 载荷）[原文证据] p.1015
- 逐任务结果补充：路径跟随任务除"关节力矩/低阻抗末端位姿"外都能过 4 个经由点；开门任务末端空间动作（中/变/高阻抗）接近 100% 成功率、关节速度动作最高 75%（常撞关节极限）、关节位置/力矩学不会；擦板任务 VICES 收敛最快且力罚最小 [原文证据] p.1013–1015
- 迁移：路径跟随/开门/擦板三个任务的跨机器人（Panda→Sawyer 仿真）迁移都只有末端空间动作成功，关节空间动作无法迁移；接触越多迁移掉分越多（关节极限差异）[原文证据] p.1014–1015
- 基线公平性：同一套控制器框架只换动作空间，比较公平；但关节空间能耗更低的结论被作者自己纠正为"初始步长不同造成的伪影"（关节角增量上限更大）[原文证据] p.1014

## 6. 最脆弱的 1–3 个假设
1. "有动力学模型（M、Λ、J）且能发关节力矩"——方法必需；[分析推断] 我们的 Elite 驱动不开放力矩接口 → **范围外迁移限制**。
2. "策略 20 Hz + 控制器 500 Hz 的分层结构"——方法必需；我们关节速度上限 0.10 rad/s 且无底层力矩环，等价于把低频策略直接接到位置环 → **范围外迁移限制**。
3. 真机擦板把真实图像"贴回仿真图像"再输入策略（视觉表示未验证）——作者明说；因此真机 8/10 只验证了动作空间，不验证视觉泛化 [原文证据] p.1016 → **尚未测试**。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **5.5 节决策证据**：引用"关节位置动作空间在开门任务学不会（常到关节极限）、在接触任务无法施加足够力"与"VICES 样本效率/安全性最优"两组结果，论证：位移残差 RL 可跑（position 接口），但必须外挂阻抗/阻尼外环，否则就是本文最差的那一档 [原文证据] p.1015
2. **外环阻抗+内环位置的变体**：VICES 的 (4) 式把力/力矩项换掉，改成"用 KWR75 测 Fe、按 Mẍ+Bẋ+Kx=Fe 解出位移修正 Δx，再以 position 命令下发"——即 admittance 式实现，500 Hz 由 1 kHz 力信号 + 位置插值近似；验收指标：插入期接触力波动 ≤ 设定阈值（参考本文 40 N 载荷惩罚线）。
3. **迁移测试**：Panda→Sawyer 零样本迁移的做法可搬到我们 sim（Gazebo CS625）→ real（同一 CS625），用"末端空间动作"作为共性层；验收：同一策略 sim/real 成功率差 ≤ 某阈值。

## 8. 与本课题现有路线的冲突点
- 与"站位表选站"不冲突（那是观测层）；与"紧间隙 0.005 m/s 慢速插入"一致——本文同样靠低刚度避免过大接触力。
- 与"ros2_control 只有 position 命令"直接冲突：VICES 需要力矩接口与动力学模型，做不了；若强行只在 position 上做变阻尼，等价于本文证明效果最差的关节位置/低阻抗档位。
- 与"六维力柔顺"路线（KWR75）互补：本文证明无需力传感即可控制接触力（真机未用力传感），但前提是力矩环；我们有 1 kHz 力传感但无力矩环，正好走到本文的对偶侧（admittance）。
