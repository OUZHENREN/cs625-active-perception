## 2. 一句话结论与相关性
- 一句话：为一台 **3-PSR/PSS（水平调整，Z/α/β）+ 4-PRP（平面调整，X/Y/γ）串联**的六自由度装校平台，用**矩阵微分法**建立末端位姿误差与 **32 个（水平）/ 28 个（平面）** 结构参数误差之间的线性误差模型 ΔM = G·ΔS，用"单项误差各置 0.1 mm 扫三种工况"的数值注入法排出敏感误差次序，再用**最小二乘法**辨识真实参数误差、用**关节空间补偿法**把位置误差压小 **4 个数量级**、角度误差压小 **1 个数量级**（[原文证据] p.65）；最后用**蒙特卡洛**给出 6 个运动分量的运动可靠度（位置分量 **0.968–0.9996**、转动分量恒为 **1**），并把 σ 从 0.04 mm 加到 0.08 mm 时 Z 向可靠度从 **0.9768 掉到 0.9208**（[原文证据] p.79–p.82）。
- 相关性分类：**方法迁移**。理由：不给本课题提供任何对象证据（对象是冗余并联装校平台、负载 ≥900 kg、行程 3000 mm，与我们 6R 串联臂 + 7 kg 工件不同族），但它把"**误差链 → 敏感误差识别 → 参数辨识 → 补偿 → 可靠度**"整条链路写成了可抄的算式，是本批 6 篇里唯一真正做公差/精度分配与可靠性计算的论文。
- 影响本课题的具体决定：**误差预算**（误差源枚举口径与灵敏度排序）、**定位要求**（把"精度要求"翻译成"可靠度 ≥ 目标"的判据）、**验证方式**（敏感误差用单项注入而不是等实测）。

## 3. 对象与任务
- 对象：巨型激光装置下装类 LRU 模块，矩形外形、种类多、尺寸与重量差异大、洁净度要求高、装校空间狭小且"可视范围小"、需在**盲源**条件下完成六自由度精密对接（[原文证据] p.3、p.19、p.51）。
- 平台指标（表 2.1）：行程 X ±50 mm、Y ±80 mm、Z 0–3000 mm、绕 X ±3°、绕 Y ±3°、绕 Z ±5°；精度 X ±0.01 mm、Y ±0.01 mm、Z ±0.1 mm、三转角 **±0.01°**；负载 **≥900 kg**；尺寸限制 长 <850 mm、宽 <85 mm、高 <380 mm（[原文证据] p.20）。
- 内部口径疑点：表 2.1 的"平台宽度＜85 mm"与"长＜850 mm"差一个数量级，疑为 850 mm 之误；该值直接决定机构能否装进洁净厢，属必须回原文核对的数字（[原文证据] p.20）。
- 构型：水平调整单元 = 3 条 PSR 支链 + 1 条 PSS 支链（4 驱动 / 3 自由度 ⇒ 冗余 1），实现 Z 向大行程提升与绕 X/Y 转动；平面调整单元 = 4-PRP（4 驱动 / 3 自由度 ⇒ 冗余 1），实现 X/Y 移动与绕 Z 转动；两者**串联**成六自由度（[原文证据] p.21–p.22）。
- 传感配置：装校流程里提到"全景相机完成粗定位"与"视觉相机和力传感器…经总线反馈"（[原文证据] p.19），但**全文没有视觉/力觉的测量模型、精度或标定数据**，精度全部由机构闭环与补偿承担——这一点是本系列论文的共同取向。

## 4. 方法与机制链
- 主链：`误差源分类（静态/动态/热）` → `单支链封闭矢量方程全微分 → 误差雅可比 G` → `ΔM = G·ΔS（线性误差传播）` → `单项误差注入（各 0.1 mm）扫三工况 → 敏感误差排序` → `最小二乘参数辨识（50 组位姿）` → `关节空间补偿 ΔH = J·ΔZ` → `蒙特卡洛 → μ/σ → 正态裕量积分得可靠度 R`（[原文证据] p.51–p.88）。
- **误差源枚举（可复现的部分）**：静态 = 零部件加工误差 / 装配误差 / 运动副间隙误差 / 控制精度误差；动态 = 驱动误差 / 振动 / 弹性变形；热误差单列。作者引文献称"并联机构运动误差有 **60%** 由静态误差引起"，因此只建静态误差模型（[原文证据] p.52）。水平单元细化为 4 类：3 个回转铰点位置误差、5 个球铰定位中心圆位置误差、驱动杆杆长误差、直线模组控制误差；平面单元细化为 3 类：8 个滑块位置误差、4 个回转轴承位置误差、丝杠滑块控制误差（[原文证据] p.52、p.65）。
- **敏感误差识别方法（本笔记认为最值得抄的一条）**：不做实测扫参，而是"**令其它误差源为 0、只留一项，赋 0.1 mm，在三种运动工况下算末端位姿误差最大值**"，得到单项目录表 4.1–表 4.3（水平）与表 4.5（平面）（[原文证据] p.56–p.58、p.68）。结论：水平单元**支链 1 的上下铰点位置误差影响最大、支链 3 最小**，且**所有误差源对 Z 向的影响大于对转角的影响**；平面单元**支链 2 影响最大**，支链 2、4 对转动分量影响最大（[原文证据] p.60、p.69）。
- **误差传播模型能否复现**：能，算式是封闭的：单支链 `P₀ᵢ = Aᵢ + hᵢ + Lᵢ − R·Bᵢ`，全微分后左乘 uᵢᵀ 消去方向项，汇总四支链得 `K₀·ΔM = ΔH + K₁ΔA + K₂ΔB + K₃ΔL`，左乘广义逆 `K₀⁺ ∈ R^{6×4}` 得 `ΔM = G·ΔS`，`G ∈ R^{6×32}`（[原文证据] p.53–p.55，式 4.12–4.25）；平面单元同法得 `ΔM = J_p·ΔP`，`J_p ∈ R^{3×28}`（[原文证据] p.66–p.67，式 4.50–4.62）。**我们照 ΔM = J·Δq 的串联链可直接写出同构形式**，无需闭链广义逆。
- 维数口径存在一处必须先核对的不一致：正文声明水平单元 `ΔS ∈ R³²`（式 4.25），但式 4.14–4.17 印出的分量维数读作 **4 / 12 / 4 / 4 = 24**；若按"4 个下铰点 × 3 坐标 = 12"才是 12+12+4+4 = **32**（[原文证据] p.54）。此处为排版/提取歧义，引用具体维数前必须回原文核对。
- **公差/精度分配的目标函数**：本文没有真正的"分配优化"，它是"**给定已实现的 σ，算可靠度，若不够就降 σ**"的单向试算：σ = 0.04 mm ⇒ R_Z = 0.9768；σ = 0.08 mm ⇒ R_Z = 0.9208（[原文证据] p.82）。也就是说，其判据是 `R(USL, LSL, μ(ΔS), σ(ΔS)) ≥ 目标`，而**不是** `在给定 R 目标下求最小总公差成本` 的优化问题——这是它比我们"设想"差的地方，也是我们最容易补上去的地方。
- **可靠性计算（逐项核对用户要求的五个口径）**：
  - 方法：蒙特卡洛，但关键一步是——抽样只用来求 μ/σ，**可靠度本身用正态裕量公式算**：`R = Φ((USL−μ)/σ) − Φ((LSL−μ)/σ)`，见式 5.4–5.9（[原文证据] p.79–p.80、p.83–p.84）。代入其数值得 `R_z = Φ(2.247) − Φ(−2.288) = 0.9768`，其中末端 z 向误差 **μ = 9.48×10⁻⁴ mm、σ = 0.0441 mm**（表 5.3，p.79）——注意输入均值为 0.02 mm 而末端均值接近 0，说明各项误差在 z 向相互抵消，因此该可靠度实际上只由 σ 决定。
  - 分布假设：铰点位置误差与杆长误差"一般均认为服从**正态分布**"；均值 **0.02 mm**、标准差 **0.04 mm**（[原文证据] p.79 表 5.1/5.2、p.83 表 5.7/5.8）。
  - 蒙特卡洛次数：**正文从未写抽样次数**；只有图 5.8–5.10 的直方图角上标"**样本容量：5000**"（[原文证据] p.84），水平单元的图 5.2–5.4 未标（p.80）。⇒ 5000 这个数字只能算"某一张图"的样本量，不能当作全文 MC 次数的证据。
  - **K-S 检验：没有**。全文无 K-S / 卡方 / 正态性检验字样（[分析推断] 由全文检索得，p.75–p.88 无相关表述）。
  - **置信区间：没有**。R 只给点估计（0.9768、0.9208 等），没有给出 5000 次抽样的二项置信区间（N=5000 时 R≈0.97 的 95% 区间半宽约 0.0047，大于文中"公式值 0.9768 vs 仿真值 0.9732"的差 0.0036 ⇒ 二者差异在抽样误差内，作者未做这一步判断）。
- **运动规划的评价口径：本文不涉及**。全文没有规划算法、没有试次/成功率/路径长度/规划时间指标；其"评价"是误差与可靠度的定量表（表 4.1–4.6、表 5.3–5.12），这是本文的价值所在，也是我们引用它时不能拿它当"规划评价基线"的原因。

## 5. 证据强度
- 试验性质：**纯数值**。全部 5 处"试验"（参数识别验证、补偿验证、两个单元的可靠度"直接 MATLAB 仿真"、5 组工况复算）都是给定误差=0.1 mm 后跑模型，**没有实物平台、没有测量仪器、没有实测位姿**（[原文证据] p.61–p.65、p.69–p.72、p.80–p.87）。结论章自认"没有在动力学、静力学、刚度等方面研究"（p.90）。
- 基线是否公平：**不公平**。"改进"的对象是它自己构造的数值算例——设定 0.1 mm 的误差再辨识回来、辨识回来再补偿回去。这是自洽性检查（模型 → 数据 → 反解），不是方法有效性的外部验证。
- 关键量化结果（可用于对标）：辨识相对误差最大 **7.1%**（δL₃ = 0.1071/0.1）、多数 <5%（[原文证据] p.62 表 4.4）；平面单元辨识最大 **5.8%**（[原文证据] p.70 表 4.6）；补偿后水平单元位置误差降 4 个数量级、角度误差降 1 个数量级（p.65），平面单元位置误差到 10⁻⁴ 级、角度误差到 10⁻⁷ 度（p.72）。
- **内部口径冲突（四处，引用前必须扣掉）**：
  1. 表 4.4 中 `δB₁z` 设定 0.1 mm、辨识值印成 **0.9950**、"相对误差 −0.05"——0.9950/0.1 = 9.95 倍，与 −0.05 自相矛盾；而若按 −0.05 反推辨识值应为 0.095，也与 0.9950 不符。该行数值与相对误差至少有一处印错（[原文证据] p.62）。
  2. 同一工况的可靠度给了两个值：**公式法 0.9768**（p.79）与"MATLAB 直接仿真 **0.9732**"（p.81），作者称"非常接近"，但没给抽样误差，也没说明哪个是主值。
  3. 平面单元 σ→0.08 mm 那段，正文写"沿 **X** 向…由 0.991 减小到 0.9204，沿 **X** 向…由 0.993 减小到 0.9154"——第二个 X 应为 **Y**（[原文证据] p.87），数字本身与 p.83 的 R_x=0.991、R_y=0.993 对得上，属笔误。
  4. 表 4.1–4.3 的角误差列单位印作 `10⁻⁵/(°)`（每度），形态上应是 `10⁻⁵ rad`；无法从正文确证，属**必须回原文核对的单位口径**（[原文证据] p.57–p.58）。
- 统计口径：**没有失败样本概念**（纯数值），**没有重复性试验**，**没有均值/标准差报告**（μ/σ 是输入而非输出），事后分析全用点值。
- 真机 vs 仿真：100% 仿真/解析，0% 真机。
- [分析推断] 最致命的一处方法学问题：**其 MC 与正态 CDF 是同一件事的两条写法**。误差模型 ΔM = G·ΔS 对 ΔS 是线性的，正态输入必然产生正态输出，且输出协方差就是 G·Σ·Gᵀ。所以"用线性模型抽样 → 得 μ/σ → 套正态 CDF"完全等价于解析协方差传播，MC 在这里没有任何增益：它既不能暴露非线性（一阶全微分已被假定），也不能给出经验超差频率。这也解释了为什么"公式法"与"MATLAB 仿真"只差 0.0036——它们本就是同一条式子。

## 6. 最脆弱的 1–3 个假设
1. "末端位姿误差可以只用**一阶全微分**（矩阵微分法）描述，二阶及以上可忽略" —— **方法必需**（[原文证据] p.53 式 4.3–4.7）。分类：**范围内反例**（部分）。0.1 mm 级误差对 32 参数线性化尚可，但误差量级一旦到 mm 级（我们 371 mm 行程末端 1–2 mm 间隙的场合），一阶近似与真实位姿偏差会分离；作者自己的补偿结论"位置误差降 4 个数量级"正是线性模型的直接推论，不能当实测量级。
2. "各铰点/杆长的误差服从**正态分布**，且相互独立、均值 0.02 mm、σ 0.04 mm" —— **方法必需**（[原文证据] p.79）。分类：**尚未测试**。没有对真实批次的测量（无加工件实测、无装配实测），也没有正态性检验；对公差分配而言，加工误差通常是**截尾分布**（尺寸公差带内不允许超差），用正态会在尾部高估失效、低估中间段。
3. "静态误差占 60%，动态与热误差可忽略" —— **作者明说并给出引用**（[原文证据] p.52，引文献[60]）。分类：**范围外迁移限制**。其"60%"来自别的机构/别的文献，且平台速度极低（准静态）才成立；我们的插入段 0.005 m/s 也接近准静态，但换位段 0.12 m/s 与 7 kg 惯性带来的动态误差不能同样忽略。

## 7. 可迁移到本课题的具体做法
- 平台基线（§7–§8 统一引用，勿再另行换算）：**CS625** 六轴臂 + 深度相机 + **KWR75** 六维力传感器；工件 **7 kg**；槽内单边间隙 **1–2 mm**；插入深度 **371 mm**；实测**姿态重复性 0.078°**、**平移重复性 0.42 mm**；0.5° 姿态误差在 371 mm 力臂上折算 **3.2 mm** 横向偏差（371 mm × tan 0.5°）。
1. **把"敏感误差识别"做成可执行的数值注入脚本**：固定我们自己的误差链（相机位姿 → 手眼 → IK → 关节零点/连杆 → 伺服重复性），每次只放开一项、赋一个物理可解释的量（建议按我们实测的量级：平移 ← 0.42 mm、姿态 ← 0.078°），在 371 mm 插入姿态下算末端位置/姿态偏移。落点：`docs/reference/` 一份误差预算表 + `scripts/` 一个只读分析脚本。**验收指标**：输出一张"误差源 → 3.2 mm 等效末端偏移的贡献占比"排序表，且各项贡献之和与把全部误差同时注入的总偏差相差 <20%（说明线性可加假设在我们这里成立）。
2. **把"精度分配"写成判据而不是经验门限**：沿用本文的判据形式 `R = P(|Δ| ≤ 间隙/2)`，把我们 **1–2 mm 间隙**（即单边 0.5–1.0 mm）、**0.5° 姿态门限（371 mm 下 3.2 mm）** 写成两个独立裕量，求"给定实测 σ 下的插入成功率"。**验收指标**：给出 `R(位置) ≥ 0.95` 与 `R(姿态) ≥ 0.95` 所需的最大允许 σ；再与实测 0.42 mm / 0.078° 对比，看姿态项是否才是瓶颈（[分析推断] 按 371 mm×tan(0.5°)=3.2 mm，姿态项裕量最紧）。
3. **借用"关节空间补偿"而不是"工作空间补偿"**：我们的 IK 在 MoveIt 里已有，可直接把识别出的连杆/零点偏差作为**输入偏置**前馈给规划请求，避免改控制层。落点：`cs625_motion_adapter` 的规划请求构造处（只加参数，不加新节点）。**验收指标**：同一目标位姿 20 次重复，补偿前后末端到位偏差均值下降 ≥30%，且不引入新的 IK 失败（规划成功率不降）。

## 8. 与本课题现有路线的冲突点
- **更严谨的地方（应吸收）**：① 它把"误差链"写成了**显式线性映射 + 灵敏度矩阵**，任何一项的贡献都能单独读出来，比我们"误差链 + 角度杠杆解析放大（371 mm 下 0.5°→3.2 mm）"更可审计——我们的杠杆公式只覆盖一项（姿态），它的 G 矩阵覆盖全部 32/28 项；② 它有**参数辨识 + 补偿的闭环**，我们目前只有"测量 → 门限判断（slot 1.0 mm/0.5°）"，没有"辨识 → 补偿"；③ 它有**以概率为目标函数的判据**（R ≥ 目标），我们的门限是确定性的，遇到边界样本只能靠 gate 拒绝。
- **不适用/不能照搬**：① 结构不同——它 32/28 个参数来自**闭链约束方程与广义逆**，我们 6R 串联臂的误差雅可比是 6×n 的常规形式，直接抄闭链那套会在无冗余的串联链上退化为普通雅可比，收益为零；② 量级不同——900 kg / 3000 mm 行程 / 0.01 mm 指标的平台，其"支链 1 最敏感"的排序（p.60）在我们 7 kg / 371 mm 的台面上**没有对应意义**，敏感次序必须重算；③ 其可靠度**只覆盖运动精度，不覆盖"接触/碰撞/抓取成功"**，而我们的任务级指标是"插入是否成功"，需要把力/接触判据并进可靠度定义，这是本文完全没有的维度。
- **与我们"蒙特卡洛"设想的直接冲突**：我们的设想是"跑 N 次蒙特卡洛、统计超差频率/成功率"。本文示范的却是"MC 求 μ/σ → 正态 CDF 求 R"。**后者只有在误差模型线性 + 输入正态时才合法**；我们的链里有**姿态杠杆（非线性）+ 间隙接触（强非线性、有硬边界）**，必须走**经验频率**路线（抽样直接统计超差比例），并给出 N 与置信区间。本文反过来印证了这条：它的 MC 在其自身模型下是冗余的，我们不能复制这个冗余。
- **与"站位表选站"的关系**：无冲突。本文的误差源全是机构内部误差，不含"观测位姿选择"；它默认观测（全景相机/视觉）只做粗定位（p.19），与我们的"视觉主导定位"分工相反，引用时须注意这是相反的证据链。
