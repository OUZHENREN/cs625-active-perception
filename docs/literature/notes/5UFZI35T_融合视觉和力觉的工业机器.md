## 4. 方法与机制链（Q1 / Q2 / Q3）
- 链条：`视觉（改进 YOLOv3 + 颜色阈值 + 最小外接圆）→ 九点标定把像素变机器人坐标 → 抓取（靠力传感器 z 向阈值触发夹爪）→ 视觉伺服引导到装配口（每次运动 100 ms，停下再拍）→ 力反馈柔顺：串口读力 → 接触力模型补偿 → 改进阻抗算六维增量 → 运动 100 ms → 停 → 再采力 → 循环至期望力` [原文证据] p.57–58、p.20–21。

### Q1 六维力怎么接入
- **采样/通信**：力传感器"通过**串口**的方式读取模拟信号"（实为经采集卡的模拟量→串口转发）；**读一组力传感器数值时会读 100 次，取平均值**；采集时"不改变机器人末端的位置，仅改变姿态"，**改变姿态后停留 1 s** 等读数稳定 [原文证据] p.47。**采样率/更新周期全文未给**（无 Hz、无控制周期数值；唯一的 ms 量是 p.58 的 **100 ms 运动节拍**）→ [未定位]。
- **滤波**：只有"对力传感器的读数进行噪声过滤，减少读数波动"[p.21] 与"同一位置多次采集取平均"[p.47]；**滤波类型/截止频率未给** → [未定位]。
- **重力/零点/偏心补偿（分两段最小二乘，公式完整）**：
  1. **安装偏角 + 重力 + 力零点**：先假设末端的负载重力 G 经"绕 x 偏移 φ、绕 y 偏移 ω"两次旋转进入机器人坐标系（式 5.1），得重力在机器人系的三分量 `[F_rx, F_ry, F_rz] = G·[cosω·sinφ, −sinφ, −cosω·cosφ]`（式 5.1 的展开形式；符号以原文为准）；
     传感器真实读数 `F = F_r + F_0`（式 5.2）；把未知量写成单向量，得 `[F_rx, F_ry, F_rz, F_0x, F_0y, F_0z] = f`，用
     `a_i = [R_rt, I]`、`f = (aN^T aN)^{-1} aN^T FN`（式 5.3–5.4）最小二乘求解，**要求采集 n ≥ 3 组**；
     再由 `G = √(F_rx²+F_ry²+F_rz²)`、`φ = arcsin(−F_ry/G)`、`ω = arctan(−F_rx/F_rz)`（式 5.5）反解 [原文证据] p.44–45。
  2. **负载重心 + 力矩零点**：`M = [M_0] + [(F−F_0) × t]`（式 5.6），`t = [t_x, t_y, t_z]` 是传感器中心到力作用线的分量；线性化成 `M = [F 阵, I]·[t; …]`（式 5.7），同样最小二乘 [原文证据] p.45–46。
  3. **真实接触力**：`F_G = R_rt·[0,0,−G]^T`（式 5.8）；`F_touch = F − F_G − F_0`（式 5.9）；`M_touch = M − M_G − M_0 − (F_G × t)`（式 5.10）[原文证据] p.46。
- **标定步骤（照做即可）**：① 把装配件夹在夹爪上（"以备后续能减去这个负载"）；② 机器人自动采集 **250 组**姿态–力数据对；③ 只改姿态不改位置，**每次变姿态后停 1 s**；④ 每组读 100 次取均值；⑤ 两段最小二乘 [原文证据] p.47。
- **标定结果（数值很关键）**：`F_0 = (−56.741, −71.008, −133.666) N`（**原文如此，量级异常大**——含传感器自身零点/预载）；安装偏移角 `φ = −20.015°`、`ω = −0.763°`；负载重力 **G = 27.843 N**（"包含力传感器敏感器件下部自身重量 + 夹爪 + 抓取的装配零件"）；重心 `GC = (−0.0005, 0.0009, 0.0595) m`；力矩零点 `M_0 = (−10.373, −1.547, 5.0717) N·m` [原文证据] p.47–48。
- **补偿后残差（本文最有价值的一组数）**：机器人**悬空不接触任何物体**时，算出的"接触力"应当为 0，实测却是
  **F_x ∈ [−9.41, +0.80] N、F_y ∈ [−9.92, +8.90] N、F_z ∈ [−0.07, +3.90] N**；力矩残差 ≤ **0.106 N·m**（表 5.3 十组）[原文证据] p.48。
  作者的解释："力的波动情况会更多，后续需在力控算法中兼容力的偏差；由于本身力矩较小，所以力矩产生的误差较小" [p.48]，并承认"由于有不同的装配件，所以需要**进行多次重力补偿**" [p.47]。
- **零漂**：并入 F_0 一次性标定；**无上电重零、无温漂监测** [未定位]。

### Q2 接触阶段怎么划分/识别
- **阶段**：抓取 → 视觉引导（到装配口）→ 力反馈柔顺装配（接触后）[p.20、p.53、p.58]。
- **力反馈闭环判据**：流程图上只有"**达到受力阈值 / 达到期望力值**"两个判断 [原文证据] p.20 图 2.2、p.58 图 6.9；**阈值数值未给** → [未定位]。
- **接触/卡阻识别**：定性——"若产生卡阻，则采用**接触力信息判断插入状态**，使用控制算法实现平滑插入" [原文证据] p.21；实际用的是"力在高度 450 mm 左右因一个不被期望的位移导致突变，利用**平滑系数**避免" [p.60]。**无状态机、无状态数、无阈值表**。
- **控制节拍（本文最实用的一条）**：力反馈与视觉伺服**都是"运动 100 ms → 停止 → 采集 → 再决策"**：
  > "以 100ms 为运动时间，运动 100ms 后停止机器人，采集力传感器数据，重复以上步骤，直到达到理想接触力。" [原文证据] p.58（图 6.9 流程）
- **误判率：未给**（没有对"卡阻/未卡阻"做标注统计）→ [未定位]。

### Q3 柔顺类型：阻抗还是导纳？为什么？
- **它自称"阻抗"，实质是"位置型（导纳）× 力/位混合"**：
  - 先论证阻抗控制在装配中的不足："由于并不知道真实环境中的参数，k 值为人为设定，在这种小间隙的环境中，使用阻抗控制极易产生较大受力波动，导致**收敛速度很慢**…若没有达到平衡，调整位移不断变大，接触力不断变大，**出现发散就无法完成装配**" [原文证据] p.49。
  - 再给改进律（式 5.14）：`d_p·f_r + d_i·∫f_r dt + d_d·ḟ_r = k·Δx`（原文形式），拉氏变换后 `k_d s /(d_d s² + d_p s + d_i)`（式 5.15）；稳定性结论："根据**霍尔维茨稳定性**可知只要 `d_p, d_i, d_d, k_d` 为正，则系统稳定" [原文证据] p.50。**这不是标准 M/B/K 二阶阻抗**，而是"力误差的 PD+I → 位置增量"。
  - 六维增量输出：`ΔL_imp = [Δx, Δy, Δz, ΔRx, ΔRy, ΔRz]^T`（式 5.16），逐维由对应力/力矩通道经上式预测；再加**选择矩阵** `D_imp`（对角 0/1）与 `D_env`，最终 `ΔL_t = D_imp·ΔL_imp + D_env·ΔL_env`（式 5.17）；约束是"两个矩阵不能同时选同一个维度，也可以都不选" [原文证据] p.50–51。
- **参数（仿真整定，给了数）**：仿真条件"初始位置差 100、每次以 2 的恒定速度拉紧、环境刚度 10"；固定 `k_d = 10`，从 `d_i`、`d_p`、`d_d` 三组扫描中选出 **`d_d = 0.5`、`d_p = 55`、`d_i = 0`**（其解释：d_d=0 的曲线放大后不够平滑，故取稍大）[原文证据] p.51–52。
  → **单位未给**；`k_d` 与 `d_p` 的关系只能从"力→位移"量级反推 → [分析推断]。
- **控制周期**：**没有控制周期，只有 100 ms 的运动节拍**；再叠加"停→采集"的等待，实际修正次数 ~10 Hz 级甚至更低 → [分析推断，基于 p.58]。
- **装配时用到的选择矩阵**（深长盲孔，竖直装配）：`D_imp = diag[1,1,0,1,1,0]`、`D_env = diag[0,0,1,0,0,0]`，即"不做 R_z 旋转、Z 方向直接位置下压、其余维度力控" [原文证据] p.59。

## 5. 证据强度（Q4 实验口径）
- 试验类型：**真机**（安川 MCL50 + ATI + 大恒相机），无仿真替代实测；改进阻抗只有 Matlab/Simulink 单方向仿真 [p.51–52]。
- **抓取**：装配台上"随意平稳摆放 20 次"，记录成功次数——**圆柱 19/20 = 0.95**、**五棱柱 20/20 = 1.00**（表 6.1）[原文证据] p.59。
- **装配试次**：竖直装配 1 次（图 6.10/6.11）；绕 R_x 旋转（≤10°）1 次（图 6.12/6.13）；绕 R_y 旋转（≤10°）1 次（图 6.14/6.15）[原文证据] p.59–62。**无重复、无间隙分档、无成功率**。
- **力峰值**：**未给数值**。只有曲线与定性："在出现卡阻现象后，短时间内位移偏移增大，接触力增大，但很快随着改进阻抗控制算法的调整回到轨迹上"；"力在高度 **450 mm** 左右，由于一个不被期望的位移，导致力的突变"；绕 R_x 时"姿态误差过大导致装配件底端直接与孔洞壁碰撞，出现 **F_z 较大**的情况，需要的调整时间较长" [原文证据] p.60–61。
- **失败样本**：未给；但给出两种失败机理（底端撞壁、单向偏移导致调整过度）[p.61]。
- **口径不一致**：① 最小间隙在 p.19 写 **0.1 mm**，在 p.55 写**两边 0.3 mm**（深长盲孔）、1 mm（异形件）；② 重复定位精度在表 2.1 写 **±0.07 mm**，正文写 **0.06 mm**（p.19）；③ 仿真"环境刚度 10"、"初始位置差 100"无单位 [p.51]。
- 结论：作为"**大长径比深孔 + 0.3 mm 单边间隙 + 0.138° 姿态要求**下力/位混合能装进去"的工程存在性证据可用；作为"精度/成功率/力峰值"的定量证据**不可用**（全部定性、单次）。它最硬的数据其实是 **补偿后 ~10 N 的残差** 和 **100 ms 节拍**这两个"负面对照"。

## 6. 最脆弱的 1–3 个假设
1. "**补偿后残差可以并入控制算法容忍**"——**作者明说**（"后续需在力控算法中兼容力的偏差"）[p.48]。分类：**范围内反例**：它自己测出 F_x 残差近 **−9.4 N**、F_y 近 **±9.9 N**，而这台传感器的期望接触力只有几 N–几十 N 量级 ⇒ **残差与信号同量级**。这是本批最诚实的"重力补偿不干净"的实测数据。
2. "**力零点/重力/质心在换工件后只需重标一次**"——**方法必需**（"由于有不同的装配件，需要进行多次重力补偿"）[p.47]。分类：**尚未测试**：文中没说 250 组数据是每个工件各采一次还是共用，也没给换件后的残差。
3. "**100 ms 运动 + 停顿采集的节拍足以完成 250 mm 插入**"——**作者明说**（流程图）[p.58]。分类：**范围外迁移限制**：250 mm/100 ms 节拍意味着插入过程被切成很多小步，停顿期间的蠕变/回弹没有被讨论；我们 371 mm 更长（见 §7）。

## 7. 可迁移到本课题的具体做法（CS625 + KWR75 + 7 kg + 371 mm + 0.10 rad/s）
1. **把"100 ms 运动 → 停 → 采力 → 再动"直接作为我们"整条轨迹下发"架构下的导纳近似实现**。这是本批**唯一与我们架构天然兼容**的柔顺节拍：它不要求流式改目标，只要求"每个小段一条短轨迹"。落地：在 `scripts/execute_assembly_chunks.py` 之上加 `--chunk-ms 100`，把插入段切成 N 段（371 mm ÷ 0.005 m/s = 74 s ⇒ **740 段**），每段之间读一次 KWR75 并算一次增量。需要先解决"每段都走 `plan_pose_ik` 安全闸"的开销（否则 740 次规划不可行）；建议在**同一 MoveIt 规划会话内**做笛卡尔小步（`compute_cartesian_path`），只在超限时才回退到 IK 规划。验收：单段耗时 ≤ 100 ms 规划 + 100 ms 执行，20 次插入无中止。
2. **照它的两段最小二乘把 KWR75 的"力零点 + 安装偏角 + 重力 + 质心"一次标出，并把"补偿后残差"当作验收指标而不是副产品**。我们现状 `scripts/ft_sensor_node.py` 只发原始 wrench，无补偿。做法：`scripts/ft_calibrate.py --workpiece 7kg`，采集 ≥15 组姿态（要覆盖 J2/J3/J5/J6），输出 `F_0、G、φ、ω、t、M_0` 与"悬空残差表"。验收：**残差 ≤2 N / ≤0.3 N·m**（本文 10 N 级是反面教材；7 kg 工件下若达 2 N 已属可用），并且"换一件 7 kg 工件后重标残差变化 <1 N"。
3. **把"选择矩阵"思路加到我们的插入动作里**：`D_env` 让 Z（插入方向）走纯位置、`D_imp` 让 X/Y/Rx/Ry 走力柔顺、R_z 关闭（深孔不需要绕轴转）。这正好对应我们"CS625 位置接口 + KWR75 力反馈"的分工，且比"六维全柔顺"少 1 个自由度、少一半风险。验收：20 次插入中 R_z 通道零动作、侧向纠偏 ≤0.5 mm。

## 8. 与本课题现有路线的冲突点
- **与"100 Hz 级流式位置下发"的冲突是"反向"的**：本文用 **100 ms 节拍**（≈10 Hz 甚至更低）就完成了 0.3 mm 单边间隙的深孔装配 [p.58]，这**削弱了"必须 100 Hz 流式"的必要性论证**——至少在"深孔直插 + 小间隙"这类任务上，10 Hz 的"停走式"导纳够用。对我们的意义：可以先用 10 Hz 切片验证，再决定是否值得改造到 100 Hz。
- **与"整条轨迹下发"的冲突可调和**：本文的每一步也是一条独立轨迹（运动 100 ms），与我们"一次一条 `FollowJointTrajectory`"是一致的，只是它把 1 条长轨迹切成了 740 条短的。真正的冲突不在"下发方式"，而在**每段的规划开销**（我们现在每段都要过 `plan_pose_ik` 的安全闸 + 碰撞检查）。
- **与"7 kg 工件"冲突**：本文负载 27.8 N（≈2.8 kg），质心在传感器下方 59.5 mm；我们 68.6 N、353 mm 力臂 ⇒ 力矩量级差 **~7 倍**，它的"力残差 10 N"经验直接外推会更差。必须先做重力补偿再谈柔顺。
- **与"0.3 mm 双边间隙 + 0.138° 姿态窗口"对照**：我们的单侧 1–2 mm 更宽松（角度窗口约 0.4–0.8°/371 mm 折算，视倒角而定）[分析推断]，但由于插入深 371 mm，累积的同轴度要求反而更严——本文的 0.138° 是按 250 mm 深孔算的，可作为我们的量级参照。
- **与"effort 判据"冲突**：本文的力判据是"卡阻时力突变 + 平滑系数"，与我们的 effort 0.68/1.63 属两套物理量；同样需要一次同工况对齐。
