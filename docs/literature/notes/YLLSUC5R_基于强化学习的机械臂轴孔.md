## 2. 一句话结论与相关性
- 一句话：把"寻孔 + 插孔"拆成两个 MDP，用 TD3 直接输出**末端速度指令**（寻孔 3 维平动、插孔 3 平动 + 2 转动），配合"知识驱动动作 + 自适应退火选择"把冷启动问题压下去（[原文证据] PDF p.57–59、p.47–49）；仿真里成功率收敛到 100%，但**真机实验只做了方案没做结果**，作者自评"深度强化学习训练出的装配策略的实际效果仍略低于阻抗控制"（[原文证据] PDF p.69）。
- 相关性分类：**方法迁移**。理由：任务形态（UR5 + 六维力 + 轴孔 + 0.05 mm 级间隙）与我们的插孔段同构，但它**学的是速度不是导纳参数**，所以对我们的"参数整定"只能提供对照口径，不能直接搬参数。
- 影响本课题的具体决定：**接触切换**（两阶段 MDP 的分界判据）+ **柔顺参数**（它用 3665 次网格实验定 m/b/k，是本批唯一给出"手工寻参代价"的一篇）+ **验证方式**（五组干扰源的对照设计可直接借）。

## 3. 对象与任务
- 机器人：**UR5**（负载 5 kg、工作半径 850 mm、关节范围 ±360°、工具端速度 1 m/s，[原文证据] PDF p.67 表 4-1）；力传感器 **JR3 六维力**（量程/分辨率**未报告**）。
- 孔：**孔径 25.0 mm、深 36.0 mm**，倒角部分**最大直径 40 mm、深 8 mm**；轴：**直径 24.95 mm、长 10 mm**（[原文证据] PDF p.58）。
- 间隙：25.0 − 24.95 = **0.05 mm 直径间隙 ⇒ 单侧 0.025 mm**（[原文证据] PDF p.58 参数 + [分析推断] 换算）。倒角使初始对准容差放宽到 (40−24.95)/2 = **7.53 mm**（[分析推断]，按倒角最大直径折算）。
- 装配精度要求：**未给定位精度指标**；只给了失败判据"倾角 ≥ 3° 或位置偏差 ≥ 2 mm 则中止并重启插孔"（[原文证据] PDF p.58）。
- 环境：纯仿真（V-rep，无洁净度/空间限制描述）；**重力被置 g = 0**，真机时再加重力补偿（[原文证据] PDF p.58）。
- 传感：六维力（仿真中设 Fzmax = 50 N 上限）+ 关节编码器；**无视觉**（视觉只用于"人为降低传感器精度"来模拟定位误差，PDF p.55）。

## 4. 方法与机制链
- 主链：`状态 s（位姿误差 + 六维力）→ TD3 actor → 末端速度指令 a → 速度雅可比 → 关节角速度 → V-rep 内层 PID → 接触力 → 奖励 r`（[原文证据] PDF p.55–58、p.58 末段）。
- **RL 到底学什么（本批必答 1）**：**学的是"末端速度/角速度指令"（连续 3 维 / 5 维），不是导纳参数 M/B/K，不是残差位移，也不是离散动作**：
  - 寻孔阶段：`a = [v_x, v_y, v_z]`，3 维平动速度；送入控制器时补成 `a = [v_x,v_y,v_z,0,0,0]`（[原文证据] PDF p.56 式 4-3）；
  - 插孔阶段：`a = [v_x, v_y, v_z, w_x, w_y]`，5 维（3 平动 + 2 转动；因轴对称略去绕 z 转动）（[原文证据] PDF p.57 式 4-8）。
  - 另有**知识驱动动作**（比例控制器）：`v_x = k_1 p_x + k_2 F_x`、`v_y = k_3 p_y + k_4 F_y`、`v_z = b`（寻孔，式 4-4）；插孔阶段 `v_x = k_1 F_x, v_y = k_2 F_y, v_z = b, w_x = k_3 T_x, w_y = k_4 T_y`（式 4-9）（[原文证据] PDF p.56–57）。**k_1…k_4、b 的具体数值未报告**。
- **状态（必答 2）**：寻孔 `S = [p_x, p_y, p_z, F_x, F_y, F_z]`，**6 维**（删掉了角度 α、β、γ 与 T_z，理由是"角度由内部策略调节器控制""γ 与 T_z 无实际作用"）；插孔 `S = [p_z, F_x, F_y, F_z, T_x, T_y]`，**6 维**（位姿误差小且噪声大，故只用深度 + 力/力矩）（[原文证据] PDF p.55–57 式 4-2、4-7）。**无图像、无历史帧**（LSTM 是作者列出的"不足与展望"里的未来工作，PDF p.69）。
- **奖励（必答 2）**：`penalize = K_f·p_f + K_pos·p_pos`，其中 `p_f = ‖[F_x,F_y,F_z]‖`、`p_pos = ‖[p_x,p_y,p_z]‖`，两者先经**线性限幅函数**压到 [0,1]；装配成功时 `reward = 1 − n/n_max`（n 为回合内步数，n_max 为上限）；其余一律用惩罚值，**总值域 (−1, 1)**（[原文证据] PDF p.56–57 式 4-5、4-6，p.50 式 4-10/4-11）。插孔阶段再加一项力矩惩罚 `K_M·p_M`（M 的 2-范数）。**若因非完成动作触发重启，reward = −1**（[原文证据] PDF p.58）。
- **安全约束/动作限幅（必答 2）**：`Fzmax = 50 N`（z 向最大接触力）；姿态阈值 `|θ| ≥ 3°`、位置阈值 `|Δp| ≥ 2 mm` 触发重启；运动范围硬约束：寻孔 x、y ∈ (−9, 9) mm、z ∈ (27.0, 40.5) mm，插孔 z ∈ (0, 28.5) mm（[原文证据] PDF p.58）。**这是本批唯一给出力阈值（50 N）+ 位置/姿态重启阈值的论文**。
- **是否残差结构（必答 3）**：**不是残差叠加**。RL 输出与知识驱动动作之间是**按概率 ε 二选一的切换**，不是相加：`a = ε·a_g(s) + (1−ε)·a_r(s)` 的**选择器**写法（式 3-15 是分段选择函数，不是加权和）；ε 初值 **1**，每"连续 100 次装配中出现 N = 60 次完成"就把 ε 乘 **λ = 3/4**，然后重置计数（[原文证据] PDF p.48 式 3-15 及其后参数）。→ **残差幅度限制：不适用（未报告，因为无残差项）**。
- 其它改进：网络预训练、replay buffer 环式链表、分段奖励、训练与探索分离、长期回报形式改进（[原文证据] PDF p.52–53、p.59）。
- 改变的关键假设：把"RL 必须从零探索"改成"**先用模型化比例控制器把探索压进合法域，再逐步交权**"（[分析推断]，依据 ε 从 1 退火到 0）。

## 5. 证据强度
- 训练环境：**纯仿真**（V-rep + Bullet **2.78** 动力学引擎，高精度模式，仿真步长 **5.0 ms**；显卡 **1660Ti 6 GB**，CPU **AMD 2700x 3.7 GHz**）（[原文证据] PDF p.58）。
- 样本量：**最多 100 万 episode**；每回合最大步数寻孔 **200**、插孔 **450**；replay buffer **100 万**、batch **1024**（[原文证据] PDF p.58）。**训练墙钟时长未报告**。
- 仿真训练结果：改进后"在 **600 训练步**时已经出现 1 次完成，之后完成度稳步提升并最终达到 **100%**"，所需步数"比训练早期减少一半，比纯指导动作减少四分之三"（[原文证据] PDF p.59）。**注意这是"训练步数（k）"不是 episode 数**，两者口径未统一说明。
- 阻抗参数寻优的试验量（**这是本篇最有价值的一组数字**）：三次网格共 **180 × 3 = 540 次**，第四次 **3125 次**，合计 **3665 次仿真实验**（[原文证据] PDF p.37–39）；最终 `m1 = 0.095、m2 = 0.0001`（其余 b/k 在正文只给"提高 m1、降低 m2 后"的定性描述，**完整最终参数组未报告**）。
- 失败样本与统计口径：在 1° 随机初始角下，"**仅 3 组的成功率接近 60%**"，失败"主要发生在刚开始装配的前几个控制周期内"（[原文证据] PDF p.39）；随后 m1 提到 0.095、m2 降到 0.0001 并把起止位置靠近孔中心后，"**共计 100 次均较好的完成**"；再"随机起始位置 + 随机起始角度，**共计 200 次，完成率达到 100%**"（[原文证据] PDF p.40）。**这 200/100 次是阻抗控制（不是 RL）的仿真统计**。
- 真机成功率与试次（必答 4）：**未报告**。§4.6 标题是"装配验证实验**方案**"，只写了平台（UR5 + JR3 + PCI 板卡，TCP 30003 每 **8 ms** 收一次）、功能清单与流程图，**没有任何真机装配数字**（[原文证据] PDF p.66–68，其中平台细节在 p.67）。作者在结论"不足与展望"里明确写："由于一些客观因素的影响，**在真实实验的方面存在着论证不充分的问题**"（[原文证据] PDF p.69）。
- **五组干扰对比（本批最值得借的对照设计）**：控制信号加高斯噪声 / 控制信号加均匀噪声 / 力传感器精度降到 **0.5 N** / 力信号加高斯噪声 / 力信号加 **0.1 N 常值偏置**，结论是 RL 在 3 组（控制高斯噪声、力高斯噪声、力偏置）上更强、阻抗控制在 2 组（均匀噪声、0.5 N 精度）上更强（[原文证据] PDF p.57–58 图 4-17~4-21）——**但五组都是单次仿真轨迹的目视对比，无重复次数、无统计量**。

  3. **章节编号错乱**：目录里"3.3 TD3 算法"与"3.3 面对装配任务对 TD3 算法的改进"**同号**，正文实际是 3.3 / 3.4 / 3.5 / 3.6，而目录写 3.3 / 3.4 / 3.5（[原文证据] PDF p.7–8）。

## 6. 最脆弱的 1–3 个假设
1. **"仿真置 g = 0 不影响策略有效性"**（作者明说，PDF p.58；**方法必需**，因为他们要简化运算）。分类：**范围外迁移限制**——我们工件 7 kg，重力引起的偏心矩与摩擦是插孔阻力的主项，g = 0 下学到的速度策略直接搬过来会过冲。
2. **"0.025 mm 单侧间隙下的策略可代表间隙更大的场景"**（**我的推断**）。分类：**尚未测试**——本文只测了一个间隙（0.05 mm 直径差），没有做间隙扫描；而我们要 1–2 mm 单侧间隙（宽 40–80 倍），策略若只学"贴着壁滑"在我们这里会表现为无接触、空推。
3. **"Φ50 N 上限就够安全"**（作者明说 Fzmax = 50 N，PDF p.58；**方法必需**）。分类：**范围内反例**——7 kg 工件 + 371 mm 插入深度下，50 N 的轴向力已可能让末端姿态偏出；本文的工件只有 10 mm 长、没给质量，两者不可比。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **两阶段 MDP 的分界判据直接借**：本文用"是否进入倒角/接触"作为阶段切换点（寻孔阶段 z ∈ 27.0–40.5 mm，插孔阶段 z ∈ 0–28.5 mm，PDF p.58）。**在我们这里怎么做**：371 mm 插入按"接近（空载）→ 倒角就位 → 直插（tight，0.005 m/s）"分三段，每段单独一个策略/一组参数，切换判据用 **KWR75 的 F_z 由 0 变正 + 插入深度阈值**（我们已有 `insert/straighten` 分段）。**验收指标**：每段切换时 F_z 无 > X N 的阶跃（X 取我们现有力超限阈值的 50%）。
2. **"先验动作 + ε 退火选择器"这套冷启动方案比残差叠加更安全**：ε 初值 1、λ = 3/4、每 60 次成功退一次（PDF p.48）。**在我们这里怎么做**：把"知识动作"设成我们现有的定参数导纳输出，ε 前 100 个 episode 取 1.0，之后按每 20 次成功 ×0.75 退火。**验收指标**：前 100 episode 的力超限中止次数 ≤ 基线；退火到 ε < 0.2 后策略接管、超调 σ 不高于基线。
3. **五组干扰源当鲁棒性验收清单**（PDF p.57–58）：控制指令噪声（高斯/均匀）、力传感器降精度到 0.5 N、力信号高斯噪声、力信号 0.1 N 常值偏置。**在我们这里怎么做**：KWR75 1 kHz 数据离线注入这五种扰动，回放到同一段轨迹的策略上。**验收指标**：五种扰动下均不触发力超限，且 σ 增幅 ≤ 20%。

## 8. 与本课题现有路线的冲突点
- **与"位置型导纳 + 只有 position 命令"的冲突**：本文 action 是**速度**，且 V-rep 里用速度雅可比把末端速度换成关节角速度（PDF p.58）——我们的 ros2_control **没有速度/力矩命令接口**，只能把速度积分成位置增量再下发。→ 300 Hz 以上的速度流在我们这儿做不到；若按 0.10 rad/s 关节上限反推，末端可用速度上限很低，**它那套 5 维速度动作会被重定时压成很慢的斜坡**。
- **与"1–2 mm 单侧间隙"的冲突**：本文 0.025 mm 单侧间隙、靠倒角（7.53 mm 容差）吃初始误差；我们 1–2 mm 间隙意味着**倒角容差相对更宽松但深度 371 mm 是它的 37 倍**，长距离插入的累积偏斜是本文完全没有的场景。→ 它的"100% 成功率"不能外推。
- **与"六维力柔顺"路线不冲突**：同样是六维力 + 阻抗/速度混合，方向一致；它的 50 N 力上限可作我们的力阈值参考（我们 7 kg 工件下的安全力**未标定**，见 §9）。
