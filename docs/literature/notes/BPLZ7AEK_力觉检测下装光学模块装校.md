## 2. 一句话结论与相关性
- 一句话：面向 ICF 装置**下装 LRU 光学模块**（自下而上举升装入洁净厢），在视觉进入盲区后用"平台自身并联支链的低维力传感器解算六维力 → 力与位姿的几何查表 → 先绕 Z 再 X/Y 的微位移纠偏"实现柔顺装校；结果**仅在 Adams+Matlab 仿真中验证**，组合载荷下原始解得误差约 35%，经按初始位姿减基线的误差补偿后 Fx/Fy 精度 10⁻¹ 量级、Mz ≤3% [原文证据] p.81、p.85、p.87。
- 相关性分类：**直接对象证据**。理由：与本课题同属"大型激光装置光学模块从底部装入插槽/洁净厢"的下装场景；给出了同类对象的间隙量级（导轮-导轨 2 mm）、模块尺寸/质量量级（2400 mm×718 mm、最重 300 kg）、以及"视觉对接→力觉装校"的切换边界与力-位姿纠偏策略 [原文证据] p.44–p.46。
- 影响的具体决定：**接触切换判据**（何时从视觉切到力觉）、**柔顺参数**（纠偏顺序与方向符号）、**误差预算**（把绕 X/Y 0.05°、绕 Z 0.02° 归到平台侧的口径）、**验证方式**（只有仿真，不能当作真机可行性证据）。

## 3. 对象与任务
- 对象：某大型激光装置（ICF/NIF 类）下装 LRU 模块，由光学器件+电子元件+机械组件构成；装校最高高度 **4120 mm**，最重模块 **300 kg** [原文证据] p.44；平台额定负载 **500 kg**，洁净度 **ISO 5 级** [原文证据] p.17 表 2.1。
- 平台指标：X/Y 平移 ±**10 mm**、重复精度 **0.1 mm**；Z 提升行程 **3500 mm**、精度 **0.1 mm**；α/β ±**1°**、**0.01°**；γ ±**2°**、**0.01°** [原文证据] p.17 表 2.1。注意摘要写竖直行程"最大可达 **4120 mm**"、英文摘要写 **3500 mm**，两处口径不一致 [原文证据] p.3 / p.4。
- 间隙与几何：导轮与导轨间隙 **2 mm**；左右最小间隙 **30 mm**、前后最小间隙 **10 mm**；模块高 **2400 mm**、宽 **718 mm** [原文证据] p.46 表 4.2、式(4.1)。
- 精度要求（几何折算）：模块最上/最下同时轻触时对应倾角 θ≈**0.09°**（式 4.1），而倾角仪精度优于此值，故仅需 X/Y/绕 Z 三个方向调整即可完成装校 [原文证据] p.46。绕 Z：机构**无**绕 Z 转动传感器，绕 Z 运动精度优于 **0.02°**；当前后/左右对应面成角 **>0.31°** 时洁净厢与模块必然发生接触 [原文证据] p.52。
- 环境：洁净厢只有底部开口、内部光线差，**装校阶段视觉看不到导轮与导轨的接触** [原文证据] p.44。

## 4. 方法与机制链
- 链条：`视觉辅助对接（模块进洁净厢）` → `进入视觉盲区` → `平台支链上的 4 个拉压力传感器测力` → `螺旋理论解算动平台六维力` → `按 5 个单自由度的位姿-力对应表判断方向` → `先绕 Z 转、再沿 X/Y 移的微位移纠偏` → `举升到下组导轮再对接` [原文证据] p.36–p.37、p.54–p.56。
- 关键机制 1（六维力来源）：不装六维力传感器（理由：传感器截面小导致模块不稳、额外占高度、侧向力/纵向力差值过大造成量程浪费），改为在 3-PRS/PSS 水平调整机构的 4 条连杆处布置力传感器（其中 1 个为冗余驱动），把"运动"和"测力"合二为一；用 ΣF=0、ΣM=0 与螺旋理论（Plücker 坐标、力螺旋）反解动平台上表面的六维力 [原文证据] p.36–p.38。
- 关键机制 2（力→位姿的作用是**查表而非反解**）：作者明确说明"从合力反解到分力在理论上几乎不可能"，因此改为枚举模块的 5 个单自由度位姿偏移，逐一给出接触力/摩擦力/力矩的组成，再用"机构间隙+精度"把这些力归属到唯一调整方向 [原文证据] p.45、p.48–p.54。表 4.3 结论：任何单自由度偏移产生的接触力都只沿 X 或 Y；沿 Z 的力都是摩擦力；"沿 X 移"与"绕 Y 转"受力同构、"沿 Y 移"与"绕 X 转"同构；只有绕 Z 偏移产生绕 Z 力矩 [原文证据] p.54。
- 关键机制 3（判据式）：对解算六维力做偏置修正 `Fxt=Fx, Fyt=Fy, Mzt=Mz−M_Fxz−M_Fyz`，其中 `M_Fxz=|Fx·(y±2)|`、`M_Fyz=|Fy·(x±2)|`，括号里的 **2** 就是导轮-导轨间隙（mm），符号随 Fx/Fy 正负按右手定则取 [原文证据] p.54 式(4.2)。
- 关键机制 4（顺序）：先绕 Z（用 Mzt），再沿 X（Fxt），再沿 Y（Fyt）；判据为 ±0 不调整、正负定方向 [原文证据] p.54 表 4.4。
- 改变了哪个假设：把"视觉必须一直看得见才能装配"改为"视觉只负责到对接为止，之后的位姿偏差由接触力承担"，即用**力觉承担盲区段的位姿闭环** [分析推断]。

## 5. 证据强度
- 试验类型：**全部为仿真**（Adams 刚体模型 + Matlab 解算），**无实物装校实验**；作者在展望中自认"基于力觉检测的装校方法需更加贴近现实的模拟和进一步的实验验证""只提供了控制依据和控制策略，还需深入研究运动控制算法并采集更多实验数据" [原文证据] p.89。
- 报告的数字（均为仿真）：纯 8000 N 偏中心正压力 → 解算误差 **10⁻² 量级**；21000 N·mm 偏心力偶 → **10⁻²**；60 N 倾翻力 → 最大误差 **<3%**；三者叠加（模拟实际受力）→ 误差约 **35%**，原因是 Fz 8000 N 是 Fx/Fy 60 N 的 **133 倍**，误差被矩阵 G 放大 [原文证据] p.68、p.72、p.77、p.81。
- 补偿后：每个位姿减去"初始位姿仅 8000 N"的解算分量，消除稳态误差后 Fx/Fy 精度 **10⁻¹ 级**、Mz **≤3%**；稳态误差随 Fz 增大而增大，作者称同型号模块该稳态误差"是一定的、可消除的" [原文证据] p.85、p.87。
- 基线公平性：**没有与直接装六维力传感器的方案做同工况对比**，只有"方案一/方案二"的定性取舍（成本、空间、各向同性差）[原文证据] p.37。
- 统计口径：未给出试验次数、重复性、失败样本比例、扰动范围；误差只以"数量级/百分比上限"表述，无分布或均值±方差 [原文证据] p.68–p.87。仿真步长 0.01 s、时长 4 s [原文证据] p.58。
- 结论：作为**对象与策略证据**可用，作为**精度证据**不可用（无实测、误差量级在 10⁻¹ 以上且随载荷比恶化）。

## 6. 最脆弱的 1–3 个假设
1. "洁净厢底面绝对水平、导轨绝对竖直，把所有误差都换算到六自由度调整平台" —— 作者明说 [原文证据] p.47。分类：**范围内反例**。同一篇论文 p.44 把"地面不平整导致洁净保持箱中轴线与洁净厢底面垂直度误差过大"列为接触力过大的三大原因之一，与"底面绝对水平"的前提直接冲突；换言之该假设把现场最真实的扰动量刚性地归零了。
2. "从合力到分力的归属可以被几何/间隙唯一化" —— 方法必需 [原文证据] p.45–p.46。分类：**范围外迁移限制**。其唯一化依赖"只在下部导轮对接前分析受力""模块与洁净厢只有导轮-导轨一处接触"两个条件 [原文证据] p.54；一旦出现多点接触（我们的插槽侧壁+底面同时接触），表 4.3 的同构关系不再唯一。
3. "提升过程中位姿保持不变、匀速" —— 方法必需 [原文证据] p.49（"若模块匀速提升且位姿保持不变，力传感器读数不会改变"）。分类：**尚未测试**。论文未给出位姿在提升中的漂移量，也没有验证"变化位姿下补偿仍然有效"（只把 8000 N 换成 8000·t 验证了载荷变化的一般性，未验证位姿变化）[原文证据] p.86。

## 7. 可迁移到本课题的具体做法
1. **"力→调整方向"查表 + 固定调整顺序**：在插入阶段的柔顺层加一个方向判据模块——对 KWR75（`/ft_sensor/wrench`，1 kHz，原始单位 kgf/kg·m，需乘 9.80665 转 N/N·m）做工具重力补偿（工件约 7 kg ⇒ 约 68.6 N 的常值分量必须扣掉，否则 Fz 会淹没 Fx/Fy）与 0.5 s 滑动均值，用 `Mzt` 先转、`Fxt/Fyt` 后移的顺序输出微位移方向；死区建议 0.5 N / 0.05 N·m 起步。需要：KWR75 上电零偏标定流程、`tool0`→TCP（`tool_flange_to_tcp_mm: 353`）的力臂换算、以及 `0.005 m/s` 的紧间隙速度上限。验收指标：10 次插入中卡阻/中止 **0 次**，接触力峰值不超过我们既有 `compliant_insert.py` 的安全阈值（`--safety 1.63` 的等效量），每次纠偏位移 ≤0.2 mm。
2. **插入前角度准入判据（把间隙折成允许角）**：照式(4.1) 的思路给出我们自己的判据 `θ_max = arctan(2g/L)`，代入插槽单侧间隙 g=1–2 mm、插入深度 L=371 mm 得 θ_max≈**0.31°–0.62°** [分析推断，公式来自原文 p.46]。把它写进插入前检查：站位表选站后测得的工件姿态重复性（`config/tasks/common.yaml` 精拍登记为 0.028°–0.155°）应 ≤0.2·θ_max，否则先补一次精观测再插。需 要：站位表里的角度重复性字段、`plan_pose_ik` 之前的角度断言。验收：20 次插入中因角度原因触发的接触报警 0 次。
3. **"视觉→力觉"切换判据显式化**：论文的切换点是"模块进入洁净厢即盲区"（几何判据）[原文证据] p.44；我们可换成可观测量：插入深度 > 60 mm 或点云在插槽口覆盖率 <0.95（我们精拍登记为 0.954–0.985）即切力觉主导。需要：`cs625_target_perception` 输出覆盖率与插入深度到柔顺层；验收：切换点前后的位姿跳变 ≤0.5 mm、接触力峰不因切换而跳增。

## 8. 与本课题现有路线的冲突点
- **与"六维力柔顺"的冲突**：我们现在的柔顺是**关节 effort 残差**触发的降速/中止（`scripts/compliant_insert.py`：0.68 接触、1.63 安全，超限取消控制器目标并停），**不主动纠偏**，KWR75 目前只发布 `/ft_sensor/wrench` 用于记录，未闭环。本文要求用腕部六维力**主动移动平台**纠偏。二者不是参数差别而是控制结构差别：照搬需要新增"力→微位移方向"的执行环节，并将安全阈值从 effort 口径换成 N/N·m 口径，两套阈值必须做一次同工况标定对齐，否则会出现"力觉要求继续、effort 判据要求停"的互锁。
- **与"站位表选站 + RANSAC 三平面 + CAD ICP"的冲突**：本文把视觉只用到"对接为止"，之后不再需要视觉；我们的定位链默认在插入全程维持位姿可信（gate：slot 1.0 mm/0.5°、workpiece 3.0 mm/1°，`config/tasks/common.yaml`）。若接受本文口径，就等于承认**盲区段视觉不可用**，需要显式声明"插入深度超过某值后，位姿可信度由力觉而非 ICP 承担"，这会改动我们现有 gate 的语义（由几何偏差 gate 变成偏差+接触力双 gate）。
- **与"误差链/公差分配"的冲突**：本文把地面不平度、洁净厢安装误差**全部**折算到调整平台一侧（"假设洁净厢底面绝对水平…把所有误差都换算到平台"）[原文证据] p.47，且平台 X/Y 精度 0.1 mm、Z 0.1 mm [原文证据] p.17。我们的误差链把 camera→hand-eye→TCP→slot 分开分配，若直接引用本文 0.05°/0.02° 的数值作为"平台项"，会把本属于夹具/地基的误差塞进平台项，导致公差分配重复计数。
- **与"约 7 kg/371 mm 插入"的尺度冲突**：本文是 300 kg、4120 mm 行程、间隙 2 mm 的下装重载场景，其"仅靠间隙即可无接触完成装校"的结论建立在 0.09°/0.31° 的**大件长距离**几何上；我们工件 7 kg、插入 371 mm、单侧间隙 1–2 mm，允许角只有 0.31°–0.62°，量级相近但受力水平低两个数量级，不能把"重载形变导致位姿漂移"的叙事直接套过来 [分析推断]。
