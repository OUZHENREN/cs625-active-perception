## 2. 一句话结论与相关性
- 一句话：为**空间机械臂舱段对接**设计**基于位置的笛卡尔空间阻抗控制**（关节内环 PID 位置、外环阻抗生成位置修正量），先用**解析式**推出"匀速拉紧下力误差/位置误差的稳态值与峰值"（式 3-14～3-17），再在 Simulink 里单变量扫描 **M_d/B_d/K_d** 得到选参规则（M_d 0–10 kg、B_d 45–55 N·s/m、**K_d 取 0**），最后用**遗传算法**优化到 `[0.751 kg, 48.806 N·s/m, 0]`；真机（7 关节原理样机 + 三维吊挂微重力模拟）在捕获/拉紧/锁合三阶段做力位跟踪，接触力峰值 **300 N（捕获 X）/110 N（捕获 Y）/300 N（拉紧稳态）/150 N（锁合）**，并实测出**机械+通讯延迟约 4 s** [原文证据] p.27–37、p.52–56。
- 相关性分类：**方法迁移（弱）**——对象（空间舱段对接，300 N 量级、4 s 延迟、微重力）与我们（7 kg/371 mm、1–2 mm 间隙、0.10 rad/s）差得远；但它是本批**唯一给出 M/B/K 单位 + 完整选参规则 + 离散化实现**的一篇，且"K_d 在力随动自由度上应取 0"这一条对我们的导纳整定直接有用。
- 影响本课题的具体决定：**柔顺参数**（K_d=0 的理由与稳态误差解析式）、**末端接口**（位置型阻抗不依赖力矩传感）、**误差预算**（延迟对力超调的影响）。

## 3. 对象与任务
- 机械臂：**7 自由度空间机械臂原理样机**（肩滚转/肩偏航/肩俯仰/肘俯仰/腕俯仰/腕偏航/腕滚转），各关节为无刷直流伺服 + 行星减速 + RV 减速两级；**最大尺寸 9386 mm**，臂杆中空（发射减重要求）[原文证据] p.47–48、p.50。
- 结构柔性：仿真"全臂伸展平直 + 末端 1000 N 垂直臂向力" ⇒ 变形约 **12.2 mm**，即柔度 **0.0122 mm/N**；接触力安全范围写为 **0–5000 N**（在该范围内容许 60.4 mm 内的位置偏差）[原文证据] p.50。
- 地面模拟：**三维随动吊挂**（四点吊挂；负载重时一点吊挂；共 5 套吊挂及检测装置）+ 高速工控机 + 两块 Maestro + 7 台 ELMO 驱动器（CANopen）[原文证据] p.47、p.49。
- 对接件：末端效应器（3 个锁紧器 + 摄像头 + 3 根环形钢丝绳）与地面适配器（导向棒 + 3 个导向块 + 标靶）；**文中未给导向间隙数值** → [未定位] [原文证据] p.51–52。
- 传感器：六维力传感器装在"**末端效应器与第七关节的连接处**"，即**不在接触点上** → 必须做坐标变换才能得到接触点受力 [原文证据] p.28。
- 工件质量、洁净度、表面精度要求：均未给。

## 4. 方法与机制链（Q1 / Q2 / Q3）
- 链条：`六维力传感器（传感器系）→ 变力臂坐标变换 T(t) → 接触点力 F_c → 与期望力相减得 E_f → 阻抗外环 1/(M_d s²+B_d s+K_d) → 位置修正量 X̃ → 叠加期望轨迹 X_d → 逆解 q_d → 关节 PID 位置内环 → 机械臂` [原文证据] p.29 图 3-3。

### Q1 六维力怎么接入
- **采样率/滤波：正文实现章节未给**（全文无 Hz、无采样周期数值；"滤波"仅在 p.16 第 1 章研究现状里出现过一次，该章我未精读）→ 相关实现细节 [未定位]。唯一与"周期"有关的符号是离散化时出现的采样周期 `T`（双线性变换，式 3-24/3-25），**但 T 的取值未给** [原文证据] p.36。
- **力信号预处理 = 坐标系/力臂变换（本文的"工具偏心"特例，且力臂是时变的）**：
  > "由于…**六维力传感器位于末端效应器与第七关节的连接处，与末端效应器与地面适配器之间接触点存在有一定的距离**，因此力传感器的反馈信号所反映的只是…连接处的受力情况，与我们所需要的**对接接触点处钢丝绳受力**存在一定的差距。" [原文证据] p.28
  变换：`F_c = T(t)·F_s`（式 3-4），其中
  `T(t)` 为 6×6（力矩行含力臂 `L= L_0 − v·t`，式 3-5）：**接触点沿轴向以拉紧速度 v 移动 ⇒ 力臂随时间线性缩短** [原文证据] p.29。
  → 这是"工具偏心补偿"的一个特例：**偏置不是常量而是 t 的函数**。我们做 371 mm 深孔插入时，接触点沿轴向移动 371 mm，同理力臂是时变的。
- **零点**：控制框图里明确画了 `F_b`（"传感器的零点偏差"）参与相减 [p.29]，但**没有标定步骤、没有重力补偿、没有偏心质量力矩项** → [未定位]。原因是**微重力环境**：地面实验的重力由吊挂系统抵消（吊挂钢丝绳还因此引入侧向牵引干扰）[p.47]，所以作者不需要做重力补偿。这一点必须显式说明：**本文的"没有重力补偿"不是遗漏，而是任务环境使然**。
- 力信号还受**吊挂系统**污染："吊挂钢丝绳的弹性使得牵引力可能产生震荡，导致机械臂也随之震荡"；"吊挂系统伴随运动的反应延迟…机械臂运动速度不能太快，否则吊挂无法及时调整，重力便不能很好抵消，甚至令钢丝绳产生侧向牵引力，**对接触力检测造成干扰**" [原文证据] p.47–48。→ 这是"力信号里混入外部非接触力"的典型案例。

### Q2 接触阶段怎么划分/识别
- **阶段（3 段，流程驱动）**：捕获 → 拉紧 → 锁合（图 5-8）；唯一的分支判断是"**接触力是否超限**"这一安全出口 [原文证据] p.52。
- **各段的控制维度不同**（这是它划分阶段的真实依据）：捕获段"在水平面 X、Y 平动自由度上进行力随动控制（期望刚度取小），其余自由度采取**高期望刚度的位置控制**"；拉紧段 Z 向力随动；锁合段修正残余位姿 [原文证据] p.53–55。
- **阈值**：**没有给任何力阈值**；只有"接触力安全范围 0–5000 N"这一环境约束 [p.50]。
- **状态机/误判率：无**（无状态数、无漏报统计）→ [未定位]。可复现证据是三条时间曲线（力/位置 vs 时间）。

### Q3 柔顺类型：阻抗还是导纳？为什么？
- **结论：基于位置的笛卡尔空间阻抗控制（position-based impedance，即导纳结构）**，理由同样是"不依赖力矩环"：
  - 控制器结构："阻抗控制器得到位置修正量 X̃ 去修正期望轨迹 X_d…经过逆运动学得到关节轨迹控制量，对机械臂**位置控制内环**进行位置控制，机械臂的**关节位置控制器采用 PID**" [原文证据] p.29。
  - 与"基于力矩的阻抗"对比时作者明确选位置型（第 3.2.3 节标题即"基于位置的笛卡尔空间阻抗控制"）[p.29]。
- **解析结论（选参的理论依据，可直接引用）**：把环境等效为刚度 `k_e` 的弹簧（式 3-7），可得
  - 稳态力误差 `e_f,ss = b_d V/(k_e + k_d)`（式 3-16）：**只与期望阻尼 b_d 和拉紧速度 V 有关**；
  - 稳态位置误差 `e_x,ss = b_d V/k_e`（式 3-16）；
  - 峰值 `e_f,max = b_d V·[1 − exp(−π b_d/(2√(m_d k_e)))]/(b_d+ ...)`（式 3-17，形式以原文为准）[原文证据] p.30–31。
- **参数（有单位，这是本批唯一一组"带量纲"的 M/B/K）**：
  - **M_d（期望惯量）**：扫描 **0 / 50 / 100 / 150 / 200 kg**（50 kg 跨度）；随 M_d 增大，接触力振荡与超调增强，力峰值由 **340 N 增至 ~470 N**，位置超调由 **5 mm 增至 25 mm** ⇒ 结论"**M_d 取 0~10 kg**"（不能取 0 以免不稳定）[原文证据] p.33–34、p.35。
  - **B_d（期望阻尼）**：扫描 **35/45/55/65/75/100 N·s/m**；B_d 决定稳态力误差（正比），但 B_d 减小会增大振荡与调整时间 ⇒ 结论"**B_d 取 45~55 N·s/m**" [原文证据] p.34、p.35。
  - **K_d（期望刚度）**：扫描 **0 / 0.1 / 0.3 / 0.5 / 0.7 / 1 N/m**；K_d ≠ 0 时"**接触力稳定误差随拉紧过程进行而不断增加**，增加速度与 K_d 正相关" ⇒ 结论"**力随动自由度上 K_d 取 0 N/m**" [原文证据] p.34–35。
  - **环境与工况**：`K_e = 10 N/mm（=10000 N/m）`、拉紧速度 **V = 5 mm/s**、初始位置 **250 mm**、期望接触力 **0 N**、机械+通讯延迟 **4 s** [原文证据] p.32 表 3-1。
  - **遗传算法优化**：目标函数 = 接触力误差振动面积 + 最大力项（式 3-22/3-23）；样本 20、初值 `[1, 50, 0]`、区间 M_d 0.1–100、B_d/K_d 0–100；结果 **`[M_d, B_d, K_d] = [0.751 kg, 48.806 N·s/m, 0]`**，仿真最大接触力 **323 N** [原文证据] p.36。
- **控制周期/采样周期：未给数值**（只有离散化公式，双线性变换后 `X̃(n) = (w3/w1)·X̃(n−1) − (w2/w1)·X̃(n−2) + …`，其中 `w1 = M_d B_d T + 2M_d K_d T²`… 式 3-24/3-25）[原文证据] p.36。
- **延迟（本文最重要的实测数字之一）**："经过实验环境中的测量可知空间机械臂的机械与通讯有**将近 4 s 的延迟时间**，主要是由于在垂直地面的方向上有**吊挂系统**的牵制…因此我们在仿真过程中仍然保留 4s 的延迟时间"（仿真取 a=4, b=1）[原文证据] p.32。

## 5. 证据强度（Q4 实验口径）
- 试验类型：**真机地面半物理实验**（7 关节原理样机 + 三维吊挂微重力模拟 + 地面适配器）+ 第 3 章纯 Simulink 仿真（用于选参）；第 4 章自适应阻抗另有仿真（未读）。
- **试次**：捕获 1 次、拉紧 1 次、锁合 1 次 [原文证据] p.53–56。**无重复、无间隙分档、无成功率**。
- **力峰值（给了数值）**：捕获段 X 向**最大约 300 N**、Y 向**最大约 110 N**；拉紧段接触力"先增大到 **300 N** 左右…之后在阻抗控制器作用下逐渐稳定在 **300 N**，直到 60 s 拉紧结束迅速降为 0 N"，65 s 处出现一次**冲击力**后回零；锁合段接触力偏差**最大 150 N**，Z 向转矩最大约 **−30 N·m** [原文证据] p.54–56。
- **位置量级**：捕获 X 向位置误差走过 **54 mm**；拉紧 Z 向位置误差在 0.1 m 量级（图 5-11a 纵轴 −50~300 mm）；锁合各向位置误差在 ±100 mm 量级 [p.54–56]。
- **失败样本/事故**：唯一承认的失效模式是——"由于末端效应器**导向棒在制造精度上的欠缺**，拉紧结束时可能出现末端效应器与地面适配器上的**齿轮齿齿相对**"，"如果不及时检查纠正而直接锁合就会对机械臂造成**很大的破坏**"，因此"**每次锁合前都需要有人员前去试验平台上检查齿啮合情况**" [原文证据] p.55。→ 这是"用人工流程规避结构性失效"的典型，**没有任何自动检测/容错**。
- 统计口径问题：① 仿真里"最大接触力 323 N"与真机 300 N 属同一量级但**参数不同**（仿真 GA 参数 0.751/48.806/0 vs 真机未说明用哪组参数）→ [未定位]；② 4 s 延迟被保留进仿真，但真机实验的力超调/振荡究竟多少来自延迟、多少来自吊挂，未分离。
- 结论：作为"**位置型阻抗的 M/B/K 选参规则与解析稳态误差**"的方法证据可用；作为"柔顺性能/鲁棒性"的定量证据**不可用**（每阶段 1 次、300 N 量级、无成功率）。

## 6. 最脆弱的 1–3 个假设
1. "**环境可等效为单自由度线性弹簧 k_e，且 k_e 已知/可估**"（式 3-7，仿真取 10 N/mm）——**方法必需**（稳态误差公式全部由它推出）。分类：**范围外迁移限制**：我们的插槽是"大平面 + 单侧 1–2 mm 间隙"，接触刚度在"自由→接触→侧壁"之间跳变，单一 k_e 不成立。
2. "**力随动自由度上 K_d = 0**"——**作者明说**（K_d≠0 会让稳态力误差随行程累积）[p.35]。分类：**范围内已知代价**：K_d=0 意味着该方向**没有位置约束**（刚度为零），一旦外力消失就停在任意位置 ⇒ 我们做 371 mm 插入时不能全段 K_d=0，否则退出后位姿不可复现。
3. "**位置内环可以用二阶模型 + 固定延迟 4 s 近似**"——**作者明说**（式 3-18、a=4、b=1）[p.32]。分类：**范围外迁移限制**：我们的 CS625 延迟是"整条轨迹 goal 下发 + 服务器端插值"，量级与 4 s 完全不同，且不是纯延迟而是"批处理延迟"，模型不可照搬。

## 7. 可迁移到本课题的具体做法（CS625 + KWR75 + 7 kg + 371 mm + 0.10 rad/s）
1. **用本文的"K_d 取 0 + B_d 决定稳态误差"规则给我们导纳整定定骨架**。换算到我们的尺度：插入速度 0.005 m/s（比本文 5 mm/s 慢 40 倍）、环境刚度按插槽近似取 `k_e ≈ 10⁴–10⁵ N/m`（[分析推断]），则若 `B_d = 50 N·s/m`，稳态力误差 `b_d V/(k_e+k_d) = 50×0.005/10⁴ ≈ 0.025 N`——比本文小两个数量级，说明**慢速下 B_d 不是主要矛盾**，主要矛盾是重力补偿残差（7 kg ⇒ 68.6 N 量级）。落地：`config/tasks/` 里导纳参数先取 `M_d = 1 kg、B_d = 50 N·s/m、K_d(插入方向) = 0`，K_n 方向按 §7.2 另定。验收：三档偏置各 10 次，力峰值波动 <20%，退出后位姿可复现（重复插入同一点 ≤0.3 mm）。
2. **把"接触点力臂随时间变化"的变换用到我们的深孔插入**：本文 `L = L_0 − v t`（式 3-5）。我们做 371 mm 插入时接触点从孔口往下移 **371 mm**，而 KWR75 在法兰上、工具链长 **353 mm**（`config/tasks/common.yaml: tool_flange_to_tcp_mm: 353.0`）⇒ 力臂变化量 **0.371 m ≈ 一个工具链长**，会直接把 F_x/F_y 变成几十 N·m 的伪力矩（[分析推断]）。落地：在 `scripts/ft_sensor_node.py` 的输出里加 `contact_point_from_tcp_mm` 参数，按插入深度算时变力矩修正（本文式 3-4/3-5 的 6×6 形式可直接照抄），并把"当前插入深度"从 `phases.json`/状态机传进来。验收：在 3 个不同插入深度（0/150/371 mm）静止不接触时，补偿后 |M| < 0.5 N·m。
3. **把"延迟"当成一等公民做量化测试**：本文实测 4 s 并把它写进仿真。我们应该测自己的：从"发出 goal"到"joint_states 反映目标"的端到端延迟、从"力超阈"到"运动停止"的急停延迟。落地：后台跑一次"下发 10 mm 小段 + KWR75 记录"，用时间戳算延迟直方图（KWR75 已有 1 kHz 时间戳）。验收：**急停延迟 ≤100 ms**、单段 goal 延迟 <300 ms；若实测远超，则导纳外环频率必须降到 5 Hz 以下（这直接决定 §8 的结论）。

## 8. 与本课题现有路线的冲突点
- **与"导纳式（位置型）外层闭环 + 100 Hz 流式"冲突（最有价值的一条）**：本文同样是位置型阻抗，但它的位置内环"**每个周期收一个位置修正量**"，靠的是"工控机 → Maestro → ELMO"这条**在线轨迹**通道 [p.29、p.49]；我们的位置通道是"**一条 `FollowJointTrajectory` goal**"，没有"每周期改参考"的语义。本文的结构在我们这里等价于"每个周期重发一条 goal"，而它自己的实测延迟就有 **4 s**（哪怕原因是吊挂）——这提醒我们：**位置型导纳的真实上限是"重发 goal 的延迟"，不是"控制算法频率"**。我们必须先测这个延迟，再谈 100 Hz。
- **与"整条轨迹下发"冲突（结构级）**：本文阻抗外环的输入是"期望轨迹 X_d + 修正量 X̃"，期望轨迹本身是**连续时间函数**；我们的 X_d 是离散的整条关节轨迹。若要在我们架构上实现等价物，必须把"期望轨迹"换成"当前 goal 的插值参考"（即 MoveIt Servo / 控制器侧的实时参考），否则外环的修正量无处叠加。
- **与"重力补偿"不冲突但不可照搬**：本文在微重力下不需要重力补偿（重力由吊挂抵消）[p.47]，我们相反；它的"零点偏差 F_b"只是一个框图符号，没有可执行的标定流程 [p.29]。
- **与"300 N 量级"冲突**：本文接触力 300 N、结构柔度 0.0122 mm/N、安全范围 0–5000 N；我们 7 kg 工件、1–2 mm 单侧间隙的光学模块，接触力上限必须远低于此（总量级应在 N–10 N 级）。**不能把本文的任何阈值当参照**。
- **与"effort 判据"的关系**：本文用关节 PID 位置内环 + 阻抗外环，**完全不用 effort 判接触**；我们的 `compliant_insert.py` 用 effort 残差（0.68/1.63）——两套判据并存时，本文路线会让 effort 判据几乎不触发（因为位置内环会把 effort 波动吸收掉），需实测确认。
