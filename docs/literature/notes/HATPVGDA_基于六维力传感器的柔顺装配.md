## 2. 一句话结论与相关性
- 一句话：把"轴孔接触"用**螺旋理论 + 虚功原理**离散成 **5 种接触状态（单点×2、双点×2、三点×1）**，用"虚系数 ω_AB 的符号"（正=分离、负=穿透、零=保持接触）判状态，再用"**改变运动方向做二次激励**"把不可直接判别的状态逐个转化到单点接触，最后按"力方向 → 转角方向"做**增量式位置修正**，在 6-PUS/UPS 并联机器人上完成 **∅31/∅30 mm、无倒角、单边间隙 0.5 mm、插入 45 mm** 的轴孔装配（约 90 s，7 次一点↔两点接触转化，无卡阻楔紧）[原文证据] p.18–28、p.63–70。
- 相关性分类：**方法迁移**（并联机器人 + 专用传感器，硬件不可搬；但"接触状态怎么用力的符号/方向判 + 用运动激励把状态转成可判形态"是**接触阶段识别**最完整的一篇，且它给的传感器采样/滤波/清零参数可直接对照我们的 KWR75）。
- 影响本课题的具体决定：**接触切换**（用状态辨识而不是单一力阈值）、**验证方式**（用"接触状态转化次数/序列"当可复现证据）、**柔顺参数**（它证明"不用 M/B/K，纯增量位置修正"也能装进去——这是我们 CS625 最现实的保底方案）。

## 3. 对象与任务
- 孔台：材料 **Q235**，一块板上 4 个孔；本次用 **∅31 mm、深 45 mm、无倒角**的直孔（作者特意选无倒角："以往实验大多采用带倒角的孔…无倒角装配相关研究较少"）[原文证据] p.60。
- 轴：**∅30 mm、长 45 mm**，即**单边间隙 0.5 mm（直径间隙 1 mm）**；轴根部接"联轴装置"，可伸缩，"在强力作用下可以伸缩，起到保护六维力传感器的作用…也可以给柔顺装配留有一定的间隙" [原文证据] p.60–61。
- 机器人：**6-PUS/UPS 并联机器人**（6 分支，动平台），6 个驱动单元为 BAHR EGK40 直线运动单元，位置反馈用 RENISHAW RGH41X 光栅尺，"具有很高的位置伺服精度" [原文证据] p.55。
- 传感器：课题组专利"**整体预紧双层并联式六维力传感器**"，三个平行平台（预紧/测力/定），**7 个分支杆**（上 3 下 4），分支杆只受压力、无过零 → 迟滞/非线性小；样机装在测力平台与动平台之间 [原文证据] p.36–37。
- 量程/指标（表 4-1）：F_x/F_y/F_z **100 N**，M_x/M_y/M_z **10 N·m**；重复性 0.66/0.24/0.88/0.70/0.13/0.56 %；线性度 0.89/0.25/0.91/0.92/0.43/1.03 %；回差 0.88/0.39/0.81/0.77/0.78/0.80 % [原文证据] p.37。
- 无工件质量、无洁净度、无插入力上限的实测数据。

## 4. 方法与机制链（Q1 六维力接入 / Q2 接触阶段识别 / Q3 柔顺类型）
- 链条：`7 路电压 → 放大 → 硬件滤波模块 → USB2080（AD）→ 软件巴特沃斯低通 → 560 点均值 → F = G·V（标定矩阵）→ C 系转 T 系（轴交换+Z 反向）→ 清零（减初值）→ 虚系数判接触状态 → 力方向定转角方向与步长 → 逆解 → 运动文件下载 PMAC → 光栅尺校验 → 下一循环` [原文证据] p.41–42、p.48–49、p.55–57。

### Q1 六维力怎么接入
- **采样（三个数字，必须区分）**：采集卡 USB2080 标称"采样速率 **400 kHz**"（整卡）、14 位、±5/±10 V、32 单端/16 双端、系统测量精度 0.1%、工作主频 144 MHz [原文证据] p.41–42；软件实际设 **采样频率 100000 Hz、分组间隔 1000 µs、首通道 0、末通道 7、内触发/边沿/负向、程控增益 1×** [原文证据] p.48；每个控制循环"**一次选取 560 个电压值**"求均值后再算力 [原文证据] p.55。→ 单次力更新约 **560/100 kHz ≈ 5.6 ms（≈178 Hz）** [分析推断]。
- **滤波（硬件 + 软件两级，软件给了截止频率）**：硬件"滤波模块"（无参数）[p.41]；软件用 LabVIEW **巴特沃斯低通**，"通过反复观察滤波后的波形，最终将滤波频率设置在 **400 Hz**；由于软件滤波会造成失真，所以将采集的后一部分数据去掉" [原文证据] p.49。注意：100 kHz 采样 + 400 Hz 截止 + 560 点均值 ⇒ 通带远低于控制节奏，**但文中没有给滤波阶数** [未定位]。
- **零漂（"每次使用前清零"，不是模型补偿）**：原因写得很清楚——"六维力传感器是在**预紧力**作用下的精密机构，**每次使用时预紧力的大小都是不同的**，所以必须在使用前进行一次清零"；做法是"测量前先把各通道的电压初始值保存下来，测量中让测量值与这个初始值作差"，并做成界面上的"**传感器清零**"按钮（`OnBUTTONZERO()`）[原文证据] p.49、p.55。
- **重力补偿与工具偏心：全文没有**（关键词"重力/质心/重心"在 77 页里 0 次命中）。原因是结构上轴很轻（∅30×45 mm 钢件≈0.25 kg）且姿态始终竖直，重力只体现为 F_z 的常值 → 被"清零"一次性吸收。→ **这恰好是它的边界：一旦工件重（我们 7 kg）或姿态倾斜，"清零"就失效**。
- **标定（出厂式一次性）**：`F = G·V`（式 3-6），G 为 **7×6 标定矩阵**（由课题组最小二乘标定，是常量），文中逐元素给出 42 个数（量级：力行 0.0345–0.5063，力矩行 0.0000–0.0444）[原文证据] p.38。
- **坐标变换（C→T，含 Z 反向）**：传感器标定系 C 与测量系 T 原点重合，`T` 的 X 与 C 的 Y 同向、T 的 Y 与 C 的 X 同向、**T 的 Z 与 C 的 Z 反向** ⇒ `R_C^T = [[0,1,0],[1,0,0],[0,0,−1]]`（式 3-14），代入得 6×6 变换（式 3-16）[原文证据] p.39–41。

### Q2 接触阶段怎么划分/识别（本文最硬的部分）
- **阶段划分**：接近（非接触）→ **接触** → 入孔；接触段再细分为 **5 种状态**：单点接触 2 种、双点接触 2 种、三点接触 1 种（图 2-2/2-4/2-5）[原文证据] p.18–19。
- **识别原理（不需要 M/B/K，只要力螺旋 + 运动螺旋）**：对每种状态的接触力螺旋 `(β1..β6)` 与运动螺旋 `(α1..α6)` 算虚系数
  `ω_AB = β1α6 + β2α5 + β3α4 + β4α3 + β5α2 + β6α1`（式 2-10）[p.21]
  判据：`ω_AB > 0` 接触点分离、`< 0` 接触点破坏（干涉）、`= 0` 保持接触 [p.21]。
  逐状态代入得到式 (2-11)–(2-15)：状态 I/III 得 `ω_AB < 0`、状态 II 得 `= 0`、状态 IV/V 得 `< 0` [p.22–23]。
- **状态机（显式、靠运动激励）**：第一步只能把**状态 II** 与其他 4 种分开；对其余 4 种"**需要改变轴零件的运动方向，使其沿 z 轴负方向运动**"，重算力螺旋/运动螺旋后再判，可识别出**状态 III**，此时剩下三种都转化成状态 I 的情形 —— "通过这种**接触状态的识别和转化相结合**的方式来进行接触状态判断"[原文证据] p.24。装配策略：任何初始状态最终都先转化为**单点接触**，再做偏转角调整 [p.28]。
- **阈值**：① 接触判据只写"当超过系统设定的**临界值**时认为轴零件与孔台相互接触"，**数值未给** [未定位 p.63]；② 孔底判据 `f_z ≥ f_0 且 z ≥ z_0 + l`（式 2-19），文中"将阈值设置成 **100 N**，轴长 45 mm"，即 `f_z ≥ 100 N` 且 `z ≥ 45 mm` [p.27、p.63]（**PDF 文本层把不等式方向打乱，`f_z ≥ f_0` 以式 2-19 为准**）。
- **误判率：全文未给**（没有漏报/误报统计）。可复现证据是过程曲线：整套装配出现 **7 次"一点↔两点"接触状态转化（节点 A–G）**，其中 A/B/G 三处 `f_x` 与 `f_y` 方向都突变、C/E 只有 `f_x` 突变、D/F 只有 `f_y` 突变 [原文证据] p.67–68。

### Q3 柔顺类型：阻抗还是导纳？
- **结论：两者都不是**。它用的是"**显式力反馈 + 增量位置修正**"的位置型力控（position-based force control），既没有质量-弹簧-阻尼模型，也没有 M/B/K 参数：
  > "本文提出的力控制方案**不破坏并联机器人的位置伺服系统**，利用力反馈数据和并联机器人高精度的位置伺服能力，求出其动平台目标位姿并控制其运动以调整和校正位姿偏差。" [原文证据] p.57
- **控制律（定性的方向 + 步长循环）**：`f_x` 为正 → 绕接触系 J_Y 轴正向转 `δβ`；`f_y` 为正 → 绕 J_X 轴负向转 `δα`；"设定一个角度的步长，然后进行循环调整"，调整角度的同时轴持续向下运动 [原文证据] p.25、p.27。角度步长 `δ`、速度增益**未给数值** [未定位]。
- **接触系→末端系的雅可比映射**（式 2-16–2-22）：以轴半径 r、轴底端到动平台中心距离 l 构造 `S(p_J)`，得
  `Δx = l·δα + r·sinβ·δβ`、`Δy = r·δβ`、`Δz = −r·cosβ·δβ`（式 2-22，符号以原文矩阵为准）[p.25–27]。**这就是"工具偏心"在这个任务里的等价物**：修正量必须按接触点位置换算，而不是直接加在末端。
- **参数/周期**：无 M/B/K；"阻尼阈值"指孔底力阈 f_0=100 N [p.27、p.63]。**控制周期未给**；单次循环包含"读 AD→560 点均值→算力→解 IK→**生成运动文件下载到 PMAC 卡**→读光栅尺校验（误差>0.01 报错退出）"，全装配 90 s ⇒ 单循环量级 **0.5 s**（[分析推断]，由其"180 点/2 点每秒"与 7 次状态转化估）[p.55–57、p.67]。

## 5. 证据强度（Q4 实验口径）
- 试验类型：**真机**（并联机器人 + 专利六维力 + USB2080 + Windows XP 上位机 + Fiso-UA USB 隔离器抗干扰）[p.59–62]；**无仿真对照**。
- **试次：1 次代表性装配**。记录方式："实验过程中每一秒取 2 个点，一共取了 180 个点"，即 **90 s**、2 Hz 采样存证 [p.67]；文中明确"一分半钟之内可顺利地将轴插入到孔中"[p.67]。
- **间隙分档：无**（只有 0.5 mm 单边一档；孔台另 3 个孔未做实验）。
- **成功率：未给**；**失败样本：未给**（结论只写"装配过程平稳、连续，无楔紧、卡阻等现象"[p.5 摘要、p.70]）。
- **力峰值：未给数值**，只写"可有效地把装配力控制在比较小的范围内"[p.70]；唯一数值是 100 N 孔底阈值。
- 统计口径问题：以"1 次成功 + 曲线定性解读（力突变点对应状态转化）"作为验证，**没有重复性、没有置信区间、没有反例**；但它的"7 次状态转化 A–G"是**可复现的过程证据**（如果换人做同一实验，转化次数应可比），比纯"看起来平滑"强。
- 结论：作为"**接触状态可辨识 + 位置型增量修正能装上**"的存在性证据可用；作为"精度/间隙极限/鲁棒性"的定量证据**不可用**（样本量 1、无间隙分档、无力峰值）。

## 6. 最脆弱的 1–3 个假设
1. "**接触力 = 传感器读数 − 上电初值**（清零即可），无需重力/偏心补偿"——**方法必需**（全文无重力补偿）。成立条件：负载轻 + 姿态恒定竖直。分类：**范围外迁移限制**。我们 7 kg、353 mm 力臂、插入过程中姿态会变（371 mm 深孔内有姿态调整）⇒ 该假设直接失效。
2. "**7 个分支只受压力、无过零 ⇒ 力–电压关系可近似线性常量 G**"——**作者明说**（结构优点，式 3-6 的 G 为常量）[p.37–38]。分类：**范围内合理，范围外未知**：G 是标定得到的常量，没有温度/预紧力漂移项；而作者自己又说"每次预紧力不同必须清零"[p.49]，两者口径存在张力（清零抵掉了零点，但抵不掉灵敏度变化）。
3. "**虚系数判据只用接触力的法向分量就能唯一决定状态**"——**方法必需**（式 2-10 只取力螺旋在法线方向的分量）[p.21]。分类：**尚未测试**：文中从未量化"力噪声多大时会误判状态"，也没有把 7 次转化中的每一次与真值（如视觉/深度）对齐验证。

## 7. 可迁移到本课题的具体做法（CS625 + KWR75 + 7 kg + 371 mm + 0.10 rad/s）
1. **把"接触状态辨识"降级成 3 态最小状态机，放进插入段**：本文 5 态需要 6 维力 + 运动螺旋 + 主动改变运动方向做二次激励，我们只有一只 KWR75（单点六维），但可以保留它的核心思想——**"用力的符号突变判断接触拓扑变化"**。落地：在 371 mm 插入段把 `f_x/f_y` 的符号突变次数记下来（KWR75 1 kHz，取 20–50 ms 滑窗均值），定义 `APPROACH → CONTACT_SINGLE → CONTACT_TWO → BOTTOM` 四态；`CONTACT_TWO` 的判据照抄本文"两方向力同时/先后突变 + 插入深度停止增加（`depth_below_fixture_mm` 不再增长）"[p.67] 的思路。需要：KWR75 已有 1 kHz 流（`config/ft_sensor/kwr75.yaml: publish_rate_hz 1000`），但**必须先做重力补偿**（否则 68.6 N 常值会把 f_x/f_y 淹掉）。验收：20 次插入中"两点接触"误报 ≤1 次（人工看录像标注真值），且每次状态序列与深度单调性一致。
2. **孔底/到位判据做成"力 + 位置"双条件**（照式 2-19）：`f_z ≥ f0 且 z ≥ 371 mm`。我们已有 `depth_below_fixture_mm: 371`；需要新增的是 `f0` 的取值——本文给 **100 N**（对它 100 N 量程的传感器是满量程！），我们应先测"插入到底时的稳态 f_z"再定 f0，不要照搬 100 N。验收：10 次到底判定 0 次误判、0 次超行程。
3. **采样/滤波参数直接对照用**：本文 100 kHz AD → 400 Hz 巴特沃斯 → 560 点均值 ≈ 178 Hz 力更新；我们 KWR75 是 **1 kHz 串口流（460800 8N1、28 字节帧）**，若照它做 **400 Hz 低通**，在 1 kHz 上已经接近奈奎斯特（400/500），实做建议 **50–100 Hz 低通 + 20 ms 均值**（先把 1 kHz 降到 50 Hz 给外环用，原始 1 kHz 存盘）。需要：给 `scripts/ft_sensor_node.py` 加 `--lowpass-hz` 与 `/ft_sensor/wrench_filtered` 话题。验收：静止时补偿后 f_z 的极值差 ≤1 N（对照本文原始 4.6 N→滤波后 0.6 N 的量级，见 RLHBFRBA 笔记）。

## 8. 与本课题现有路线的冲突点
- **与"导纳式（位置型）外层闭环"冲突**：本文是**位置型但非导纳**——它没有 M/B/K，靠"力方向 → 固定角度步长"的增量修正。这条路对我们其实是**更现实的保底**（不需要 100 Hz 流式位置下发，因为它的循环本身就是"改一个目标位姿 → 下发一条"）；而我们的"导纳外层闭环"要求连续 100 Hz 修正，两者是**同一接口下的两种节拍假设**，必须先回答"CS625 能不能在一个 goal 内改目标"。
- **与"整条轨迹下发"冲突**：本文每次修正都生成**运动文件下载到 PMAC** 再执行（一次一条），循环周期 ~0.5 s [p.55–57]。我们 `scripts/execute_assembly_chunks.py` 是**一次下发整条 `FollowJointTrajectory`**（position 接口、关节速度 ≤0.10 rad/s、单计划行程 ≤0.44 rad）。照本文做法，371 mm 插入按 0.5 s/循环、每循环修正量 ~0.1 mm 级 ⇒ 需要几百到上千次 goal 重发，且每次重发都要重新过 `plan_pose_ik` 的安全闸，**实时性完全不够**。⇒ 结论：本文的"慢循环增量修正"只能用于**搜孔/纠偏前段**，不能覆盖 371 mm 全插入。
- **与"effort 残差接触判据"冲突**：本文这一类方案要求用**力符号**做主判据；我们现在是关节 effort 残差（0.68/1.63）。两套判据并存会互锁（力觉说停/effort 说继续），必须做一次同工况对齐标定。
- **与"7 kg/353 mm"冲突**：本文"清零代替重力补偿"的做法**不能照搬**（见 §6 第 1 条），它的 100 N 满量程阈值也不能照搬。
- **与"无倒角"这一点不冲突反而有用**：我们的插槽实测"以大平面为主"、间隙 1–2 mm，比本文 0.5 mm 宽松，但插入深度 371 mm 是本文 45 mm 的 **8.2 倍**，深孔内的摩擦累积与姿态漂移本文完全没有覆盖。
