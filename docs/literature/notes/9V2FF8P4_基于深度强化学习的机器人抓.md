## 2. 一句话结论与相关性
- 一句话：DQN + DenseNet 从 RGB-D 图像直接预测**对准调整方向**（正向/负向/零，3 个离散动作），触觉力信号只作**自监督标签**；仿真与真机各训 **14 000** 回合，再用 **1000 次**装配测试比"单一感知 / 交替感知 / 联合感知 / 多视角"四种方法的**总耗时**——真机上多视角比单一感知省 **8.63 h**、效率提升 **21.4%**（[原文证据] PDF p.104 表 5.3、p.103–104）。
- 相关性分类：**方法迁移**。理由：动作空间极简（3 个方向）且完全不需要力矩接口，与我们的 position 命令最能对上；但**全文只报时间、不报成功率**，因此不能当成功率证据，只能当"方向类动作 + 触觉做标签"的方法证据。
- 影响本课题的具体决定：**观测动作**（多视角补遮挡）+ **接触切换**（"视觉预测 / 触觉标签"的分工）+ **验证方式**（它用"总装配时长 + 标准差"做指标，正好提示我们必须同时报成功率，否则无法与它比较）。

## 3. 对象与任务
- 机器人：仿真 **UR5 + RG2**（CoppeliaSim Edu v4.0，Bullet Physics **v2.83**）；真机 **UR5e + RG6**，末端与夹爪之间装六维力/力矩传感器（[原文证据] PDF p.87、p.89、p.67）。
- 视觉配置：**单视角版** = 1 个单目（俯视，负责寻孔）+ 1 个 **D435**（前方，负责对准）；**多视角版** = 1 个单目 + **2 个 D435**（主视角 + 辅助视角）（[原文证据] PDF p.87、p.102、p.104）。
- 装配对象：**轴 φ30 mm、长 100 mm**，**质量 0.55 kg**，**轴孔间隙 0.8 mm**（直径差），**轴与孔均无倒角**（[原文证据] PDF p.67、p.87、p.102）。→ [分析推断] 单侧间隙 = 0.8/2 = **0.4 mm**；无倒角意味着**没有倒角容差**可吃初始对准误差。
- 孔的深度/材质/摩擦：**未报告**（只说"装配孔"，未给深度与质量）。
- 精度要求：**未报告**；只用"是否完成装配"作为隐含判据，没有给角度/位置/力阈值（[分析推断]，依据第 4、5 章均无阈值表）。
- 传感：六维力（量程/采样率**未报告**）+ RGB-D；**无触觉阵列**（"触觉"即指六维力，"触觉感知"与"力/力矩感知"在文中同义，PDF p.83）。
- 环境：仿真 + 实验室真机；无洁净度要求描述。

## 4. 方法与机制链
- 主链：`RGB-D 图像 → DenseNet（121/169）提取特征 → 全局平均池化 → 全连接 → Q 值 → 3 个方向动作之一 → 机器人位姿微调 → 六维力判断接触状态 → 作为视觉预测的标签 → 反向传播`（[原文证据] PDF p.83、p.85、p.96–98）。
- **RL 到底学什么（本批必答 1）**：**学的是 3 个离散动作（对准调整方向：正向 / 负向 / 零）**，不是 M/B/K，不是残差位移。原文："由线性层输出最大 Q 值的装配对准调整动作，即**正向调整、负向调整和零**。调整动作将逆时针调整方向设置为正向调整"（[原文证据] PDF p.85）。→ **调整幅度的量化值全文未报告**（只说"标注为正向/负向/零"）。
- 补充：章标题写"多视角**变步长**的智能装配策略"，但正文对寻孔只写"采用**等步长**逐步接近装配孔中心"（[原文证据] PDF p.96），**"变步长"在全文没有任何定义、动作集合或幅值**（[分析推断]，全文检索"变步长"仅出现在章标题与页眉）。
- **状态（必答 2）**：`RGB-D 图像`（端到端，无显式力向量入状态、无历史帧堆叠）；触觉（六维力）**不是状态而是标签**——"系统使用触觉感知作为视觉感知的预测标签"（[原文证据] PDF p.87）。→ [分析推断] 这是把"力 → 调整方向"的专家规则固化成标签，用视觉去模仿它，本质是**自监督模仿**而非任务奖励驱动的 RL。
- **奖励（必答 2）**：`预测判断奖励`——"如果视觉感知预测与标签信息相同，则视觉预测神经网络将获得预测判断奖励。如果…不同，则…进行反向传播运算以修正网络参数"（[原文证据] PDF p.83）。另有抓取章的 `r_G`（抓取奖励）与 `r_AM`（装配约束奖励，装配完成时间小于设定值才给）（[原文证据] PDF p.65–66）。**奖励的数值形式（大小、折扣、稀疏度参数）未报告**；只说"稀疏奖励"并因此采用优先经验重放（PDF p.85）。
- **安全约束/动作限幅（必答 2）**：训练期用 ε-贪婪，**ε 初值 0.5 退火至 0.1**（[原文证据] PDF p.87、p.102）。**没有力阈值、没有速度阈值、没有动作幅值上限的数值**——**均未报告**。这是本批安全约束最弱的一篇。
- **是否残差结构（必答 3）**：**不是**。动作是"方向选择"，作用效果是让机器人沿该方向做一个（未给出的）增量。既不在导纳输出上叠加，也不在参数上缩放。**残差幅度限制：未报告（不存在残差项）**。
- 训练细节：14000 回合（仿真、真机各一轮）、Huber 损失、优先经验重放（prioritized replay，含超参"优先值"但数值未给），网络 DenseNet-121（第 4 章）/ DenseNet-169（第 5 章），全连接 = 3 层线性 + 2 层 ReLU（[原文证据] PDF p.85–87、p.96–97）。
- 改变的关键假设：把"装配对准需要连续量控制"改成"**对准只需要方向**"——[分析推断] 这要求每一步的方向判断足够准，且步长由外部固定，因此精度上限由外部步长决定，而步长**未报告**，这是本篇最大的不可复现点。

## 5. 证据强度
- 训练环境：**仿真 + 真机双轨**（仿真 CoppeliaSim、真机 UR5e），两边各训 **14 000** 回合；作者称"实验训练奖励值曲线的收敛趋势与仿真训练基本一致"（[原文证据] PDF p.87、p.89）。
- 真机训练量：**14 000 回合**（[原文证据] PDF p.89）——这是本批最大的真机训练量，但**没有给墙钟时间、工件损耗、人工干预次数**。
- 测试规模：每种方法 **1000 次**装配测试（仿真 4 种方法 = 4000 次；真机同样 4 种方法 = 4000 次）（[原文证据] PDF p.88、p.89、p.103）。
- **真机成功率与试次（必答 4）**：**成功率未报告**。报的是"装配测试总时长（小时）"与"总体标准差"：
  - 仿真（[原文证据] PDF p.103 表 5.2）：单一感知 **38.46 h / σ 11.6926**；交替 **34.31 h / 8.2279**；联合 **32.15 h / 5.1998**；多视角 **30.41 h / 4.7815**；
  - 真机（[原文证据] PDF p.104 表 5.3）：单一感知 **40.29 h / 12.7381**；交替 **36.06 h / 11.9704**；联合 **33.53 h / 10.6771**；多视角 **31.66 h / 9.6229**。
  - → [分析推断] 38.46 h / 1000 次 = **138.5 s/次**（仿真）；40.29 h / 1000 次 = **145.0 s/次**（真机）。对一个 100 mm 长、0.4 mm 单侧间隙的轴来说，138 s/次意味着**极多的微小步**，但论文没有给每步的时长与步数，所以无法核对。
- 失败样本：**没有**。1000 次测试只汇总时长，**没有失败次数、没有剔除失败后重试的说明**（[分析推断]，依据 p.103–104 只给时长与标准差）。
- 基线公平性：作者声明"在测试过程中的所有装配方法均选择相同的抓取策略""使用相同的装配模块"（[原文证据] PDF p.75、p.65）——这一点做得好；但**四种方法的差异只在感知，不在动作空间**，所以它测的是"感知质量 → 用时"，不是"RL 策略优劣"。
- **内部口径冲突（3 条）**：
  1. **章标题"变步长"与正文"等步长"矛盾**：第 5 章标题与页眉均为"多视角**变步长**的智能装配策略"，正文唯一相关句是"采用**等步长**逐步接近装配孔中心"（PDF p.96），全文**没有任何变步长的动作集、幅值或切换逻辑**。
  2. **同一方法的仿真与真机用时差异未解释**：同一"单一感知法"仿真 38.46 h、真机 40.29 h（差 1.83 h，+4.8%），而"多视角"仿真 30.41 h、真机 31.66 h（差 1.25 h，+4.1%）——**趋势一致但绝对值不同**，作者未说明是同一批工件/同一天测试，也未给置信区间（PDF p.103–104）。
  3. **"1000 次测试 4 种方法"与"14000 次训练"的统计口径不衔接**：训练期的奖励曲线（图 4.15、5.16）与测试期的时长表之间没有任何失败率/丢弃样本的说明，无法判断 1000 次里是否有失败被计入时长（PDF p.89、p.104）。
- 结论：作为**真机训练量与测试规模**的证据很强（14 000 + 4 000 次），作为**成功率/安全证据为零**；作为**方法证据**偏弱（自监督模仿，动作幅度未给）。

## 6. 最脆弱的 1–3 个假设
1. **"对准只需要 3 个方向、幅度由外部固定步长决定"**（**方法必需**，作者明说输出是三个方向，PDF p.85）。分类：**范围内反例**——无倒角 + 0.4 mm 单侧间隙下，固定步长若大于间隙，方向对也会顶壁；本文没给步长，无法排除；我们 371 mm 深插会让固定步长的误差累积。
2. **"触觉（六维力）可以无条件当视觉的标签"**（作者明说，PDF p.87；**方法必需**）。分类：**范围外迁移限制**——标签本身有噪声（力传感器偏置、摩擦），标签错则视觉学错，且误差会自我强化；本文没做标签噪声实验。
3. **"用时可以替代成功率作为装配质量指标"**（**我的推断**，因为全文只报时长）。分类：**尚未测试**——如果失败样本被剔除，用时会系统性偏短；如果没有剔除，则时长里混入了失败重试。两种情况下"效率提升 21.4%"的解读都不同。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **"触觉做标签、视觉做预测"的自监督结构可搬到我们的门控/切换判据上**：本文用六维力判断接触状态、再给视觉打标签（PDF p.87）。**在我们这里怎么做**：用 KWR75 的 F_z/M_x/M_y 判"是否已进入倒角/是否开始承力"，给腕相机的图像打标签，训一个"图像 → 接触阶段"的分类器，用来做**视觉失效时的阶段切换**。**验收指标**：阶段分类准确率 ≥ 90%，且切换延迟 ≤ 2 个控制周期。
2. **"总装配时长 + 总体标准差"必须和成功率一起报**：本文只报时长（表 5.2/5.3），我们不重复这个错误。**在我们这里怎么做**：在 `archive_experiment.py` 的 summary 里同时写 success/fail、单次用时、力峰值、阶段数。**验收指标**：每次归档实验都能回答"成功几次/失败几次/失败原因"。
3. **多视角补遮挡的思路可部分借，但要换成"移位观测"**：它用主视角 + 辅助视角补视觉特征缺失（PDF p.102）。我们没有第二个固定相机，但有**站位表**。**在我们这里怎么做**：把"辅助视角"实现为"从站位表换一个已验证站位再拍一张"，用两张图的特征做一致性校验。**验收指标**：遮挡场景下（人为挡住 1/3 视场）目标位姿偏差 ≤ 2 mm。

## 8. 与本课题现有路线的冲突点
- **与"位置型导纳 + 残差 RL"的冲突**：本文**完全没有导纳/阻抗在装配回路里**——第 2.4.3 节的"基于触觉感知的柔顺控制"是**基于位置的阻抗（即在位置内环外做力的映射）**，但第 4、5 章的装配策略直接输出方向、绕过柔顺控制器（[原文证据] PDF p.50、p.85）。→ [分析推断] 它是"用学习替代柔顺"的路线，与我们"柔顺为主、学习为辅"相反；对我们有用的只是它的**感知侧**，不是控制侧。
- **与"关节速度上限 0.10 rad/s"的冲突**：它每次测试平均 138~145 s，说明步数极多、每步很小；我们每步都要走 `execute_assembly_chunks.py` 的重定时，**动作频率被压到很低**，无法复现这种"小步高频"的节奏。
- **与"1–2 mm 单侧间隙"的关系**：它 0.4 mm 单侧间隙更紧，但**无倒角**；我们 1–2 mm 更松但深 371 mm——它的经验不能直接换算。
- **与"必须报成功率"的验证纪律不冲突但需补**：本文的指标缺口正好是我们验收模板要避免的。
