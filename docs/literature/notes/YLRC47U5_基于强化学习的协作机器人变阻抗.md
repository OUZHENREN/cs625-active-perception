## 2. 一句话结论与相关性
- 一句话：在**球面恒力跟踪**任务上，用 PPO 让策略网络直接输出**阻抗参数**（质量 m、阻尼 d、刚度 k，或 K_d、D_d）或**目标跟踪半径 r**，把恒力跟踪的累积力误差 e_s 从定参数基线的 1.090e3（jsc）/2.208e3（osc）降到 650.934/597.887（[原文证据] PDF p.53 表 4-4、p.63 表 5-1）；但**结论明确写"未能在实体机器人系统部署"**（[原文证据] PDF p.68）。
- 相关性分类：**方法迁移**。理由：不是装配任务（是球面恒力跟踪），但它是本批 6 篇里唯一把"**RL 输出 = M/B/K 本身**"写成完整闭环的一篇，正好对应本章"导纳参数整定"的位置；且它给出 4 档具体参数值可直接当我们的初始参数网格。
- 影响本课题的具体决定：**柔顺参数**（主要）+ **验证方式**（力误差累积量 e_s、超调 σ 这类可量化指标，而不是只看力曲线好不好看）。

## 3. 对象与任务
- 机器人：**6 自由度协作机器人 JK5**，六伺服驱动器（位置环 + 速度环 + 用于力矩控制的电流环），末端装 **ATI mini45 六维力传感器**（[原文证据] PDF p.30）。**未报告**关节行程、负载、重复定位精度。
- 控制周期：**T = 0.002 s（500 Hz）**（[原文证据] PDF p.53）——这是"部署笛卡尔空间阻抗控制器"时的周期。
- 任务对象：一个**半球面**，末端沿球面做恒力跟踪；目标点个数 **N = 10 000**；期望跟踪半径 **r_s = 10 cm**（[原文证据] PDF p.52、p.58）。球的材质、刚度、曲率半径以外的几何参数**未报告**。
- 期望接触力 f_d：正文只在奖励函数里出现 f_d，**具体数值未定位**（表 4-4 的指标都以 f_d 为基准，但 f_d 本身没给数值）。
- 精度要求：以"接触时刻 t_c、累积误差 e_s、平均误差 e_a、超调 σ"四项衡量，**没有给通过/不通过的阈值**（[原文证据] PDF p.53）。
- 传感配置：ATI mini45 六维力（量程/分辨率**未报告**）+ 关节编码器；无视觉、无触觉阵列。

## 4. 方法与机制链
- 主链：`关节角 q、q̇（状态）→ MLP 策略 → 阻抗参数 (m,d,k) 或 (K_d,D_d) → 阻抗控制器 → 目标轨迹/位置修正 → JK5 关节力矩（或关节位置）→ 接触力 f_i → 奖励`（[原文证据] PDF p.58–59、p.62）。
- **RL 到底学什么（本批必答 1）**：**学的是阻抗参数 M/B/K，不是残差，不是离散动作**。两种动作设计二选一：
  1. 动作 = **目标跟踪半径 r**，1 维连续：`r = r_s/4·a + 3r_s/4`（笛卡尔阻抗 OSC）或 `r = r_s/2·a + r_s`（关节阻抗 JSC），a ∈ [−1,1]（[原文证据] PDF p.58 式 5-4）；
  2. 动作 = **阻抗参数 m, d, k**，3 维连续，按参考值指数缩放：`m = 10^{2a₁}·m_ref, d = 10^{2a₂}·d_ref, k = 10^{2a₃}·k_ref`，即 **0.01 倍 ~ 100 倍**参考值（[原文证据] PDF p.58 式 5-5）；
  3. 第二阶段（"先验经验"再训练）：动作 = **K_d、D_d 各 6 个对角元共 12 维**，`K_di = 10^{(a_i+5)/2}`、`D_di = 10^{(a_i+6+5)/2}`，**数值上强制落在 [100, 1000]**（[原文证据] PDF p.65 式 5-21）。
- **状态（必答 2）**：`s = [q, q̇]`，**12 维 = 6 关节角 + 6 关节角速度**；**状态里没有力/力矩、没有位姿误差、没有历史帧**（[原文证据] PDF p.58 式 5-6）。作者的理由是"末端的力又在机器人各关节有反馈，因此采用机器人的关节信息"（[原文证据] PDF p.58）——[分析推断] 这是把关节力矩反馈当成了力观测的代理，实际 JK5 的关节力矩由电流估计 + Stribeck 摩擦补偿得到（PDF p.37），不含末端六维力的方向信息，因此这是**部分可观测**设置。
- **奖励（必答 2）**：`r = −|f_i − f_d|`，周期累积 `R = −Σ|f_i − f_d| = −[(t_c−1)f_d + Σ_{i=t_c}^{N}|f_i−f_d|]`（[原文证据] PDF p.59 式 5-7/5-8）。第二部分训练改为 `r = −‖s − s_ref‖ − 0.1 = −‖q−q_ref‖ − ‖q̇−q̇_ref‖ − 0.1`，常数项用于约束回合长度（[原文证据] PDF p.66 式 5-22）。
- **安全约束/动作限幅（必答 2）**：网络输出 `a_i` 限幅到 **[−1, 1]**（tanh）（[原文证据] PDF p.58）；第二阶段 K_d、D_d 数值域强制 [100, 1000]（PDF p.65）；奖励里**没有**接触力上限惩罚项，全文**没有**力超限终止条件 → **无安全约束**，只有参数范围约束。
- **是否残差结构（必答 3）**：**不是输出空间残差**。RL 直接替换控制器的参数/期望轨迹半径，不在导纳输出上叠加 Δx。唯一"相对基准"的写法是式(5-5)的**乘性缩放**（相对 m_ref/d_ref/k_ref 的 0.01~100 倍）——[分析推断] 可理解为"参数空间的比例型残差"，但它作用于参数而非位移，**输出侧残差幅度（mm）未报告**（无从报告，因为不存在）。
- 训练：PPO-CLIP；MLP 隐藏层 **[32,32]**（半径动作用 [32,32,3]）；γ = 0.99、ε = 0.2；四组模型 = {动作: r / ipd} × {控制器: OSC / JSC}（[原文证据] PDF p.61–62）。
- 改变的关键假设：把"阻抗参数必须靠人手反复试凑"改成"**参数可由策略网络按状态在线给出**"，而且把参数搜索范围先验地压到参考值的两个数量级内（[分析推断]，依据式 5-5）。

## 5. 证据强度
- 训练环境：**MuJoCo（mujoco_py），JK5 的 URDF 转 MJCF，配 6 个 motor**（[原文证据] PDF p.37）；**四组模型全部只在仿真里训练与测试**。
- 样本量：**"与环境接触次数达到 200 万次后，四组模型都保持基本稳定"**（[原文证据] PDF p.62）。**训练时长（小时/GPU 型号/显存）未报告**。
- 真机成功率与试次（必答 4）：**未报告——因为没有真机 RL 实验**。结论原文："**未能在实体机器人系统部署的控制算法，有待在强化学习能够大规模应用于实际生产场景时实现**"（[原文证据] PDF p.68）。真机上只部署了**定参数**阻抗控制器（第 4 章），RL 部分没有上机。
- 量化结果（仿真，[原文证据] PDF p.63 表 5-1）：定参数基线（表 4-4，p.53）osc：t_c = 946、e_s = 2.208e3、e_a = 0.244、σ = 20.107%；jsc：t_c = 70、e_s = 1.090e3、e_a = 0.110、σ = 462.111%。RL 后：ipd_jsc **t_c = 1、e_s = 650.934、e_a = 0.0653、σ = 7.335%**；ipd_osc t_c = 915、e_s = 597.887、e_a = 0.0658、σ = 11.979%；r_jsc t_c = 21、e_s = 6.221e3（比基线**更差**）、e_a = 0.6234、σ = 6.560%；r_osc t_c = 910、e_s = 1.395e3、e_a = 0.1535、σ = 1.614%。**e_s 与 σ 的单位全文未给**（按 f_d 的量纲应为 N·步，**未定位**）。
- 优化模型（opt）：t_c = 717、e_s = **516.029**、e_a = 0.0556、**σ = 53.850%**（[原文证据] PDF p.66 表 5-2）——超调从 ipd_osc 的 11.979% **涨到 53.850%**，作者只写"超调 σ 有上升，但在接触力的安全范围内"（[原文证据] PDF p.66），**"安全范围"的数值阈值未报告**。
- 基线是否公平：**不完全公平**。四组 RL 模型与"demo"定参数基线对比时，基线的参数（表 4-3）是人工调的，而 RL 的动作空间又允许在参考值 0.01~100 倍内搜索（PDF p.58）——[分析推断] 上下各两个数量级的搜索域意味着 RL 有很大余地"碰"到好参数，而基线被固定在单点；这不能证明"学到了策略"，只能证明"搜索有收益"。
- **内部口径冲突（4 条，均可核对）**：
  1. **动作维数与"充分大"的自证矛盾**：作者说"动作空间范围都充分大，符合达到任务目标附近区域的要求"（PDF p.58），但 m/d/k 的名义参考值 osc 为 (10, 110, 12)、jsc 为 (0.05, 10, 3)（PDF p.53 表 4-3），乘 0.01~100 后 osc 刚度可到 1200、jsc 质量可到 5 kg 当量——[分析推断] 这个范围内阻抗控制本身已可能失稳，作者未给稳定性边界。
  2. **表 4-3 中 D_d 与 K_d 的注释口径不一致**：osc 行的 D_d 为 diag(300,300,300,**600,600,600**)，同表 K_d 全 100，但正文 p.52 说"期望阻尼矩阵 D_d 与刚度矩阵 K_d 采用对角矩阵形式，期望质量矩阵 M_d 采用式(4-31)"，而"m,d,k"三列的物理含义（对应 M_d 的哪个构造）**未说明**。
  3. **r_jsc 的 t_c = 21 与 e_s = 6.221e3 并存**：t_c 最小（21 步接触）却累积误差最大，说明"接触早"与"力跟得好"在这套指标下脱耦；作者自己的表 4-4 里也承认 jsc 的 σ = 462.111%（PDF p.53）这种异常值，但未解释就进入 RL 对比。
  4. **"先验经验"的用法在摘要与正文不一致**：摘要（PDF p.4）说"以跟踪过程中的**状态序列**作为先验经验"，正文式(5-21)前又说"仅采用状态序列作为先验经验"（PDF p.65），但奖励式(5-22)里同时用了 `s_ref` 的 q 与 q̇ —— 即**状态含速度**，与"状态序列"表述一致，但与摘要"仅半径/参数"的暗示不一致。

## 6. 最脆弱的 1–3 个假设
1. **"状态 = [q, q̇] 足以决定最优阻抗参数"**（作者明说，PDF p.58；**方法必需**）。分类：**范围内反例**——若 q、q̇ 相同而接触刚度不同（换工件/换夹具），同一状态会对应不同最优 k；本文没做这种换刚度实验，所以是未测反例而不是已证伪。
2. **"仿真中的 MuJoCo 接触模型能代表 JK5 的真实接触"**（作者明说用了 MuJoCo，PDF p.37；**方法必需**）。分类：**范围外迁移限制**——MuJoCo 的接触刚度/阻尼是参数化的软接触，而真实装配是刚性接触 + 摩擦；本文**没有 sim2real 环节**，因此这条假设**尚未测试**。
3. **"参数范围 0.01~100 倍参考值内不会破坏稳定性"**（**我的推断**，因为作者只给了范围没给稳定性证明）。分类：**尚未测试**——作者做了 Lyapunov 稳定性分析（第 4.4 节），但那是针对**固定**参数的串联控制器，不是针对参数在线跳变。

## 7. 可迁移到本课题的具体做法（1–3 条）
1. **"RL 输出导纳参数、但用参考值的对数缩放 + 硬边界"这一条直接抄**：我们的位置型导纳（ros2_control 只有 position 命令）可以照式(5-5) 把动作定义为 `B = 10^{2a}·B_ref`、`K = 10^{2a}·K_ref`，a ∈ [−1,1]，即 **0.01×~100×**；建议比本文更保守，先取 **[0.1×, 10×]**。**需要**：一组实测 B_ref、K_ref（可用我们现有的 tight-clearance 0.005 m/s 段做基准）。**验收指标**：同一插入深度（371 mm 分段）下，累积力误差 e_s 与超调 σ 相比定参数基线不劣化，且无一次力超限终止。
2. **用"接触时刻 t_c + 累积误差 e_s + 超调 σ"三件套做验收指标**（本文表 5-1/5-2 的四个量去掉 e_a）。**在我们这里怎么做**：在 1 kHz KWR75 数据上按阶段切分（371 mm 插入可分 4–6 段），每段算这三个量。**验收指标**：σ ≤ 20%（本文定参数基线 20.107%，取它当上限）。
3. **把"先验模型 → 再训练"的两段式改成"参数粗网格 → RL 微调"**：本文第 1 段训 4 个模型再挑最优（ipd_jsc）当先验（PDF p.65），成本是 200 万次接触。[分析推断] 我们没有仿真训练预算，可把第 1 段换成**在真机上做小网格实验**（参照 YLLSUC5R 的 180×N 次网格法），再让 RL 只在这个网格附近微调。

## 8. 与本课题现有路线的冲突点
- **与"位置型导纳 + position 命令接口"的冲突**：本文的 ipd_jsc 模型是**关节空间阻抗控制器**，输出**关节力矩**（PDF p.20–21、p.64）；我们的 CS625 ros2_control **没有 torque 命令接口**，只有 position。→ **jsc 那一半结论（ipd_jsc 指标最优）在我们平台上不可复现**，只能取 ipd_osc（笛卡尔阻抗，最终仍要转成位置）那一半。
- **与"关节速度上限 0.10 rad/s"的冲突**：本文控制周期 0.002 s 且允许阻抗控制器直接改关节力矩，加速度不受限；我们的执行器在 `MAX_JOINT_SPEED_RAD_S = 0.10 rad/s` 下重定时（见 `scripts/execute_assembly_chunks.py`），**参数级高频抖动会被重定时抹平**，等于削弱了 RL 输出的时间分辨率。→ [分析推断] 我们只能把动作定义为**每段（而非每步）一组参数**，而不是每 2 ms 一组。
- **与"六维力柔顺"路线不冲突**：本文就是六维力 + 阻抗，方向一致；但它**把力排除在状态之外**，与我们"KWR75 1 kHz 力必须进状态"的直觉相反，见 §6 第 1 条。
