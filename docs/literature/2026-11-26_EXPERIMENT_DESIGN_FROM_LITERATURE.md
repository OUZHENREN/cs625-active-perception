## 0. 先说结论：为什么之前的 A1/A2/A3 显得"不像机械"

我原来设计的是 **三臂视觉对比**（固定 0° / 固定 +11° / 选站 → 精度–偏转角曲线）。
它在**视觉算法**层面是对的，但它回答的是"哪个观测位更好"，属于感知/算法评价；
而库里这条线（重庆大学光机装校系列）的学科语言是：

```text
误差源建模 → 敏感误差识别 → 精度（公差）分配 → 不确定度传播/蒙特卡洛可靠度
→ 刚度与柔顺/接触力学 → 力—位姿映射 → 阻抗/导纳控制 → 装配成功率与可靠度
```

所以正确的改法不是"把对比做得更复杂"，而是**换主线**：
视觉对比降级为"误差源之一"，主线变成**误差链与装配成功率的定量关系**。

## 2. 建议的实验主线：五个模块（按"能不能马上做"排序）

### M1 误差链建模与精度分配（**离线可做，不占真机**）

```text
问题：视觉位姿误差 → 插入端偏差 → 与槽内单侧间隙（1–2 mm）的相容性。
方法：① 建立误差传播链：测量误差(σx,σθ) → 工具坐标变换 → 插入端横向偏差
      ② 插入深度 371 mm 是杠杆臂：Δx ≈ d·Δθ（0.1° 在 371 mm 处 = 0.65 mm；1° = 6.5 mm）
      ③ GUM 不确定度传播 + 蒙特卡洛（1e5 抽样）→ 插入成功率 P_success(σθ)
      ④ 反推"为保证 P_success ≥ 95% 所需的姿态精度指标"，与实测 0.078° 比较
产出：误差传播曲线、成功率–精度曲线、**公差分配表**（哪一环必须收紧）
文献依据：130（误差源/精度分配/蒙特卡洛可靠度）、543（位姿误差建模）
机械属性：公差分析、误差敏感度、可靠度 —— 这是最"机械"的一块，而且不需要真机。
```

### M2 杠杆臂敏感度实验（**真机，无需六维力**）

```text
问题：姿态误差随插入深度放大多少？理论 Δx = d·Δθ 是否成立？
方法：固定观测位，在插入链上取 4 个深度（0 / 100 / 200 / 371 mm），
      每个深度测末端横向偏差 5 次 → 拟合 Δx–d 斜率，与理论 θ 比较。
产出：Δx–d 直线（斜率=姿态误差），验证"深度放大姿态误差"这一设计约束
文献依据：90、543（误差传递）
机械属性：把"测量精度"翻译成"装配可行域"，审稿人一看就懂。
```

### M3 测量系统重复性–再现性（R&R）（**真机，可分批**）

```text
问题：视觉测量系统本身有没有能力支撑 2 mm 级装配？（工业化评价）
方法：同一姿态重复 10 次（重复性）+ 3 个观测位各 5 次（再现性）
      方差分解 → %GRR = σ_GRR / σ_tolerance（tolerance 取槽内间隙 2 mm）、NDC
产出：R&R 表 + 判定（%GRR<10% 优秀 / <30% 可接受）
文献依据：130（精度分配）、543
机械属性：标准计量方法，答辩时最容易被认可为"工程规范"。
```

### M4 六维力接触状态识别与柔顺接管（**传感器到位后**）

```text
问题：视觉不可用/遮挡时，力觉能否接管完成最后一段插入？
方法：① 重力补偿 + 零漂标定；② 分阶段力特征（接近→首次接触→座合→过冲）
      ③ 接触状态机；④ 视觉单独 vs 视觉+力觉 的成功率与力峰值对比
产出：力–位姿曲线、接触状态机、成功率对比
文献依据：668（接触阶段划分/重力补偿）、683、176
前置条件：**法兰加工 + 传感器安装后**（当前阻塞）。
```

### M5 装配可靠度与失败模式（**离线统计，用现有归档**）

```text
问题：单次装配的期望失败率与主要失败类型是什么？
方法：用历史归档（phases.json + measurement JSON）做失败模式分类与帕累托，
      按 130 的蒙特卡洛运动可靠度思路估计 P_fail
产出：失败帕累托图、单次装配期望失败率、可靠度随精度的变化
文献依据：130
注意：自动重测已上线（手册第 60 条），必须记录**尝试次数**，否则成功率虚高。
```

## 3. 原来的 A1/A2/A3 怎么处理

降级为 **M1/M2/M3 的输入支撑**，不单独做主线：

```text
A1/A2/A3（固定 0° / 固定 +11° / 选站）× 偏转角
  → 作为"姿态误差 σθ 随观测位变化"的实测来源
  → 喂给 M1 的误差传播模型中 σθ 的取值
  → 也就是：先有"选站能降低测量误差"，再有"降低的误差能否满足 2 mm 间隙"
这样三臂对比就从"孤立对比"变成"误差链的第一环"，学科属性自然成立。
```

