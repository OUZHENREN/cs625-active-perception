# 论文精读笔记模板（依据所有者 2026-09-19《精密光学模块_论文阅读提示词_v2》压缩）

> 每篇论文一个文件：`docs/literature/notes/<Zotero itemKey>_<短标题>.md`
> 证据规则（必须遵守）：内容分 **[原文证据] / [分析推断] / [待验证设想]** 三类；
> 原文证据尽量给页码（`p.23`）或章节/图表号；**无法定位就写"未定位"，绝不编造数字**；
> 数字必须带单位与条件；没读全文就写"仅摘要/目录"，不得假装读过正文。

## 1. 元数据
Zotero itemKey / 标题 / 类型（硕/博/期刊/会议）/ 年份 / 单位 / PDF 页数

## 2. 一句话结论与相关性
- 一句话：做了什么、结果如何
- 相关性分类（四选一）：**直接对象证据 / 方法迁移 / 工程工具 / 暂不相关**，并说明理由
- 影响本课题的哪一个具体决定（末端接口 / 定位要求 / 观测动作 / 接触切换 / 柔顺参数 / 误差预算 / 验证方式）

## 3. 对象与任务
装配/抓取对象、尺寸、质量、间隙/公差、精度要求、环境（洁净度/空间）、传感配置。
凡有数字必须带单位与条件（[原文证据] p.X）。

## 4. 方法与机制链
`输入 → 关键机制 → 输出 → 任务收益`；说明它改变了哪个关键假设/约束。
机械结构类讲清受力/运动/接触/误差；控制类讲清状态/输入/反馈/稳定条件；
视觉类讲清观测量/不确定性/任务决策。

## 5. 证据强度
基线是否公平、试验次数、失败样本、扰动范围、统计口径（均值是否掩盖失败）、真机 vs 仿真。

## 6. 最脆弱的 1–3 个假设
每个假设标注：作者明说 / 方法必需 / 我的推断；并分类为
**范围内反例 / 范围外迁移限制 / 尚未测试**（三者不可混称"漏洞"）。

## 7. 可迁移到本课题的具体做法（1–3 条）
必须可落地：写清"在我们这里怎么做、需要什么、验收指标是什么"。

## 8. 与本课题现有路线的冲突点
例如与"站位表选站""三平面+CAD ICP""误差链/公差分配""六维力柔顺"是否矛盾，矛盾在哪。

## 9. 待确认
原文没写、但本课题需要知道的参数或条件。
