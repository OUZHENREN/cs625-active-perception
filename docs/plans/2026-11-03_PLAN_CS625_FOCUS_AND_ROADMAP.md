## 3. 三条工作流

### 流 A：纯视觉插入（当前主线）

```text
目标：空夹爪观测 → 抓取 → 依视觉位姿直接插入，插槽入口横向误差 ≤ 3 mm
验收：3 种位姿偏差工况（0 / ±2 mm / ±5°）各 3 次，成功率 ≥ 2/3
```

关键认知（2026-11-03 实测，见 §6.1）：**RVS 的粗匹配输出会被夹爪里的工件污染**，
今天在同一固定插槽上把 T0 输出带偏了 39 mm，进而把精匹配 R1 带偏 50 mm。
所以"观测必须在空夹爪下完成"是流 A 的第一条硬规则。

```text
A-1  RVS 侧修复：验证"空夹爪观测"假设，恢复 T0/T1 输出到教学参照附近
A-2  流程固化：观测段与抓取段严格分离，任何中途重观测必须确认夹爪为空
A-3  插入：先用实时 R1，配合力矩余量监督（contact 0.68 / safety 1.63）
A-4  若 A-3 在 ±2 mm 工况下成功率 < 1/3 → 转 A-5
A-5  视觉精测量替代 RVS 精匹配：自研 GICP/RANSAC 三平面（模块 2 的算法提前落地）
```

### 流 B：六维力插入（模块 1 前身，先做仿真）

```text
目标：无真实传感器时，用关节 effort 建立"接触→柔顺"的行为基线
验收：同一插入任务在"位置控制 / 固定导纳 / 自适应"三种策略下各 5 次，
      记录 成功率、effort 峰值、耗时、卡滞次数（对应总规划 §5.2 的 MVP）
```

```text
B-1  仿真六维力平台：Gazebo 侧给末端加力传感接口 + 导纳控制节点（PyBullet 或 gz）
B-2  实机代理信号：关节 effort（余量制）→ 接触判据，已在 compliant_insert 落地
B-3  真实传感器到位后替换信号源，控制律不变（这是本流的价值：提前把控制律跑通）
```

### 流 C：主动视觉与位姿精测量（模块 2）

```text
目标：把抓取精度从 RVS 的"十几毫米"提升到 ≤2 mm
验收：同一工件 10 次测量，重复性 σ ≤ 1 mm；与三坐标/已知位姿比对误差 ≤ 2 mm
```

```text
C-1  交叉偏振成像 + 点云质量指标（对应总规划 §3.1/§3.4）
C-2  RANSAC 三平面正交约束封闭解（粗，2–5 mm）
C-3  GICP 精配准 + 角点消歧（精，≤1 mm）
C-4  多帧融合与 NBV 视角选择（1/3/5/10 帧对比）
```

## 4. 依赖与顺序

```text
流 A（RVS 修复 + 纯视觉插入）
   └─ 产出一个"可用的视觉插入基线"
        ├─ 流 B 用它做三策略对比的载体（无基线就没有对比）
        └─ 流 C 用它做精度提升的落点（新算法要替换掉 RVS 精匹配）
```

**结论：流 A 必须先跑通一个"能插进去"的版本，B 和 C 才有实验载体。**

## 6. 关键教训（写进策略，不写进日志的部分）

### 6.1 插槽位姿必须用"新鲜 R1"，且 RVS 的 R1 有跨会话漂移（2026-11-03 修订）

```text
【曾被误判】"工件遮挡导致粗匹配漂移 39 mm"──已被实验推翻：
  空夹爪 T0 = (1.0805, 0.0143, 0.6139)
  持件  T0 = (1.0785, 0.0101, 0.6172)      两者只差 4 mm，遮挡不成立。

【真实数据】同一固定插槽，R1（插槽位姿）的 y 值跨会话大幅漂移：
  师兄 6 月工程:  154.5 / 159.6 / 175.5 mm
  2026-10-30   :  192.7 / 196.0 mm
  2026-11-03   :  148.3 mm（空爪、教学 S0 站位、三帧 8.8 mm）

【判据】2026-11-03 的碰撞证据站在 148.3 这一边：
  用 10-30 的旧 R1 推出的插入 y = -0.0094；
  用今天 R1 推出的插入 y = -0.0447；  两者差 35 mm
  所有者现场观察"往左偏 3–5 cm"，与 35 mm 定量吻合
  → 今天那次碰撞是【用了 74 小时前的旧 R1】造成的，不是 RVS 坏了

【结论 / 规则】
  1. 插槽位姿只认【新鲜 R1】（≤6 h），永不复用旧值；师兄的模式（实时 R1）是对的。
  2. 我 16:24 把插入链改成了"机械标定值"，那是错的，已回退。
  3. R1 的跨会话漂移是 RVS 精匹配的固有局限（几十毫米），所以：
     插入必须配力矩余量监督（contact 0.68 / safety 1.63）作为兜底，
     这也是"纯视觉插入 + 力觉兜底"这条路线在论文里的正当性所在。
```

### 6.2 力矩阈值必须是"基线 + 余量"

```text
空载基线 16.00 → 携件 19.7（不同姿态还不同）。绝对值阈值必然误触发。
现行：contact = 基线 + 0.68，safety = 基线 + 1.63（所有者确认值的余量化）
```

### 6.3 保护停止后禁止自动重试

```text
2026-11-03 三次碰撞的机制：保护停止 → 反控掉线 → 自动 resend → 重试 → 再撞。
现行：停止后 60 s 内禁止自动恢复；力矩接口死亡（peak<1）时执行器直接拒绝运动。
```
