# 插入流程设计（2026-11-26，所有者要求"把插入流程考虑清楚"）

> 本文回答三个问题：
> ① 为什么纯位置/纯视觉的长行程插入做不成；
> ② 师兄的虚拟机程序为什么能做（以及我们的链路和他的差别在哪）；
> ③ 我们的插入流程应该怎么设计——每一段的输入、动作、判据、失败处置。

## 0. 先纠正一个错误判断（重要）

我在 20:50 说过"师兄的工装/工件/间隙与我们不是同一套"——**这是错的**。
所有者确认：**工装、工件、夹具几乎完全一致，没有变化**。

这条更正的意义：师兄的纯视觉插入结果**可以直接作为对照证据**，不是"另一个问题"。
我们做不成，必须解释成**流程/链路差异**，而不能用"硬件不同"糊过去。

## 1. 已知事实（全部有出处）

```text
几何：
  · 插入深度 444 mm（pre_insert → insert，实测 Δz=444.6 mm；11-04 记录 "depth_below_fixture 371 mm"
    是保护停机位置，不是物理底）
  · Y 方向两侧间隙各约 2 mm（所有者口述，手册第 23 条③）
  · X 方向约束来自四处：插槽滑轮、工件滑轮、楔形槽（倾角 5.004°/12.62°）、底部安装槽侧面
  · 0.5° 角度误差在 444 mm 处 = 3.9 mm 端部位移 > 2 mm 间隙 → 纯位置直插必然失败

今天的失败（2026-11-26）：
  · 两次手摆插入位（19:45 / 20:12），数值差仅 2–3 mm；两者都**只能转正、插不到底**
  · 19:45 版在尝试记录"取出时外边缘与滚轮/楔形窄区首次接触点"时，肘部堵转过载、
    机械臂重启、J4 掉落 41.4°（手册第 72 条）

链路查证（关键）：
  · scripts/run_pick_and_place.py:2420  SLOT_REFERENCE = runtime/slot_reference_verified.json
  · reference_insert_chain() 从这份 **2026-11-04 的静态参考**推导 pre_insert/insert/straighten
  · 每次运行新测的 runtime/measurements/slot_latest.json **只被 check_slot_reference.py
    当闸门比对，不参与插入链推导**
  → 插入路径是一条"算死的直线"，新测量只用来报警，不修正路径。
```

## 2. 师兄为什么能做成（源码已核对）

```text
tcp_server.py:272-305
  · slot_insert_tcp   = world_slot_pose × T_s_tcp          ← 用**当次 RVS 测到的** slot 位姿
  · pre_insert_rotated = insert 原地 Ry(−10°)               ← 只转姿态
  · pre_insert_tcp    = rotated 沿自身 z 轴 −350 mm          ← 纯轴向
```

**差别不在几何，在"输入从哪来"**：他的 `world_slot_pose` 来自**当次 RVS 测量**，
我们的插入链来自**22 天前的静态参考**。同一套工装，他的路径随每次测量更新，我们的不更新。

还有一个可直接检验的差别：他的链只有 3 个点，中间没有分段复测——
说明他的 RVS 位姿精度足以让 350 mm 直插一次通过。我们现在的插入位姿来源是
"手摆两次都插不到底"，等价于承认**我们当前没有可靠的 slot 位姿来源**。

## 3. 插入流程设计（分 5 段，每段有判据与失败处置）

```text
S1 测量与推导（视觉，闭环起点）
   输入：本轮 slot 测量（slot_latest，覆盖率 ≥0.95、重复性 ≤1 mm/0.1°）
   动作：**用当次测量**推导 pre_insert / insert / straighten（不再用静态参考）
   判据：与上一轮参考的偏差 > 阈值 → 判"工装/桌子动过"，要求重新示教或重测
   失败处置：拒绝插入，不带着偏差往下走
   ⚠ 这需要改一处代码：reference_insert_chain() 接受当次测量作为输入（见 §5）

S2 接近（视觉 + 间隙闸）
   动作：从停车位/粗观测位 → pre_insert（倾斜 −10°），笛卡尔直线 + 点云间隙闸
   判据：到位误差 ≤1 mm/0.2°；点云间隙不报警

S3 入口段（视觉主导，前 50–80 mm）
   动作：沿倾斜轴下降，**每 50 mm 停一次**，用残余视觉（槽口仍可见）复核横向/角度
   判据：横向偏差 ≤0.5 mm、角度 ≤0.2°；`F_y` 左右对称（手册 23③）
   失败处置：超差 → 回退 20 mm 重测，不回退到起点（避免反复摩擦）
   为什么只用前 50–80 mm：再深槽口被工件自身遮挡，视觉失效（这是 4 章误差链的结论）

S4 深插段（力觉主导，剩余 ~360 mm）**← 论文第 5 章主体**
   动作：**边转边插**（手册 23④）：绕工具 Y 轴逐步减小摆角（末段保留 1.5°，手册 23②）
         位置型导纳闭环，M/K 冻结、只调阻尼 B（变阻尼 RL）
   判据（每条对应工艺经验）：
     · `|F_y|` ≤ 间隙耗尽阈值（左右各 2 mm，需先标定接触刚度）
     · `F_z` 不呈指数增长（直插的特征；边转边插应平台化）
     · `|M_x|` 与左右余量差相关（手册 23⑤）
   失败处置：`F_z` 超阈值 → 停、回退 5 mm、加大摆角重试（最多 N 次）
   到底判据：`F_z` 达到底反力 + 深度到位（双条件，避免误判）

S5 槽内转正与释放
   动作：`straighten`（位置不变，绕工具 Y 轴转平 +9.81°）
   判据：`|M_x|` 峰值（手册 23⑤：左右不平衡会让阻力大很多）
   失败处置：`M_x` 超阈值 → 先执行 23⑥ 的"Y 向横移 ±2 mm 放大间隙"再转
```

## 4. 三个实验臂（对应纲要 5.6）

```text
A 纯视觉/纯位置（基线，也是第五章"纯视觉实验"）
   · A1 师兄代码 + 师兄 RVS 数据（复现，作为"能做到"的上界）
   · A2 我们的链路（静态参考 + 一次直线插入）→ 预期失败，记录失败模式
   · 待补：向师兄索取他的纯视觉数据（slot 位姿时间序列、插入轨迹、成功/失败记录）

B 视觉 + 定参数导纳（S3+S4 分段，固定摆角策略）

C 视觉 + 变阻尼 RL（S4 的 B_t 由策略输出）

对照指标：成功率、`F_z` 峰值、`|F_y|` 最大、到底深度、分段用时、失败归因（按手册 23 ①–⑥）
```

## 5. 需要改的代码（一处，可离线验证）

```text
reference_insert_chain() 改为接受"当次插槽测量"作为输入：
  · 新增参数 slot_measurement（默认读 slot_latest.json）
  · 若测量不存在或质量不达标 → 回落静态参考并**打印警告**（保持可运行）
  · 与静态参考偏差 > 阈值（建议 10 mm/2°，与 check_slot_reference 同口径）→ 拒绝并说明
验收：单元测试覆盖"用新测量推导"与"偏差过大拒绝"两条路径。
```

## 6. 明确不做

```text
· 不把"逐点录制 400 mm 行程"当主线（只作 A 臂上界证据）
· 不在没有接触刚度标定的情况下设定力阈值
· 不在 slot 位姿来源不可靠时继续长行程插入
```
