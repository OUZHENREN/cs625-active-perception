# 计划：把"前验位姿观测"压到 2 分钟内

> 所有者 2026-11-12 明确的目标。本文件是长期计划，不依赖对话上下文。

## 1. 目标与定义

```text
目标：一次"前验位姿观测"（工件粗观测 + NBV 换位 + 工件精观测 + 插槽粗观测）
      端到端 ≤ 120 s，并且精观测结果满足 1.0 mm / 0.5° 的质量门。
约束：插入间隙每侧 2 mm，所以最终位姿精度不能靠"放宽门"换时间。
```

## 2. 当前实测耗时（2026-11-12，真机）

| 环节 | 现状 | 说明 |
|---|---|---|
| 每个观测位移动 | 8–15 s | 关节空间规划 + 执行（已加动程护栏） |
| 到位后稳定等待 | **10 s** | 机械臂惯性大，所有者要求 |
| 一次 measure_object（3 组） | **~55–75 s** | 采集 3 组 × 3 帧 + 每组 16–20 次 ICP |
| 一次 measure_object（4 组） | ~75–95 s | 精观测常用 |
| NBV 换视角（推算+移动） | ~30 s | 含规划与执行 |

```text
⇒ 现状：粗观测 ~75 s + NBV ~30 s + 精观测 ~95 s ≈ 200 s，明显超预算。
```

## 3. 优化优先级（按收益/风险排序）

```text
P0 降低单组分析成本（最大头，收益 30–45 s）
   · 多起点候选 16 → 6（三平面路径只保留"覆盖率前 4 + 扶手最优 2"）；
   · 点云在配准阶段降采样到 8 mm，只对最终解做 2 mm 精修；
   · 平面分割只在 40k 随机子集上做，指派后在全体点上精修。

P1 减少采集组数（收益 15–25 s）
   · 粗观测 2 组（已放宽到"可信 ≥2"）；
   · 稳定等待 10 s → 6 s（先测 3 次到位抖动再定）；
   · 采集帧数 3 → 2（中位数仍可用，噪声主要来自深度）。

P2 并行化（收益 20–30 s）
   · 采集与上一组分析流水线并行（现在是一组采完再采下一组）；
   · 多组分析用进程池（4 核以上可用）。

P3 省掉不必要的移动（收益 10–20 s）
   · 粗观测与精观测若同一视角皆可用，跳过 NBV 换位；
   · 插槽粗观测与工件精观测合并到同一次移动（同一观察位能同时看到两者时）。
```

## 4. 里程碑与验收

```text
M1（基线）：记录一次完整前验观测的分段耗时（当前 ~200 s）。
M2（P0）：单组分析 ≤10 s，前验观测 ≤150 s。
M3（P1+P2）：前验观测 ≤120 s，且精观测仍满足 1.0 mm / 0.5°。
M4：连续 3 次跑进 120 s 且质量门全部通过，写入工作日志作为验收证据。
```
