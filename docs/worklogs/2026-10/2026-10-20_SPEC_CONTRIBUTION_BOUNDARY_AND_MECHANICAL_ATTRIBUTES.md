# 一页纸：本文与杨非凡师兄工作的边界，以及机械属性落在哪

> **一句话结论**：师兄解决的是"**看得准、走得对、放得进**"的半自动拆装系统；本文解决的是"**遮挡下看哪里、什么时候重看、看了之后抓不抓得到、插不插得进**"的自主决策问题。**系统平台复用师兄与厂商底座并明确引用；方法与验证是本文的。**

> **用途**：下次与白老师讨论时先给这一页，再展开技术路线。题目、章节、边界三件事请老师先定调。

## 2. 复用 / 引用 / 新增清单（写作时必须落到这三栏）

**A. 复用并引用（不写成创新）**
- 系统总体架构、统一机器人描述/控制/规划接口、多构型 IK 处理、任务位姿生成；
- 环境点云处理与碰撞对象生成、工件场景表达与状态同步、任务状态机；
- RVS 视觉引导与粗/精定位流程；接触阶段监测（tau 指标）；
- CS625 驱动、模型、MoveIt 配置、仿真底座。

**B. 本文新增（创新点，三条）**
1. **遮挡条件下的可达性约束观测—抓取一体化规划**：候选视点必须通过 IK 多解/关节限位/自碰撞/环境碰撞/规划可达过滤；评分融合可见性、运动代价、关节裕度、抓取衔接代价；给出触发与停止准则。
2. **自动决策闭环**：用质量门禁 + 可达性 + 接触/卡滞 + 有界重试替代人工确认，所有失败有明确失败码。
3. **任务级可靠性与接触耦合实验**：遮挡分级 + 配对统计；并分析"观测位姿误差 → 抓取/插入接触失败"的传递关系。

**C. 明确不主张**
- 不主张 RVS 的视觉定位算法；不主张师兄的拆装系统架构；不主张师兄的接触监测实现本身；
- 不使用"首次研究遮挡"这类表述（师兄已在展望中指出遮挡不足），改为"针对该不足给出可量化的观测决策方法"。
