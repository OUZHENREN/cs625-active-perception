## 三、今天三次危险事件的根因与修复

### 事件 1：接近插槽时差点碰撞（急停）

- 原因：附着工件用简化碰撞网格（无扶手），实际外廓更大，余量不足。
- 修复：改用师兄 `collision_object_publisher` 的 attach + touch_links；接近插槽前加“外侧安全接近点”。

### 事件 2：释放后在插槽内直接旋转（急停）

- 原因：把“退出”和“回基准位”混在一次规划里，轨迹含旋转。
- 修复：释放后必须“初始化手指 → 纯平移沿插入轴离开 ≥150 mm → 才允许旋转/平移”。

### 事件 3：抽出时来回抽搐（两次急停）

- 第一层原因：分段失败后**重放旧轨迹**，旧轨迹首点在当前位置内侧 → 先跳回再前进。
- 更深层原因：规划请求里显式填了 `start_state = 本进程缓存的 /joint_states`，
  执行期间进程不 spin，状态落后约一步（~10 mm），规划以落后位置为起点 → 控制器先“拉回”再走。
- 修复（三层）：
  1. 规划请求**不再填 start_state**，让 MoveIt 用自己 125 Hz 的实时状态；
  2. 执行器新增 `--max-start-offset`（默认 0.03 rad），首点偏差超限直接拒绝；
  3. 抽出循环加**进展检查**：单步位移不足 50% 立即停止。

## 四、其他重要经验

### 夹爪

```text
- init 约 10 s，必须等 init==5 才能发下一条命令，否则会停在初始化中途
- 这类“向外撑开”电爪没有自锁，保持夹力必须持续通电 → 夹持时有电流声，正常
- 归零有偏移，显示开度不等于真实开度
- 寄存器 70 的电流反馈不可信（读数乱跳），以电源面板电流为受力依据
- 所有者经验：50 mm 已完全顶住；52 mm 之后电源稳定 ~1 A（硬顶）
- 配置已统一为 grip_width_mm 50.0 + grip_current 0.1
- 初始化改为条件式：init==5 就跳过，避免每次重跑都校准
```

### 碰撞建模（试过五条路，结论明确）

```text
1. attach + touch_links（师兄做法）      → 可用，但位姿查询显示 identity（实际有效）
2. 手工下发 ACM                          → 会破坏 SRDF 默认豁免，不可用
3. 世界系实心 mesh 跟随 TCP              → 位姿对，但与腕部自碰撞
4. 点云体素模型                           → 几何真实，仍可能自碰撞
5. 体素 + 挖空夹爪通道                    → 规划能过，但模型失真，禁止使用
正解：用师兄的 attach 节点，配合插入段移除插槽碰撞体
```

### 控制恢复

```text
goal_time 中止后控制器会失效，表现为“命令接受但不动”或 TIMEOUT
恢复：bash scripts/recover_control.sh（resend → deactivate → activate → slider 1.0）
编排脚本每个阶段前自动过健康门，不要干等或反复重试
```
