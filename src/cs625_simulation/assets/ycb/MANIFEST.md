## 溯源与边界

- 官方原始模型页：<https://ycb-benchmarks.s3.amazonaws.com/index.html>；三份归档 URL 写入本项目的工作日志，不使用来历不明的重分发网格。
- BOP 使用毫米模型坐标、将 YCB-V 物体模型的包围盒中心对齐到原点。上述 `YCBV/BOP 对象 ID` 仅用于指标和结果文件的跨基准映射；当前运行时视觉/物理模型仍是 YCB 原始米制网格。
- 当前未把 500 MB 级完整 `ycbv_models.zip` 写入 Git 工作树。正式声称“BOP 模型完全版本化”前，必须额外保存 BOP archive revision、`models_info.json` 的 SHA-256 以及三对象对应的 BOP PLY 文件；本清单不得替代该验收。
- 该资产引入不改变既有 P4 `minimum_showcase_20260821_run6` 或正在运行的 Jazzy 扩展矩阵；它们仍使用各自固定的静态场景定义。
